# 十只红利指数大比拼：十年收益冠军，为什么仍不能直接抄作业？

> 对比对象：中证沪港深红利成长低波动、中证全指红利质量、中证红利质量、中证红利低波动、标普中国A股红利机会、中证红利低波动100、中证红利、上证红利、标普中国A股大盘红利低波50、深证红利。  
> 收益区间：2016-06-30至2026-07-31；前九只统一使用人民币全收益指数。国证官网没有提供可核实的深证红利全收益序列，因此深证红利用工银深证红利ETF（159905）的复权单位净值估算，数据已扣除基金费用，不能与官方全收益指数完全等量齐观。  
> 本文只评价指数规则和历史表现，不讨论当前估值、买入时机与具体ETF，不构成投资建议。

## 一、先说结论：不选唯一冠军，只分梯队

过去约十年，收益最高的是**中证全指红利质量**：累计上涨290.52%，精确年化收益14.47%。但红利指数不是百米赛跑，只看谁先撞线，会漏掉三个问题：这段成绩有多少来自发布前回溯，回撤时能否拿得住，组合有没有把筹码压在少数行业或公司上。

综合评分中，中证全指红利质量、中证沪港深红利成长低波动、中证红利质量、中证红利低波动100和中证红利低波动进入领先组。它们没有谁能通吃全部目标：中证全指红利质量赢在收益与质量约束，却缺少完整发布后周期；沪港深方案低波和个股分散更好，金融权重却达到44.08%；中证红利质量财务排雷最细，发布后收益又明显弱于回溯。

本文用五个维度评分：**规则稳健性30%、历史风险收益25%、表现稳定性15%、结构分散15%、证据可信度15%**。低波不是所有指数的必答题，质量指数不会因为没有低波筛选先丢6分；发布前回溯只在证据可信度中折价，不会在历史收益和稳定性里反复扣分。完整评分见第八部分。

十只指数可以先分成四类：

| 类型 | 包含指数 | 核心特点 |
|---|---|---|
| 红利成长低波 | 中证沪港深红利成长低波动 | 同时筛选连续分红、盈利成长和低波动，并覆盖内地与香港市场 |
| 红利质量 | 中证全指红利质量、中证红利质量、标普中国A股红利机会 | 重点检查盈利、现金流、支付率、ROE和再融资质量 |
| 红利低波 | 中证红利低波动、中证红利低波动100、标普中国A股大盘红利低波50 | 在高股息基础上筛选或加权低波动股票 |
| 经典红利 | 中证红利、上证红利、深证红利 | 主要依据分红历史、股息率、规模和流动性选股 |

四类策略解决的问题不同。评价它们更像给十项运动选手打分：不能因为游泳重要，就要求短跑选手先下水。下面先看每只指数想解决什么，再判断它有没有把这件事做好。

一句话概括：**质量因子提高了收益上限，低波因子改善持有体验，结构上限防止组合押得太重。综合分只能帮助比较，不能把不同目标压成一个绝对冠军。**

## 二、比较红利指数，先避开三个误区

红利指数的全收益来自：

> 股价变化 + 现金分红再投资

公司分红后股价会除息，分红不是白捡的钱。只比较价格指数，会系统性低估红利策略；只看静态股息率，又容易把股价下跌、一次性分红和周期顶部误认为“便宜”。

真正需要回答的是：

1. **分红能否持续**：利润、现金流、支付率和再融资行为能不能支撑分红。
2. **高股息是不是陷阱**：高股息来自稳定盈利，还是股价暴跌、利润周期高点或异常分红。
3. **组合是否过度集中**：40只或100只股票不等于分散，权重仍可能集中在少数公司或行业。

还要区分三个容易混淆的概念：

- **红利质量不等于低波。**质量指数主要筛盈利和现金流，股价照样可能大幅波动。
- **低波不等于不会跌。**低波只能压低相对波动，不能消除系统性下跌。
- **基日不等于发布日期。**基日只决定点位从哪里算起；发布日期之前的历史通常是回溯试算。

## 三、十只指数的规则，到底在筛什么

### 1. 中证沪港深红利成长低波动：把分红成长和低波装进同一套规则

**选股链条：**

内地中证全指样本空间与香港中证港股通综合指数 → 内地剔除成交额后20%、香港要求日均成交额不少于3000万港元 → 连续三年现金分红 → 剔除“三年净利润变化为负且PE为负”的证券 → 按预期股息率保留前60% → 按ROE增速波动率和最近四季度ROE增速保留前60% → 选过去一年波动率最低的100只 → 按预期股息率加权。

预期股息率并不是分析师预测值，而是用过去三年平均支付率、最近四季度ROE增速和PE（TTM）计算。若同一家公司A股和H股同时入选，优先保留预期股息率更高的一只。

- **优点：**连续分红、盈利成长、ROE增长稳定性和价格低波层层筛选；100只样本横跨内地与香港；单股不超过10%。
- **缺点：**盈利过滤是联合条件，并不等于所有利润下滑公司都会被剔除；预期股息率公式受短期ROE增速和PE影响；没有行业或市场上限，当前金融权重44.08%。

### 2. 中证全指红利质量：高股息打底，再用盈利和现金流选优

**选股链条：**

中证全指样本空间 → 剔除市值或成交额后20% → 过去三年连续现金分红 → 三年平均支付率在10%至100%之间 → 按三年平均股息率剔除后50% → 剔除过去12个季度ROE波动最大的20% → 用ROE、ROE同比变化、经营现金流/总负债、股息率计算质量得分 → 选得分最高的50只。

金融行业不使用经营现金流/总负债指标，其余指标先在金融与非金融行业内分别标准化，再合成得分。

- **优点：**同时看分红、支付率、ROE水平、ROE改善和现金流偿债能力；不是直接追最近一年最高股息；单股10%、前五大40%、一级行业30%的上限，能约束结构集中。
- **缺点：**没有股价低波筛选；质量得分仍包含最近一年股息率，不能完全回避周期因素；2024年7月8日才发布，长期证据主要来自回溯。

这只指数最值得注意的不是“名字里多了质量”，而是它把红利和质量做成了两阶段：**先保证候选股票确实有分红和股息，再用盈利质量决定最终名单与权重。**

### 3. 中证红利质量：不只看分红，还看公司有没有一边分红一边融资

**选股链条：**

中证全指 → 剔除市值或成交额后20% → 最近一年现金分红少于净利润 → 过去四年现金分红总额大于再融资总额 → 连续三年现金分红 → 最近两年平均支付率和最近一年支付率均高于20% → 用六项财务指标综合打分 → 选前50只。

六项指标分别是：每股净利润、每股未分配利润、经营现金流与营业利润之差/总资产、毛利率、过去三年ROE均值减标准差、ROE同比变化。

- **优点：**“分红大于再融资”很有辨识度，可以过滤一部分一边融资一边制造高分红形象的公司；同时评价盈利、现金流、毛利率、ROE水平和稳定性；单股10%、前五大40%封顶。
- **缺点：**没有行业上限，也没有价格低波机制；2020年5月21日发布，2016年至发布日前的数据属于回溯；发布后表现弱于完整十年回测。

它更像一只**财务质量指数叠加分红门槛**，而不是传统意义上按股息率排序的红利指数。

### 4. 中证红利低波动：分红质量与低波结合得最完整

**选股链条：**

中证全指 → 连续三年现金分红 → 剔除支付率为负或处于最高5%的公司 → 三年每股股息增长率为正 → 按三年平均股息率选前75只 → 选过去一年波动率最低的50只 → 股息率加权。

- **优点：**连续分红、异常支付率、每股股息增长、三年平均股息率和低波动依次筛选，红利与低波目标都落实到了规则。
- **缺点：**没有直接要求利润或ROE增长；没有行业上限。2026年6月金融权重53.6%，规则有效不代表结构没有风险。

### 5. 标普中国A股红利机会：基本面排雷完整，但不负责低波

**选股链条：**

A股全市场 → 规模和流动性筛选 → 最近12个月盈利为正 → 三年利润正增长 → 支付率低于100% → 过去两年均有分红 → 选近12个月股息率最高的100只 → 股息率加权，单股不超过3%、行业不超过33%。

- **优点：**盈利、利润增长、支付率和分红历史约束直接；个股3%上限有利于分散。
- **缺点：**近12个月股息率仍可能追到周期高点；没有低波机制，历史波动和回撤偏大。

### 6. 中证红利低波动100：用分散和行业上限换平稳

**选股链条：**

中证全指 → 剔除成交额后20% → 连续三年现金分红 → 按三年平均股息率选前300只 → 选过去一年波动率最低的100只 → 按“股息率÷波动率”加权，行业权重不超过20%。

- **优点：**100只股票、行业20%封顶，结构最均衡；选样和加权都使用低波信息。
- **缺点：**没有支付率、利润增长、现金流或每股股息增长约束；季度调样响应快，也可能增加换手。

### 7. 中证红利：全市场经典高股息基准

**选股链条：**

中证全指 → 市值和成交额进入前80% → 连续三年现金分红 → 三年平均支付率和最近一年支付率均在0至100%之间 → 选三年平均股息率最高的100只 → 股息率加权。

- **优点：**规则简单；多年股息率和支付率比只看单年分红更稳健；2008年发布，真实运行历史充分。
- **缺点：**没有低波、盈利增长、现金流或行业上限。2026年6月金融与能源合计约47.7%。

### 8. 上证红利：沪市高股息的经典版本

**选股链条：**

上证180样本空间 → 总市值与成交额均进入前80% → 连续三年现金分红 → 三年平均支付率和最近一年支付率均在0至100%之间 → 按三年平均股息率选前50只 → 股息率加权。

- **优点：**连续分红、支付率和多年平均股息率的逻辑清楚；单股上限10%，总市值低于100亿元的股票权重不超过1%；每年调样一次，并设置原样本缓冲与一般不超过20%的调整比例，换手控制较好。
- **缺点：**只覆盖沪市，没有盈利增长和低波筛选，也没有行业上限。2026-08-05能源和金融分别占32.72%和30.72%，两者合计63.44%。

### 9. 标普中国A股大盘红利低波50：大盘高息之后，再挑股价最稳的

**选股链条：**

A股大盘股 → 规模和流动性筛选 → 按近12个月股息率选前100只，单个行业最多入选20只 → 选过去一年波动率最低的50只 → 按波动率倒数加权。

- **优点：**大盘股流动性较好；先高股息、再低波、最后继续用倒数波动率加权，防守逻辑清楚。
- **缺点：**没有明确的连续分红、盈利增长或支付率约束；近12个月股息率容易受周期影响；2019年发布前的数据属于回测。2024年指数单张与更新编制方案对加权方式的表述还曾出现变化。

### 10. 深证红利：高分红大公司，加上一层预期ROE

**选股链条：**

深市A股 → 剔除风险警示、经营异常和上市时间不足的股票 → 最近三年至少两年现金分红，且股息率至少两年位于深市前20% → 三年支付率在0至100%之间且位于深市前50% → 自由流通市值前20%、日均成交额超过500万元 → 剔除预期ROE后50%且ROE变化后20%的股票 → 按三年累计分红金额和成交额综合排名选40只 → 调整后自由流通市值加权。

- **优点：**分红历史、支付率、规模和流动性条件较完整；2006年1月24日发布，规则经受了较长真实市场周期。
- **缺点：**使用未来三年分析师预期ROE，引入预测误差；累计分红金额和市值加权容易偏向少数大公司；单股上限15%、前五大上限60%都偏宽；没有行业上限。

## 四、规则最终买成了什么：跨市场分散了个股，却没有消除行业集中

最新结构快照不能代表过去十年，但能检查规则现在把组合带到了哪里。这里还要分清“规则允许怎样集中”和“现在实际上有多集中”：前者看编制方案，后者必须有完整持仓和行业权重。资料不完整时，只评价规则护栏，不把“有上限”直接写成“当前一定分散”。

从结构看，中证沪港深红利成长低波动和上证红利代表了两种不同的分散方式：

- **中证沪港深红利成长低波动分散了市场和个股，但没有分散行业。**100只股票覆盖沪、深、港，前十大只占19.41%，显著低于其他多数指数；但金融仍占44.08%，跨市场不等于跨行业。
- **上证红利用沪市单一市场换取规则简洁。**前十大仅32.21%，个股不算集中；能源与金融合计63.44%，收益仍高度依赖传统高股息行业。

两个质量指数的结构差异也很明显：

- **中证全指红利质量更偏“高股息质量”**。截至2026-08-05，原材料24.83%、通信服务16.35%、主要消费15.87%，前十大权重较高，但行业30%上限提供了硬约束。
- **中证红利质量更像“财务质量组合”**。截至2026-08-05，医药卫生20.12%、原材料18.10%、信息技术17.12%、工业13.44%，最大个股只有4.52%，当前分散度较好；不过规则没有行业上限，当前均衡不能外推到未来。
- **深证红利的集中风险主要在个股而非传统金融。**宁德时代和美的集团两只合计30.05%，前五大接近一半。它不是银行、煤炭主导的经典红利组合，而是深市制造、消费龙头的集中组合。

中证红利低波动的历史持仓代理还说明了一件事：行业集中不是固定押注某个行业，而是规则会把权重交给当期最符合条件的行业。跟踪ETF 512890的前十大持仓，2019年以基建为主，2020—2023年在基建与周期之间切换，2024年后才明显转向金融。问题不在于“永远押金融”，而在于**没有行业上限时，主导行业一旦胜出就可能占得过重。**

## 八、综合评分：先把尺子摆正，再量长短

任何总分都带有价值判断。为了尽量少偏向某一种策略，本文没有把“有没有低波机制”设为所有指数的统一考题，而是看规则有没有服务于指数自己宣称的目标。质量指数做好质量筛选可以得高分，低波指数把波动压下来也可以得高分。

总分100分，五个维度如下：

| 一级维度 | 权重 | 子项 | 设置理由 |
|---|---:|---|---|
| 规则稳健性 | 30% | 分红持续性12、陷阱防御7、策略一致性6、加权调仓3、透明度2 | 低波不是所有策略的通用要求 |
| 历史风险收益 | 25% | 年化全收益10、最大回撤8、收益/波动7 | 不单列波动率，避免和收益/波动重复 |
| 表现稳定性 | 15% | 完整年度7、滚动3年5、滚动5年3 | 降低高度重叠的滚动窗口权重 |
| 结构分散 | 15% | 个股集中5、行业集中6、结构护栏4 | 区分规则上限和当前实际持仓 |
| 证据可信度 | 15% | 数据可比性5、发布后历史7、资料一致性3 | 回溯问题只在这里折价一次 |

评分不是拿尺子凭感觉比一比。规则项采用以下原则：连续分红但缺少盈利和现金流约束，分红持续性只能拿中等分；只看近12个月股息率，陷阱防御不能满分；策略一致性看“想做什么”和“规则实际做什么”是否一致，不奖励规则堆料。

- 中证红利低波动100牺牲了一部分质量筛选和收益上限，换来100只样本与20%的行业硬上限。
- 中证红利低波动规则、稳定性和真实历史都扎实，当前金融权重53.6%却像一块压在秤盘上的铁，直接拖低结构得分。

特色鲜明组也不是“差”。标普大盘红利低波50的基本面排雷偏弱，但最大回撤最浅，发布后年化8.89%；它是目标明确、历史防守出色，规则容错较弱。中证红利与上证红利没有新潮配方，胜在简单、透明、真实运行时间长。

深证红利大概率位于最后一档。ETF费用和跟踪误差不足以把它推到综合领先组，却足以让精确分差失去意义。根据代理误差给历史风险收益留出上下浮动后，它的合理区间约为49—54分，中位数52分。

## 九、没有万能冠军，只有更适合某个任务的选手

如果只记住几句话：

- **要分红成长、低波和跨市场的综合平衡：**中证沪港深红利成长低波动更完整，但必须接受金融集中和部分回溯历史。
- **要A股内部更直接的红利低波方案：**中证红利低波动的规则和历史验证较扎实，但行业集中与结构漂移更明显。
- **要更高的盈利质量与收益上限：**中证全指红利质量更突出，但正式运行历史太短。
- **要最直接的基本面排雷：**标普红利机会和中证红利质量都值得看；前者波动大，后者发布后表现弱于回测。
- **要行业均衡：**中证红利低波动100最清楚，但质量筛选和历史收益一般。
- **要简单、透明和长期真实运行：**中证红利与上证红利都是经典基准；前者覆盖更广，后者回撤更浅但沪市传统行业更集中。
- **要历史防守：**标普大盘红利低波50最亮眼，但质量约束不足、资料一致性也需要留意。
- **看深市龙头分红：**深证红利有独特市场定位，却不应把它误解为低波红利指数。

比较这十只指数，结论不是“83分一定胜过82分”，更不是“跨市场一定胜过A股”。真正有用的是知道每只指数把力气花在哪里：

> **质量决定公司能不能持续创造利润和分红，低波决定持有过程是否平稳，结构约束决定组合会不会把正确逻辑押在少数公司或行业上，证据可信度决定我们该有多大把握。**

中证全指红利质量展示了更高收益上限，中证沪港深红利成长低波动把分红成长、低波和跨市场结合得更均衡，中证红利低波动保留了更纯粹的A股红利低波逻辑。三者不是同一道题的标准答案。至于当前贵不贵、现在该不该买，是估值与择时问题，不应混进指数质量评分。
