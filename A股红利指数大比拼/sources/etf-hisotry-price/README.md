## 512890跟踪差复算

- `512890_历史净值_东方财富_2018-12-19_2026-08-04.json`：东方财富历史净值接口原始响应；
- `512890_vs_中证红利低波动全收益_2019-01-18_2026-07-31.csv`：基金累计净值与中证红利低波动全收益指数的1826个共同交易日；
- `512890_vs_中证红利低波动全收益_跟踪差汇总.csv`：上市以来、近5年的累计收益、年化收益、年化跟踪差和年化跟踪误差；
- 复算脚本：`../../scripts/collect_512890_tracking_difference.py`。

基金侧使用累计净值，不使用二级市场价格；接口记录显示期间无现金分红，2021-10-22发生基金份额分拆，累计净值已保持可比。指数侧使用中证指数官方H20269税前全收益行情。年化跟踪差为“基金年化收益－指数年化收益”；年化跟踪误差为日收益差标准差乘以`√250`，两者不能混用。
