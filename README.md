## 二、个股深度研究

基于“好行业、好公司、好时机”打分体系与 3R 投资分析框架，深度覆盖 A 股与港股核心标的。

### 1. 评估体系
* **100分制综合评分**：
  * **好行业（20分）**：竞争格局、成长性、行业壁垒
  * **好公司·定性（20分）**：商业模式、护城河、定价权、管理层
  * **好公司·定量（40分）**：ROE（杜邦分解）、利润增长、现金流质量、现金头寸、产品结构
  * **好时机（20分）**：股价vs利润线、PE百分位、PEG、股息率、预期差
* **3R 独立简报**：Right Business（好生意）/ Right People（好管理层）/ Right Price（好价格）
* 详见 [个股投资分析报告框架.md](references/个股投资分析报告框架.md)

## 四、方法论与工程工具

### 1. 核心方法论
* **彼得·林奇净现金头寸公式**：
  $$\text{现金头寸} = \text{现金等价物} + \text{定期存款} + \text{有价证券} - \text{长期负债}$$
  *注：短期借款通常对应营运资本，彼得·林奇在原著中建议忽略短期债务，专注于长期负债与高流动性现金资产的对比。*
* **股价 vs 扣非利润双Y轴对比法**：
  采用双Y轴对比股价与扣非TTM利润走势，重在研判两者方向与增速是否匹配，规避单一归一化折线受基期PE扭曲的影响。

### 2. 自动化图表脚本
`scripts/generate_charts.py` 为通用绘图工具，支持命令行一键生成多维度图表：
```bash
python3 scripts/generate_charts.py 600660 SH 福耀玻璃
python3 scripts/generate_charts.py 600809 SH 山西汾酒
python3 scripts/generate_charts.py 000858 SZ 五粮液
```
自动输出：归一化走势图、双Y轴扣非TTM图、双Y轴单季度图及清洗后的季度数据 CSV。

### 3. 数据来源
* **东方财富 API**：三张财务报表与高频估值指标（PE/PB）
* **同花顺 Excel 数据**：核心财务指标（用于与研报数据交叉复核）
* **Yahoo Finance (yfinance)**：前复权历史股价与行情数据
* **官方年报与定期报告 PDF**：产品营收结构、现金头寸附注明细、管理层讨论
