# A股个股投资分析

基于巴菲特、西格尔、彼得林奇、邱国鹭、段永平等投资思想，结合A股/港股实际案例整理的投资分析框架，并用年报、季报、同花顺Excel、行情数据做交叉验证。

## 分析框架

**好行业 / 好公司 / 好时机**（100分制打分）

- 好行业（20分）：竞争格局、成长性、壁垒
- 好公司·定性（20分）：护城河、定价权、管理层
- 好公司·定量（40分）：ROE、利润增长、现金流、现金头寸、负债率、产品结构
- 好时机（20分）：股价vs利润线、PE百分位、PEG、股息率、预期差

详见 [投资分析框架.md](references/投资分析框架.md)

## 数据来源

- **东方财富API**：财务数据（利润表、资产负债表、现金流）、估值数据（PE/PB）
- **同花顺Excel**：主要财务指标（交叉验证用，有同花顺时以同花顺为准）
- **Yahoo Finance (yfinance)**：历史股价（前复权）
- **公司年报PDF**：产品结构、现金头寸校验、附注明细

## 关键方法论

### 现金头寸（彼得林奇公式）

```text
现金头寸 = 现金等价物 + 定期存款 + 有价证券 - 长期负债
```

- 现金等价物：货币资金
- 定期存款：其他流动资产中的短期定期存款（需查年报附注确认）
- 有价证券：交易性金融资产
- 长期负债：长期借款 + 一年内到期 + 应付债券 + 租赁负债
- 短期借款不计入（彼得林奇原文：忽略短期债务）

### 股价vs利润趋势对比

用双Y轴折线图对比股价与扣非TTM利润的趋势：
- 看趋势方向是否一致、增幅是否匹配
- 不看绝对位置谁高谁低（归一化图会被基期PE扭曲）

## 指数估值看板

基于蛋卷基金API的指数估值数据，计算PE/PB/ROE历史百分位，生成可视化看板。

```bash
cd 指数估值 && python3 generate.py
```

输出：HTML看板（白底清新风格，含PE/股息率色带标注）

详见 [指数估值/generate.py](指数估值/generate.py)

- 本地入口：`docs/index.html`
- 仓库内归档目录：`docs/index-valuation/`
