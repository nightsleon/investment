## 二、个股深度研究

基于“好行业、好公司、好时机”打分体系与 3R 投资分析框架，深度覆盖 A 股与港股核心标的。

### 1. 评估体系
* **100分制综合评分（最新 6 章 13 节新投资分析框架）**：
  * **基本面质地（80分）**：好生意（70分，含定性30分+定量40分）+ 好管理层（10分）
    * **质地等级**：**A 档**（≥64分且定性≥24分，顶级印钞机）、**B 档**（56~63.5分，坚实良好资产）、**C 档**（48~55.5分，单品依赖/护城河缺陷）、**D 档**（<48分，基本面恶化）
  * **好价格（20分）**：时机与安全边际（林奇收益线、历史分位、股息托底、三年赔率推演）
    * **买入时机**：**`+`（买入信号）** 代表**价格低**（好价格 ≥12分，价格极低/偏低，买入击球点）；**`-`（观望信号）** 代表**价格高/偏贵**（好价格 <12分，价格公允/偏贵/陷阱，观望回避）
  * **综合总分（100分）与最终评级**：A+ / A- / B+ / B- / C / D
* 详见 [个股投资分析框架重构大纲.md](references/个股投资分析框架重构大纲.md)

### 2. 重点公司研究包（直达）
各公司研究包采用规范结构统一归纳在 `stocks/` 下，内含 `reports/`（研报）、`charts/`（可视化图表）、`data/`（财务数据）与 `年报/`（官方PDF）。

> **买入时机与评级符号说明**：
> - **`+`（买入信号）**：代表**当前价格低**（好价格得分 $\ge 12$ 分，处于“极低”或“偏低”估值带，具备显著安全边际与击球性价比）；
> - **`-`（观望/回避信号）**：代表**当前价格高/偏贵**或处于周期与单品估值陷阱（好价格得分 $< 12$ 分，处于“公允”、“偏贵”或“陷阱”状态，缺乏赔率保护，耐心观望绝不追高）。
> - **基本面质地**：以字母定质地（A 档 $\ge 64$ 分且定性 $\ge 24$ 分；B 档 56~63.5 分；C 档 48~55.5 分；D 档 $< 48$ 分）。

## 四、方法论与工程工具

### 1. 核心方法论
* **彼得·林奇净现金头寸公式**：
  $$\text{现金头寸} = \text{现金等价物} + \text{定期存款} + \text{有价证券} - \text{长期负债}$$
  *注：短期借款通常对应营运资本，彼得·林奇在原著中建议忽略短期债务，专注于长期负债与高流动性现金资产的对比。*
* **股价 vs 扣非利润双Y轴对比法**：
  采用双Y轴对比股价与扣非TTM利润走势，重在研判两者方向与增速是否匹配，规避单一归一化折线受基期PE扭曲的影响。

### 2. 自动化图表脚本
`scripts/generate_charts.py` 为通用绘图工具，支持命令行一键生成多维度图表：
```bash
python3 scripts/generate_charts.py 600660 SH 福耀玻璃
python3 scripts/generate_charts.py 600809 SH 山西汾酒
python3 scripts/generate_charts.py 000858 SZ 五粮液
```
自动输出：归一化走势图、双Y轴扣非TTM图、双Y轴单季度图及清洗后的季度数据 CSV。

### 3. 数据来源
* **东方财富 API**：三张财务报表与高频估值指标（PE/PB）
* **同花顺 Excel 数据**：核心财务指标（用于与研报数据交叉复核）
* **Yahoo Finance (yfinance)**：前复权历史股价与行情数据
* **官方年报与定期报告 PDF**：产品营收结构、现金头寸附注明细、管理层讨论
