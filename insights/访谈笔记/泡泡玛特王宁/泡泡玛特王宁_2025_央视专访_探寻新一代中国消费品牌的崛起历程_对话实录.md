### 第一篇章：Labubu 的爆红与“十年一剑”的潮玩逻辑（01:05 - 05:20）

**【主持人】**：（拿着彩色 Labubu 玩偶）眼睛看着它挪不开，哈哈！这是什么时候会跟我们见面的 Labubu？

**【王宁】**：这个有可能是10月份跟大伙见面吧。

**【主持人】**：为什么把它设计成彩色的？

**【王宁】**：其实我也是第一次见（笑）。我也是第一次见。对对对，我们其实现在产品的开发还是非常完善的，就是他们每个 IP 背后都有一个经纪团队一样，我觉得我们有一个还是非常体系化的、对整个 IP 运作和产品开发的团队。其实是非常保密的。

**【主持人】**：Labubu 已经10岁了，为什么在10岁的时候，它突然之间爆红呢？

**【王宁】**：我们最近内部还在聊一个话题，觉得很有意思，就是好像每年大家总觉得我们是一家突然蹦出来的新的企业，好像每年比如我们的这些，不管是 Labubu 爆红，还是 Molly 爆红，大家总认为是一个好像是突然就“砰、砰、砰”蹦出来的这样一个……

**【主持人】**：一夜之间爆红的。

**【王宁】**：对，但实际上很多人不知道，比如 Labubu 已经10岁了，然后 Molly 20岁了，泡泡玛特今年已经15岁了。其实这个大家想象的不一样，我觉得核心原因是，可能我觉得我们一路过来还是一个相对慢的一家公司，和相对克制的一家公司。所以说我们其实包括潮流玩具，它本来其实是一个小众的消费品。每一次在这个不断扩圈的过程当中，其实它原来它都积累了很多粉丝。Labubu 确实的出圈，然后让我们看到了一种可能性，就首先我们其实可以去孵化出来一个世界级的 IP，然后在世界范围之内都这么受欢迎。其实我觉得这个还是非常非常有价值的。

**【主持人】**：开始破圈的时候，那是是不是已经变成了大众消费品呢？

**【王宁】**：我们大概去年（注册）会员大概是5000万，今年可能有一个比较大的增长。那比如说我们门店数，如果跟同样的消费品比的话，我们门店数是非常少的。我们门店数大概只有国内只有400家。前两天比如说我去西双版纳旅游，我下了飞机我就说我还有时间，我说我去逛一下店，但我会发现，这么著名的城市我们没有店。就意味着绝大多数大家是没有真正去买过我们的产品的，就它还是需要一个过程。其实它还是聚焦在一个相对小众的一个圈子在不断的向大众慢慢扩圈的这样一个过程。

### 第二篇章：面对火考与周期的战略定力（05:20 - 08:35）

**【主持人】**：Labubu 火了，所以 Labubu 被火考着，你也被火考着，是不是？有一种被火考着的感觉吗？

**【王宁】**：我们其实经历过很多次。其实五年前，我觉得我们都经历过很多质疑。就是你不管是不是……那个时候其实红的是 Molly。当然我觉得 Molly 现在依旧很红，明年 Molly 20周年。其实 Molly 的销售额都还是一直在涨的。但是那个时候大家会觉得，你是一个 IP 类的企业，你是不是过于依赖 Molly？你是不是会有持续诞生爆款的能力？包括 Molly 本身它是不是可持续？其实大家都会有很多质疑。然后包括大家会质疑，你是不是依赖盲盒这种模式？就大家会有各种各样的问题和质疑。

**【主持人】**：在泡泡玛特的门店里面看见人排队，你是高兴还是焦虑？

**【王宁】**：其实每次开会更多的是让大家讨论如何才能让大家不排队。你买完东西以后，你还需要排很长的队去结账，体验也是不好的。其实我们在用很多种办法来解决大家购物体验的问题，优化更多的这些购买形式，或者说去开更大的门店。我记得之前我们不管在英国、法国，包括前段时间，如果我们发现线下它是稍微有些混乱，比如说那种销售方式是一个体验很不好的，我们是暂停的。就是我们知道我们认为可以用一个更好的方式去卖给真正的用户，让真正用户去买到它。

### 第三篇章：IP生命力之争：无故事IP凭什么长青？（08:35 - 14:10）

**【主持人】**：但是，如果我们的这个文化平台里的这些 IP 是没有故事、只有形象的 IP，它的长久化会不会在未来打一个问号？

**【王宁】**：我觉得其实大家不应该有一个思维定式。就比如说，好像讲了一个故事的那样子的 IP，它才成为、可以成为 IP。

**【主持人】**：因为在我们的心中，可能对于这个文化 IP，我们最容易对标的就是迪士尼公司。


**【王宁】**：但是比如说我可以问你两个问题，如果你现在给小朋友，我说你可以给他讲一个米老鼠的故事吗？你能讲出来吗？或者说你讲一个小黄人的故事？你会发现你讲不出来。就是其实你自己都放大了那个故事的重要性。当然，它其实也很重要，因为他有可能通过一个故事让你认识了这个角色，可能它的某个情绪，或者说它某个点它打动了你，你就爱上了这个角色。我觉得其实这是故事的一个重要性。

其实你会发现，当内容爆炸的时候，当信息变得更丰富和大家时间变得更碎片化以后，其实诞生 IP 的方式也会非常的不一样。

**【主持人】**：其实特别直接的问题就是，当我们说 Labubu 的时候，一定会有问 Labubu 接下来会不会有属于它的电影、属于它的电视剧、属于它的动画、属于它的人生故事继续续写下去？会有吗？

**【王宁】**：那我们现在也在去讨论，包括现在全世界这些著名的这些电影公司，包括好莱坞很多公司在找我们，说能不能一起来去来拍 Labubu 的电影。我觉得这些都是我们考虑的一个方向。

**【主持人】**：好莱坞找你，你也只是在列入考虑范围之内吗？

**【王宁】**：我们在考虑这个事情，但是好莱坞也很多公司啊。那我们到底是自己做，还是跟好莱坞合作，还是用什么样的方式来去做，或者说它要不要做？比如说当年 Molly 我们就想了很长时间，它要不要做内容？因为因为我们有时候它做内容的时候，其实有很多你意想不到的困难。就比如说它做内容，我们在想那它说话它会是个什么声音呢？比如说它张嘴，Molly 是一个很傲娇的脸，那如果它开口说话了，那它又是一个什么样子的表情呢？其实你会发现当你想要把它变成一个非常鲜活的，然后或者说给它注入更多内容的时候，其实还是会有非常不一样的挑战的。

**【主持人】**：所以其实我们对于文化 IP 到底怎么深化，大家现在都还在困惑当中。我们不知道这样一个潮玩文化的 IP 如果想持续带有长期主义经营下去，会以什么样的形式？它才能存活并且长青？

**【王宁】**：其实我觉得它内容不一定只是大家想象中的电影的内容。就好比就比如大家看到梵高的一幅画，它只是一幅画，难道它就没有内容？这个行业它是叫做艺术家玩具，其实你可以理解为它是一个绘画和雕塑的作品。比如说这个 Molly 就是我们和敦煌合作，它的壁画和它的作品本身它没内容，它是有内容的。就比如像 Labubu，我觉得乐园就是对它来讲是一个非常好的这样一个内容本身。比如说我和 Labubu 之间互动的一个内容，那可能是各种各样的内容，也许只是简单打个招呼，也许是一次拥抱，也许是一次互动，那它都会感动你，它都会让你去喜欢，就像一个一个的小故事一样。

**【主持人】**：所以其实大家一定会问那个问题，就是一代人有一代人的泡泡玛特，一代人有一代人的 Labubu，一代人有一代人的 Molly。那当然那是不是它会一直红下去？或者大家会一直喜欢它？还是会随着时间的流逝，我们会把它就放在抽屉里，它就变成了记忆而已？

**【王宁】**：我觉得大家忽略了一个价值，就是什么价值？就是全世界人，然后我刚从欧洲回来，然后不管国内还是全世界，就是从小朋友到银发的老人都指着这个形象说：“哎，这个是 Labubu。”我觉得这是一个巨大的价值。我觉得我们内部就好比说，我说大家一下发现了这个金矿，然后这会儿人声鼎沸在讨论它，哇，我们发现一个金矿。哪怕比如说这会儿大家可能不再讨论它了，不意味着这个金矿就没了，就可能对它的价值的挖掘才刚刚开始。你想，就像我们现在生活当中，今年你也没有讨论米老鼠啊，很少讨论皮卡丘啊，很少讨论 Hello Kitty，但是它的价值是非常巨大的。不是说你不讨论它，好像它就没价值了。这个 IP 的价值就在于，其实是一个巨大的价值就在于你看到它你认识它，从小朋友开始你都认识它，这叫 Labubu，那它的价值的挖掘我觉得才刚刚开始。它的价值会伴随着这个小朋友的一生。但是就看，我觉得一个优秀的 IP 企业，就是你怎么来去去运筹这个 IP 本身。

是因为我们路还很长嘛，就是我们其实今年才15年。我们自己的理念叫“尊重时间，尊重经营”。其实我觉得我们未来，你想 IP 企业的特点就是属于你一旦可以培养出来一些优秀的 IP，它不一定就是可能它的企会有波动，但是我相信 IP 类的企业是很长寿的。你看 Hello Kitty 50多年的历史了，迪士尼已经超过100年历史了，它有可能它的有波峰有波谷，但实际上其实因为 IP 的诞生，它的最有魅力的价值就是它可以穿越很多周期。我觉得我们还是整个团队也很年轻，所以我们还是有足够的耐心，然后希望去做一个更长期的事情。

### 第四篇章：全球化 2.0——来自世界，走向世界（14:10 - 20:30）

**【主持人】**：好像你们是从2018年开始迈出全球化的脚步？

**【王宁】**：整个全球的潮玩产业，它一定程度上诞生在20多年前的香港。就比如这些艺术家，就大家聊起来艺术，就比如说是画画的、做雕塑的。其实画画大家可以理解，你可以通过版画然后能够大家更熟悉我。但是不管是做雕塑的，哪怕是做画画的，你会发现其实它很难在在商业社会当中放大它的价值。因为你想我们生活当中其实已经极少数人我要花很多钱买一幅画，或者买雕塑就更不可能了。但是实际上那个是非常纯粹的艺术的表达，因为它只是艺术，它只是表达本身。

但有很长一段时间，他们就发现，我的表达必须附加在一个有用的东西身上。可能哪怕是一个丝巾、一个T恤、一个盘子，就是我把我的设计和表达放在它身上。大家去做这个表达的时候就诞生了这个行业。它的潮流玩具它原来叫 Art Toys（艺术家玩具）。他们就发现用玩具的材质，它既颜色很丰富，然后又线条很完美，它其实有点像绘画和雕塑的一个结合。那刚好香港当年和东莞和广州挨着，有很成熟的制造业，它可以帮它把这个表达出来。然后这个行业就诞生了。只不过相当于是我们其实是通过我们的方式去发现了这个产业，去把它真正的去做大。

那我们做大也是得益于比如中国我们说改革开放这么多年，一个是中国成熟的制造业，一个是中国庞大的市场。我们最近经常聊，我们是“From the World, To the World”（来自世界，走向世界）。就是我们来自于世界，在走向世界。我们只不过是用中国的制造业和市场，然后我们孵化全世界的艺术家，然后再走到全世界各地。

**【主持人】**：但我看到你在泡泡玛特海外的店选择的选址上面，一定是有你的思考。

**【王宁】**：因为其实我自己是就喜欢两件事情：一个是喜欢艺术，一个是喜欢商业。其实我觉得这两件事情是一个很矛盾的。因为商业是追求普遍，它是一个理性的；那艺术又是追求独特和感性的。其实我们一直想找一个平衡点，就怎么去……因为如果你只是太独特了、太艺术了，你也很难让大家看到嘛。所以说我们选择很多地方，要么就全世界最好的商业的地标，要么就是比如像卢浮宫，它其实是更贴近艺术的。但总体来讲的话，因为我们是用一个很笨的方式在做全球化，因为全世界你看到的所有店都是直营店。哪怕是很多欧洲的一些国家，它只有一家店两家店，也都是我们自己去自己搭建团队自己来做。就我们还是希望认真开好每一家店。

**【主持人】**：当我们看到迪士尼它的米老鼠，看到它的 Elsa 公主的时候，当我们总是能够看到一些国外的 IP 它以更大的溢价生活在我们的空间里，中国的品牌什么时候出现？什么时候会是中国的形象、中国的品牌、中国的 IP 来让全世界买单？

**【王宁】**：首先我们这些艺术家是来自世界各地的，然后我觉得我们希望搭建的是一个世界级的 IP 的平台。今年海外业务增长真的比我们想象的还是要快，整体收入有可能超过国内。我们在走出去的时候，在欧洲经常会有顾客问我们店员两个问题：第一，你这个东西为什么卖这么贵？然后第二，你是不是一个日本品牌？然后我们的店都非常骄傲的跟他说是第一，为什么卖这么贵？是因为我们是一个艺术品，就它是一个艺术家玩具，它是一个艺术的表达，它对它对整个设计它花了很长时间；然后第二就属于我们是一个中国品牌。然后大家还是属于非常的这个惊讶，但我们也挺自豪的。

### 第五篇章：创业回忆与“树型”企业哲学（20:30 - 27:00）

**【主持人】**：你现在还是在一个创业的心态吗？

**【王宁】**：最起码我们在海外，比如很多国家我们都是一个创业的状态。因为我们比如我们需要当地搭建团队，当地一家店一家店开。比如说我们现在在很多国家，比如我们在墨西哥还没有店，我们可能明年现在有可能慢慢墨西哥，他们下个月我们整个团队有好多人要去巴西。然后我们在荷兰只有一家店，在意大利马上要再开一家店，这也才两家店。

**【主持人】**：所以你享受这个创业过程吗？

**【王宁】**：就很多挑战，但也很有趣。然后你发现你可以跟不同的文化之间去进行交流，然后你有很多不同文化的同事，然后大家会给你这个不同文化的东西，然后让整个公司也会变得更丰富，因为大家擅长的也不一样。

**【主持人】**：我看到这张照片呢，应该是在12年你们在满庭芳园的一个普通民宅里。

**【王宁】**：对对对，我们在一个民宅里面两室一厅，对，这里面也有很多故事。

**【主持人】**：这个梯子是你吗？

**【王宁】**：对，这个是我在开会。

**【主持人】**：那个时候的你是感性的还是理性的？

**【王宁】**：他说两室一厅，然后我们有一个房间还住着四个人，然后有一个房间是办公室，客厅还摆着几张桌子，我们的仓库是厨房。你看我们其实就有很多人跟着我们一起成长起来了。比如那个时候我们一些同事他管仓库，就是从一个厨房开始。比如我们现在整个全球负责管仓储物流的，他原来是我北漂认识的一个同事，是个卡车司机，当过两年卡车司机，没有任何的物流经验。只是我们认为他性格挺有耐心的，说那你就加入团队，那你就管仓库吧，然后就从一个厨房开始。现在全球你想这么复杂，从一个几平米的厨房开始管管全球这么超级复杂的物流和全球我们现在有很多大型的仓库。其实这是一个大家一起成长的一个过程。

**【主持人】**：我在看到网上很多人去转你说你北漂的那段经历。在北漂的时候，那个时候你心里有明确的目标吗？

**【王宁】**：很多人会问我说你有没有什么什么时候就属于痛苦流涕的时刻啊，觉得这个卖不出去的坎啊，觉得压力很大的一时刻。我说我其实我们我我觉得我还是挺享受这样一个过程的。我觉得如果这就是你一个人生的剧本的话，你如果你完全没有波澜，没有没有挫折，这个故事一点不好玩嘛。

**【主持人】**：你会经常回忆那段时光吗？

**【王宁】**：我是属于非常喜欢记录的，就是我是非常觉得其实每段时光都有它的意义和价值。我记得当年我们上市的时候，我还自己剪了一个我们创业十周年的一个片子。

**【主持人】**：那个片子是你自己剪辑的？

**【王宁】**：对，是我自己剪的。因为我觉得其他人剪了多遍以后，我觉得表达不出来我想表达的这个情感，所以说我自己剪的那个。但在十周年的那个片子里面最后，你选择以一首歌作为结尾，就是你在唱《蜗牛》。“我要一步一步往上爬……”对，我很喜欢这首歌。

### 第六篇章：去“盲盒”化、黄牛炒作与资本市场波动的应对（27:00 - 34:25）

**【主持人】**：在很长一段时间泡泡玛特被人称为是一个“盲盒”零售企业。

**【王宁】**：这个也不是属于我们的专利嘛，因为它在全世界已经各国家很多品类就大家都都很喜欢的一一种方式。早些年的时候，我们发现盲盒跟潮流玩具是一个非常好的一个结合。那我们也看着这个盲盒这个词汇从一个从一个新鲜词汇到潮流词汇，到大家不理解它变成一个负面词汇。你发现为什么它从一个大家质疑的词变成一个中性词汇？因为你发现我记得当年我们 IPO 的时候，很多企业就会说“这是一家盲盒成功的企业”。但是慢慢的这么多年过去了，大家你会发现今年大家讨论我们讨论了更多是 Labubu，更多是新心人。然后大家当认知我们是一家 IP 企业的时候，大家才会知道：“哎，原来那个只是锦上添花的一个点。”如果我们是一家盲盒类的公司的的话，那我们就不需要做做 IP 了，不需要做产品了，那它这个所有产品卖的都一样了。

**【主持人】**：能量化吗？比如说在泡泡玛特的初期，盲盒的业务所占的比例和今天盲盒业务比例？

**【主持人】**：隐藏款其实还是给大家一个……给到大家一个特殊的惊喜嘛。这个特殊的惊喜会困扰你们吗？因为对这个特殊的惊喜在一定程度上会带来质疑，因为它变成了可以溢价的巨大的空间。
