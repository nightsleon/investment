# 唐书房 + 唐书院 文章归档（2016–2026）

个人备份归档。收录唐朝在微信公众号「唐书房」（2016–2023）与「唐书院」（2024 起）发布的原创文章，共 1756 篇，按发表年份分文件夹存放，每篇为独立 Markdown 文件。

## 内容来源

- 原始来源：唐朝微信公众号「唐书房」与「唐书院」
- 抓取来源：第三方镜像站 [唐朝投资知识库](https://laotang.pages.dev)（Cloudflare Pages 静态站）
- 抓取时间：2026-08-17
- 每篇文章头部 `source` 字段为镜像站链接，`original` 字段（若有）为微信原文链接

## 目录结构

```
唐书房_archive/
├─ 2016/ ~ 2026/     # 按年份存放每篇 .md
├─ index.html        # 可检索、可内联阅读的总索引（浏览器打开）
├─ manifest.json     # 元数据清单（标题/日期/分类/路径/链接）
├─ README.md
└─ NOTICE.md         # 版权声明
```

## 使用

直接用浏览器打开 `index.html` 即可检索、点开阅读全文；或把各 `.md` 导入 Obsidian / 微信读书等工具。
