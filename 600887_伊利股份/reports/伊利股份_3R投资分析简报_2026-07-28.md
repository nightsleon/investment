# 伊利股份（600887）3R投资分析简报

> 数据截止：行情截至2026-07-16收盘；财务截至2026Q1；年度数据截至2025年报；重大公告截至2026-07-15。  
> 3R总分：**76.0/100**  
> 当前评级：**关注；好生意成立、价格有吸引力，但增长、治理与资产效率限制上限**  
> 一句话结论：**伊利是一门“把原奶加工成大众乳品，再用品牌、渠道和规模赚钱”的成熟消费生意；护城河宽、现金流好、估值低、股息高，但液体乳基本盘承压，强定价权并不成立，巨额存单与短期借款并存，真正要等的是收入、渠道和资产效率企稳。**

## 一、公司概况：它到底靠什么赚钱？

| 项目 | 内容 |
|---|---|
| 主营业务 | 液体乳、奶粉及奶制品、冷饮、奶酪、乳脂及专业餐饮等 |
| 核心产品 | 金典、安慕希、舒化、金领冠、巧乐兹等 |
| 赚钱方式 | 规模化采购和生产降低单位成本，品牌与全国渠道形成溢价，多品类共用供应链、营销和终端网络 |
| 2025产品结构 | 液体乳61.48%、奶粉及奶制品28.61%、冷饮8.57% |
| 行业位置 | 液态类乳品、婴幼儿奶粉、成人奶粉和冷饮均位居行业第一 |
| 控制与管理 | 无控股股东、无实际控制人；潘刚任董事长兼总裁 |
| 报告基准日价格 | 26.03元，总市值1,646.49亿元，PE(TTM)13.62倍 |

用人话说，伊利卖的不只是“一盒奶”，而是一套消费品系统：上游锁定奶源，中游用大规模工厂生产，下游靠品牌和渠道让产品随处可买。配方和单品可以模仿，难复制的是品牌矩阵、全国铺货、供应链效率和多品类协同；但消费者换成蒙牛、光明或植物蛋白饮料并不困难，所以伊利的护城河深于单个产品，定价权却没有护城河看起来那么强。

### 3.2 业务持续性：营养需求长期存在，乳品形态和品牌却可以替换

乳品属于高频日常消费，周期性弱于可选消费；液体乳、奶粉、冷饮等品类组合也能互相缓冲。不过，出生人口、居民收入、乳糖不耐和消费习惯会限制行业增速，豆奶、燕麦奶、咖啡及功能饮料也会分流。长期存在的是营养需求，不是任何单一乳品形态或品牌。

| 具体指标 | 判断依据 | 得分 |
|---|---|---:|
| 商业模式是否简单、容易理解 | 原奶采购—加工—品牌溢价—渠道销售，收入与利润形成清楚 | 5.0/5 |
| 需求是否长期存在 | 日常营养需求稳定，但人口与消费习惯限制渗透速度 | 4.0/5 |
| 周期性是否可控 | 弱周期但受原奶、促销、收入和库存影响，多品类可缓冲 | 1.5/2 |
| 产品或品类替代风险 | 乳品不易消失，但植物蛋白及其他饮品能分流 | 1.0/2 |
| **小计** |  | **11.5/14** |

### 3.3 护城河与定价权：难复制的是系统，不是牛奶配方

伊利与蒙牛构成全国双龙头。伊利拥有多品牌矩阵、全国多渠道、77个生产基地、1,600余万吨综合产能，并让液体乳、奶粉、冷饮和奶酪共用采购、营销与终端网络。2025年液态类乳品、婴幼儿奶粉、成人奶粉和冷饮均居行业第一，说明壁垒已由经营结果验证。

但护城河不等于无限定价权。2025年毛利率和净利率改善，更多来自原奶成本、产品结构与费用控制；液体乳销量下降1.92%，产品结构和销售价格变化合计减少收入约41亿元，说明直接提价会损失销量或收入。

### 3.4 资本回报与现金流：现金创造力不错，资产效率却在下降

2025年加权ROE由15.81%修复至20.87%，主要靠净利率从7.33%升至9.96%，而非继续加杠杆；但总资产周转率已由2020年的1.47降至0.76，权益乘数升至2.65。也就是说，利润率修复是好事，扩表后资产转得更慢却不是好事；ROIC和产能利用率缺失，不能只凭高ROE断言新增投入回报优秀。

### 3.5 盈利成长：利润在修复，收入基本盘仍没有恢复

2020—2025年扣非利润五年CAGR为10.81%，2022—2025年三年CAGR为8.84%；但营收五年CAGR仅3.65%。2024年澳优商誉减值使扣非利润下降40.04%，2025年又增长84.13%，两者都不能代表常态。2026Q1扣非利润增长15.11%、高于收入5.47%，方向积极，但一季度通常是利润高峰，不能简单年化。

## 六、最终行动

### 现在怎么办？
- 可纳入成熟消费、高股息候选清单；低估值允许分批研究和验证，不支持只看PE、股息和账面存单一次性重仓。
- 已持有者优先跟踪收入、合同负债、经营现金流和短期借款，而不是只看利润同比和分红承诺。

### 什么情况下提高关注？
- 液体乳降幅明显收窄，奶粉、冷饮等增量继续覆盖缺口，集团收入恢复稳定增长；
- CFO重新稳定覆盖利润，合同负债不再下滑，短期借款见顶或下降；
- 新增产能和优然投资能够改善ROIC或资产周转，而不是再次产生减值。

### 什么情况下说明判断错了？
- 液体乳持续收缩，奶粉、冷饮也明显放缓，基本盘和第二曲线同时失速；
- 自由现金流不能覆盖分红，短债继续上升而现金类资产下降；
- 再次发生重大并购减值，或减持、质押和权力集中演变为实际治理损失。

## 七、数据边界与盲评披露

- **事实范围**：底层数据复用完整投资报告中的年报、2026Q1季报、公告、同花顺数据和行情底稿；财务截至2026Q1，行情基准日为2026-07-16。
