# 红利低波优选

红利低波指数与可投资基金专题研究。目标是区分底层指数质量与基金实际交付，服务长期持有、分红再投资和总回报复利决策。

## 最新结论

- **综合单基金：**景顺沪港深A（007751）。
- **低费率ETF方案：**70%易方达A股ETF（563020）+30%摩根港股ETF（513630）。
- **纯A股方案：**易方达A股ETF（563020）。

完整证据、适用条件和风险见基金购买推荐，不要只依据本页摘要交易。
