# 华泰柏瑞红利低波ETF（512890）历史前十大持仓

## 数据来源

- 移动端页面：`https://fund.10jqka.com.cn/fefund/fundAssetTrace/ifundapp_web/public/positionReview.html?fundCode=512890&share=true`
- 页面底层接口：`https://fund.10jqka.com.cn/bff-server/v1/fund/position_rank?fund_code=512890`
- 采集脚本：`collect_position_history.py`

## 数据覆盖

- 接口返回31个报告期，其中2018-12-31为空。
- 有效数据为2019-03-31至2026-06-30，共30个季度报告期。
- 每期只提供前十大重仓股，共300条持仓明细。
- 前十大持仓合计占基金净值24.61%—38.31%。

## 文件说明

- `512890_position_rank_raw.json`：接口原始响应。
- `512890_季度前十大持仓.csv`：每个报告期的前十大证券、排名、行业大类和基金净值权重。
- `512890_前十大持仓行业构成.csv`：前十大内部的行业占比，以及这些股票合计占基金净值的实际比例。
- `512890_季度前十大持仓变化.csv`：相邻报告期前十大名单的新进、退出和连续保留数量。
- `512890_2026Q2前十大盈利分红_2025.csv`：2026年二季度前十大持仓的2025年盈利、ROE、EPS、每股分红和支付率。
- `512890_历史前十大高频持仓_2025质量.csv`：历史进入前十大次数最多的6家公司，包含出现期数、连续期数、历史权重及2025年盈利分红质量。

盈利数据来自东方财富 `RPT_F10_FINANCE_MAINFINADATA`，分红数据来自 `RPT_SHAREBONUS_DET`。2025年每股税前分红按同一报告年度的年中及年末方案合计；支付率按“每股分红÷基本EPS”估算。该表只覆盖前十大，不代表ETF全部50只成分股。

“高频持仓”只表示多次进入季度前十大，不等于基金连续持有，也不自动代表公司具备持续成长或稳定分红能力。

## 重要限制

1. 这是ETF定期报告的前十大持仓，不是指数公司披露的完整历史成分股。
2. ETF虽跟踪中证红利低波动指数，但仍可能受现金仓位、申赎、跟踪误差和披露时点影响，不能直接等同于指数官方持仓。
3. 接口的 `shareClassPosition.rate` 每期合计100%，表示“前十大持仓内部”的同花顺行业大类构成，不是全基金行业权重。CSV另按前十大股票的基金净值权重汇总了实际占比。
4. 新进或退出仅表示进入或离开披露的前十名，不能据此认定基金完成了买入或清仓。
5. 同花顺使用“金融、周期、基建、制造、消费、医疗”等宽口径行业分类，与中证一级行业不一致，跨来源比较前必须建立映射。

因此，这组数据适合观察指数主要权重股和风格重心的变化，可作为历史结构的代理线索；不能单独用于计算完整行业权重、行业集中度或收益归因。
