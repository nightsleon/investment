# 红利类基金实盘对比（二期）

> 基于基金实际净值，而非指数回溯数据。以华泰柏瑞红利低波ETF（512890）为基准。30只红利类指数各选1只代表基金，共30只。

## 筛选与排名说明

**样本：** 一期报告30只红利类指数，每只选取规模最大的跟踪基金作为代表（ETF优先，其次场外指数基金，LOF/指数增强为兜底）。

**分组规则（按基金成立时间）：**
- 5年组：成立满5年（截至2026-08-07，即2021-08-07前成立），11只，四维度评分（收益40%、风险30%、效率15%、稳定性15%）
- 3年组：成立3-5年（2021-08-08至2023-08-07），6只，三维度评分（收益50%、风险30%、效率20%，稳定性因数据不足暂不参评）。基准512890截取相同区间参与评分
- 观察池：成立不足3年，13只，仅供参考，不参与排名

**比较基准：** 华泰柏瑞红利低波ETF（512890），当前规模最大的红利类ETF（324亿）。

**打分方法：** 总分100分，各维度均为**组内相对排名百分位**（该指标在组内从差到优的百分位×100），不是绝对收益分，因此分数只在同组内可比、不能跨组比较。具体指标：

- **收益（5年组40% / 3年组50%）：** 共同区间年化收益（CAGR）的组内百分位，越高越好。
- **风险（均30%）：** 最大回撤的组内百分位，回撤越小得分越高。
- **效率（5年组15% / 3年组20%）：** 收益/波动（CAGR ÷ 月波动率年化）的组内百分位，即单位波动换来的收益。
- **稳定性（仅5年组15%）：** 由"完整年度胜率"和"滚动3年年化收益中位数"各占一半组成，两者分别取组内百分位后等权；衡量是否年年正收益、任意时点持有3年的体验是否稳定。3年组因数据不足一个完整3年滚动周期，本项不参评，权重并入收益和效率。

总分 = 收益分×权重 + 风险分×权重 + 效率分×权重 + 稳定性分×权重。基准512890在5年组用全区间参评，在3年组截取相同区间参评。

**分档规则：**
- 第一梯队：总分 ≥ 基准 + 3分（综合显著更优）
- 第二梯队：基准 - 3分 ≤ 总分 < 基准 + 3分（综合接近，各有千秋）
- 第三梯队：总分 < 基准 - 3分（全面落后）

**净值口径：** 基金净值采用手工复算的分红再投净值（单位净值+现金分红+分拆事件），与全收益指数口径一致。香港红利ETF（3070 HK）数据来自Yahoo Finance前复权价格。

## 要点总结

**5年组（2020.3-2026.8，覆盖完整牛熊周期）：**
- 没有基金显著跑赢基准512890。景顺长城红利成长低波（007751）以低12.91%的回撤追平基准收益，风险调整后表现最优，但跟踪误差偏大（1.98%）且累计跑输指数19%，说明该指数基金有较明显的跟踪损耗
- 平安香港高息股ETF（3070 HK）绝对收益最高（CAGR 15.04%），但回撤大、与基准不在同一市场，跟踪误差参考意义有限
- 多数传统宽基红利ETF（510880、515180、515300）在6年区间内跑输基准5-20个百分点，主要因为基准的红利低波策略在回撤控制上优势明显
- LOF和指数增强产品（501307、007178）跟踪误差大、收益差，不适合作为指数工具

**3年组（2023.5-2026.8，红利风格占优期）：**
- 华泰柏瑞港股通高股息（513530）以CAGR 15.04%大幅领先，但4.73%的跟踪误差反映QDII产品在汇率和交易时差上的天然劣势
- 央企红利主题（561580、560700）受益于估值重塑，表现优于基准
- 东方红红利低波（012708）以最低回撤（-12.25%）进入第一梯队，作为场外指数基金适合定投
- 工银港股通高息精选（159691）和华夏红利质量（159758）因回撤较大落入第三梯队

**观察池值得关注的：**
- **招商中证全指红利质量ETF（159209）★重点观察**：作为红利质量类的补充标的，跟踪的932315指数10年回溯CAGR 13.98%、收益/波动0.74、发布前后无明显衰减，规模25亿流动性领先。不足是仅340个交易日实盘，等满3年再正式评分
- 华夏港股通央企红利（513910）和广发智选高股息（159207）短期CAGR超15%，但成立不足2年，需等待完整周期验证
