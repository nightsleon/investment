# 基金全收益计算方法说明

## 为什么不用前复权交易价

在做ETF收益对比和跟踪误差分析时，不建议直接使用行情软件的前复权交易价格，原因如下：

### 1. 交易价 ≠ 基金净值

ETF的交易价格是市场买卖形成的，围绕基金净值上下波动（折溢价）。虽然长期来看折溢价会收敛，但短期波动会引入噪音，导致：
- 跟踪误差被高估（折溢价波动被计入了"跟踪偏差"）
- 短期收益对比不可靠

基金的真实收益应该用基金净值来衡量，而不是市场成交价。

### 2. 不同平台前复权算法不一致

不同行情软件（东方财富、雪球、同花顺）的前复权算法存在差异，主要体现在：
- 分红除权日和到账日的处理方式
- 分红再投的价格假设（开盘价/收盘价/均价）
- 是否处理分拆、折算等其他份额事件

同一基金、同一时间段，不同平台的前复权区间收益可能相差十几个百分点（如嘉实300红利低波ETF近5年，雪球52% vs 东方财富72%）。数据口径不统一，结论不可靠。

### 3. 累计净值也不行

累计净值（LJJZ） = 单位净值 + 历史累计分红金额。这是简单相加，不是复利计算。
分红次数越多、时间越长，累计净值的收益率和真实分红再投收益差异越大。

**累计净值低估了分红再投的复利收益。**

## 手动计算基金全收益（分红再投）

### 核心公式

```
财富指数[t] = 财富指数[t-1] × (单位净值[t] + 当日分红[t]) / 单位净值[t-1]
```

初始值：`财富指数[0] = 单位净值[0]`

### 原理

每天的真实收益 = （当天净值 + 当天分红）÷ 前一天净值。分红相当于当天派发的现金，要加回当天的价值里。把每天的收益连乘，就得到分红再投的累计收益。

这个口径和指数公司计算全收益指数的方法完全一致，具有可比性。

### 计算示例

以某基金为例：

| 日期 | 单位净值 | 分红（元/份） | 财富指数 | 说明 |
|------|----------|--------------|----------|------|
| 8月1日 | 1.000 | - | 1.000 | 初始值 |
| 8月2日 | 1.050 | - | 1.050 | 净值上涨5% |
| 8月3日 | 1.000 | 0.050 | 1.050 | 分红除权日，净值下跌0.05元，但分红加回去后财富不变 |
| 8月4日 | 1.020 | - | 1.071 | 净值上涨2%（1.02/1.00 = 1.02） |
| 8月5日 | 1.050 | - | 1.102 | 继续上涨 |

5天累计收益：10.2%（如果不分红再投，只有5%的净值增长 + 0.05元分红 = 10%，差异来自分红再投的复利效应，虽然这里时间短差异很小）。

### 数据来源

- **单位净值**：东方财富基金净值接口（`api.fund.eastmoney.com/f10/lsjz`）返回的 `DWJZ` 字段
- **分红金额**：同一接口返回的 `FHSP` 字段，用正则匹配"每10份派现金X元"，除以10得到每份分红金额
- **其他事件**：分拆、份额折算等不影响财富指数（因为总资产不变，只是份额变化），无需处理

### 注意事项

1. 分红除权日当天的净值已经是扣完分红的，所以公式里要把分红加回去
2. 分拆不影响全收益计算（单位净值变了，但份额同比变化，总资产不变）
3. 基金净值接口返回的是基金公司官方数据，比第三方行情数据更权威
4. 计算结果和全收益指数直接可比，口径一致
