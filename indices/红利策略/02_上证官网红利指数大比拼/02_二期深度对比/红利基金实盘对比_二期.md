# 红利类基金实盘对比（二期）

> 基于基金实际净值，而非指数回溯数据。以华泰柏瑞红利低波ETF（512890）为基准。

## 筛选与排名说明

**分组规则：**
- 5年组：基金成立满5年（约1200个交易日），四维度评分（收益40%、风险30%、效率15%、稳定性15%）
- 2年组：基金成立2-5年，三维度评分（收益50%、风险30%、效率20%，稳定性因数据不足暂不参评）
- 观察池：成立不足2年，仅供参考，不参与排名

**比较基准：** 华泰柏瑞红利低波ETF（512890），当前规模最大的红利类ETF（324亿）。

**分档规则：**
- 第一梯队：总分 ≥ 基准 + 3分（综合显著更优）
- 第二梯队：基准 - 3分 ≤ 总分 < 基准 + 3分（综合接近，各有千秋）
- 第三梯队：总分 < 基准 - 3分（全面落后）
