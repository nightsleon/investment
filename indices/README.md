# 指数与策略研究体系 (Indices & Strategy Research)

本目录为投研体系中聚焦**指数化投资、策略因子回溯、ETF 实盘评价与资产估值监控**的核心模块。

为了兼顾**人类读者浏览**与**大语言模型（LLM）精准上下文检索**，本模块遵循清晰的“**事实底座（Data）— 计算引擎（Code）— 研究成果（Research）**”三层物理分离架构。

### 2. 数据资产治理与真净值计算口径

1. **绝对物理隔离（No Symlinks）**：
   - 严禁设立软链接，全量原始数据集中在 `indices/sources/`；
   - 子专题目录（`01_`、`02_`、`03_`）只保留各自专属的研究报告、专属图表和私有佐证截图，保持结构轻量纯粹。
2. **标准分红再投真净值计算口径**：
   - 严禁使用行情软件直接导出的“前复权价格”或不含分红现金流再投资的“累计净值”计算复合年化收益率；
   - 必须采用现金流再投资标准公式递推生成真净值：
     $$\text{NAV}_{\text{adj}, t} = \text{NAV}_{\text{adj}, t-1} \times \frac{\text{UnitNAV}_t \times \text{SplitRatio}_t + \text{Dividend}_t}{\text{UnitNAV}_{t-1}}$$
   - 其中 $\text{UnitNAV}_t$ 为当日单位净值，$\text{SplitRatio}_t$ 为拆分比例，$\text{Dividend}_t$ 为每份现金派息。

## 四、 大模型与开发者上下文引导 (Agent & LLM Guidelines)

如果大模型或自动化脚本在本项目中执行任务，请严格遵守以下索引与执行规则：

- **核实底层规则时**：直接查阅 `sources/index-methodologies/` 对应指数的官方 PDF，以官方文档为最高准则；
- **评估收益率与回撤时**：调用 `scripts/metrics/metrics.py`，传入基金代码或指数日线路径，禁止自行手写估算逻辑；
- **编写专栏或报告时**：
  - 引用数据相对路径向上穿透至公共底座（如 `../../../sources/index-factsheets/...`）；
  - 图表脚本使用 `BASE.parent.parent / "sources"` 定位公共数据；
  - ETF 第一次出场写“全称 + 代码”，正文后续统称“ETF 简称”。
