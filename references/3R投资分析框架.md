# 3R投资分析简报框架

## 一、框架定位

本框架用于生成一份可独立阅读、快速预览的投资分析简报，只回答三个核心问题：

1. **Right Business：是不是好生意？**
2. **Right People：是不是好管理层？**
3. **Right Price：当前是不是好价格？**

简报不沿用完整投资分析报告的“好行业、好公司·定性、好公司·定量、好时机”章节结构，也不机械压缩完整报告。它以3R为主线，选择对决策最重要的事实、数据和图表，形成独立评分与行动结论。

适用场景：

- 快速预览一家公司的投资价值；
- 从完整投资分析报告生成决策型简报；
- 在不重复完整研究的情况下更新3R判断；
- 为README、公司研究入口或阶段性复盘提供简洁版本。

核心原则：

- 先让读者看懂公司，再进行3R判断；
- 先复用已有报告和本地资料，再补充外部官方资料；
- 只保留影响评分和行动的决定性证据；
- 好公司不等于好价格，公司质量与当前买点必须分开；
- 不因资料缺失而推造数据，无法验证时明确标注并保守评分；
- 简报有独立的3R评分，不直接继承完整报告原有总分。

## 二、3R评分体系

总分100分，按段永平3R顺序设置权重：

| 模块 | 权重 | 核心问题 |
|---|---:|---|
| Right Business | 60 | 这是不是一门能长期创造自由现金流的好生意？ |
| Right People | 20 | 管理层是否值得信任，能否经营好并合理配置资本？ |
| Right Price | 20 | 当前价格是否留有安全边际，赔率是否合适？ |
| **合计** | **100** |  |

### 2.4 评级与3R门槛

| 总分 | 评级 | 含义 |
|---:|---|---|
| ≥85 | 重点候选 | 好生意、好管理层、好价格基本同时成立 |
| 75—84 | 关注 | 整体较好，但至少有一个维度仍需验证 |
| 65—74 | 观察 | 公司质量或当前价格存在明显短板 |
| <65 | 不碰 | 3R至少一项明显不成立 |

总分不能替代3R顺序判断：

- Right Business低于36/60：生意本身不够好，不因低估值买入；
- Right People低于12/20：不适合作为核心持仓，即使价格便宜也应谨慎；
- Right Price低于10/20：好公司但不是好价格，优先等待；
- 若重大治理红线、商业模式不可理解或核心数据无法验证，即使总分较高也应降级。

## 三、简报固定结构

## 3.1 公司概况：这家公司靠什么赚钱？

简报必须先介绍公司基本情况，避免读者在不了解业务的情况下直接进入3R判断。

推荐表格：

| 项目 | 内容 |
|---|---|
| 主营业务 | 公司主要做什么 |
| 核心产品/服务 | 最重要的产品和收入来源 |
| 赚钱方式 | 靠销量、提价、订阅、渠道、规模效率还是服务收费 |
| 客户与场景 | 谁在购买，为什么持续购买 |
| 行业位置 | 龙头、寡头之一、细分冠军或普通参与者 |
| 实际控制人 | 控制权归属 |
| 核心管理层 | 董事长、总经理及主要经营负责人 |
| 数据截止 | 财务、行情和重大事项分别截至什么日期 |

表后用一段直白语言说明：

- 公司向谁提供什么；
- 客户为什么愿意付钱；
- 公司依靠什么获得利润；
- 最关键的经营变量是什么。

公司概况只负责解释“公司是什么”，不提前重复后文的护城河、管理层和估值分析。

## 3.2 3R决策摘要

开头用一张表展示最终判断，便于快速预览：

| 维度 | 得分 | 核心判断 |
|---|---:|---|
| Right Business | /60 | 好生意 / 部分符合 / 不是好生意 |
| Right People | /20 | 好管理层 / 需要观察 / 不适合信任 |
| Right Price | /20 | 好价格 / 合理价格 / 价格偏高 |
| **总分** | **/100** | **当前评级与行动** |

摘要下只保留：

- 一句话结论；
- 当前最大矛盾；
- 最关键的一个验证条件。

## 3.3 Right Business：是不是好生意？

Right Business占60分，是简报主体，采用“评分概览在前、五个微型分析章节在后”的结构。不能用一张评分表代替分析，也不在章节末尾重复总表。

### 3.3.1 Right Business评分概览

先用一句话给出生意质量总判断，再展示五个大维度：

| 维度 | 得分 | 满分 | 核心判断 |
|---|---:|---:|---|
| 业务简单可持续、不易被替代 |  | 14 |  |
| 竞争格局清晰、护城河深厚、有定价权 |  | 18 |  |
| 轻资本投入、高资产回报率、自由现金流好 |  | 14 |  |
| 盈利成长真实、稳定、可持续 |  | 8 |  |
| 有长期增长空间 |  | 6 |  |
| **Right Business** |  | **60** |  |

### 3.3.2 业务简单可持续、不易被替代

分别分析：

- 商业模式：公司向谁提供什么、客户为什么付钱、利润如何形成；
- 需求持续性：底层需求是否长期存在；
- 周期性：需求是否受宏观、库存、价格或出口周期影响；
- 品类替代风险：产品或服务是否可能被其他技术、品类或消费方式替代。

商业模式简单、容易理解同时是评分项和研究门槛；若无法说明公司靠什么赚钱，应停止研究，而不是只做普通扣分。具体公司是否容易被其他供应商替代不在本节重复评分，统一放入护城河。

本节末尾按5/5/2/2拆分得分，并列出每项判断依据。

### 3.3.3 竞争格局清晰、护城河深厚、有定价权

三个问题必须分别分析：

- 竞争格局：行业集中还是分散，低端与中高端是否分层，主要竞争者是谁；
- 公司位置：市场份额、排名和相对规模能否用公开数据验证；缺少行业分母时不得推造份额；
- 护城河：品牌、渠道、技术、规模、成本、客户认证、转换成本、全球服务等壁垒是否真实且可持续；具体公司替代风险在这里判断；
- 定价权：提价、单位收入、量价变化、成本传导和毛利率表现是否支持“有定价权”。

有护城河不等于有定价权。销量增长快于收入、单位收入下降或成本无法转嫁时，定价权必须实质扣分。

本节末尾按4/3/6/5拆分得分。

### 3.3.4 轻资本投入、高资产回报率、自由现金流好

四项分别分析，具体权重保持4/4/2/4：

- 资本投入：历年资本开支、在建工程、产能利用率、新项目投产和回报；不能从ROE直接推断轻资本；
- 资产回报：ROE/ROIC的长期水平和趋势；
- 杜邦质量：净利率、总资产周转率、权益乘数分别如何变化，是否依赖杠杆；
- 现金转化：经营现金流/净利润、自由现金流/净利润，以及近5—6年累计CFO/累计净利润和累计FCF/累计净利润。

重资本不自动等于坏生意，关键是新增投入能否带来高回报和自由现金流。单年经营现金流好也不能掩盖长期资本开支对自由现金流的侵蚀。

优先复用ROE与杜邦趋势图，以及净利润、经营现金流和自由现金流图。本节末尾按4/4/2/4拆分得分。

### 3.3.5 盈利成长真实、稳定、可持续

分别分析：

- 3年、5年扣非利润增长，CAGR年数必须正确并注明低基数；
- 年度增长是否稳定，还是集中在少数年份；
- 增长来自收入、销量、提价、份额、产品结构和效率，还是并购、补贴或一次性收益；
- 最新年度、季度和TTM利润趋势；
- 利润增长是否与经营现金流和自由现金流匹配。

优先复用扣非利润趋势与同比图。本节末尾按2/1/2/2/1拆分得分。

### 3.3.6 有长期增长空间

分别分析：

- 核心业务和行业是否仍有增长空间；
- 公司能否继续提升市场份额；
- 地域扩张、产品升级和第二曲线是否已经形成实际收入与利润；
- 增长所需再投资能否改善资产周转、ROIC和自由现金流。

未来故事不能代替历史兑现。只有收入、利润、资本回报和自由现金流能够同步改善，长期空间才有高质量。

本节末尾按2/2/1/1拆分得分。

判断纪律：

- 区分“品类不易替代”和“具体公司不易替代”：前者归入业务持续性，后者归入护城河，避免重复评分；
- 竞争格局、护城河和定价权分别验证，不能互相代替；
- “经营现金流好”不能代替轻资本、高回报和自由现金流的完整判断；
- 重资本公司应明确写“不符合轻资本”，再判断投入回报是否仍可接受；
- 盈利成长重点验证3年/5年扣非利润增长、增长稳定性、增长来源及经营现金流和自由现金流是否同步；
- 低基数、并购并表、补贴、资产处置和投资收益带来的增长不能直接视为高质量成长；
- 区分“已经实现的盈利成长”和“未来长期增长空间”，不能用未来故事代替历史兑现；
- 增长必须结合资本回报和现金流，低回报扩张不等于创造价值。

## 3.4 Right People：是不是好管理层？

固定使用三项评分：

| 维度 | 判断 | 决定性证据 | 得分 |
|---|---|---|---:|
| 诚信与治理 | 符合/部分符合/不符合 | 1—2项证据 | /6 |
| 专注与经营能力 |  |  | /7 |
| 资本配置与股东利益 |  |  | /7 |
| **Right People** |  |  | **/20** |

重点分析：

- 实际控制人与经营管理层是否清晰；
- 是否长期专注主业；
- 面对行业逆风时是否保持经营纪律；
- 分红、回购、扩产、并购和新业务投入是否合理；
- 是否存在高质押、大比例减持、重大关联交易或损害中小股东利益的问题。

不写冗长履历，只保留影响股东长期回报的事实。表后用一段话给管理层定性。

## 3.5 Right Price：当前是不是好价格？

固定使用四项评分：

| 维度 | 判断 | 决定性证据 | 得分 |
|---|---|---|---:|
| 利润位置与股价利润匹配度 | 好/一般/差 | 1—2项证据 | /5 |
| 当前估值与历史位置 |  |  | /6 |
| 股息及持有回报 |  |  | /3 |
| 保守/中性情景与赔率 |  |  | /6 |
| **Right Price** |  |  | **/20** |

优先引用原报告已有的：

- 股价vs扣非TTM利润图；
- 当前PE、历史分位、现金头寸和扣现金后PE；
- 股息率、派息率和自由现金流覆盖；
- 保守/中性情景估值表。

Right Price默认只保留股价vs利润图。PE及历史分位用紧凑数据表表达，不默认再放PE历史区间图。

判断顺序：

1. 先判断当前利润处于正常期、高点、低点、修复期还是下滑期；
2. 再看股价与利润趋势是否匹配；
3. 再看当前估值、历史分位和现金安全垫；
4. 最后用保守/中性情景判断赔率。

估值低不能自动等于好价格。如果利润仍在快速下滑、历史分位失真或保守情景下行明显，应降低Right Price得分。

## 3.6 最终行动

结尾不重复3R分析，只回答三个问题：

### 现在怎么办？

给出当前行动：重点候选、分批验证、纳入观察池、等待价格或不碰。

### 什么情况下提高关注？

列出不超过3个确认条件，例如利润止跌、自由现金流改善、产能利用率提升、第二曲线兑现或估值仍处合理区间。

### 什么情况下说明判断错了？

列出不超过3组证伪条件，优先关注：

- 核心产品或市场份额持续恶化；
- 利润池、经营现金流或自由现金流持续恶化；
- 扩产、并购或第二曲线投入无法兑现；
- 管理层、治理或资本配置出现重大问题；
- 价格上涨后安全边际消失。

## 四、数据与图表使用优先级

采用“先复用、后补缺”的顺序。

### 4.1 第一优先级：完整投资分析报告

先读取指定的完整投资分析报告，盘点已经存在的：

- 公司画像和商业模式；
- 产品结构与增长来源；
- ROE、杜邦、现金流和资产负债数据；
- 管理层、治理和资本配置事实；
- 股价vs利润图、PE图和情景估值；
- 风险、证伪条件和待验证事项；
- 已生成图表及其路径。

已有内容能够支持3R评分时直接引用，不重新抓取和统计数据。

简报不直接继承原报告旧总分。必须根据3R的新维度和权重重新评分，但每项评分证据应能在原报告中找到。

### 4.2 第二优先级：当前公司目录下的本地资料

原报告缺少某项3R证据时，再读取：

```text
{公司}/
  年报/
  data/
  charts/
  reports/
```

优先顺序：

1. `年报/`中的PDF；
2. `data/`中的源数据表、计算底稿和来源台账；
3. `charts/`中的已有图表；
4. 公司专用脚本已经生成的结果。

本阶段只补齐缺失证据，不重新完成整套投资分析。

### 4.3 第三优先级：公司官网及官方公告

前两级仍无法满足评分需要时，再检索：

- 公司投资者关系官网；
- 交易所公告；
- 巨潮资讯；
- 港交所披露易；
- 正式年度报告、季度报告；
- 分红、回购、减持、质押、并购和重大投资公告。

外部检索只围绕缺失的3R证据展开，不扩展成新的完整行业研究。

### 4.4 第四优先级：下载缺失年报PDF

如果本地缺少必要年报或附注，再从官方来源下载PDF，并记录：

- 报告年度；
- 公告日期；
- 官方URL；
- 本地文件名；
- 用于支持哪个3R维度。

### 4.5 读取顺序与权威性

分析读取顺序是：

```text
投资分析报告 → 本地年报/data/charts → 外部官方资料
```

发生数据冲突时，事实权威性顺序是：

```text
官方年报/公告 > 本地保存的官方PDF > 原投资分析报告 > 结构化或二手数据
```

如果补充核对发现原报告数据有误，简报应采用官方口径并标注修正，不能因为“优先复用原报告”而继续沿用错误数据。

## 五、价格数据时效规则

Right Business和Right People变化较慢，可以优先复用原报告数据。

Right Price变化较快，必须区分：

### 5.1 与原报告同一时点生成

直接使用原报告中的股价、市值、PE、历史分位、股息率和情景估值。

### 5.2 距离原报告已经较久

二选一：

1. 刷新当前行情和估值，再称“当前价格”；
2. 不刷新，但必须称为“报告基准日价格”，不能冒充当前价格。

刷新价格后，只重新评价Right Price；除非出现新的财报或重大事项，不重复分析Right Business和Right People。

## 六、图表与可读性规则

### 6.1 图表使用顺序

1. 优先引用原报告已嵌入图表；
2. 其次引用公司`charts/`目录已有图表；
3. 本地有数据但缺少必要图表时，才生成新图；
4. 本地也缺少数据时，才查官方资料补充；
5. 不重复生成与原图表达相同的图。

每张图注明数据截止日期和来源，并说明是原报告已有图还是本次补充生成。

### 6.2 图表数量

整份简报默认使用4张核心图：

- Right Business三张：ROE与杜邦趋势图、扣非利润趋势图、净利润/经营现金流/自由现金流图；
- Right Price一张：股价vs扣非TTM利润图。

如果原报告缺少对应图表，先检查`charts/`和本地数据；只有该图确实影响判断时才补充生成。若公司最大矛盾是产品结构、资本开支或产能利用率，可以替换Right Business中的默认图，不为形式强行保留固定图表。PE历史区间默认用表格，不占用图表名额。

### 6.3 表达顺序

Right Business统一采用：

```text
一句话判断 → 五维度评分概览 → 五个微型分析章节 → 决定性证据/图表 → 每节具体指标评分拆解
```

Right People和Right Price继续采用：

```text
一句话判断 → 评分表 → 决定性证据/图表 → 一段综合结论
```

正文标题可以直接带结论，例如：

- Right Business：好生意，但资本投入偏重；
- Right People：经营能力较强，资本配置仍需验证；
- Right Price：估值合理，赔率暂时一般。

图表标题保持中性，判断放在正文中。

### 6.4 信息控制

- 每个具体评分指标最多保留2项决定性证据；
- 不复制完整六年财务表；
- 同一事实只在最相关的3R模块展开一次；
- 最终行动不超过3条；
- 提高关注条件不超过3条；
- 证伪条件不超过3组；
- 不设置机械字数限制，以完整回答3R问题为准。

## 七、评分纪律

| 证据状态 | 评分处理 |
|---|---|
| 原报告已有充分证据 | 正常评分 |
| 本地年报/data补齐 | 正常评分，注明补充来源 |
| 官方资料补齐 | 正常评分，注明新核验 |
| 仍然无法验证 | 标注“待验证”，不得给满分 |
| 关键数据冲突 | 采用官方口径，必要时暂缓评分 |

具体指标采用证据驱动的分档评分：

| 得分比例 | 含义 |
|---:|---|
| 90%—100% | 充分符合，证据完整且趋势稳定 |
| 70%—89% | 基本符合，存在少量短板 |
| 50%—69% | 部分符合，正负证据并存 |
| 25%—49% | 明显偏弱，主要证据不支持 |
| 0%—24% | 不符合或触发重大风险 |

其他纪律：

- 最小评分单位为0.5分；每个大维度的得分必须由具体指标逐项加总，不能直接凭整体印象给分；
- Right Business在章节开头展示五维度评分概览，每个微型分析章节末尾展示具体指标、判断依据和得分；
- 评分必须让风险真正进入分数，不能只在文字中提示；
- 正面和负面证据同时存在时，使用“部分符合”，不强行二选一；
- 同一证据原则上只归入一个主要评分指标，避免重复加分或扣分；
- Right Business、Right People、Right Price各子项之和必须等于模块小计；
- 三个模块小计之和必须等于总分；
- 评级若因重大红线或证伪条件降档，必须写明原因；
- 简报结论与原报告出现差异时，必须说明差异来自新评分体系、补充证据还是数据更新。
