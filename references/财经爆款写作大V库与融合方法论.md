## 一、 大V经典代表作与核心手艺档案库

### A. 大众传播爆款派（传播心理学与情绪力学）

#### 1. 洞见 / 十点读书体系
* **定位**：中年、中产、家庭客群的精神按摩与情绪自愈工厂。
* **经典代表作**：
  * 《别再逼孩子运动了！哈佛大学研究发现：孩子最缺的不是篮球、游泳，而是“疯跑、打滚、爬树”等无序运动》
  * 《层次越低的人，越喜欢讲大道理》
  * 《人到中年，最好的活法：富养自己》
  * 《真正的高手，早已戒掉了情绪》
* **核心手艺拆解**：
  * **反常识立意（心理卸责）**：颠覆读者的常识认知，为读者的焦虑、疲惫或无力感提供“特赦令”。
  * **身边人生活化对照**：用“表姐报班失败”对比“隔壁小男孩放养松弛”，30 秒内唤醒强烈代入感。
  * **极低门槛三步清单**：把复杂问题简化为“做好三件事”，给读者即时的虚幻掌控感与安慰剂。
  * **金句旷野升华**：结尾脱离具体事件，升华为人性哲思（如“从轨道奔向旷野”），赋予社交货币属性。

#### 2. 粥左罗
* **定位**：职场跃迁、认知变现、底层逻辑拆解的知识干货标杆。
* **经典代表作**：
  * 《我年薪百万，但我不买房》
  * 《为什么大多数人一辈子只能赚小钱？》
  * 《所有厉害的人，都具备这3种底层能力》
  * 《成年人的世界，没有“容易”二字》
* **核心手艺拆解**：
  * **价值观极端化站队**：用反常规的极端主张（如“年轻时不攒钱”、“年薪百万不买房”）引爆舆论争议。
  * **真实数字刺激**：高频使用具象金额与时间跨度（“3年、从月薪2300到年入百万”），增强代入感。
  * **高度模块化干货体**：严格遵循“提出概念 $\rightarrow$ 拆解底层逻辑 $\rightarrow$ 输出实操步骤”，逻辑极其工整，易读性强。

#### 3. 六神磊磊（六神磊磊读金庸）
* **定位**：借古典文学与金庸武侠江湖，透视现代职场、社会百态与人情世故。
* **经典代表作**：
  * 《猛人杜甫：一个小号的逆袭》
  * 《金庸江湖里的底层打工人》
  * 《那些在群里沉默的人》
  * 《岳不群的公关危机》
* **核心手艺拆解**：
  * **古典壳子装现代内核（降维隐喻）**：将人人皆知的文化符号映射为当代生活，形成极大的喜剧张力与共情。
  * **戏谑温和的讽喻**：用诙谐口吻道破普通人的心酸与无奈，具有极高的文化格调与传播安全垫。

#### 4. 咪蒙 / 情绪极化派
* **定位**：极致痛点洞察、情绪宣泄与爽文体验。
* **经典代表作**：
  * 《致贱人：我凭什么要帮你？！》
  * 《致low逼：不是我喜欢装逼，是你们见识太少》
* **核心手艺拆解**：
  * **情绪二元对立**：非黑即白，迅速划定“敌人”与“盟友”，让受众在阅读中获得替代性的复仇快感。
  * **口语化极短句**：语速极快，高密度感叹号与口语化修辞，直接刺激多巴胺。

### B. 严肃商业财经派（商业穿透与买方投研）

#### 1. 晚点 LatePost（管艺雯、宋玮团队）
* **定位**：中国顶尖商业非虚构特稿、商业巨头微观战略与组织观察。
* **经典代表作**：
  * 《字节跳动的扩张与边界》
  * 《美团王兴的关键抉择》
  * 《拼多多这一年：在深水区寻找确定性》
* **核心手艺拆解**：
  * **穿透数字看“人与组织”**：不单看财务数字，而是穿透到商业战略、CEO 心智认知与一线组织执行力。
  * **切口极小、立意极深**：以一次具体战役或人事变动切入，抽丝剥茧还原整个公司的底层商业飞轮。
  * **克制精准的白描**：杜绝空洞赞美与情绪化用词，只用事实细节、业务数据与核心人物原话驱动叙事。

#### 2. 表外表里
* **定位**：中概股、科技互联网、消费赛道深度财务与商业模型拆解。
* **经典代表作**：
  * 《美团的边界到底在哪里？》
  * 《泡泡玛特的全球化野心与暗礁》
  * 《拼多多到底赚的是谁的钱？》
* **核心手艺拆解**：
  * **核心假设检验法**：提炼市场当前最大分歧与核心假设，用财报与运营数据逐一验证。
  * **单位经济模型（UE）穿透**：把大而化之的概念拆解为单店收入、获客成本（CAC）、生命周期价值（LTV）等硬指标。
  * **反直觉悖论推进**：从“营收高增为何股价大跌”、“利润翻倍为何市场担忧”等反直觉问题层层推进。

#### 3. 远川投资评论（饭统戴老板体系）
* **定位**：宏观产业周期、商业历史大变局、地缘与实业非虚构特稿。
* **经典代表作**：
  * 《中国芯酸往事》
  * 《白酒的黄金时代》
  * 《光伏大败局》
  * 《腾讯的隐形长子》
* **核心手艺拆解**：
  * **电影蒙太奇镜头**：以带有画面感的历史关键瞬间开篇，将宏观周期与微观人物命运交叉剪辑。
  * **5-10年宏观产业周期透视**：跳出单季度财报，从技术演进、政策周期与行业出清角度看商业终局。
  * **通俗的生活化比喻**：将高深的产业技术参数转化为老百姓听得懂的生活意象。

#### 4. 唐朝（雪球大V）
* **定位**：长线个人价值投资、老老实实读财报与安全边际实战。
* **经典代表作**：
  * 《手把手教你读财报》系列
  * 对贵州茅台、腾讯控股、海康威视的长达数年的定期财报跟踪长文
* **核心手艺拆解**：
  * **防守优先的排雷原则**：先讲公司怎么死、怎么造假，排除毁灭性风险后再看盈利。
  * **会计科目的人性化翻译**：把“预收款/合同负债”翻译为“无息霸占下游的钱”，把“应收账款”翻译为“打了欠条的假富贵”。
  * **常识化保守估值**：拒绝复杂的黑箱贴现模型，基于“老老实实折现、三年翻倍/保本、给足安全边际”的常识推导。

#### 5. 韭圈儿（北落的师门） & 望京博格
* **定位**：指数基金、ETF、红利策略与全天候资产配置实操。
* **经典代表作**：
  * 《为什么红利低波能躺平穿越牛熊？》
  * 《如何挑选一只真正能防守的红利 ETF？》
  * 《全天候组合的底层逻辑》
* **核心手艺拆解**：
  * **底层编制规则穿透**：剖析指数的成分股筛选、加权机制、调仓频率与行业偏离度，而非单纯比拼收益率。
  * **产品横向 1v1 擂台 PK**：设立统一标尺（跟踪误差、超额收益、夏普比率、持仓重合度），多场景压力测试。
  * **拟人化表达**：将红利比喻为“收租金的包租婆”，将成长风格比喻为“冲锋的少年”，形象生动。

## 二、 底层相通性与深度融合方法论

### 1. 概念映射矩阵：从大众爆款到严肃财经

大众爆款的心理抓手与严肃财经的买方逻辑，在底层是完全相通的映射关系：

| 大众爆款工具箱（传播力） | 严肃财经/投资映射（专业度） | 融合后的实战落地（降维打击） |
| :--- | :--- | :--- |
| **反常识立意（心理卸责）** | **预期差 / 逆向投资思维** | 绝不随波逐流复述市场共识；挖掘被市场忽视的隐蔽变量或被恐慌错杀的安全边际。 |
| **身边人生活化案例** | **生活常识与一线观察** | 从日常生活、身边消费、渠道走访切入，作为切开宏大商业模式的第一把手术刀。 |
| **极端危机（恐惧营销）** | **致命陷阱 / 排雷前置** | 严格贯彻“防守优先”，先讲清本金永久损失的风险点，把商业模式的硬伤作为一票否决项。 |
| **学术概念 / 权威背书** | **硬核财务穿透与机制推导** | 不借名校空头衔，而是用真实的资产负债表健康度、自由现金流造血能力与护城河机制说话。 |
| **极简三步法清单** | **清晰的 3R 决策卡片** | 拒绝模棱两可的套话，直接给出好生意、好管理层、好价格的三维独立结论与打分。 |
| **旷野升华金句** | **投资哲学与心性自律** | 从具体的数字计算，升华为长期主义复利观、胜率与赔率的博弈思维、知行合一的心态。 |

### 2. 融合后的“五步推进黄金骨架”

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 预期差引入 (反常识切入 + 市场核心分歧)                    │
│    └─ 抛出反直觉悖论，用生动的一线常识拉开序幕              │
├─────────────────────────────────────────────────────────────┤
│ 2. 致命陷阱排雷 (危机感前置 + 买方防守视角)                  │
│    └─ 先讲怎么亏钱，排查造假、压货、高估与商业不可持续性    │
├─────────────────────────────────────────────────────────────┤
│ 3. 硬核机制穿透 (商业模式解构 + 说人话翻译)                  │
│    └─ 穿透好生意底层壁垒、管理层组织力，用生活比喻讲清财务  │
├─────────────────────────────────────────────────────────────┤
│ 4. 极简决策卡片 (3R评分 + 三档情景估值)                      │
│    └─ 悲观/中性/乐观明确假设，给出明确买入区间与证伪边界    │
├─────────────────────────────────────────────────────────────┤
│ 5. 哲学升华收尾 (心性金句 + 合规风险提示)                    │
│    └─ 提炼长线认知金句，附带固定的互动引导与免责声明        │
└─────────────────────────────────────────────────────────────┘
```

#### 第一步：预期差引入（制造认知冲突与阅读张力）
* **目标**：在 15 秒内抓住读者，打破市场同质化论调。
* **执行**：
  * 抛出一个令读者费解的**“商业悖论”**或**“价格与价值背离”**的现象；
  * 引入一个**极具生活体感的一线细节**（消费者行为、渠道商现状、身边的真实痛点）。
* **标题句式示例**：
  * 《净利润连续三年翻倍，为何我劝你警惕这家“牛股”？》
  * 《都在抢买红利低波，但你真的看懂它的防御底牌了吗？》

#### 第二步：致命陷阱排雷（防守前置与危机感塑造）
* **目标**：建立买方严肃防守壁垒，避免投资者踩中“价值陷阱”。
* **执行**：
  * 先排雷，后谈收益：检查应收账款恶化、存货积压、关联交易、现金流背离；
  * 指出**“市场最担心的那只靴子究竟何时会落地”**。

#### 第三步：硬核机制穿透（严密投研 + 通俗表达）
* **目标**：提供无可辩驳的事实深度，同时保证 0 门槛阅读流畅感。
* **执行**：
  * **好生意（商业模式）**：讲清定价权与护城河，回答“它凭什么能多赚钱、凭什么能不赊账、别人为什么抄不走”；
  * **好团队（管理层）**：看关键抉择是做大蛋糕还是掏空上市公司，看激励与股东是否同向；
  * **说人话的财务翻译**：用“菜市场账本”解构三张表，绝不堆砌无解释的金融行话。

#### 第四步：极简决策卡片（清晰定性 + 情景化估值）
* **目标**：给读者输出极高决策价值的确定性框架。
* **执行**：
  * 输出 **3R 独立评分卡**（好生意、好管理层、好价格）；
  * 输出 **三档情景化估值**（悲观、中性、乐观），明确说明核心假设何时会被证伪。

#### 第五步：哲学升华与合规收口（建立人设与社交货币）
* **目标**：引发朋友圈与社群高频转发，同时遵守合规底线。
* **执行**：
  * 提炼 1~2 句关于时间、复利、周期与人性克制的投资哲学金句；
  * 文末严格附带固定的互动引导与合规风险提示。

### 3. 融合取舍红黑榜：吸收与剔除

| 维度 | **红榜：坚决吸纳的精髓** | **黑榜：坚决剔除的毒药** |
| :--- | :--- | :--- |
| **立意与选题** | 找真实存在的预期差、打破人云亦云的刻板印象 | 虚假承诺、耸人听闻、炒作小道消息代码 |
| **论据与事实** | 官方财报穿透、可溯源的数据、扎实的一线调研 | **移花接木、伪造专家/名校背书、编造故事** |
| **叙事逻辑** | 环环相扣、单段短促、视觉动词白描、节奏明朗 | 纯情绪宣泄、毫无推导过程的二元拉踩 |
| **结论呈现** | 概率思维、情景估值、给出清晰边界与证伪条件 | 给出唯一确定的绝对目标价、宣扬包赚不赔 |
| **文风语态** | 克制、理性、真诚，充满对常识和周期的敬畏 | 爹味教条、排比口号堆砌（“扬帆起航”等AI腔） |

## 三、 未来 Skill 转化蓝图（Skill Blueprint）

> 本模块为后续创建或升级专属写作 Skill（如 `stock-investment-article` 升级版）提供核心逻辑输入与执行规范。

### 1. Skill 核心定位与处理流程
* **Skill 触发场景**：输入一份个股 3R 投资简报、完整投资报告或指数研究数据，将其改写为雪球、知乎、微信等平台的高传播力投资文章。
* **转化处理流水线**：
  1. `Input Ingestion`：提取原报告中的核心事实、财报数据、3R 评分与估值区间。
  2. `Paradox Extraction`：定位市场核心分歧，提炼出 1 个反直觉的“预期差抓手”。
  3. `Tone & Rhythm Shift`：将券商研报语气翻译为“第一读者视角的大白话与动词白描”。
  4. `Structural Assembly`：按五步黄金骨架装配全文。
  5. `Ending & QA Gate`：强制校验文末免责声明与去除 AI 腔。

---

### 2. 五大核心执行模块设计

#### 模块一：标题生成引擎（5 种爆款标题公式）
1. **反直觉反思型**：《业绩连创新高，为何我却劝你警惕这家白马股？》
2. **底层本质穿透型**：《都在抢买红利低波，但你真的看懂它的防御底牌了吗？》
3. **数字冲突对比型**：《从估值 80 倍到跌破净资产：这家行业龙头到底做错了什么？》
4. **终极拷问型**：《三年跌去 60%，它到底是价值陷阱，还是被错杀的金子？》
5. **常识归纳型**：《看懂这家公司的财报，只需要看透这一个核心数字》

#### 模块四：三档情景估值可解释性规范
禁止单点预测，强制以“假设 $\rightarrow$ 结果 $\rightarrow$ 证伪”三步呈现：
* **悲观情景**：若核心假设破裂，业绩停滞，合理市值/价格为多少（安全底线）；
* **中性情景**：按现有逻辑稳步推进，合理市值/价格为多少（基准收益）；
* **乐观情景**：若超预期催化落地，合理市值/价格为多少（上行弹性）；
* **证伪红线**：一旦发生哪些业务事件，即证明当前投资逻辑彻底失效，必须离场。
