# 投资分析文章写作框架

## 一、框架定位

本框架用于把已经完成的完整投资分析报告、3R投资分析简报和配套图表，改写为适合雪球、知乎等平台发布的公司投资分析文章。

文章不是把研报删短，也不是重新研究公司。三类材料职责不同：

- 完整投资报告是证据仓库，提供业务、财务、治理、估值、表格和图表；
- 3R投资简报是决策出口，提供评分、评级、行动、核心矛盾和证伪条件；
- 平台文章围绕一个核心矛盾重新组织证据，让读者看懂为什么得出这个判断。

文章要达到四个目标：

1. 有结构：读者知道每一部分在回答什么；
2. 有故事：全文围绕一个核心矛盾推进；
3. 有观点：明确判断实际经营大概率好于还是差于市场预期；
4. 有边界：区分事实、估算、判断、投资价值和仓位条件。

参考案例：`600809_山西汾酒/reports/山西汾酒_投资分析文章_2026-07-29.md`。

---

## 二、材料与决策源

同时存在完整报告和3R简报时：

1. 评分、评级、行动和方向性结论，以用户指定或最新锁定的3R简报为唯一来源；
2. 完整报告只补充数据、事实、表格和图表；
3. 不混用完整报告旧分和3R新分；
4. 数据冲突先核对报告期、行情基准日和口径；
5. 公开文章不写盲评、锁分、评估器数量、旧分差异和内部裁决过程。

文章文末使用：

```markdown
本文参考[《文章名》](URL)。
```

不写“改写自”。文末只保留读者需要的数据截止时间、未验证事项和口径边界。

## 三、五个选股问题

### 3.1 能不能看得懂

业务简单、盈利模式清楚，未来自由现金流才有一定可预测性。公司的价值本质上是未来自由现金流的折现；如果看不清公司靠什么赚钱、现金流由什么驱动，估值就没有可靠基础。

重点回答：

- 公司卖什么，谁付钱；
- 真正的利润池在哪里；
- 收入、成本、利润和现金流由什么驱动；
- 为什么未来自由现金流可以大致预测。

### 3.2 能不能活得久

需求、产品和品类不易被替代，长期投资才有复利基础。只有活得久，增长、估值和长期持有才有意义。

重点回答：

- 需求和消费场景能否长期存在；
- 产品或品类会不会被技术、习惯或监管替代；
- 行业总量扩张、稳定还是收缩；
- 公司未来靠行业扩容、份额、提价、产品结构、地域还是新业务增长；
- 历史高增长是否受低基数和高速扩张期影响。

原“未来增长从哪里来”并入本节，不再单设泛泛的“增长空间”。

### 3.3 利润能不能守得住

行业竞争要“月朗星稀”，避免价格战、重复扩产和无利润跑马圈地。公司还要有品牌、技术、成本、规模、网络、渠道、牌照或垄断资源等护城河，让竞争者难以抢走客户和利润。

重点回答：

- 行业是否集中，竞争是否理性；
- 护城河来自哪里；
- 什么事实证明竞争者难复制；
- 护城河是否转化为复购、份额、毛利、回款和现金流；
- 公司能否提价或传导成本；
- 监管、价格管制和强势客户是否限制定价权。

必须区分：

- 品类不易替代，决定公司能不能活得久；
- 公司护城河，决定利润会不会被同行抢走；
- 定价权，决定公司能否把优势转化为更高经济回报。

护城河不等于定价权。受监管的垄断企业可能壁垒很深，却不能自由提价。

### 3.4 能不能高效复利

轻资本的三项核心价值：增长成本低、复利效率高、下行风险较小。

#### 增长成本低

比较资本开支与经营现金流、净利润。判断维持和增长业务需要投入多少钱，利润是否容易被新增投入吞噬。

#### 复利效率高

看ROE/ROIC及历史趋势，再用杜邦分析净利率、周转率和杠杆。高ROE如果主要来自加杠杆，不能证明高效复利。

#### 下行风险较小

看自由现金流、负债、固定成本、闲置产能和现金头寸。上行期轻资本提高复利效率；下行期低固定投入、低债务和现金储备提高生存能力。

正文顺序：

```text
资本开支与经营现金流/利润对比
→ ROE/ROIC与杜邦
→ 自由现金流、分红、负债和现金头寸
```

### 3.5 当前价格买得值不值

市场预期增长已经反映在当前股价中。增长陷阱的核心不是买增长，而是比较实际增长与市场预期增长：

> 只有实际增长超过当前股价所隐含的市场预期增长，投资者才容易获得好的回报；如果实际增长低于预期，即使公司仍然高速增长，回报也可能很差。

重点回答：

- 市场按高增长、低增长还是衰退型资产定价；
- 实际经营大概率好于还是差于这一预期；
- 股价与利润经历了估值扩张、估值压缩还是利润下修；
- 当前回报需要多高增长才能兑现；
- 股息、回购、现金和估值变化分别贡献什么。

前四问判断公司值不值得长期持有，第五问判断当前价格值不值得买。

## 四、文章结构

固定结构：

1. 标题与数据范围；
2. 我的选股框架；
3. 公司一句话判断与3R评级；
4. 决定性数字和核心矛盾；
5. 一、能不能看得懂；
6. 二、能不能活得久；
7. 三、利润能不能守得住；
8. 四、能不能高效复利；
9. 五、当前价格买得值不值；
10. 六、五个问题的答案、3R评分、行动与证伪；
11. 数据与口径说明。

标题直接写判断，不使用“行业分析”“财务分析”等研报式标题。

## 五、开头模板

```markdown
# {公司}：{估值或价格事实}，但{核心经营问题}

> 数据范围：行情截至{日期}，财务截至{报告期}，年度数据截至{年报期}。本文仅供学习研究，不构成投资建议。

**我的选股框架**：我先问五个问题。第一，能不能看得懂……第二，能不能活得久……第三，利润能不能守得住……第四，能不能高效复利……第五，当前价格买得值不值……前四问判断公司值不值得长期持有，第五问判断当前价格值不值得买。

> **{公司}的一句话判断｜3R综合评级：{字母}（{分数}/100，{行动}）**：按五个问题看，{五关答案和决定性证据}；{预期差方向}。但{最新经营压力}，{投资价值判断}，{仓位条件}。

{决定性经营数字。}

{报告基准日估值、股息或现金安全垫。}

{一句话说明最大矛盾、当前行动和验证条件。}
```

框架段解释“为什么看”，公司一句话给“这家公司答案”。两段分开，不揉成一个巨句。

## 六、3R字母评级

| 3R总分 | 字母评级 | 含义 |
|---:|---|---|
| 90—100 | A+ | 三个R均突出，重大短板很少 |
| 80—89.9 | A | 高质量候选，强烈关注 |
| 75—79.9 | B+ | 基本面较好，关键问题待验证 |
| 70—74.9 | B | 优点明确、短板明显，以观察为主 |
| 60—69.9 | C | 公司质量或价格存在明显不足 |
| 60以下 | D | 暂不投入研究精力 |

字母评级由3R总分机械映射。若门槛或重大红线导致降级，必须说明原因。

公开文章引用总分时，必须保留分项、权重和核心判断：

```markdown

|---|---:|---:|---|
| Right Business |  | 60 |  |
| Right People |  | 20 |  |
| Right Price |  | 20 |  |
| 合计 |  | 100 |  |
```

## 七、情景估值

### 7.1 PE估值与现金流折现的关系

公司的价值最终来自未来自由现金流。平台文章为了直观比较不同预期，可以不用完整现金流折现，而采用“未来利润×期末PE”做简化情景估算，但要明确它只是估值近似。

### 7.2 计算公式

```text
未来利润 = 当前利润 × (1 + 增长率)^年数
期末市值 = 未来利润 × 期末PE
价格回报 = 期末市值 ÷ 当前市值 - 1
累计总回报 ≈ 价格回报 + 静态股息率 × 年数
```

### 7.3 表格模板

```markdown
| 情景 | 未来利润公式 | 期末PE | 期末市值 | 价格回报 | 累计静态分红 | 累计总回报 |
|---|---:|---:|---:|---:|---:|---:|
| 中性 |  |  |  |  |  |  |
| 保守 |  |  |  |  |  |  |
```

表后用一句话解释：先估未来利润，再乘期末PE得到未来市值，最后加入持有期间的分红。

必须说明：

- 静态股息率乘年数只是粗略估算；
- 未考虑未来分红变化、税费和分红再投资；
- 情景用于比较赔率，不是精确预测；
- 使用利润×PE时不机械加回全部现金，避免现金价值重复计算。

## 八、图表与篇幅

优先复用四类图：

1. 利润趋势与增速；
2. ROE与杜邦三因子；
3. 净利润、经营现金流和自由现金流；
4. 股价与TTM利润。

每张图紧跟相关分析，不把多张图堆在一起。产品结构、现金头寸和营运质量只有在改变主线判断时才加图。

正文通常2500—3900个汉字。完整五问框架会增加篇幅，可以适度超过3600字，但不能变成5000字以上的压缩研报。新增方法论后，要删除开头、估值和结尾中的重复判断。

## 九、写作与去AI味

文章要像一个人在做判断，而不是机器在拼装报告。

- 保留明确的“我认为”，不写两面都对的空话；
- 用具体数字和数字之间的关系代替泛泛形容；
- 少用“这意味着、总体来看、核心在于”等套话；
- 不写“下面开始分析、计算逻辑并不复杂”等元话语；
- 不堆加粗、emoji、破折号和整齐口号；
- 不为了结构强行凑三点；
- 同一个数字或结论不要重复三次以上；
- 结尾直接给行动和证伪条件，不重复全文，也不写“未来可期”。

专业术语可以保留，但第一次出现要用一句话解释。事实、推断和观点要能区分，无法确认的事项写“待验证”。

## 十、常见矛盾与统一方法

| 主题 | 常见矛盾 | 统一方法 |
|---|---|---|
| 五问用词 | 看懂/看得懂、守住/守得住混用 | 全文统一标题用词 |
| 评级 | B+、关注、强烈关注并存 | 以3R映射和门槛为准 |
| 价值与仓位 | 有投资价值又写完全不能买 | 区分关注、分批验证和重仓 |
| 定价权 | 长期存在、短期失效混写 | 明确长期能力与短期压力 |
| 增长 | 未来低增却套历史高CAGR | 历史与未来分开 |
| 市场预期 | 一会儿过度悲观，一会儿两面列举 | 给出唯一基准判断 |
| 现金 | 年报确认值与季报估算值混用 | 正文优先确认值 |
| 分红 | FCF低于分红却写完全覆盖 | 写接近覆盖并核算 |
| 行情 | 历史基准价写成实时价格 | 全文使用“报告基准日” |
| 估值 | 开头讲现金流折现，后文突然只用PE | 增加简化估值桥接 |
| 来源 | 公开文章写旧分、盲评和锁分过程 | 只保留参考链接和数据边界 |

## 十一、执行流程

1. 读取3R简报、完整报告、图表和现有文章；
2. 锁定评分、评级和行动的唯一来源；
3. 完成故事卡；
4. 按“五问 + 行动”列提纲；
5. 将完整报告证据重新分配到五个问题，不按原章节机械删减；
6. 写初稿并嵌入决定性图表；
7. 删除重复观点，做去AI味处理；
8. 做矛盾审计和数据校验；
9. 验证图片、参考链接和Markdown；
10. 只修改用户明确确认的文件。

用户说“仅讨论”“先讨论”时，不修改文件；用户确认后，仅修改已确认范围。

## 十二、发布前检查

- [ ] 开头先讲五问框架，再给公司一句话答案；
- [ ] 全文只有一个核心矛盾和一个基准判断；
- [ ] 五个问题的用词前后一致；
- [ ] 评分、评级和行动来自同一决策源；
- [ ] 投资价值与重仓条件没有混写；
- [ ] 长期护城河、长期定价权与短期压力分开；
- [ ] 增长陷阱落到当前股价隐含的市场预期；
- [ ] 情景估值过程可看懂、可重算；
- [ ] 数据截止时间和估值口径一致；
- [ ] 估算现金与确认现金没有混用；
- [ ] FCF低于分红时没有写“完全覆盖”；
- [ ] 图片和参考链接有效；
- [ ] 文章没有明显AI腔和重复结论；
- [ ] `git diff --check`通过。
