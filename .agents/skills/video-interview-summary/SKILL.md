# 视频访谈与商业演讲深度整理 (Video Interview Summary)

将商业领袖访谈、路演演讲、财经对话等视频/音频，提炼为**高信噪比的投资研报**与**通俗易懂的纯问答实录**双层文档。

---

## 触发条件

用户提供音视频链接（B站、YouTube、媒体网页等）或本地音视频文件，提出：
- “总结/整理该视频内容”
- “视频转换为 md 文档”
- “提取访谈/演讲的核心观点与商业逻辑”
- “归档访谈笔记”

---

## 归档规范：以【人物/公司】为第一维度的专属子目录体系

产出文件**一律输出至专属目录 `insights/访谈笔记/{人物或公司}/`**。`insights/访谈笔记/` 根目录下**仅保留全局主索引导航 `知名投资人核心音视频与文字研读清单.md`**，严禁在根目录散落任何个人或视频文件。

每次归档生成一组互相链接的配对文档：

| 文档类型 | 存储路径与命名规范 | 核心定位与特色 |
| :--- | :--- | :--- |
| **1. 深度商业研报** | `insights/访谈笔记/{人物/公司}/{人物/公司}_{年份}_{来源}_{主题}.md` | **高维认知与决策**：天然形成时间轴，Mermaid 全景导图 + 3~5个强业务语义章节 + 选配分析积木。 |
| **2. 纯问答对话实录** | `insights/访谈笔记/{人物/公司}/{人物/公司}_{年份}_{来源}_{主题}_对话实录.md` | **细节溯源与语境还原**：按话题分章节，完整还原一问一答，保留案例细节与现场交锋。 |

> **命名关键原则**：必须显式加入四位数字 `{年份}`（如 `2016`、`2019`、`2026`），使同人物/公司的多期访谈在文件管理器中按时间轴自动升序排列，清晰呈现其商业认知与企业生命周期的演进脉络。  
> **专属子目录强制归档**：所有人物或公司相关的音视频总结、对话/演讲实录、官方文字录、研读 PDF 等一律统一沉淀在 `insights/访谈笔记/{人物/公司}/` 文件夹内，不得在根目录堆叠。  
> **文档互链要求**：两篇文档均需在顶部元数据说明中提供指向对方的相对链接（如 `[查看问答实录](./xxx_对话实录.md)`）。  
> **母体清单导航**：所有子目录内的文档顶部，必须添加指向全局主索引的相对链接：  
> `> **母体清单导航**：[知名投资人核心音视频与文字研读清单.md](../知名投资人核心音视频与文字研读清单.md)`  
> **全局主索引同步**：每次归档完成后，必须在 `insights/访谈笔记/知名投资人核心音视频与文字研读清单.md` 对应人物/公司条目下同步追加新归档文档的相对路径（如 `./{人物/公司}/{文档名}.md`）。

## 研报架构：组件化拼装指南

> 💡 **核心禁忌与文风红线（平衡专业严谨与平实表达，告别 AI 伪深刻与庸俗化）**：
> 1. **严禁“新闻联播 / 机关公文 / 社科学术大词”**：严禁出现如“重构……基石”、“本质辨析”、“深层嵌合”、“要素大腾挪”、“深刻启示与战略定力”等假大空、端着身架的官样套话。这类词只有政治姿态或学术包装，毫无具体商业论点与信息增量。
> 2. **小标题必须“业务语义化、标题即论点、清爽自然”**：小标题要直接亮出该部分的核心商业论点与事实（例如：《除了格雷厄姆前五条，李录加了第六条：财富是你在全球购买力中所占的份额》、《股市是一座“附带赌场的教堂”：四类市场参与者的分流》、《造AI芯片的都拿筷子：全球共同市场难以拆解，脱钩只是多绕远路》、《每隔十年换一组目标：在国家转型中，你的资产是目标还是代价？》），杜绝空泛抽象。
> 3. **严禁“为了通俗而通俗”（严守严谨底线，拒绝俚语与轻浮化）**：
>    - 通俗是指“用符合商业常识、清晰自然的人话讲透逻辑”，**绝非市井俚语、地摊口嗨或自媒体轻浮热梗**（严禁出现如“扒底裤”、“发癫”、“悲观鬼”、“挨耳光的安全余量”等庸俗口语）；
>    - 避开生造矫情或容易产生歧义的修辞（如不用“痛切的代价”或“痛彻”，直接使用自然严密的“沉重的代价”）。
> 4. **100% 忠实保留原对话的核心专业概念与原语境论断（原汁原味原则）**：
>    - 对受访者提出的关键概念、理论基石与经典原话（例如李录的“你在全球购买力中所占的份额”、“递归自我改进（RSI）与定义 Improvement 的红线”、“持续物理增量成本”、“由彼此值得信赖而形成的无缝信任之网 (A seamless web of deserved trust)”等），**必须精准保留、原样引用与深度阐释**，绝不能为了“通俗”将其擅自降解、篡改或稀释。
> 5. **保留现场鲜活论据与微观常识**：完整收拢受访者使用的真实微观案例、物理常识与硬核测算数据（如筷子定律、单细胞50GB信息量、新房降70%腾挪10万亿等），以客观事实说话。严禁空泛套用“AI模板标题”（如“核心逻辑提炼”、“焦点质疑攻防”）。

一份优秀的访谈研报由**“必备骨架”**与**“按需积木”**组合而成：

```
研报骨架
├── 1. 顶部元信息（来源、人物、背景坐标、实录链接）
├── 2. Mermaid 全景业务导图（提纲挈领，看透商业本质）
├── 3. 核心业务章节（3~5个根据访谈定制的专属语义标题，内含翔实论据）
└── 4. 选配积木（根据访谈内容，有则添加，无则不强行凑数）：
    ├── 🧩 [数据看板]：硬核经营指标（规模/销量/坪效/估值）
    ├── 🧩 [攻防对照表]：外部尖锐质疑 vs 内部破局逻辑
    ├── 🧩 [复盘演进表]：历史路演/早期决策 vs 今日成果对照
    └── 🧩 [底层哲学/金句]：创始人认知金句、反常识思考
```

## 执行流程（5 步标准流）

### 步骤 0：字幕优先探测（秒级处理）
优先检查视频是否自带现成字幕（如 YouTube CC 字幕、B站官方/AI 字幕），若有则直接提取文本，无需耗时下载与模型推理：
```bash
# 检测 YouTube/B站字幕
uvx yt-dlp --list-subs "<VIDEO_URL>"
# 若有中文字幕，直接抓取
uvx yt-dlp --write-sub --sub-lang "zh.*,en.*" --skip-download -o "/tmp/subs" "<VIDEO_URL>"
```

---

### 步骤 1：音视频提取与极简压缩（若无现成字幕）
使用 `yt-dlp` 提取音轨并压缩为 16kHz 单声道（30分钟音频仅 ~8MB，便于秒级上传与稳定推理）：
```bash
# 1. 抓取音轨（B站需附带 Chrome Cookie 防 412）
uvx yt-dlp --cookies-from-browser chrome -x --audio-format mp3 -o "/tmp/raw_audio.%(ext)s" "<VIDEO_URL>"

# 2. 压缩为 16kHz mono 32k
ffmpeg -y -i /tmp/raw_audio.mp3 -ac 1 -ar 16000 -b:a 32k /tmp/audio_16k.mp3
```

---

### 步骤 2：语音转录与先验信息注入

#### 首选方案：Gemini Flash API（长音频直出、自带语义分段）
利用 Gemini File API + 本地代理（`http://127.0.0.1:7897`）转录。
**关键技巧**：在 Prompt 中主动注入从视频标题/简介中提取的 **5~10 个核心专有名词与人名**（如角色名、设计师、行业行话），防止 ASR 识别错别字：
```python
import os
from google import genai
from google.genai import types

client = genai.Client(api_key=os.environ.get("GOOGLE_API_KEY"))

# 1. 上传音频
audio_file = client.files.upload(file="/tmp/audio_16k.mp3")

# 2. 注入背景先验与转录指令
prompt = """
视频背景：专访XX创始人XX。涉及核心实体与专有名词：[列出核心人名/IP/品牌/术语]。
任务：
1. 提取核心洞察，输出各章节要点。
2. 逐字转录完整一问一答，区分【主持人】与【受访者】，口语适度微调，保留全部细节与数据。
"""
response = client.models.generate_content(
    model="gemini-3.6-flash",
    contents=[audio_file, prompt],
    config=types.GenerateContentConfig(max_output_tokens=65536, temperature=0.2)
)
```

#### 备选方案：本地 faster-whisper（离线/网络受限时）
```python
from faster_whisper import WhisperModel
model = WhisperModel("base", device="cpu", compute_type="int8")
segments, _ = model.transcribe("/tmp/audio_16k.mp3", language="zh")
```

### 步骤 3：双层文档编撰与数据防幻觉核查

1. **编撰研报**：根据组件化架构，撰写带有 Mermaid 导图与业务语义章节的研报，存至专属目录 `insights/访谈笔记/{人物/公司}/{人物/公司}_{年份}_{来源}_{主题}.md`。顶部添加指向实录与全局研读清单的相对链接。
2. **编撰实录**：按话题章节整理清晰的纯一问一答，存至专属目录 `insights/访谈笔记/{人物/公司}/{人物/公司}_{年份}_{来源}_{主题}_对话实录.md`。顶部添加指向研报与全局研读清单的相对链接。
3. **数据量级红线**：对文中出现的**金额、销量、门店数、估值、年份**做严格上下文核对，严防“万/亿”单位遗漏或多零少零。
4. **主索引更新**：在 `insights/访谈笔记/知名投资人核心音视频与文字研读清单.md` 中添加对应新文档条目。

---

### 步骤 4：长视频截断防护（针对 >60 分钟视频）
- 若视频总长超过 1 小时，为防止单次生成被截断：
  - **研报层**可全量一次性输出；
  - **问答实录层**若字数过大，可分上、下两半部分或精简冗余寒暄，确保主体问答完整无截断。
