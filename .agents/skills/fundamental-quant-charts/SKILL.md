# 四、好公司·定量图表标准

## Overview

本 skill 用来统一投资分析报告第四章「好公司·定量：利润是不是真，增长是否健康？」的图表风格和脚本逻辑，避免每家公司每次画出来的图都不一样。

核心原则：
- 图表只服务一个判断，不炫技。
- 白底、清新、主图大、标注克制。
- 同一章节固定 6 张图：4.1 到 4.6。
- 图看趋势和异常，表核对数字；报告中不要只放图不放表。
- 标题保持中性，结论放正文或图下注释，不把强结论塞进图标题。

## When to Use

使用场景：
- 写个股投资分析报告第四章「好公司·定量」。
- 需要生成 ROE/杜邦、利润增长、产品结构、现金流、现金头寸、营运质量图。
- 用户反馈图表尺度误导、风格不统一、标签重叠、每家公司图不一致。
- 需要把某家公司专用脚本沉淀为通用模板。

不适用：
- 第五章「股价 vs 利润线」季度图，优先使用 quarterly-stock-profit-analysis。
- 指数估值看板，使用 index-valuation-dashboard。
- 创意海报/信息图，不用本标准。

## 数据文件约定

默认公司目录结构：

```text
{code}_{公司名}/
  data/
    annual_core.csv
    product_structure.csv              # 可选
    quarterly_profit.csv                # 可选，用于4.2最新TTM
  charts/
  scripts/
```

如果已有公司专用文件名，也可以通过命令行参数指定。

### annual_core.csv 必需字段

字段名可以使用中文标准名，也可以通过脚本参数覆盖。

| 标准字段 | 用途 |
|---|---|
| 年份 或 date/index | 横轴年份 |
| 营收 | 4.6 存货/营收 |
| 股东应占溢利 或 净利润 | 4.2/4.4 |
| 毛利率 | 表格用，图中可不画 |
| 净利率 | 4.1 杜邦 |
| 总资产周转率 | 4.1 杜邦 |
| 权益乘数 | 4.1 杜邦 |
| 简单ROE | 4.1 ROE |
| 经营现金流 | 4.4 |
| 资本开支 或 自由现金流 | 4.4；若无自由现金流则用经营现金流-资本开支计算 |
| 现金头寸_近似 | 4.5 |
| 资产负债率 | 4.5 |
| 应收账款 | 4.6 |
| 存货 | 4.6 |
| 合同负债 | 4.6 |

### product_structure.csv 可选字段

| 字段 | 说明 |
|---|---|
| 业务 | 产品/分部名称 |
| 收入_亿元 | 当年收入 |
| 同比_% | 同比增速，用于反推收入增量 |
| 毛利率_% | 可选，标签展示 |

4.3 输入必须是**单一报告期快照**，例如只含2025年各产品。若底稿是“年份×产品”的长表，先筛选最新年份另存为 `product_structure_2025.csv` 再传给 `--product`。不要把多年长表直接传入：脚本会把同一产品画成多根重复横条，并把不同年份收入混在一起计算占比和增量。

## 推荐命令

先把通用脚本复制到公司目录：

```bash
mkdir -p stocks/1810_小米集团/scripts
cp .agents/skills/fundamental-quant-charts/scripts/generate_fundamental_quant_charts.py \
  stocks/1810_小米集团/scripts/generate_fundamental_quant_charts.py
```

生成第四章 6 张图：

```bash
python3 1810_小米集团/scripts/generate_fundamental_quant_charts.py \
  --base 1810_小米集团 \
  --code 1810 \
  --company 小米集团 \
  --annual data/xiaomi_annual_core.csv \
  --product data/xiaomi_2025_product_structure.csv \
  --quarterly data/1810_小米集团_季度股价利润数据.csv \
  --latest-ttm-label 2026Q1
```

如果公司没有产品结构文件，脚本会跳过 4.3 并提示，不要瞎编产品数据。

## 视觉规范

固定风格：
- 画布：白底，dpi=180。
- 字体：macOS 优先 PingFang/Hiragino/STHeiti，Linux/Windows 自动 fallback。
- 主色：蓝、橙、绿、红、紫、灰，颜色含义固定。
- 网格：只开 y 轴浅灰网格。
- 标题：图表名称中性；副标题写口径，不写投资结论。
- 标签：只标关键值，避免每个点都密密麻麻。
- 双轴：慎用；若右轴是资产负债率、毛利率这类百分比，默认从 0 开始或给出不夸大的固定范围。

## 关键口径规则

1. ROE/杜邦：
   - ROE 用柱状图。
   - 净利率、总资产周转率、权益乘数按首年=100归一化。
   - 只判断驱动因素趋势，不比较三条线绝对高低。

2. 利润增长：
   - 港股没有 A 股扣非口径时，用「股东应占溢利」或报告主线利润口径。
   - 低基数年份必须在正文注明，图上不写夸张结论。
   - 最新季度 TTM 可以作为最后一根不同颜色柱，但必须标注 TTM。

3. 产品结构：
   - 左图画收入结构/占比/毛利率。
   - 右图画收入增量贡献，而不只画同比百分比。
   - 年报“占营收10%以上产品”表可能只披露大类，输入前必须检查产品收入合计是否等于总营收；若不等，补“其他产品及业务”残差。其同比可用本年/上年总营收分别扣除已披露品类后反推，毛利率未披露则留空，并在报告标注“残差反推”。禁止把已披露品类重新归一化到100%，否则会夸大核心品类占比。
   - 例外：纵向一体化公司若明确披露“合并抵销前分部收入”，因内部交易存在，分部收入合计可以高于集团营收。此时不要补残差或强行归一化；在 `product_structure.csv` 增加 `口径=合并抵销前`，图表改称“分部收入结构”，占比仅表示抵销前分部构成。
   - 负增量标签是否放柱内不能只看数值正负或固定金额阈值，还要看柱宽相对最大柱是否足够容纳完整文字。只有足够宽的负柱才用内部白字；中小负柱统一放在柱左侧、深红字、右对齐，避免文字一半落在红柱、一半落在白底而消失。

4. 现金流：
   - 同时看利润、经营现金流、自由现金流。
   - 覆盖率超过极值时可以截断，但必须标注「极值已截断」。
   - 自由现金流 = 经营现金流 - 资本开支；若已经有自由现金流字段，优先使用。

5. 现金头寸/资产负债：
   - 现金头寸按 investment-analysis-framework 的彼得林奇规则计算或读取已校验字段。
   - 资产负债率如果只是小幅波动，不允许自动缩放成剧烈变化。
   - 推荐右轴 `0%-60%` 或 `0%-100%`，除非公司负债率超过区间。

6. 营运质量：
   - 绝对值图只展示应收、存货、合同负债。
   - 下方图看营收同比、存货同比、存货/营收。
   - 判断重点是存货增长是否快于收入，以及合同负债/订单是否匹配。

## 通用脚本

脚本位于：

```text
scripts/generate_fundamental_quant_charts.py
```

调用前优先复核 annual_core.csv 字段；不要为了跑通脚本而自动造字段。除检查“列是否存在”外，还必须检查 4.5/4.6 在目标年份区间内是否有 NaN：列存在但中间年份为空同样属于缺数据。缺少已校验数据时应停止生成对应图并在 stdout 列出缺失年份，或在图中显式标注“缺少已校验数据”；禁止让 matplotlib 静默跳过柱子。

## 3R简报集成

3R简报固定复用四张核心图：4.1 ROE/杜邦、4.2 利润趋势、4.4 现金流与利润，以及由季度股价利润流程生成的股价vs利润线。

- 3R简报直接引用完整投资分析报告使用的同一`charts/`文件，不复制或另存3R专用图片。
- 若完整报告缺少4.1/4.2/4.4，先用报告中已校验表格或底稿生成标准图并补入完整报告，再让3R引用同一路径。
- 图表必须紧跟对应分析段落：ROE图跟ROE/杜邦段，现金流图跟现金流段，利润图跟盈利成长段；不得集中堆叠大图。
- 4.3产品结构、4.5现金头寸、4.6营运质量可以作为附加图，但不能替代3R固定四图。
- 交付时验证：四类图齐全、链接存在、完整报告与3R路径相同、图前一段是其直接支撑的正文。

## Common Pitfalls

1. 资产负债率右轴自动缩放，导致 47%-53% 的变化看起来像大起大落。解决：右轴从 0 开始，通常设 0-60 或 0-100。
2. 图标题写成结论句，后续公司复用时每张图标题都要重写。解决：标题中性，结论放正文。
3. 同一指标有时画柱、有时画线，风格漂移。解决：本 skill 固定图型。
4. 产品结构只画占比，不画增量贡献，会看不出增长来源。解决：固定左右双图。
5. 极端覆盖率不截断，导致现金流图失真。解决：覆盖率线截断并标注。
6. 港股公司强行写“扣非利润”。解决：按报告主线口径写「股东应占溢利/经调整净利润」，图名避免误导。
7. 图中颜色随手变。解决：蓝=规模/主线，橙=利润，绿=现金/正贡献，红=风险/负向或百分比警示，紫=杠杆/权益乘数，灰=辅助。
8. 收入增量图的负柱标签仍按正柱逻辑向右偏移，会与Y轴品类名重叠或让同色文字落进负柱。解决：较大负值放在柱内并用白字；极小负值放零轴左侧；生成后目视确认最大负贡献标签完整。
9. 现金头寸用整数标签会把 `-0.26亿元` 显示成 `-0亿`，掩盖由正转负的信号。解决：现金头寸默认保留两位小数，负值标签放在柱底下方，并保留清晰的零轴。

## Verification Checklist

- [ ] 6 张图文件名和编号稳定。
- [ ] 图表路径位于公司目录 `charts/`。
- [ ] 图标题中性，副标题写口径。
- [ ] 双轴图没有视觉夸大。
- [ ] 关键最新值标签不重叠。
- [ ] 4.1 杜邦三因子按首年=100归一化。
- [ ] 4.4 现金流覆盖率极值已截断并注明。
- [ ] 4.5 现金头寸字段已按图示区间内每一年度年报附注逐年校验，不把其他流动资产整体当现金。
- [ ] 4.5 每个图示年份都有现金头寸柱；任何缺柱都必须先查 CSV NaN，而不是当作零值或正常现象。
- [ ] 4.6 应收、存货、合同负债在每个图示年份都完整；合同负债不能只补最新两年。
- [ ] 4.6 存货同比、营收同比、存货/营收口径正确。
- [ ] `--recent-years` 与报告声明的趋势区间一致（2020—2025 应传 6，默认 5 会漏掉 2020）。
- [ ] 图表生成后做视觉验收：逐年数柱子/数据系列，并与正文表格逐项核对。
- [ ] 报告正文仍保留数据表，不能只有图。
