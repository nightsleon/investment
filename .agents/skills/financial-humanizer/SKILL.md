# 财经文本去AI味与大众化改稿规范

这份规范用于把带有 AI 腔、研报黑话或公文大词的财经文字，改写成普通读者容易看懂、语言自然、事实与数字完全准确的成稿。

---

## 1. 使用原则与输入模式

本技能由用户按需调用，写作技能自身完成初稿，不在后台隐式嵌套。

根据用户的输入方式，选择对应的输出形式：

* **对话框片段输入（一段文字）**：
  直接在回复中给出改写后的文字（可根据需要附上核心改动说明）。不新建文件，不附加文末免责声明，保持对话清爽。
* **文件输入（针对某篇完整文章文件）**：
  读取原文件后生成新文件，文件名为 `{原文件名}_特稿版.md`（或 `{原文件名}_商业特稿.md`）或 `{原文件名}_雪球知乎版.md`。摒弃浮夸俗套的“爆款版”命名，严禁覆盖原稿，并在新文件末尾附上标准合规声明。
* **可选：参考声线同频（Voice Calibration）**：
  若用户随附了参考作者样章或指明风格（如“按老唐风格”、“按深蓝特稿笔调”），优先比对样本的平均句长、标点习惯（如括号补充）、段落节奏与口吻，在改写时自然贴合，避免改后千篇一律。

## 2. 改稿动作与底线约束

### 2.1 就地剪枝，严禁通读重概括（防失真）
* **就地修改（In-place Editing）**：改稿是“给原树枝修剪枯叶”，绝不是“把整棵树砍倒重新栽”。严禁读完一段后凭印象重新归纳概括。
* **保住逻辑链条**：逐句、逐段在原文基础上脱水与微调。一旦大面积重新概括，极易丢失原本严密的因果推导次序（“因为 A，导致 B，进而影响 C”）。

### 2.2 绝对不能改动的底线
1. **财务数字与口径**：所有金额、百分比、日期、估值倍数（PE/PB/PS）、股票代码、公司与人物名字原样保留。不擅自四舍五入，不弄错“万”与“亿”，不混淆 Non-IFRS 与 GAAP、账面现金与林奇净现金。
2. **诚实限定语**：原文中说明信息局限的表述必须保留，如“财报未披露具体构成”、“此为推算估值，非官方口径”、“尚需后续报表验证”。不能为了句子读起来顺畅而删掉不确定性。
3. **鲜明的投资判断**：作者原本的多空倾向、买卖评级、持有逻辑与证伪条件原样保留，不要改写成“两面都有道理、既有机遇又有挑战”的中庸套话。
4. **专业术语豁免**：单位经济学（UE）、资本开支（CapEx）、净现比、加权平均资本成本（WACC）等具备明确金融与会计定义的术语不是套话，严禁将其粗暴删减；首次出现时做通俗注释即可。
5. **表格与代码**：Markdown 表格、计算公式、代码块在原位置完整保留。

## 3. 必须清理的套话与机械句式

### 3.1 删掉开头的空泛铺垫与起手副词口癖
* **禁止宏观空话**：正文第一句禁止出现“随着宏观经济的发展……”、“在当今充满不确定性的市场环境中……”、“回顾过去几年……”。
* **禁止寒暄与打招呼**：删掉“大家好，今天我们来聊聊……”、“下面由我为大家拆解……”。第一句直接呈现核心矛盾、反常识数据或商业现场。
* **剔除起手副词口癖**：删掉段首习惯性的“值得注意的是”、“诚然”、“毋庸置疑”、“不可否认”、“显而易见”、“平心而论”、“坦率地说”，直接从主句事实切入。

### 3.2 狙击段首悬空评述（零回指感慨）
* 严禁在段落开头使用无主语的感慨式金句。这类表达在 AI 生成文本中极其高发，缺乏信息增量：
  * 避免：“不可否认，这是一场豪赌。”
  * 避免：“显而易见，代价是极其沉重的。”
  * 规范：段首第一句必须带着具体主体、动作或经营数据切入（如：“账上趴着 200 亿，但三季度单车净亏损扩大到了 3 万块。”）。

### 3.3 破除机械句式与公文语法病
* **清除“进行＋动词”的公文软骨病**：删掉多余的“进行/开展/推进”，直接使用实际动词。
  * 避免：“对销售渠道进行了优化”、“推进了库存的去化”
  * 规范：“优化了销售渠道”、“清理了积压库存”
* **消除设问自答（Rhetorical Questions）**：删掉自言自语式的设问提白，直接陈述论点。
  * 避免：“宁德时代的底牌究竟是什么？答案是规模优势。”
  * 规范：“宁德时代的底牌是规模优势。”
* **拆解虚假对偶与刻意升华**：改掉“不仅是一次……更是一次……”、“这不仅是……更是……”、“这不是……而是……”，直接陈述具体事实。
* **消除虚假区间（False Ranges）**：“从 X 到 Y”只在具有明确连续尺度或度量衡时使用，避免把两个不相干的概念生硬并列（如：“从动力电池到欧洲出海”）。
* **还原被刻意回避的系动词“是”**：不用“充当了……的角色”、“标志着……的开端”来生造庄重感，直接说“是……”。
* **打散对称三段式排比**：拒绝“既要……又要……还要……”或同构短语强行凑三，长短句交错。

### 3.4 删掉行文预告、自纠痕迹与空洞结尾
* **行文预告**：删掉“下面我们从三个方面展开分析……”、“接下来看一下现金流……”。
* **自纠痕迹**：删掉“经笔者核对修正……”、“此前推算有误，现重新核对……”。
* **空洞结尾与总结套话**：删掉“综上所述”、“总而言之”；删掉“未来可期”、“扬帆起航”、“书写新的篇章”、“站在新的历史起点上”。结尾直接给出观察指标、操作边界或证伪时间点。

### 3.5 格式与标点节制
* **拒绝滥用破折号（——）**：能用逗号或句号断开的不用破折号，不用破折号逃避真实的从属因果。
* **避免正文 PPT 胶囊化**：长文叙事中，避免把正文每一段都写成“- **维度：** 内容”的垂直列表，将其还原为自然段落。
* **拒绝轻浮市井俚语**：不引入“扒底裤”、“发癫”、“悲观鬼”等词，通俗不等于粗俗。

## 4. 怎么把专业内容改得通俗易懂

### 4.1 穿透模糊动词，找回责任主体与动作
财经公文常通过被动句或抽象动词隐藏责任。改稿时追问“谁在对谁做什么”，把行政大词还原为具体动作：
* 避免：“完成了对供应链采购体系的协同重组，实现边际降本。”
* 规范：“采购部把二线供应商从 20 家压到 3 家，直接省下 15% 的物料费。”

### 4.2 把研报行话翻译成生意小账本

| 研报行话 / 会计术语 | 通俗大白话 / 商业实质 |
| :--- | :--- |
| **合同负债大幅攀升** | 客户排队交全款订货，货还没造出来钱先到账了 |
| **应收账款与存货双高** | 卖出去的货只拿到欠条，剩下的货在库房里积灰 |
| **营运资本（Working Capital）为负** | 做生意强势，上下游资金两头占，拿别人的钱做自己的生意 |
| **商誉减值** | 当年高价买的公司现在承认买贵了、暴雷了 |
| **资本开支（CapEx）大幅收缩** | 不再盲目买设备建厂房，开始捂紧钱包过冬 |
| **单均 UE（Unit Economics）转正** | 每卖出一杯奶茶/一单外卖，扣掉成本能实实在在赚到几毛钱 |

### 4.3 术语首现说明机制
冷门或易混淆的专业术语，仅在**第一次出现时**用括号配一句大白话解释（如“商誉（通俗说就是当年收购多付的溢价）”）。后文再次出现时直接使用该术语，不再反复做通俗解释。

### 4.4 小标题业务语义化
标题自带结论与具体业务，拒绝 PPT 目录与设问党：
* 避免模板式小标题：“一、行业背景与宏观环境”、“二、公司核心竞争优势”、“三、财务分析与风险提示”。
* 避免设问式标题：“谁动了利润？”、“增收不增利的背后是什么？”
* 规范为业务语义化小标题：“单车毛利只剩 500 块，全靠金融分期利息撑着”、“账上趴着 100 亿，能动用的活钱还不够还下半年利息”、“宁德主动降价的阳谋：不是被逼的，是在熬死二线对手”。

### 4.5 自然的段落与句子节奏
* **段落长度**：一段控制在 120 字以内（2~3 句话），保证手机屏阅读不费力。
* **单句长度**：单句建议在 35 字以内，少用嵌套层级过多的复合从句。
* **弹性原则**：遇到严密的因果推导或连续财务核算时，允许完整成段，绝不为了断句而强行切碎逻辑。

## 5. 改写对照示例

### 原文（典型 AI 腔、研报腔与公文套话）：
> 值得注意的是，在当前复杂多变的宏观经济环境下，某某公司通过深化内部组织变革与供应链协同创新，开展了全方位的降本增效，不仅实现了单车毛利的边际改善，更展现出了穿越周期的战略定力。这不仅是一次商业模式的升华，更是对核心竞争护城河的夯实。那么，公司的底牌究竟是什么？答案就是技术积累。展望未来，随着新工厂产能的逐步释放，公司发展前景未来可期，值得投资者持续关注。

### 改写后（就地脱水、业务明确、保留判断）：
> 这半年行业价格战打得激烈，但某某公司交出的数据让人意外：单车毛利逆势多挤出了 1200 块。原因很具体，采购部把电池包和线束的供应商压到两家，直接砍掉 15% 的物料成本。技术底牌撑住了毛利，但不确定性依然在——新工厂能不能跑满、下半年会不会被友商拖进新一轮降价，还要等三季报的数据对账。

## 6. 交付前自查清单

改完之后，快速过一遍以下 6 点：

1. **就地剪枝到位没有**：是否严格在原句骨架上改动，有没有脱离原文概括重写？
2. **数字全不全**：所有金额、百分比、日期、倍数是否和原文一致，有没有手误改动？
3. **限定语在不在**：“财报未披露”、“仅为推算”这类诚实限定语有没有被删掉？
4. **立场有没有变软**：多空结论是否鲜明，有没有被抹平为中庸废话？
5. **语病清干净没有**：“进行＋动词”、设问自答、段首无主语感慨、起手副词口癖（“值得注意的是/诚然”）是否已经绝迹？
6. **排版有没有受损**：表格、代码块、公式是否完整保留？

## 7. 文件输出末尾规范（仅用于生成文件时）

在生成独立 Markdown 文件时，正文结束后附上以下文案（对话回复中不输出）：

```markdown
---

如果您觉得这篇文章有启发，欢迎点赞、转发、关注！

风险提示： 本文仅供参考，不构成投资建议。市场有风险，入市需谨慎。
```
