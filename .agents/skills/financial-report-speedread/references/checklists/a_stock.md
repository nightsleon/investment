## 利润表

- [ ] 营收、归母净利、**扣非归母净利**三者增速对比（扣非与归母偏离 >5pct 需归因）
- [ ] 扣非口径核对：财务摘要表的"扣非归母" vs MD&A 正文可能给含少数股东口径——两者不同，引用前核对来自哪张表
- [ ] 毛利率趋势（同比+环比），板块毛利率变动按收入占比加权复算后再归因
- [ ] 财务费用大额变动 → 先拆汇兑（涉外企业走 conditional.md）
- [ ] 非经常性损益占比高（>10%）→ 逐条看构成，判断趋势性 vs 一次性

## 现金流量表

- [ ] 经营现金流 / 归母净利 ≥ 1.0（<0.7 标黄灯）
- [ ] 收现比 = 销售收现 / 营收（<0.85 标黄灯，白酒等预收款行业例外）
- [ ] 自由现金流 = 经营现金流 − 资本开支（给完整算式）

## 资产负债表排雷

- [ ] **大存大贷**：货币资金+定存（翻附注确认真实构成）vs 有息负债（短借+长借+应付债券+一年内到期），同时高企标红灯
- [ ] **商誉**：占归母净资产比（>30% 黄灯、>50% 红灯）；并购标的是否过业绩承诺期（第一年减值高发）
- [ ] **应收账款**：增速远超营收增速需归因；账龄结构恶化标黄灯
- [ ] **存货**：拆类别结构（库存商品 vs 原材料 vs 在产品），库存商品堆积=需求走弱，原材料堆积=备货扩产——含义相反
- [ ] **在建工程**：进度 vs 挂账年限，常年不转固=美化利润嫌疑；进度接近 100% 的最先转固，折旧压毛利率
- [ ] **有息负债**：按公司自己的有息债务表抄，不自拼资产负债表科目；括号枚举分项必须加总核对
