# 条件触发 Pitfall

> 按公司类型/特征索引。路由阶段判断是否触发对应板块。每个 pitfall 标注触发条件和来源案例。

---

## 一、涉外企业（海外收入 >20%）

### C1：汇兑损益——摆动额 vs 单期额不能混

**触发条件**：财务费用同比变动 >50%，或公司有显著海外收入/外币负债。

**三个不同的数，别混**：
1. 本期汇兑损益（如 H1 损失 8.03 亿）
2. **同比摆动额**（去年收益 6.02 亿 → 今年损失 8.03 亿 = 摆动 14.04 亿）
3. 税后归母影响

旧写法"汇兑吃掉了约14亿利润总额（税后影响归母约7亿）"把**摆动额14亿**和**单期税后7亿**并列——读者算不出账。正确做法：一组配对，不交叉。要么"摆动14亿（税后约12亿）"，要么"本期损失8亿（税后约7亿）"。

**来源**：福耀2026中报翻车。

### C2：单季汇兑归因必须比"同比摆动额"

**触发条件**：需要拆解 Q1/Q2 的利润变动归因。

**规则**：任何单季因素对比一律算摆动额（带上期符号），上年同期为收益/负值时尤其致命。

错误示范：Q1 损失 4.39 亿、Q2 损失 3.64 亿 → "Q2 汇兑拖累更小" ✗
正确算法：Q1 摆动 = 4.39 + 2.36 = 6.75 亿；Q2 摆动 = 3.64 + 3.66 = 7.30 亿 → Q2 拖累更大 ✓

归因结论必须配一个"扣除该因素后的同比"数字自证方向。

**来源**：福耀2026中报两轮翻车。

### C3：扣非利润的衍生工具分类陷阱（美的模式）

**触发条件**：A 股制造业，归母微增但扣非大跌；非经常性损益中"衍生金融工具"占比极高。

**机理**：外币货币性项目的汇兑损益计入**经常性**损益，但用于管理外汇风险的衍生金融工具（远期、掉期）产生的公允价值变动和处置收益计入**非经常性**损益。结果是：汇兑损失扣了经常性利润，套保收益被踢去非经常性，扣非只看到损失那半面。

**识别标志**：非经常性损益中"衍生金融工具公允价值变动+处置收益"占比 >80%。

**处理**：不能直接用扣非增速判断经营恶化。要加回净汇兑影响（或扣非+衍生套保收益）再看真实经常性利润增速。

**来源**：美的2026中报。

## 二、制造业企业

### C4：存货异常先拆类别结构

**触发条件**：存货同比增速 > 营收增速，或存货周转天数显著上升。

**规则**：附注存货分类（库存商品 vs 原材料 vs 在产品）必须拆开再看归因。
- 库存商品堆积 → 需求走弱/去化变慢
- 原材料堆积 → 主动备货/扩产
- 两者对投资者的含义**相反**

如果公司披露分产品周转天数，一并报。单看合计会掩盖分化。

**来源**：福耀2026中报翻车。

### C5：在建工程规模与资本开支拐点

**触发条件**：在建工程 / 固定资产 > 30%。

**规则**：进度接近 100% 的项目最先转固，转固后折旧直接压毛利率。资本开支趋势（连续3年+当期年化）决定拐点方向。如果"毛利率创新高"是核心多头论据，在建工程转固压力就是判断毛利率能否守住的一号变量。

**来源**：福耀2026中报遗漏。

### C6：商誉不摊销

**触发条件**：商誉账面余额发生变动（非零变动）。

**规则**：中国准则下商誉只减值不摊销。账面下降通常是外币报表折算差额（境外并购主体如欧元记账，汇率变动折算缩水），不是摊销。判别：看其他综合收益外币折算差额方向 + 利润表有无减值损失。

IFRS 下同理（IAS 36 不摊销），但需注意廉价购买利得（IFRS 3）。

**来源**：迈瑞2026中报。

## 三、白酒/季节性企业

### C7：H1 利润前置

**触发条件**：白酒/春节旺季行业。

**规则**：H1 利润约占全年 69%（2024/2025 实测），Q4 是全年最低点。"H1×2"年化会高估约 38%。全年利润 = H1 / 历史H1占比。

**来源**：汾酒2026中报翻车。

## 四、所有企业通用

### C8：税项附注 = 有日期可量化的风险金矿

**触发条件**：所有财报速览，必读税项章节。

**检查清单**：
- 出口退税率变动（有生效日期）
- 高新资质到期日（15%→25% 的敞口，按到期子公司数量和利润占比估算影响）
- 西部大开发/区域优惠政策到期日
- 海外子公司亏损 / 未确认递延所得税可抵扣亏损余额变动

**规则**："需要跟踪的变量"优先放有日期、可量化的确定事项，而不是"汇率走向""行业能否企稳"这类不可预测变量。

**来源**：福耀2026中报最严重遗漏。

### C9：一次性损益报净额

**触发条件**：营业外支出中出现大额非常损失/事故损失。

**规则**：先在营业外收入、其他应收款两处找保险理赔/回款对冲项，报净额并说明未决部分。只报支出不报理赔会夸大损失。

**来源**：福耀2026中报遗漏。

### C10："当期报告未披露"是一句可证伪的断言

**触发条件**：准备写"公司未披露 X"或"中报未披露"之前。

**规则**：写之前必须把 MD&A + 风险章节 + 附注都过一遍关键词。当期报告披露了却写成"未披露"，是比漏引更严重的硬伤。

收入占比、境外资产占比、单一子公司收入是**三个不同维度**，不能跨用。

**来源**：福耀2026中报翻车。

### C11：净现金/净负债报口径与方向性变化

**触发条件**：计算净现金/净负债时。

**规则**：
- 口径：货币资金 vs 现金及等价物（含受限保证金的不同）不能混用
- 方向性变化（净现金→净负债 或反向）比静态差额信息量大
- 公司若在"资本管理"节直接披露债务净额与资本负债比率，优先用公司口径

港股 IFRS 下公司常直接披露 net debt / gearing ratio，抄它。

**来源**：福耀2026中报翻车。

### C12：括号内分项枚举必须加总核对

**触发条件**：正文中出现"合计 X 亿（A + B + C + D）"的枚举格式。

**规则**：当场加一遍总数。有息负债以"流动资金与资本来源"里的有息债务表为准，不要自己从资产负债表科目拼（拼出来的口径和公司披露的不一致）。

**来源**：福耀2026中报翻车。

### C13：ROE 缺席 = 结构性缺失

**触发条件**：所有财报速览。

**规则**：加权平均 ROE（及扣非后）正文必须报。速览表因跨期口径不可比（中报半年 vs 年报全年）不列，但正文要写。PE 低分位要配 PB 分位一起看：PE 低+PB 高 = 估值收缩来自盈利端，ROE 仍在高位。

**来源**：福耀2026中报遗漏。

### C14：行情数据以日频 pe_history.csv 为准

**触发条件**：引用现价/市值/PE/历史最高价/回撤幅度时。

**规则**：日频 pe_history.csv（含 CLOSE_PRICE / TOTAL_MARKET_CAP / PE_TTM / PB_MRQ）是权威数据源。季度 CSV 的 close 字段可能是错的。自洽（市值÷净利=PE）不等于取数正确——必须回到日频原始行核对日期。

**来源**：福耀2026中报翻车。

### C15：估值节结构

**触发条件**：写估值节时。

**规则**：
1. 先图读走势（股价 vs 利润线相对位置）
2. 再口径数字（PE-TTM 推导）
3. 后分位与观察点
4. 节内锚句：图注后第一句放判断式结论
5. 段落加粗引导用立场句不用问句
6. 图内数字（如 2.0/1.4 倍数）正文不复述

**图读法表述随股价形态走**：
- 上涨股："股价涨这么多，利润跟上没有"
- 下跌/震荡股：林奇两线图法——"盈利站住，股价追上来补课；盈利再掉，就下来找股价"
- 杀估值 ≠ 戴维斯双杀：业绩创新高中估值腰斩 = 纯杀估值；双杀 = 业绩与估值同时下行

**PEG 失真两种机理**：
- 低增速成熟龙头：数学失真（PEG≤1 需 PE≤增速）
- 龙头遇困境：分母失真（低谷增速当分母 = 把暂时困境当永久低速）
