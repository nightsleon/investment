# 核心财务精算口径与数据源规范

本文件汇总个股投资分析（6章13节新框架）中最高频易错的会计核算口径与数据源优先级。

---

## 一、数据源优先级与交叉验证

1. **官方年报 / 半年报 / 季报 PDF（最高权威）**
   * 现金头寸明细（受限资金、定期存款）、分产品收入与毛利率、在建工程、关联交易、实控人持股与质押，**必须以官方 PDF 原文与报表附注为准**。
   * A 股通过巨潮资讯网下载；港股通过港交所披露易（注意中文版 `_c.pdf` 后缀）或公司 IR 官网下载。
2. **同花顺导出 Excel（优先结构化源）**
   * 若公司 `data/` 目录下已有同花顺导出的 `.xls` 文件，优先用 `python-calamine` 读取并与年报 PDF 交叉核对。
   * 注意识别表头频率：`main_simple.xls` 通常为单季度数据；`keyindex_report.xls` 可能仅含年度与 H1 累计值。
3. **东方财富 API / AkShare（无本地 Excel 时的主选）**
   * **注意累计值陷阱**：东方财富利润表接口（`RPT_DMSK_FN_INCOME` 及港股财务接口）返回的是**年初至报告期累计值**，不是单季度值！
   * 必须手动转换：`Q1单季 = Q1累计`；`Q2/Q3/Q4单季 = 本期累计 - 上一期累计`，并检验四个单季之和是否严格等于年报全年数。
4. **行情与估值数据源**
   * **长期复权股价（画股价 vs 利润图）**：使用 `yfinance` 前复权收盘价（`Adj Close`），代码格式为深市 `{code}.SZ`、沪市 `{code}.SS`、港股去掉前导零 `{code}.HK`（如 `9992.HK`）。
   * **最新市值与静态/TTM 估值**：使用最新交易日不复权收盘价與总股本计算（东财/腾讯实时行情接口），严禁直接拿 `yfinance` 前复权价当作当前真实股价。

## 二、彼得林奇现金头寸标准口径（必查年报附注）

```text
彼得林奇现金头寸 = 现金及现金等价物 + 已核实定期存款 + 有价证券 - 长期有息债务
每股现金头寸 = 彼得林奇现金头寸 ÷ 总股本
扣现金后市值 = 当前总市值 - 彼得林奇现金头寸
扣现金后 PE = 扣现金后市值 ÷ 扣非净利润 TTM（港股为股东应占溢利 TTM）
```

**科目核对铁律：**
1. **现金及现金等价物**：取资产负债表“货币资金”中**扣除受限资金**（如承兑汇票保证金、冻结资金）后的可自由支配部分；若受限金额极小，可用货币资金总额并注明。
2. **定期存款（必须翻附注）**：仔细核查“货币资金附注”、“其他流动资产附注”、“其他非流动资产附注”中的定期存款、大额存单及应计利息。**严禁不看附注直接把整个“其他流动资产”（内含待抵扣增值税等）当成现金！**
3. **有价证券**：取“交易性金融资产”（A股）或“按公允价值计入损益之短期投资/金融资产”（港股 IFRS）。
4. **严禁计入应收票据**：A 股“应收款项融资”本质是银行承兑汇票，属于营运应收链条，**不计入现金头寸**。
5. **长期有息债务**：扣除“长期借款” + “应付债券”（可含“一年内到期的非流动负债”中的有息债务部分）。
   * 按彼得林奇简化公式，**主口径不扣短期借款**（假定由日常营运资金对冲）；但若公司短期借款巨大（短债长投），必须在正文中单独警示并列出“扣除全部有息负债后的净现金”作保守对照。
   * **租赁负债**不混入主口径，可在保守净金融现金口径中另行说明。

## 三、A 股与港股关键核算差异

### 1. 利润口径与 TTM 计算
* **A 股**：主线一律采用 **扣非归母净利润**；滚动 4 个单季度求和得到 `扣非净利润 TTM`。
* **港股**：IFRS 准则无法定“扣非净利润”科目，主线采用 **股东应占溢利（归母净利润）**，若公司连续披露口径一致的“经调整净利润（Non-IFRS）”，可并列参考，但估值分位与历史对比必须同口径。
  * **仅披露半年报与年报的港股**：`年末 TTM = 当年年报全年利润`；`年中（H1）TTM = 上年年报全年 + 本年 H1 - 上年 H1`（注意三者必须同为“股东应占溢利”，不得混用期内溢利总额）。
  * **披露季报的港股（如小米、腾讯）**：按四季度单季滚动求和计算 TTM。
  * **汇率换算**：港股股价为港元（HKD）、财报多为人民币（RMB）时，计算市值/PE 必须按同日汇率统一折算为同一币种，严禁直接用港元市值除以人民币利润。

### 2. A+H 多地上市公司的总市值计算
* 严禁直接用 `A股股价 × (A股+H股总股本)` 作为公司总市值（当 AH 溢价较高时会严重高估市值与 PE）。
* **正确做法**：
  * **同币种分类加总市值** = `A股股本 × A股股价 + H股股本 × H股股价 × 港币兑人民币汇率`；
  * 或明确声明按某一市场（如 A 股）价格折算并在正文中注明“A股同价折算市值 vs A+H实际分类加总市值”的差异。

## 四、其他高频财务与治理排雷铁律

1. **季节性陷阱：半年报（H1）严禁直接 `×2` 估算全年利润与动态 PE**
   * A 股制造业（如美的）常在 Q4 集中计提资产减值、年终奖与研发营销结算，导致 Q4 单季利润显著低于 Q3；而白酒等消费品（如汾酒）春节旺季前置，H1 利润常占全年的 ~69%。
   * 因此在中报期分析估值时，**严禁把 `H1 利润 × 2` 当作全年利润算 PE**；必须统一采用滚动 TTM 利润（`上年全年 + 本年H1 - 上年H1`），或先核对该公司过去 2~3 年 H1 占全年利润的真实比例。
2. **PDF 纵向表格抽取防“空值错列”**
   * 用 `pdfplumber`/`fitz` 抽取资产负债表时，若某科目（如应付债券、长期借款、交易性金融资产）本期清零为空白，文本提取器极易把右侧紧挨着的“上年同期比较列余额”误当成本期值（曾在伊利案例中因此少算 35 亿元现金头寸）。
   * **铁律**：凡是可能归零的有息负债与金融资产科目，必须核对表头列顺序、与同页“流动/非流动负债合计”做加总勾稽，并用下一期报表的“期初数”交叉验证。
3. **“营业总收入” vs “营业收入”（防金融子公司虚增毛利率）**
   * 带有财务公司/金融子公司的企业（如美的集团），利润表首行“营业总收入”包含利息收入与手续费，若直接用它算合并毛利率会被人为拉高数个百分点。
   * 必须统一使用纯商品/服务销售的 **“营业收入”** 计算主业毛利率，并在表中注明口径。
4. **加权平均 ROE vs 年末简单 ROE**
   * 年报披露的法定指标是“加权平均 ROE”（分母为期间加权净资产），而用年末净利润除以年末净资产拆解杜邦三因子得到的是“简单 ROE”，两者通常相差 1~2 个百分点，表格中建议并列或明确注明口径。
5. **CAGR 年数准确反算**
   * `2020 → 2025` 是 **5 年**（指数为 `1/5`），不是 6 年；`2022 → 2025` 是 **3 年**（指数为 `1/3`）。
   * 若起始年处于亏损或极低利润（如疫情坑或渠道出清年），计算出的高 CAGR 必须明确标注“含低基数修复效应”，不得直接外推。
6. **产品结构残差勾稽**
   * 年报往往只单列“占营收 10% 以上”的产品。制表与画图前，必须核对**已披露产品收入之和是否等于营业总收入**。
   * 若小于总营收，差额必须单列为“其他产品及业务（残差反推）”，**绝对禁止将已披露的几个产品直接除以它们的和强行归一化到 100%**（那会人为夸大主力产品的占比）。
   * 例外：纵向一体化能源/制造企业若披露的是“合并抵销前分部收入”，合计可大于合并总营收，此时注明“抵销前分部口径”即可。
7. **重资本公司的现金流考核**
   * 不能因为单年“经营活动现金流净额（CFO）> 净利润”就给现金流满分。
   * 必须计算 **近 5~6 年累计自由现金流（`累计 CFO - 累计购建固定无形长期资产支付的现金`）**。若赚来的经营现金流长年被扩产资本开支吞噬，在 `3.3 自由现金流与资本轻重` 中必须实质扣分。
8. **管理层资本配置与治理三项深挖排雷**
   * **回购去向鉴别**：严格区分“回购并注销（减少总股本，真股东回报）”与“回购转库存股用于员工持股/低价股权激励（本质是股东买单的薪酬费用）”，只有实际注销才确认减少股本。
   * **并购与商誉排雷**：有并购史的公司必须计算 `商誉净额 ÷ 归母净资产` 比例及历年减值；重大高溢价收购需进一步核查交易所问询函/工作函回复中的预计商誉、评估增值率与业绩承诺条款。
   * **质押、冻结与减持**：区分第一大股东、控股股东与实控人；严格区分“股权质押”与风险更高的“司法冻结/标记”，分别计算占该股东持股和总股本的比例；董监高减持需核查减持比例与资金去向（如是否用于偿还质押贷款）。
9. **巴菲特“一美元原则”测算规范（留存利润创造价值检验）**
   * **核心逻辑**：巴菲特在致股东信中强调，“公司留存的每一美元利润，长期看是否为股东创造了至少一美元的市场价值”。如果一家公司赚了钱不分红，留下来再投资或扩产，但二级市场长期市值增量低于留存金额，说明资金配置效率低下甚至在毁灭价值。
   * **测算公式**：
     * `一美元检验倍数 = 近 5 年总市值增量 ÷ 近 5 年未分配利润留存总额`
     * 其中：
       * `近 5 年总市值增量 = 当前总市值 - 5 年前年末总市值`
       * `近 5 年未分配利润留存总额 = 近 5 年累计归母净利润 - 近 5 年累计现金分红总额`（或直接取资产负债表“未分配利润 + 盈余公积”近 5 年净增加额）
   * **判定与应用**：
     * **≥ 1.0 倍**：优秀/合格。管理层留存资金再投资实现了正向价值创造，留存资金越多复利效应越强。
     * **< 1.0 倍（甚至为负）**：警惕/不合格。管理层留存的资金回报率低下或用于低效扩产、亏损并购。对于此类公司，低分红率是重大利空，在 `4.2 资本配置与一美元原则` 中必须实质扣分。
