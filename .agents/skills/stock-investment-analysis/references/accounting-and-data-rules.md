# 核心财务精算口径与数据源规范

本文件汇总个股投资分析（6章13节新框架）中最高频易错的会计核算口径与数据源优先级。

---

## 一、数据源优先级与交叉验证

1. **同花顺结构化 Excel（最高优先级结构化数据源，免手动导出）**
   * **A 股自动检测与下载机制**：
     * 检查 `data/` 下是否有 `{code}_main_year.xls` 与 `{code}_main_simple.xls`；若本地缺失，**直接通过 API 自动下载**：
       * `curl -s -H "User-Agent: Mozilla/5.0" -H "Referer: https://basic.10jqka.com.cn/{code}/" "https://basic.10jqka.com.cn/api/stock/export.php?export=main&type=simple&code={code}" -o "data/{code}_main_simple.xls"`
       * `curl -s -H "User-Agent: Mozilla/5.0" -H "Referer: https://basic.10jqka.com.cn/{code}/" "https://basic.10jqka.com.cn/api/stock/export.php?export=main&type=year&code={code}" -o "data/{code}_main_year.xls"`
     * **A 股分工**：`main_year.xls` 为年度底账；`main_simple.xls` 为单季度拆分与 TTM 底账。
   * **港股自动检测与下载机制（以腾讯00700、阿里09988为例）**：
     * 检查 `data/` 下是否有 `HK{code}_keyindex_report.xls` 与 `HK{code}_keyindex_year.xls`；若本地缺失，**通过港股导出 API 自动下载**：
       * `curl -s -H "User-Agent: Mozilla/5.0" -H "Referer: https://basic.10jqka.com.cn/HK{code}/finance.html" "https://basic.10jqka.com.cn/api/hk/export.php?export=keyindex&type=report&code={5位数字代码}" -o "data/HK{code}_keyindex_report.xls"`
       * `curl -s -H "User-Agent: Mozilla/5.0" -H "Referer: https://basic.10jqka.com.cn/HK{code}/finance.html" "https://basic.10jqka.com.cn/api/hk/export.php?export=keyindex&type=year&code={5位数字代码}" -o "data/HK{code}_keyindex_year.xls"`
     * **港股参数避坑铁律**：
       * `code` 必须为 **5位纯数字**（含前导零如 `00700`、`09988`），**严禁传 `HK0700`，否则服务端返回 502 Bad Gateway**；
       * 必须携带 `User-Agent` 与 `Referer: https://basic.10jqka.com.cn/HK{code}/finance.html`，否则返回 403 拦截；
       * 亦支持其他报表导出：`export=benefit`（利润表）、`debt`（资产负债表）、`cash`（现金流量表）。
     * **港股单季度与 TTM 差分还原机制**：
       * 港股同花顺 `keyindex_report.xls` 为**报告期累计值（Cumulative）**，非 A 股的单季度直接拆分值；
       * 披露季报的港股（如腾讯）：`Q1 = 3月31日值`，`Q2 = 6月30日值 - 3月31日值`，`Q3 = 9月30日值 - 6月30日值`，`Q4 = 12月31日值 - 9月30日值`；滚动 4 个单季求和为 TTM；
       * 仅披露中报与年报的港股（如农夫山泉）：`H1 = 6月30日值`，`H2 = 12月31日值 - 6月30日值`；滚动 `当年H1 + 上年H2` 或直接取最新两期半年度之和为 TTM。
   * **读取与分工硬约束**：统一使用 `python-calamine` 读取作为核心分析底账，严禁静默调用网络接口重新爬取。
2. **官方年报 / 半年报 / 季报 PDF（附注与定性终审权威）**
   * 现金头寸明细（定期存款、受限资金附注）、分产品收入与毛利率明细、在建工程明细、关联交易、实控人持股与质押，**必须以官方 PDF 原文与报表附注为准**。
   * A 股通过巨潮资讯网下载；港股通过港交所披露易（注意中文版 `_c.pdf` 后缀）或公司 IR 官网下载。
   * **交叉比对**：将同花顺 Excel 数据与官方 PDF 关键行（营收、扣非、归母净利）比对，三源一致即确认；若有差异以年报 PDF 附注为准。
3. **东方财富 API / AkShare（仅在无本地同花顺 Excel 时的备选补充）**
   * **注意累计值陷阱**：东方财富利润表接口（`RPT_DMSK_FN_INCOME` 及港股财务接口）返回的是**年初至报告期累计值**，不是单季度值！
   * 必须手动转换：`Q1单季 = Q1累计`；`Q2/Q3/Q4单季 = 本期累计 - 上一期累计`，并检验四个单季之和是否严格等于年报全年数。
4. **行情与估值数据源**
   * **长期复权股价（画股价 vs 利润图）**：使用 `yfinance` 前复权收盘价（`Adj Close`），代码格式为深市 `{code}.SZ`、沪市 `{code}.SS`、港股去掉前导零 `{code}.HK`（如 `9992.HK`）。
   * **最新市值与静态/TTM 估值**：使用最新交易日不复权收盘价與总股本计算（东财/腾讯实时行情接口），严禁直接拿 `yfinance` 前复权价当作当前真实股价。

## 二、彼得林奇现金头寸标准口径（必查年报附注）

```text
彼得林奇现金头寸 = 现金及现金等价物 + 已核实定期存款 + 有价证券 - 长期有息债务
每股现金头寸 = 彼得林奇现金头寸 ÷ 总股本
扣现金后市值 = 当前总市值 - 彼得林奇现金头寸
扣现金后 PE = 扣现金后市值 ÷ 扣非净利润 TTM（港股为股东应占溢利 TTM）
```

**科目核对铁律：**
1. **现金及现金等价物**：取资产负债表“货币资金”中**扣除受限资金**（如承兑汇票保证金、冻结资金）后的可自由支配部分；若受限金额极小，可用货币资金总额并注明。
2. **定期存款（必须翻附注）**：仔细核查“货币资金附注”、“其他流动资产附注”、“其他非流动资产附注”中的定期存款、大额存单及应计利息。**严禁不看附注直接把整个“其他流动资产”（内含待抵扣增值税等）当成现金！**
3. **有价证券**：取“交易性金融资产”（A股）或“按公允价值计入损益之短期投资/金融资产”（港股 IFRS）。
4. **严禁计入应收票据**：A 股“应收款项融资”本质是银行承兑汇票，属于营运应收链条，**不计入现金头寸**。
5. **长期有息债务**：扣除“长期借款” + “应付债券”（可含“一年内到期的非流动负债”中的有息债务部分）。
   * 按彼得林奇简化公式，**主口径不扣短期借款**（假定由日常营运资金对冲）；但若公司短期借款巨大（短债长投），必须在正文中单独警示并列出“扣除全部有息负债后的净现金”作保守对照。
   * **租赁负债**不混入主口径，可在保守净金融现金口径中另行说明。

## 三、A 股与港股关键核算差异

### 1. 利润口径与 TTM 计算
* **A 股**：主线一律采用 **扣非归母净利润**；滚动 4 个单季度求和得到 `扣非净利润 TTM`。
* **港股**：IFRS 准则无法定“扣非净利润”科目，主线采用 **股东应占溢利（归母净利润）**，若公司连续披露口径一致的“经调整净利润（Non-IFRS）”，可并列参考，但估值分位与历史对比必须同口径。
  * **仅披露半年报与年报的港股**：`年末 TTM = 当年年报全年利润`；`年中（H1）TTM = 上年年报全年 + 本年 H1 - 上年 H1`（注意三者必须同为“股东应占溢利”，不得混用期内溢利总额）。
  * **披露季报的港股（如小米、腾讯）**：按四季度单季滚动求和计算 TTM。
  * **汇率换算**：港股股价为港元（HKD）、财报多为人民币（RMB）时，计算市值/PE 必须按同日汇率统一折算为同一币种，严禁直接用港元市值除以人民币利润。

### 2. A+H 多地上市公司的总市值计算
* 严禁直接用 `A股股价 × (A股+H股总股本)` 作为公司总市值（当 AH 溢价较高时会严重高估市值与 PE）。
* **正确做法**：
  * **同币种分类加总市值** = `A股股本 × A股股价 + H股股本 × H股股价 × 港币兑人民币汇率`；
  * 或明确声明按某一市场（如 A 股）价格折算并在正文中注明“A股同价折算市值 vs A+H实际分类加总市值”的差异。

## 四、其他高频财务与治理排雷铁律

1. **季节性陷阱：半年报（H1）严禁直接 `×2` 估算全年利润与动态 PE**
   * A 股制造业（如美的）常在 Q4 集中计提资产减值、年终奖与研发营销结算，导致 Q4 单季利润显著低于 Q3；而白酒等消费品（如汾酒）春节旺季前置，H1 利润常占全年的 ~69%。
   * 因此在中报期分析估值时，**严禁把 `H1 利润 × 2` 当作全年利润算 PE**；必须统一采用滚动 TTM 利润（`上年全年 + 本年H1 - 上年H1`），或先核对该公司过去 2~3 年 H1 占全年利润的真实比例。
2. **PDF 纵向表格抽取防“空值错列”**
   * 用 `pdfplumber`/`fitz` 抽取资产负债表时，若某科目（如应付债券、长期借款、交易性金融资产）本期清零为空白，文本提取器极易把右侧紧挨着的“上年同期比较列余额”误当成本期值（曾在伊利案例中因此少算 35 亿元现金头寸）。
   * **铁律**：凡是可能归零的有息负债与金融资产科目，必须核对表头列顺序、与同页“流动/非流动负债合计”做加总勾稽，并用下一期报表的“期初数”交叉验证。
3. **“营业总收入” vs “营业收入”（防金融子公司虚增毛利率）**
   * 带有财务公司/金融子公司的企业（如美的集团），利润表首行“营业总收入”包含利息收入与手续费，若直接用它算合并毛利率会被人为拉高数个百分点。
   * 必须统一使用纯商品/服务销售的 **“营业收入”** 计算主业毛利率，并在表中注明口径。
4. **加权平均 ROE vs 年末简单 ROE**
   * 年报披露的法定指标是“加权平均 ROE”（分母为期间加权净资产），而用年末净利润除以年末净资产拆解杜邦三因子得到的是“简单 ROE”，两者通常相差 1~2 个百分点，表格中建议并列或明确注明口径。
5. **CAGR 年数准确反算**
   * `2020 → 2025` 是 **5 年**（指数为 `1/5`），不是 6 年；`2022 → 2025` 是 **3 年**（指数为 `1/3`）。
   * 若起始年处于亏损或极低利润（如疫情坑或渠道出清年），计算出的高 CAGR 必须明确标注“含低基数修复效应”，不得直接外推。
6. **产品结构残差勾稽**
   * 年报往往只单列“占营收 10% 以上”的产品。制表与画图前，必须核对**已披露产品收入之和是否等于营业总收入**。
   * 若小于总营收，差额必须单列为“其他产品及业务（残差反推）”，**绝对禁止将已披露的几个产品直接除以它们的和强行归一化到 100%**（那会人为夸大主力产品的占比）。
   * 例外：纵向一体化能源/制造企业若披露的是“合并抵销前分部收入”，合计可大于合并总营收，此时注明“抵销前分部口径”即可。
7. **重资本公司的现金流考核**
   * 不能因为单年“经营活动现金流净额（CFO）> 净利润”就给现金流满分。
   * 必须计算 **近 5~6 年累计自由现金流（`累计 CFO - 累计购建固定无形长期资产支付的现金`）**。若赚来的经营现金流长年被扩产资本开支吞噬，在 `3.3 自由现金流与资本轻重` 中必须实质扣分。
8. **管理层资本配置与治理三项深挖排雷**
   * **回购去向鉴别**：严格区分“回购并注销（减少总股本，真股东回报）”与“回购转库存股用于员工持股/低价股权激励（本质是股东买单的薪酬费用）”，只有实际注销才确认减少股本。
   * **并购与商誉排雷**：有并购史的公司必须计算 `商誉净额 ÷ 归母净资产` 比例及历年减值；重大高溢价收购需进一步核查交易所问询函/工作函回复中的预计商誉、评估增值率与业绩承诺条款。
   * **质押、冻结与减持**：区分第一大股东、控股股东与实控人；严格区分“股权质押”与风险更高的“司法冻结/标记”，分别计算占该股东持股和总股本的比例；董监高减持需核查减持比例与资金去向（如是否用于偿还质押贷款）。
9. **巴菲特“一美元原则”测算规范（双向清洗戴维斯双击/双杀失真）**
   * **核心逻辑**：巴菲特在致股东信中强调，“公司留存的每一美元利润，长期看是否为股东创造了至少一美元的市场价值”。如果一家公司赚了钱不分红，留下来再投资或扩产，但二级市场长期市值增量低于留存金额，说明资金配置效率低下甚至在毁灭价值。
   * **失真痛点（戴维斯双击与双杀）**：
     * **戴维斯双击（泡沫虚胖）**：牛市或抱团炒作将 PE 从 10x 炒到 40x，即使留存资金乱花，市值也会暴涨，导致表观比率被虚增至 5~10 倍；
     * **戴维斯双杀（错杀优秀管理层）**：熊市或全行业杀估值将 PE 从 35x 杀到 10x，即便净利润翻倍、留存再投资回报优异，市值增量仍可能为负，导致表观比率 < 1.0 甚至为负。
   * **双口径核验模型（强制执行）**：
     * **口径 A（表观市值比率，反映市场实际情绪定价）**：
       $$\text{表观比率} = \frac{\Delta \text{总市值}}{\text{近 5 年未分配利润留存总额}} = \frac{\text{当前总市值} - \text{5年前年末总市值}}{\sum_{t=1}^5 \text{归母净利润} - \sum_{t=1}^5 \text{现金分红}}$$
     * **口径 B（估值归一化 / 内生利润比率，剥离 PE 波动贝塔）**：
       $$\text{内生利润比率} = \frac{\text{基期常态 PE} \times \Delta \text{净利润}}{\text{近 5 年未分配利润留存总额}} = \frac{\text{5年前 PE} \times (\text{最新净利润} - \text{5年前净利润})}{\text{近 5 年未分配利润留存总额}}$$
       * *注：若基期处于非正常亏损或极端泡沫，取近 10 年中枢 PE 进行归一化。*
   * **双向清洗与三层裁定规则**：
     1. **防双击虚胖（牛市抱团/估值膨胀型）**：若口径 A 虚高（> 1.5 倍），但口径 B < 1.0（内生净利润不增反降，市值全靠 PE 扩张），**强制以口径 B 为准从严扣分**，严禁因二级市场抱团泡沫在 `4.2` 给管理层打满分；
     2. **防双杀错杀（熊市系统性杀估值/逆周期回购型）**：若口径 A 承压（< 1.0 甚至为负），但口径 B ≥ 1.0（内生净利润与造血翻倍），且管理层拿出大额真金白银进行**注销式回购（年化注销股本 ≥1%~2%）**，判定为“管理层在低估时通过注销回购主动创造每股内在价值，二级市场错杀”，按卓越资本配置给予 2.5~3.0 高分；
     3. **概念炒作失真（题材炒作/过山车波动型）**：若市值随概念题材暴涨暴跌呈极端过山车，宣告“一美元检验失真”，该子项不予给分（0~1 分）。
10. **高景气峰值与单品独占暴利归一化核算规范（防低 PE 陷阱）**
    * **周期峰值与独占暴利陷阱**：强周期行业（煤炭、锂电、海运、光伏等）在景气顶峰，或医药企业在单一品种独占放量首年，TTM 利润处于历史高位，导致当前表观 PE 极低，近 10 年分位数极易跌至 0%~5%（极低带）。若机械按表观分位数给满分 6 分，会严重误判为“极度便宜”而陷入价值陷阱。
    * **常态中枢利润归一化**：
      * 凡处于高景气顶峰或单品独占暴利期的标的，**严禁直接用当期表观 TTM 利润计算分位数**；
      * 必须结合全行业供需中枢或历史景气中枢，审慎测算“常态化中枢利润”（如周期品按全周期均价或中枢吨毛利测算，独占药企按竞品入局后的常态净利率测算）；
      * 以 `当前市值 ÷ 常态中枢净利润` 计算常态 PE，并以常态 PE 进行历史分位评估与林奇收益线对齐。
