# 13 节评分细则、标准报告模板与交付校验清单

## 一、13 小节评分分档标准与打分细则

最小打分粒度为 **0.5 分**。各项指标按证据扎实程度依下列五档给分：

| 得分占满分比例 | 档位含义 | 判定标准 |
|---:|---|---|
| **90% – 100%** | 充分符合 | 商业逻辑清晰，财务连续 5~6 年扎实兑现，最新趋势健康，无明显瑕疵 |
| **70% – 89%** | 基本符合 | 主逻辑完全成立，存在次要短板、轻度周期波动或轻微数据未验证项 |
| **50% – 69%** | 部分符合 | 正负面证据并存，或核心指标处于行业中等水平、缺乏突出竞争优势 |
| **25% – 49%** | 明显偏弱 | 主要财务或业务证据不支持，存在显著竞争恶化或业绩下滑压力 |
| **0% – 24%** | 不符合 / 红线 | 触发重大负面证据、常年毁灭自由现金流，或商业模式完全无法验证 |

---

### 打分核心铁律（客观淘汰，不搞硬编码）

1. **客观机制淘汰同质化品种，不搞人工硬编码**：
   * **大宗商品品种**（煤炭、化工、原油等）：随行就市，自身零自主提价权，在 **2.4 自主定价权（10分）** 严格按事实核验，自然失分，绝不给予消费垄断级的高分；
   * **缺乏原研排他专利的单品品种**：面临竞品申报围剿与价格战，在 **2.2 格局（8分）** 判定为战役未打完，在 **2.3 特许权护城河（12分）** 判定为缺乏排他壁垒，总分自然锁死在平庸区间；
   * 触发财务造假、资金占用、非标审计、大股东高比例质押爆仓等治理红线，直接一票否决入 D 档，终止研究。
2. **轻资产天然优势与高端制造资本效率并重**：
   * 考核自由现金流与资本开支时，轻资产低追加企业（CapEx/营收 < 5% 且 FCF/净利润 ≥ 85%）在 3.3 享受天然满分通道；
   * 高端制造重资产不因厂房设备扣分，重点考核资本开支效率（近5年累计经营现金流能否全额覆盖 CapEx、能否换来稳定 ≥15% 的高 ROE 与真自由现金流）。
3. **知行合一：风险必须真正进入分数**：
   * 凡在正文中被定性为“核心矛盾”、“证伪条件”或“重大风险/关键短板”（如竞品围剿申报、专利悬崖、政策限价压制）的子项，**对应打分小节实得分严禁超过该小节满分的 70%**。严禁言行脱节。
4. **一件事只算一次分，严禁一俊遮百丑**：
   * **一个亮点只能在一处给分**：如独家批文在 2.3（护城河）给分后，2.2（格局）必须独立审视潜在竞品；3.1（ROE）和 3.2（真实增长）必须看 5 年全周期常态表现，严禁把首年放量或周期高点暴利处处打满分；4.2 仅评价管理层分钱意愿，买入到手股息率归 5.2，两处不得重复给分；
   * **优点再大也不能掩盖硬伤**：哪怕公司 ROE 极高或名气极大，到了负债、现金流或竞品威胁环节，依然必须按事实核验扣分。
5. **A 档“双重门槛机制”（防伪白马刷分混入 A 档）**：
   * 晋级 A 档必须同时满足 **“基本面质地总分 ≥ 64.0 分（80%）”** 且 **“好生意·定性实得分 ≥ 28.0 分（35分的80%）”**。定性壁垒脆弱者一律锁死在 B 档。

### 各章节 13 小节打分细则

#### 二、好生意·定性（35 分｜决定未来能否持续复利）

* **2.1 业务简不简单、需求稳不稳？（商业模式与需求刚性｜5分 = 业务简单 2分 + 需求刚性 3分，及格 3.0分）**
  * **业务简单清晰（2分）**：一句话能讲清商业逻辑，模式重复易懂，非年年赌新技术、赌爆款；
    * 证据锚点：满档 = 外行一句话能复述“卖什么、卖给谁、怎么赚钱”，不依赖技术前提；明显偏弱 = 常年需要赌新技术路线或爆款，主业频繁转向。
  * **需求刚性与抗替代（3分）**：底层需求长期存在、常年高频复购、弱周期；未来 5~10 年无颠覆性新技术或消费习惯淘汰风险。
    * 证据锚点：满档 = 年报有复购率、客单价或销量等连续数据佐证高频刚需；明显偏弱 = 需求绑定单一大客户、政策补贴或一代技术周期。
* **2.2 竞争格局清不清晰？（行业格局：月朗星稀｜8分 = 行业格局 5分 + 同行领跑优势 3分，及格 4.8分）**
  * **行业格局与集中度（5分）**：坚持“胜而后求战”，行业告别跑马圈地与无底线价格战，形成“一超多强、双寡头、月朗星稀”的稳定稳态。格局看终局不看短期抢跑，若后续有明确竞品排队获批，判定为战役未打完，得分严禁超 70%；
    * 证据锚点：满档 = 行业集中度常年稳定，且竞品进入队列在注册/审批数据库可查证已清空；明显偏弱 = 竞品仍在排队申报或价格战进行中。
  * **同行对比优势（3分）**：对比 2~3 家直接可比同行，公司在市场份额、毛利率、净利率与加权 ROE 上处于领先身位。
    * 证据锚点：满档 = 份额、毛利率、净利率、加权 ROE 全面领先对比表同行；明显偏弱 = 关键指标处于同行中游或落后。
* **2.3 护城河深不深？（特许经营权与护城河｜12分 = 排他性壁垒 6分 + 转换成本与心智 6分，及格 7.2分）**
  * **特许经营权与排他壁垒（6分）**：新进入者为何抢不走生意（独家配方、排他专利、特许牌照、极深规模成本曲线）；
    * 证据锚点：满档 = 独家配方、原研化合物专利或特许牌照在注册证/公告中可指认；明显偏弱 = 壁垒仅靠规模或渠道投入，后来者可砸钱复制。
  * **转换成本、网络效应与品牌心智（6分）**：客户迁移成本高不高，是否形成强双向网络效应或不可替代的品牌心智垄断。若依赖单一大单品且无化合物原研排他专利，得分严禁超 70%。
    * 证据锚点：满档 = 年报披露留存率、续约率等硬数据，或历次提价后销量不跌；明显偏弱 = 客户流失常见，无排他专利的单品依赖。
* **2.4 有没有自主定价权？（自主定价权与抗通胀｜10分 = 主动提价 5分 + 成本转嫁机制 5分，及格 6.0分）**
  * **主动提价能力（5分）**：成本未上涨时能否主动提价而销量不跌（需求侧进攻）；命根子有无捏在单一客户手里或面临政策压制；
    * 证据锚点：满档 = 近 5 年有 ≥2 次主动提价公告且提价当年销量不跌；明显偏弱 = 定价权在大客户或政策手里，只能被动跟随调价。
  * **成本转嫁机制（5分）**：合同有无调价条款或公式联动、成本上涨期的实际转嫁记录（防御侧）。本节只考核机制与行为，毛利率坚挺这一结果只在 3.2 计分，不重复给分。随行就市的同质化大宗商品本节得分严禁超 50%。
    * 证据锚点：满档 = 有明确的公式联动、调价条款等转嫁机制，且成本上涨期有实际转嫁动作；明显偏弱 = 成本上涨只能自行消化，无转嫁条款或记录。

#### 三、好生意·定量（35 分｜历史财务是否真实兑现）

* **3.1 赚钱效率高不高、靠什么驱动？（综合回报：ROE与杜邦｜14分 = ROE水平稳定性 7分 + 杜邦驱动纯度 7分，及格 8.4分）**
  * **ROE 水平与长期稳定性（7分）**：近 5~6 年常态加权 ROE 长期稳定在 15%~20% 以上。强制执行 5 年全周期平滑，严禁把单一年份爆品放量或周期高点暴利直接当成长期稳定性给满分；
  * **杜邦驱动纯度（7分）**：拆解净利率、总资产周转率、权益乘数。高 ROE 必须由高净利率或高周转驱动。**明确无息商业浮存金属性**：若高权益乘数主要由预收账款/合同负债及应付款等经营性无息占款贡献，属于顶级产业链地位，算作优势加分项；若主要靠银行借款等金融有息负债放大，视作重大扣分项。
* **3.2 利润增长真不真、毛利费用稳不稳？（利润成色：增长与毛利｜8分 = 真实增长 4分 + 毛利费用控制 4分，及格 4.8分）**
  * **扣非利润真实增长（4分）**：近 3~5 年营收与扣非净利润（港股看股东应占溢利）复合增速扎实，剔除低基数反弹、补贴、资产处置或一次性投资收益扰动；
  * **毛利率与费用率控制（4分）**：毛利率连续多年平稳或微升（无价格战失血）；期间费用率（尤其销售费用与管理费用）控制审慎，毛利未被买量烧钱吞噬。
* **3.3 赚的是真金白银还是账面富贵？（自由现金流与资本效率｜10分 = 利润含金量 5分 + 资本效率与造血 5分，及格 6.0分）**
  * **利润含金量（5分）**：近 5~6 年累计经营活动现金流量净额显著大于累计净利润（累计净现比 CFO/净利 ≥ 1.0）；
  * **自由现金流与资本效率（5分）**：
    * **显式轻资产满分通道**：近 5 年资本开支占营收比（CapEx/营收）< 5%（或 CapEx/净利润 < 20%），且自由现金流转化率 FCF/净利润 ≥ 85%，直接给满分 5 分（总分 9.5~10分）；
    * **高端制造重资产通道**：不机械排斥厂房设备投入，重点考核资本开支效率——近 5 年累计 CFO 能否全额覆盖 CapEx，扣除 CapEx 后累计自由现金流依然为正，且高 CapEx 换来稳定 ≥15% 的高 ROE 与规模成本壁垒。若常年自由现金流严重失血、持续借债配股输血，本小节打入不及格（< 3分）。
* **3.4 家底厚不厚、资产有没有水分？（资产负债：排雷与底线｜3分 = 债务安全 1.5分 + 营运排雷 1.5分，及格 1.8分）**
  * **债务安全与资金真伪（1.5分）**：账面真现金能否全额覆盖有息负债；无“存贷双高”、无大额资金受限、无短债长投；
  * **营运排雷与资产水分（1.5分）**：应收账款与存货增速未显著快于营收；合同负债蓄水池稳定；商誉占净资产比率低，在建工程无长期拖延不转固暗雷。本节作为基础合规底线，仅占 3 分，彻底挤干水分。

#### 四、好管理层（10 分｜公开硬账与分钱意愿）

* **4.1 有没有坑小股东、说话算不算数？（治理底线：排雷与言行｜4分 = 治理排雷 2分 + 言行兑现与会计诚实 2分，及格 2.4分）**
  * **治理底线与利益绑定（2分）**：大股东无高比例质押（质押率 < 30%）、无司法冻结、无清仓式减持或异常关联交易；激励门槛硬核不搞低价福利。（**红线一票否决**：若实锤造假、掏空侵占或高质押爆仓危机，一票否决直接打入 D 档）；
  * **言行兑现与会计诚实（2分）**：翻看 3~5 年前年报经营展望，历史目标按期兑现；逆风期坦诚不甩锅；研发投入费用化审慎、折旧计提老实。
* **4.2 赚了钱怎么花、分不分给股东？（资本配置：分红与回购｜6分 = 分红意愿与真回购 3分 + 主业专注与一美元 3分，及格 3.6分）**
  * **真金白银分红与真回购（3分）**：赚来的真金白银愿不愿意大比例分红（看分红/FCF 派息率）；回购为“真注销减少总股本”，而非转库存股做员工薪酬福利；
  * **主业专注度与一美元原则（3分）**：不盲目跨界多元恶化，克制高溢价并购；核算巴菲特“一美元原则”（近5年总市值增量 ÷ 近5年留存利润总额），双向清洗二级市场牛市估值膨胀（剔除PE溢价）与熊市系统性杀估值（按内生净利润增量与注销回购纠偏）。

#### 五、好价格（20 分｜纯分数判定合理、偏低、极低三档水位）

* **5.1 现在估值贵不贵？（估值位置：林奇线与PE｜10分 = 纵向分位 6分 + 扣现金PE与横向 4分，及格 6.0分）**
  * **纵向常态 PE 历史分位与林奇收益线（6分）**：考核当前处于利润中枢还是景气极值。若处于高景气高点，必须按常态中枢利润核算分位数，防低 PE 陷阱。
    * `< 10%`（极低带）：**5 ~ 6 分**
    * `10% ~ 30%`（偏低带）：**4 ~ 4.5 分**
    * `30% ~ 50%`（合理中枢）：**3 分**
    * `50% ~ 80%`（偏高带）：**1.5 ~ 2 分**
    * `> 80%`（透支高估）：**0 ~ 1 分**
  * **横向对比与扣现金真实 PE（4分）**：彼得·林奇纯净现金占市值 ≥20% 拿 3~4 分（强力托底）；扣现金后实际 PE 较表观 PE 显著折价并低于同行。
* **5.2 拿着等得起吗？（股东持有回报：股息率与回购｜5分 = 股东总回报 3分 + 现金托底 2分，及格 3.0分）**
  * **股东总回报率与现金流覆盖（3分）**：股东总回报率 = 股息率 + 回购注销收益率，均以当前总市值为分母。股息率 = 上一完整年度已实施分红（剔除特别分红）÷ 当前总市值，以分红实施公告为准；若公司已公告分红规划或承诺派息率，可叠加前瞻修正（承诺派息率 × TTM 净利），严禁自由预估分红。回购注销收益率 = 近 3 年年均**注销式回购**金额 ÷当前总市值（仅认真注销减股本，转库存股/员工持股不计入，与 4.2 同口径；3 年均值防单年脉冲，4.2 只评注销行为真伪、本节只算现价到手回报率，不属重复计分）。股东总回报率 ≥ 3.5% 且自由现金流全额覆盖拿满 3 分；2.5%~3.4% 拿 2 分；<2.5% 拿 0~1 分；
  * **纯净现金市值占比托底（2分）**：真现金占市值比例高提供防守垫。
* **5.3 往下亏多少、往上赚多少？（安全边际：三年测算｜5分 = 保守下行底线 2分 + 中性赔率 3分，及格 3.0分）**
  * **保守档测算（2分）**：测算下行最大风险（跌幅 <10% 或被持有期股息完全抹平拿满 2 分）。对周期性品种或面临重大竞品替代品种，模拟利润下调与估值下移双杀压力测试；
  * **中性档与赔率不对称（3分）**：按合理内生增长与估值中枢推算；中枢 PE 强制取 5.1 已核验的近 10 年中位数，中性档增速强制 ≤ 近 5 年扣非复合增速，禁止另起炉灶。三年赔率 ≥ 1:3 拿满 3 分。
