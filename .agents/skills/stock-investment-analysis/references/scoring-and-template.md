# 13 节评分细则、标准报告模板与交付校验清单

## 一、13 小节评分分档标准与打分细则

最小打分粒度为 **0.5 分**。各项指标按证据扎实程度依下列五档给分：

| 得分占满分比例 | 档位含义 | 判定标准 |
|---:|---|---|
| **90% – 100%** | 充分符合 | 商业逻辑清晰，财务连续 5~6 年扎实兑现，最新趋势健康，无明显瑕疵 |
| **70% – 89%** | 基本符合 | 主逻辑完全成立，存在次要短板、轻度周期波动或轻微数据未验证项 |
| **50% – 69%** | 部分符合 | 正负面证据并存，或核心指标处于行业中等水平、缺乏突出竞争优势 |
| **25% – 49%** | 明显偏弱 | 主要财务或业务证据不支持，存在显著竞争恶化或业绩下滑压力 |
| **0% – 24%** | 不符合 / 红线 | 触发重大负面证据、常年毁灭自由现金流，或商业模式完全无法验证 |

### 各章节 13 小节打分细则

#### 二、好生意·定性（30 分｜只看行业结构与商业机制）
* **2.1 业务简不简单、需求稳不稳？（需求与抗替代｜7分 = 业务简单 2分 + 需求与抗替代 5分）**
  * **业务简单清晰（2分）**：一句话能讲清商业逻辑（通过第一章初筛的基础分），模式重复易懂，非年年赌新技术/爆款。
  * **需求刚性与抗替代（5分）**：底层需求长期存在、常年复购、弱周期；未来 5~10 年无颠覆性新技术或消费习惯淘汰风险。
* **2.2 竞争格局清不清晰？（同行竞争格局｜8分 = 行业格局 5分 + 同行对比优势 3分）**
  * **行业格局与集中度（5分）**：坚持“胜而后求战”，行业告别跑马圈地与无底线价格战，形成“一超多强、双寡头、月朗星稀”的稳定格局。
  * **同行对比优势（3分）**：对比 2~3 家直接可比同行，公司在市场份额、毛利率、净利率与加权 ROE 上处于领先身位。
* **2.3 护城河深不深、有没有定价权？（进入壁垒与上下游议价权｜9分 = 进入壁垒 5分 + 议价与定价权 4分）**
  * **进入壁垒（护城河｜5分）**：新进入者为何抢不走生意（品牌心智、转换成本、规模成本曲线、渠道网络或特许牌照）。
  * **上下游议价与定价权（4分）**：能否主动提价或顺利转嫁原材料成本；命根子有无捏在单一客户手里（大客户依赖与政策集采核查）。
* **2.4 未来增长靠什么？（行业空间与竞争终局｜6分 = 增长路径 4分 + 终局份额空间 2分）**
  * **增量扩张或存量收割路径（4分）**：依靠渗透率提升、出海拓展、新品迭代，还是存量市场依靠寡头壁垒收割小厂出清。
  * **终局份额空间（2分）**：行业天花板是否尚远，竞争终局下龙头市占率能否持续抬升。（注：资本开支轻重统一归入 3.3 评分，此处不重复扣分）。

#### 三、好生意·定量（40 分｜只看历史财务报表兑现）
* **3.1 赚钱效率高不高、靠什么驱动？（综合回报：ROE与杜邦｜10分 = 回报率水平 5分 + 杜邦驱动质量 5分）**
  * **ROE / ROIC 水平与稳定性（5分）**：近 5~6 年加权 ROE 与 ROIC 长期稳定在 15% 以上。
  * **杜邦驱动质量（5分）**：拆解净利率、总资产周转率、权益乘数；高 ROE 必须由高净利率（品牌溢价/成本优势）或高周转（运营效率）驱动，若主要靠加杠杆放大则视作重大扣分项。
* **3.2 利润增长真不真、毛利费用稳不稳？（利润成色：增长与毛利费用｜10分 = 真实增长 5分 + 毛利费用控制 5分）**
  * **扣非利润真实增长（5分）**：近 3~5 年营收与扣非净利润（港股看股东应占溢利）复合增速扎实，剔除低基数反弹、补贴、资产处置或一次性投资收益扰动。
  * **毛利率与费用率控制（5分）**：毛利率连续多年平稳或微升（无价格战失血）；期间费用率（尤其销售费用与管理费用）控制审慎，毛利未被买量烧钱吞噬。
* **3.3 赚的是真金白银还是账面富贵？（现金流及资本开支｜10分 = 利润含金量 5分 + 自由现金流与资本轻重 5分）**
  * **利润含金量（5分）**：近 5~6 年累计经营活动现金流量净额显著大于累计净利润（累计净现比 CFO/净利 ≥ 1.0）。
  * **自由现金流与资本开支（巴菲特喜诗糖果测试｜5分）**：维持运营与适度增长无需常年耗尽资金，资本开支（CapEx）克制，能够留下丰沛的真金白银自由现金流。（注：本节只看造血能力，分钱意愿归 4.2，买入股息率归 5.2）。
* **3.4 家底厚不厚、资产有没有水分？（资产负债：债务安全与营运排雷｜10分 = 债务安全与真现金 5分 + 营运与资产排雷 5分）**
  * **债务安全与资金真伪（5分）**：账面真现金能否全额覆盖短期与长期有息负债；无“存贷双高”、无大额资金受限、无短债长投。（注：本节只看偿债安全，净现金占市值的估值折扣归 5.1）。
  * **营运排雷与资产水分（5分）**：应收账款与存货增速未显著快于营收（无放宽账期赊销冲量或向渠道压货）；合同负债蓄水池稳定；商誉占净资产比率低，在建工程无长期拖延不转固暗雷。

#### 四、好管理层（10 分｜只看治理底线与分钱意愿）
* **4.1 有没有坑小股东、说话算不算数？（治理底线：排雷与言行兑现｜4分 = 治理排雷 2分 + 言行兑现与会计诚实 2分）**
  * **治理底线与利益绑定（2分）**：大股东无高比例质押、司法冻结、清仓式减持或掏空型关联交易；激励门槛硬核不搞“半价福利”。（**红线一票否决**：若实锤造假、掏空侵占或高质押爆仓危机，一票否决直接打入 D 档）。
  * **言行兑现与会计诚实（2分）**：翻看 3~5 年前年报经营展望，历史目标按期兑现；逆风期坦诚不甩锅；研发投入费用化审慎、折旧计提老实。
* **4.2 赚了钱怎么花、分不分给股东？（资本配置：分红回购与一美元原则｜6分 = 分红意愿与真回购 3分 + 主业专注与一美元原则 3分）**
  * **真金白银分钱意愿（3分）**：赚来的真金白银愿不愿意大比例分红（看分红/FCF 派息率，不因股价高低扣分）；回购为“真注销减少总股本”，而非低价转库存股做员工福利。
  * **主业专注度与一美元原则（3分）**：不盲目跨界多元恶化，克制海外高溢价并购；严格核算巴菲特“一美元原则”：`近 5 年总市值增量 ÷ 近 5 年留存利润总额 ≥ 1.0`（比率 <1 甚至为负必须实质扣分）。

#### 五、好价格（20 分｜纯分数定合理、偏低、极低三档水位）
* **5.1 现在估值贵不贵？（估值位置：林奇收益线、PE分位与扣现金PE｜10分 = 纵向分位 6分 + 净现金折扣 4分）**
  * **纵向 PE 历史分位与林奇收益线（6分）**：当前利润处于周期高点还是低谷？（**特别提醒**：若当前利润处于历史超常景气高点，严禁直接使用当期 TTM 利润估值，需按常态中枢利润核算真实分位）。拉长 5~10 年看股价是否透支利润。
    * **近 10 年 PE-TTM 百分位评分参考**：
      * `< 10%`（极低带）：**5 ~ 6 分**
      * `10% ~ 30%`（偏低带）：**4 ~ 4.5 分**
      * `30% ~ 50%`（合理中枢）：**3 分**（50% 分位处即给 3 分）
      * `50% ~ 80%`（偏高带）：**1.5 ~ 2 分**
      * `> 80%`（透支高估）：**0 ~ 1 分**
  * **横向对比与扣现金真实 PE（4分）**：彼得·林奇纯净现金占市值 `≥20%` 拿 3~4 分（强力托底）；扣现金后实际 PE 较表观 PE 显著折价并低于同行。
  * **市场预期差与底部信号（定性辅助，不计分）**：市场到底在悲观恐慌什么？利空是否开始钝化？（增持回购已在第四章计分，此处用于排查价值陷阱，不重复计分）。
* **5.2 拿着等得起吗？（持有底线：股息率与回购｜5分）**
  * **股息防御垫（5分）**：静态股息率 `≥3.5%` 且自由现金流全额覆盖（有真注销回购为加分项）拿 4~5 分；`2.5%~3.4%` 拿 3 分；`<2.5%` 或现金流无法覆盖拿 0~2 分。
* **5.3 往下亏多少、往上赚多少？（安全边际：未来三年估值测算｜5分 = 保守下行底线 2分 + 中性赔率 3分）**
  * **保守档测算（2分）**：假设未来 3 年利润零增长并按历史低谷 PE 估值，测算下行最大风险（跌幅 `<10%` 或被股息完全抹平拿满 2 分）。
  * **中性档与赔率不对称（3分）**：按合理内生增长与估值中枢推算，三年赔率 `≥ 1:3` 拿满 3 分。
