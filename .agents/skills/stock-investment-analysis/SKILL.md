# 个股投资分析（6章13节全流程主技能）

## 1. 定位与核心原则

本 Skill 是个股深度价值研究与决策报告的统一主入口。框架专用于分析具备稳定复利属性的优质资产（商业模式简单、需求稳定、格局清晰、护城河深厚、有定价权、高资本回报率 ROE、轻资产低资本追加）。

将**一手财报底账精算**与**胜率（基本面质地 80分）+ 赔率（当前买入时机 20分）**解耦，每只股票仅输出一份客观、平实、严密的 **《投资分析报告》**。

**核心原则（1~4 的打分细则见 `references/scoring-and-template.md`「打分核心铁律」）：**
1. **聚焦复利资产，依靠机制客观淘汰，不搞具名硬编码**：随行就市的同质化大宗商品、缺乏化合物原研排他专利的单品品种，分别在 2.4（定价权）、2.2（格局）与 2.3（护城河）按事实严格扣分，自然无法混入高分；触发财务造假、资金占用、非标审计、大股东高比例质押爆仓等治理红线，一票否决入 D 档，终止研究。
2. **轻资产天然优势与高端制造资本效率并重**：轻资产低资本开支企业（CapEx/营收 < 5% 且 FCF/净利润 ≥ 85%）在 3.3 享受满分通道；高端制造重资产不因厂房设备扣分，重点考核资本开支能否换来稳定高 ROE 与真自由现金流。
3. **一件事只算一次分，严禁一俊遮百丑**：单一优势只在对应小节给分一处（独家批文归 2.3、分钱意愿归 4.2、买入到手股息率归 5.2），不得跨章节重复送分；业绩必须拉长看 5 年常态中枢，严禁把单年脉冲爆发当成长态给满分。
4. **知行合一（风险必须真正进入分数）**：凡在正文中被定性为“核心矛盾”、“证伪条件”或“重大风险”的子项，对应打分小节实得分严禁超过该小节满分的 70%。
5. **一手数据为准，禁用券商预测**：以官方年报/季报 PDF、交易所公告及同花顺/东财原始数据为准，不采信券商预测大饼。
6. **语言风格遵循平实、简练、通俗**：首句直切核心矛盾与账单；全篇禁用“见证、赋能、布局、助力、值得注意的是”等公文大词与套话，坚守严谨“三不碰”（不改财务数据口径、不删诚实限定语、不弱化投资判断）。

## 2. 100 分制评分体系与 A/B/C/D 决策矩阵

全篇设 **13 个评分小节**，满分 100 分。最小打分粒度为 **0.5 分**。

### 2.1 模块与 13 小节分值分布

| 评估模块 | 满分 | 包含小节与分值拆解 | 核心考核内容与及格线 (60%) |
|---|---:|---|---|
| **二、好生意·定性**<br>(决定未来能否持续复利) | **35** | **2.1 商业模式与需求刚性 (5)**<br>**2.2 行业格局：月朗星稀 (8)**<br>**2.3 特许经营权与护城河 (12)**<br>**2.4 自主定价权与抗通胀 (10)** | 2.1 模式简单清晰（一句话说清）+ 需求常年高频复购弱周期 (及格 3.0)<br>2.2 行业分出胜负、胜而后求战，告别恶性价格战 (及格 4.8)<br>2.3 **定性防守第一核心**：品牌心智、转换成本、网络效应、排他专利 (及格 7.2)<br>2.4 **定性进攻第一核心**：主动提价能力、成本转嫁机制（毛利率结果只在 3.2 计分） (及格 6.0) |

| **四、好管理层**<br>(公开硬账与分钱意愿) | **10** | **4.1 治理底线：排雷与言行 (4)**<br>**4.2 资本配置：分红与回购 (6)** | 4.1 质押/减持/关联交易公开排雷(2) + 目标按期兑现与会计诚实(2) (及格 2.4，实锤造假掏空一票否决入 D 档)<br>4.2 真金白银现金分红与真注销回购(3) + 主业专注与留存利润一美元原则(3) (及格 3.6) |

| **五、好价格**<br>(当前买入时机与赔率) | **20** | **5.1 估值位置：林奇线与PE (10)**<br>**5.2 股东持有回报：股息率 (5)**<br>**5.3 安全边际：三年测算 (5)** | 5.1 近10年常态PE分位与林奇收益线(6) + 扣纯净现金实际PE与横向对比(4) (及格 6.0)<br>5.2 股东总回报率与现金流覆盖(3，股息率=上一完整年度已实施分红剔除特别分红 + 回购注销收益率=近3年年均注销式回购，均以当前市值为分母) + 纯净现金市值占比资产托底(2) (及格 3.0)<br>5.3 保守档下行底线压力测试(2) + 中性档内生增长赔率不对称≥1:3(3) (及格 3.0) |

### 2.2 评级决策矩阵（字母定质地，符号定时机）

* **字母（A / B / C / D）评公司基本面质地（80分）**：
  * **A 档（≥64分，80%）—— 顶级复利印钞机**：商业模式简单、护城河深厚、高 ROE、轻资产、管理层老实分钱；
    * **A 档双门槛机制**：晋级 A 档必须同时满足 **“基本面质地总分 ≥ 64.0 分”** 且 **“好生意·定性实得分 ≥ 28.0 分（80%）”**。定性壁垒脆弱、仅靠单年财务脉冲刷分者，直接卡在 B 档。
  * **B 档（56~63.5分，70%）—— 良好坚实资产 / 高端制造冠军**：壁垒清晰但重资产或受轻度周期扰动；
  * **C 档（48~55.5分，60%）—— 平庸资产**：壁垒薄弱，受宏观或竞品围剿严重；
  * **D 档（<48分）—— 淘汰**：不及格，或触发造假、掏空、高质押等治理红线（一票否决入 D 档）。

* **符号（+ / -）判定当前买入时机（好价格 20分，纯分数判定）**：
  * **`+` 买入信号（好价格 ≥12分）**：
    * **价格偏低（12 ~ 14.5分）**：具备明确安全边际，下行风险可控，可按计划分批建仓；
    * **价格极低（≥15分）**：市场情绪深度错杀，多重托底，极具性价比的重点配置时机；
  * **`-` 观望信号（好价格 <12分）**：
    * **价格合理或偏贵（<12分）**：处于公允中枢或有所透支，耐心等待不追高。

| 最终判定 | 基本面评级 | 买入信号 | 对应现状 | 核心买方行动 |
|:---:|:---:|:---:|---|---|
| **A+** | **A**（顶级） | **+**（买入信号） | 顶级复利资产遇上偏低/极低价格 | **核心重仓配置（绝佳击球点）** |
| **A-** | **A**（顶级） | **-**（观望信号） | 顶级复利资产但价格处于合理或偏贵 | **核心储备池，耐心等回调，绝不追高** |
| **B+** | **B**（良好） | **+**（买入信号） | 坚实资产/制造冠军遇上偏低价格 | **高性价比配置，赚内生增长与估值修复** |
| **B-** | **B**（良好） | **-**（观望信号） | 资质良好但价格未见明显低估 | **留存次级观察池，等价格回落至 B+ 时出手** |
| **C / D** | **C / D** | — | 基本面不过关（不论价格贵或便宜） | **一律不予关注，坚决不碰（防价值陷阱）** |

## 3. 标准执行工作流（6 步闭环）

### 步骤 1：资料盘点与一手数据核验
1. **优先读取/自动下载同花顺结构化底账（免手动导出）**：
   * **A 股**：检查/下载 `data/{code}_main_year.xls`（年度指标）与 `data/{code}_main_simple.xls`（单季与TTM）；
     * 下载 API 带 Referer：`https://basic.10jqka.com.cn/{code}/`；
   * **港股**：检查/下载 `data/HK{code}_keyindex_report.xls` 与 `data/HK{code}_keyindex_year.xls`；
     * 代码必须为 5 位数字，带 Referer：`https://basic.10jqka.com.cn/HK{code}/finance.html`；
     * 港股报告期为累计值，需通过相邻期差分还原单季度与 TTM；
   * 使用 `python-calamine` 解析作为第一事实源。
2. **核验官方定期报告 PDF**：覆盖近 5~6 年年报 + 最新一期季报/中报（巨潮资讯网或港交所披露易）。核实产品线收入与毛利率明细、现金头寸定期存款附注、大股东质押明细。
3. **刷新行情与期后事项**：取最新交易日收盘价、总市值、近 10 年 PE(TTM) 历史分位；核查最新分红实施公告、注销回购与增减持。
4. **适用域前置判定**：本框架专用于稳定复利资产。遇银行/保险/券商等金融股（杜邦与 CapEx 口径失效）、上市不足 5 年（无 5 年底账）、困境反转股、常态中枢无法测算的深度周期股，在报告中明示“超出框架适用域”，终止或降级输出（只给事实账本与排雷结论，不打评分），不硬打分；C/D 档结论旁注明“超出适用域 ≠ 烂公司”。

### 步骤 2：核心财务与治理精算
* **分产品结构与残差勾稽**：各产品收入占比毛利求和，差额单列为“其他业务”，确保与总营收严格相等。
* **同行横向对账**：对比 2~3 家直接同行市值、PE、毛利率、净利率与 ROE，明确公司身位。
* **杜邦拆解与商业浮存金**：拆解销售净利率、总资产周转率、权益乘数；区分金融有息负债与经营性无息负债（合同负债/应付款带来的高杠杆算优势）。
* **自由现金流与资本效率**：精算近 5~6 年累计净现比（CFO/净利）与累计自由现金流（FCF）；核算 CapEx/营收 与 FCF/净利。
* **资本配置核算与一美元原则**：回购严格区分“真注销减股本”与“员工激励库存股”；核算巴菲特一美元原则（近5年总市值增量 ÷ 近5年留存利润总额），双向清洗牛市估值膨胀与熊市系统性杀估值。
* **林奇现金头寸与常态估值**：精算纯净现金（货币资金+定存+理财 - 长期有息负债）及扣现金后实际 PE；若处于景气峰值需核算常态中枢 PE。

### 步骤 3：生成标准定量图表
存入 `charts/` 目录：
* `stock-financial-charts`：4.1 ROE与杜邦图、4.2 利润增速图、4.3 产品结构图、4.4 现金流对比图、4.5 现金头寸图、4.6 营运质量图；
* `stock-earnings-line`：股价 vs 扣非利润 TTM 双 Y 轴图与归一化趋势图。

### 步骤 4：13 节逐项打分与自查
对照 `references/scoring-and-template.md` 细则进行 13 节打分，最小粒度 0.5 分。
* 坚守四大铁律：一件事只算一次分、知行合一（风险小节实得分不超过 70%）、A档双门槛（总分≥64且定性≥28分）、客观常识淘汰（不搞硬编码）。

### 步骤 5：按标准 Markdown 模板撰写报告
严格遵循 `references/scoring-and-template.md` 报告模板输出全文：
* 排版节奏：段首业务论述先行 → 紧凑 3 列打分小表（指标/依据/得分） → 核心插图 → 近 5~6 年原始财务账本底表；
* 第 6 章提取明确的量化证伪阈值与退出纪律，以持续两个报告期过滤单季短期噪声。

### 步骤 6：保存交付与一致性校验
报告保存至 `stocks/{代码}_{公司}/reports/{公司}_投资分析报告_YYYY-MM-DD.md`。核验算术加总无误、评级与分数匹配、图片路径真实有效。
