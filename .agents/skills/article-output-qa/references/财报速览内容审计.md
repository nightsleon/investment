# 财报速览/投资文章内容审计法（三维复核）

用于用户要求"根据财报校验这篇文章：1.数据严谨性 2.表达通俗简练 3.有没有投资者该关注却遗漏的点"。
这是**内容审计**，与 SKILL.md 前三节的机械 QA（表格渲染/图表截止日/图注）互补。

## 0. 前置：先把原始依据凑齐再动手（缺一个就会漏判）

| 依据 | 用途 | 缺了会怎样 |
|---|---|---|
| 本期报告 PDF 全文（非摘要） | 所有数字的准绳 | 无法判"未披露"类断言 |
| 上一期季报 PDF | 单季 = H1 − Q1 的减数 | 单季归因无法验方向 |
| 上年年报 PDF | 期初对比基准、上年期分红基数、全年峰值 | 分不清"较年初"还是"较去年同期" |
| `data/pe_history.csv`（日频） | 现价/市值/PE/PB 与历史分位 | 会误用季度 CSV 的错误 close |
| `charts/{code}_季度数据.csv` | 归一化图、TTM、历史营收/净利序列 | 无法验"创新高/历史高点" |

PDF 提取：`read_file` 直接读 PDF（走 anydoc 抽取），或 pymupdf 落盘成 txt 再 `search_files` 定位关键词。
**注意**：表格类 PDF 抽取后单元格会错位串列，读数时以"同一行内数值+单位"配对，并回原 PDF 交叉确认关键数字。

## 1. 数据严谨性：三类错误，按严重度排序

### A 类 硬错（必须改，会被专业读者一眼抓）
1. **括号内分项加总 ≠ 声称总额**。福耀：有息负债 217.57 亿，分项相加 227.0 亿（差 9.43 亿）——
   应付债券 8.0 亿 = 中票 8.0 亿（科目名与工具名重复计），"一年内到期 36.3 亿"取自资产负债表
   一年内到期的非流动负债（含租赁负债），公司有息债务表对应科目是 34.81 亿。
   **规则：见到括号枚举就当场加一遍；总额以公司自己的口径表为准，不自拼科目。**
2. **行情数据取错日期 / 用了错的源字段**。福耀：称"9月2日收盘实测"却写 57.06 元 / 1489.12 亿，
   9/2 真值 56.37 元 / 1471.11 亿 / PE 17.35。57.06 元在 2018 年以来 2105 个交易日只出现过两次
   （2024-10-15、2025-05-16）——溯源是季度 CSV 最后一行 close 填错而 trade_date 写 9/2。
   **规则：现价/市值/PE 一律回日频 `pe_history.csv` 按声称日期精确取值。**
   **反推自洽 ≠ 取数正确**：1489.12÷84.78=17.56 与文中 PE 自洽，但分子本身就是错的。
3. **归因方向说反**。福耀：写"Q2 汇兑拖累更小但降幅更深→主业走弱"。实际同比摆动
   Q1 6.75 亿（损失4.39 vs 上年收益2.36）、Q2 7.30 亿（损失3.64 vs 上年收益3.66）——Q2 拖累**更大**。
   扣汇后利润总额 Q1 +9.63% → Q2 +1.07%，**仍为正**，是降速不是转负。
   **规则：单季因素对比一律算"本期 −（−上年同期）"的摆动额，上期符号为负/收益时尤其致命；
   归因结论必须配一个"扣除该因素后的同比"数字自证方向。**
4. **历史极值/高点判错**。福耀："股价从 2021 年高点回落""市值从高点腰斩过"——实际最高收盘
   74.20 元（2025-09-17，市值 1936.43 亿），当前回撤 23.2%；2021 年最高仅 63.78 元。
   **规则："创新高/历史高点/腰斩"必须用日频序列算 max/min，绝不凭印象或凭当期同比方向。**
5. **口径错标**。"净现金 = **货币资金** 221.27 亿"——货币资金账面 221.58 亿（含受限保证金），
   221.27 亿是现金及现金等价物期末余额，两个概念不能混。

### B 类 口径不严谨（需补基准或补限定）
- **税前 vs 税后混叙**：+4.78% 是利润总额口径，同句却谈"归母"。摆动 14.04 亿的税后影响是 12.02 亿，
  单期损失 8.03 亿的税后才是 6.87 亿——"约14亿（税后影响归母约7亿）"把两个数交叉配对了。
- **整体报表口径 vs 主营分部口径**：福耀整体毛利率 38.84%，分产品加总对应主营口径 38.30%（+1.79pct），文中混用。
- **"近年新高"无对比区间**：必须给出比了哪几年、什么口径。
- **国内行业增速对标全球收入**：中汽协 −4.1% 是**中国**销量，福耀"一半左右收入源自海外"，对标不严谨。
- **跨维度类比当披露**：用境外**资产**占比 34.2% "参考"海外**收入**占比——重资产海外工厂的资产占比通常显著高于收入占比。
- **一次性损益只报支出**：火情营业外支出 1.6154 亿，漏了营业外收入 0.7629 亿（含该火情保险理赔款，同比+102.84%），
  净额 −0.85 亿；其他应收款还挂应收保险赔款 2512 万。
- **有效税率变动未提**：福耀 17.03% → 14.37%，贡献约 1.2 亿非经营性利润——既是当期支撑也是明年敞口。

### C 类 核对正确（审计时也要列出，证明覆盖面）
福耀核对正确约 60 项：营收/归母/扣非/经营现金流及同比、OCF÷净利润=1.146、收现比 98.5%、
FCF 45.51−22.98=22.53、现金增加 28.86 亿、汇率影响 −6.11 亿、资产负债率 48.38%、商誉 0.403%、
应收/应收票据周转、存货周转 93 vs 82、分部毛利率 32.45%/41.58%、境外资产 252.96 亿/34.21%、
福耀美国 39.75 亿收入/4.67 亿净利、中期分红 65.73%、相关系数 0.8296、H1 占比三年均值 49.55%。
**报告审计结论时先给"硬错"再给"核对正确"，让作者知道底子是好的、问题集中在哪几类。**

## 2. 表达：六个高频问题

1. **重复**：同一结论反复出现（福耀"汇兑 14 亿摆动"出现 5 次，措辞几乎一样）。保留结论节+论证节两处，其余删。
2. **注释信息过载**：一个表注塞三件事（公式+科目说明+两个对比基准）。拆成正文一句+注脚两行。
3. **术语无解释**：扣非归母/收现比/分位/TTM/归一化/PEG 直接用。最危险的是**两个同名概念**：
   资产负债率 48.38%（中国准则）vs 资本负债比率 0.93%（IFRS）——文章只用了前者却未说明差异。
4. **数字格式不统一**：38.84%/38.8%、17.6倍/17.56倍、217.57亿/218亿、221.27亿/221亿混用。
5. **调性割裂**："欢迎点赞、转发、关注！"插在严谨财务分析与风险提示之间。
6. **绿灯重复计数**：福耀"扣汇后主业利润正增长(+4.8%)"与"高附加值产品加速渗透(+8pct)"是同一因果链
   （结构升级→毛利率→利润），拆成两盏灯让 8:3:0 显得比实际乐观，与正文"Q2 主业走弱"的警告不自洽。
   **红绿灯计数是文章的自评分，同一因果链只算一盏灯。**

## 3. 遗漏点：去哪找（按命中率排序的检索清单）

内容审计最有价值的部分——作者漏掉的往往不是"没看到数字"，而是**没去读那几个章节**。

| 去处 | 能找到什么 | 福耀实例 |
|---|---|---|
| **税项/税收优惠附注** | 有日期、可量化的确定风险 | 出口退税率 7007 类玻璃 **2026-04-01 起归零**（旁证：合同资产 0→2608 万；8708 类仍 13%）；**9 家**子公司高新资质 2026 年 10–12 月到期（长春10/16、天津11/6、苏州11/6、厦门精密11/22、沈阳11/29、福清12/28、福州模具12/28、福耀饰件12/28、福耀铝件12/28）；海外子公司集体亏损 |
| **在建工程附注（项目预算表）** | 转固折旧对未来毛利率的压力 | 在建 85.89 亿 = 固定资产 46%；美国镀膜项目进度 **97%** 最先转固 |
| **存货附注（分类别）** | 备货 vs 积压的判别 | 增量绝大部分是库存商品（38.60→40.40 亿，+1.80 亿），原材料仅小幅增加，在产品略降；跌价准备反而从 1.06 亿降到 0.94 亿。⚠️ "占增量百分比"必须先说清分母：÷存货总增量(2.41亿)≈75%，÷三大类别增减净额之和(2.05亿)≈88%——两种算法都出现过，引用时要标明口径，否则同一事实两个数 |
| **主要财务指标表** | ROE、EBITDA/全部债务、利息保障倍数、资本负债比率 | ROE 10.34%（−2.84pct）全篇未提；EBITDA全部债务比 0.25（−30.56%） |
| **`pe_history.csv` 的 PB 列** | PE 低分位 vs PB 高分位的反差 | PB 3.85 = **59%** 分位 vs PE 21% 分位 → 估值收缩全来自盈利端，ROE 仍高位 |
| **未确认递延所得税资产的可抵扣亏损** | 海外/新业务持续亏损的证据 | 23.87→26.98 亿（+3.11 亿），FYSAM 饰件相关资产已减值 |
| **筹资活动现金流分解** | 分红的时点错配、加杠杆幅度 | 支付股利同比 −14.42 亿系时点差异；26.10 亿中期股利 Q4 才流出；净融资同比 +30.57 亿 |
| **债券章节** | 融资成本、主动加杠杆信号 | 中票 1.68%–1.77%、超短融 1.45%–1.49%，期后共发 4 期中票+3 期超短融 |
| **股东情况章节** | 筹码分散度、机构增减仓 | 股东户数 +5.95%（分散）；港股通 +7,047,837 股（+19.4%）；国寿/大成基金增持 |
| **主要子公司表** | 利润集中度 | 前五大子公司净利合计 21.25 亿 = 归母的 53.5% |
| **关联交易表** | 渠道依赖（不是金额大小） | 向特耐王包装采购占同类交易 **100%** |
| **员工人数 + 管理费用变动原因** | 人效信号 | 人数 −319 人，管理费用增因是"职工薪酬增加" |
| **对外投资章节** | 新设主体透露的战略方向 | 福耀饰件(安徽) 3 亿、安徽福耀模具 1 亿；税项附注首次出现福耀印尼 |
| **上年年报分红段** | 分红率的真实基准 | 2025 全年 2.10 元/股、分红率 58.85% → 本期中期 65.73% 是明显提升 |

**报告遗漏点时的排序原则**：把"有日期、可量化、已生效"的确定事项（退税归零、资质到期、转固折旧）
排在"宏观展望"（汇率走向、车市能否企稳）之前。作者常把篇幅给后者，但前者对投资决策的信息量更大。
**"第二增长曲线"类叙事必须给反面证据**（亏损子公司、减值、毛利率显著低于主业），否则第四节说服力打折。

## 4. 输出格式

三段式，与用户的三问对齐：
1. **数据严谨性** — A 类硬错（逐条：文章写什么 / 真值是什么 / 差异溯源）→ B 类口径问题（表格）→ C 类核对正确（列清单证明覆盖面）
2. **表达** — 先肯定做得好的（骨架/红绿灯/比喻），再逐条给问题，**关键处给出改写建议原文**（现文 vs 建议）
3. **遗漏点** — 按重要性 🔴/🟡/🟢 分级，每条给出：事实 + 出处章节 + 为什么投资者该关注

末尾给**总体判断**：框架是否成立、核对了几项、必须处理才能发的是哪几类、最大内容缺口是什么。
最后主动询问是否要出修订稿（全量修订 or 只修硬错+补重点遗漏）。
