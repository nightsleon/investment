# 港股检查表

> 路由到本表的条件：上市地 = 港股（5位数字代码，如 9633）。涉外企业追加 conditional.md 汇兑板块。

## 数据获取

- [ ] 财报 PDF 从港交所披露易下载：`https://www1.hkexnews.hk/search/titlesearch.xhtml`（搜股票代码或公司名），或公司官网 IR 页面
- [ ] 区分**中期业绩公告**（通常 25-30 页，含完整财务报表）与**中期报告**（完整版，含 MD&A 详细讨论）——两者都要读
- [ ] 港股行情数据源见 `references/行情与PE数据源.md` 港股专节
- [ ] PE 历史序列：港股不适用东财 `RPT_VALUEANALYSIS_DET`，走 AKShare `stock_hk_hist` 或 Tushare 港股接口 → 仍不足则用日频收盘价 + 年度/半年度 EPS 回算

## 会计口径差异（IFRS vs CAS）

- [ ] **无"扣非净利润"概念**：IFRS 不要求披露扣非。关注公司自行披露的 adjusted profit / underlying profit（如有），并在正文说明口径
- [ ] **分部报告（Segment Report）**：IFRS 8 要求披露分部收入和分部利润，这是港股分析的核心数据——比 A 股的分产品营收更详细
- [ ] **商誉**：IFRS 下同样不摊销，只减值。但 IFRS 3 允许"廉价购买利得"（bargain purchase gain），如遇收购需检查
- [ ] **使用权资产 + 租赁负债**：IFRS 16 全面资本化，A 股 CAS 21 类似但细节不同。资产负债率口径需注意
- [ ] **金融工具分类**：IFRS 9 下的 FVTPL / FVOCI / 摊余成本分类，影响利润波动——港股公司金融资产占比可能更高

## 利润表

- [ ] 营收（Revenue）、毛利（Gross Profit）、母公司拥有人应占溢利（Profit attributable to owners）
- [ ] 毛利率趋势（同比），板块毛利率变动按收入占比加权
- [ ] 销售及分销开支、行政开支、其他开支的增速对比
- [ ] **财务费用**：大额变动先拆汇兑（港股公司外币敞口通常更大）
- [ ] **所得税**：港股公司常有复杂的离岸架构（开曼→香港→大陆），关注实际税率及构成（中国企业所得税 25%、西部大开发 15%、香港利得税 16.5%）

## 现金流量表

- [ ] 经营活动现金流净额 vs 归母溢利
- [ ] 港股公司可能披露"经调整自由现金流"——注意公司口径与自行计算口径的差异
- [ ] 投资活动现金流中"购买定期存款"与"定期存款到期"可能金额很大（港股公司爱存长期定存），影响经营现金流解读

## 资产负债表排雷

- [ ] **现金家底**：长期银行定期存款 + 现金及银行结余 + FVTPL 金融资产（港股公司常把理财放这里）——三者合计才是真实流动性
- [ ] **有息负债**：计息银行借款（Interest-bearing borrowings），注意区分固定/浮动利率
- [ ] **净现金/净负债**：港股公司常在"资本管理"节直接披露 debt-to-equity ratio 或 net debt，优先用公司口径
- [ ] **其他应付款及应计费用**：港股公司可能因计提末期股息导致该项暴增——确认是否含已宣派未付股息
- [ ] **营运周转官方披露优先**：存货周转天数（Inventory turnover days）、应收周转天数（Trade receivables turnover days）**必须先检索 MD&A 原文披露值**。港股业绩报告通常已直接披露标准天数（如农夫山泉 P22 披露存货 94.7 天、应收 4.5 天），严禁未查原文便自行盲目套公式导致与官方公告冲突
- [ ] 商誉、在建工程、存货检查同 A 股检查表

## 股息与股东回报

- [ ] **港股通红利税 20%**：内地投资者通过港股通持股，股息需扣 20% 红利税；直接持股（港股账户）扣 10%。正文应提示
- [ ] 末期股息 vs 中期股息：港股公司可能一年派两次，计算全年分红率需加总
- [ ] 股息币种：港股可能以港币宣派但以人民币支付，汇率影响实际回报

## 估值

- [ ] 实时市值与 PE(TTM) 实测：直接运行 `python3 scripts/fetch_valuation.py 代码`，获取官方实时港币市值、换算人民币市值、PE(TTM) 及 PB
- [ ] **PIT 披露日生效铁律（杜绝前视偏差）**：回算历史 TTM 时，跳变生效日必须是业绩公告实际发布日（`announcement_date`），绝对禁止按 6/30 或 12/31 期末日提前调高 TTM
- [ ] **逐日动态汇率折算**：历史 PE 序列计算必须按每日实际外汇中间价换算，严禁全周期套用固定估算汇率（如 0.90）
- [ ] **PE 分位窗口明确**：标注统计时间跨度与样本分母（如：同花顺近 5 年 0.81% 分位 / 上市以来 X% 分位）
- [ ] **估值建议客观情景化**：强制采用“估值修复情景 vs 持续磨底情景”区间推演，严禁给出单一主观目标价
- [ ] AH 股同时上市的公司：需说明用的是 H 股价格还是 A 股价格算 PE

## 税项附注

- [ ] 中国企业所得税优惠政策到期日（西部大开发 15%、高新 15%）
- [ ] 香港利得税是否有应课税溢利（通常无，但需确认）
- [ ] 海外子公司亏损 / 可抵扣亏损余额变动
- [ ] 预提所得税（Withholding tax）：大陆子公司向港股母公司分红需扣 5%-10% 预提税
