# 四问框架要点

> 财报速览的核心分析骨架。详细方法论见用户仓库 `references/财报速读指南.md`。

## 四问逻辑

### 第一问：赚不赚钱？（利润表）

**核心指标**：
- 营收增速（同比）
- 归母净利增速（A 股加扣非归母）
- 毛利率趋势（同比，按业务板块拆）

**判断标准**：
- 营收和利润同步增长 + 毛利率稳定或提升 = 健康增长
- 营收增但利润不增或下降 = 增收不增利，需归因（费用/汇率/一次性）
- 营收和利润同步下降 = 行业或公司困境

**论证位预算**：最多 2 个
1. 营收增速归因（哪个业务/产品驱动）
2. 毛利率变动归因（哪个板块贡献/拖累，按收入占比加权）

### 第二问：赚到的钱到手了吗？（现金流表）

**核心指标**：
- 经营现金流净额
- 收现比 = 销售商品收到的现金 / 营收（≥1.0 健康，<0.7 黄灯）
- 自由现金流 = 经营现金流 − 资本开支

**判断标准**：
- 经营现金流 ≥ 归母净利 = 利润质量高（钱真的到手了）
- 经营现金流 < 归母净利 × 0.7 = 纸面利润，需警惕
- 收现比持续下降 = 回款恶化或压货

**论证位预算**：最多 1 个
1. 现金流/净利比值 + 收现比趋势

### 第三问：家底厚不厚？（资产负债表）

**核心指标**：
- 净现金 = 货币资金+定存+理财 − 有息负债
- 商誉 / 归母净资产（>30% 黄灯，>50% 红灯）
- 应收账款增速 vs 营收增速（差距过大需归因）
- 存货结构（库存商品 vs 原材料，含义相反）

**排雷清单**（详见 checklists）：
- 大存大贷
- 商誉减值风险
- 在建工程长期不转固
- 关联交易占比过高

**论证位预算**：最多 1 个
1. 排雷扫描结论（哪些雷没踩到 / 哪些需要跟踪）

### 第四问：明年还能赚吗？（看未来）

**核心指标**：
- 业务增长引擎（新产品/新市场/产能扩张）
- 研发投入强度（研发费用 / 营收）
- 资本开支计划（在建工程进度）
- 股东回报（分红率、回购）

**判断标准**：
- 有明确的增长引擎 + 研发投入持续 + 股东回报稳定 = 可持续
- 增长引擎模糊 + 研发下降 + 分红削减 = 需警惕

**论证位预算**：最多 2 个
1. 增长引擎（哪个业务/产品是未来主力）
2. 核心观察点（下个季度/年报需要验证什么）

## 论证位总预算

**速览 = 最多 6 个论证位**

- 第一问：2 个
- 第二问：1 个
- 第三问：1 个
- 第四问：2 个

超过 6 个 → 升级为 3R 简报
超过 12 个 → 升级为完整投资报告

**一个论证位** = 数字 + 一步推导 + 结论

示例：
- ✅ "毛利率从 35% 降至 32%，主要因原材料成本上升（附注披露 PET 采购价+15%），拖累整体 3 个百分点"
- ❌ "毛利率下降"（无推导无归因）
- ❌ "毛利率从 35% 降至 32%，主要因原材料成本上升、产品结构变化、汇率波动、竞争加剧等多重因素"（超过一步推导）

## 红绿灯速判

**格式**：
```
🟢 绿灯：八项——营收双位数增长｜毛利率稳定｜经营现金流健康｜…
🟡 黄灯：两项——应收账款增速远超营收｜存货周转天数上升
🔴 红灯：均未触发
```

**规则**：
- 行首带语义引导 + 计数
- 每行只列"结论标签 + 关键数字"，不重述正文理由
- 同一因果链不拆两盏灯（避免虚增数量）
- 删改项目时同步改计数

## 证据分级（内化于行文，不贴标签）

| 级别 | 含义 | 写法 |
|---|---|---|
| 确认 | 公司披露的报表/附注原值 | 直接陈述 |
| 推算 | 由披露值计算 | 算式揉进句子："单季=中报−一季报" |
| 未定论 | 财报无法证实的归因 | 自然限定语："财报没有解释原因" |

**禁止**：正文中出现【确认】【推算】【未定论】标签字样。
