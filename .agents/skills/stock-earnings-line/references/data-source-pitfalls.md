# 数据源踩坑记录

## 东方财富API vs 同花顺Excel

### 净利润差异
- 东方财富API的净利润系统性偏高0.1-0.8亿/年（5年累计多2.17亿）
- 同花顺Excel数据更准确
- **规则：有同花顺Excel时以同花顺为准，东方财富API作为交叉验证**

### ROE口径差异
- 同花顺用加权平均ROE（分子=全年净利润，分母=加权平均净资产）
- 手动杜邦计算用年末净资产作分母，结果偏低3-7个百分点
- **规则：ROE应使用同花顺的加权ROE**

### 分红数据
- 东方财富API的PRETAX_BONUS_RMB字段是**每10股分红**，不是每股
- 计算股息率时需除以10

## 其他流动资产辨析

### 汾酒(600809)
- 其他流动资产194.7亿 = 全部是短期定期存款（年报附注确认）
- 年报第102页："公司货币资金充裕，以定期存款方式进行日常资金管理"

### 美的(000333)
- 其他流动资产253.8亿 = 固定收益类14.3亿 + 增值税90.4亿 + 套期工具32.0亿 + 其他117.1亿
- 只有14.3亿是理财产品，其余都不是现金

### 福耀(600660)
- 其他流动资产9.1亿，金额小，未确认是否含定期存款

## FINANCE_RECE字段
- 东方财富API的FINANCE_RECE = 资产负债表的"应收款项融资"
- 实际是银行承兑汇票（经销商付款），不是理财产品
- 不计入现金头寸

## 查询股东信息
- 东方财富API: reportName=RPT_F10_EH_FREEHOLDERS
- 华润在汾酒的持股用"华创鑫睿(香港)有限公司"名义，不是直接用"华润"
