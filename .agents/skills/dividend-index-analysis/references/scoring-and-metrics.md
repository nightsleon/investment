# 评分与指标计算细则

主 skill 是执行控制器；需要计算指标、解释分数或做报告复核时加载本参考。

## 一、评分细则

默认总分100分。判断项通常存在约1分误差；总分差1—2分视为同档，不用整数制造虚假精度。

### 1. 规则稳健性：30分

| 子项 | 分值 | 评分重点 |
|---|---:|---|
| 分红持续性 | 12 | 连续分红、盈利、利润/ROE、支付率、现金流、每股股息增长 |
| 高股息陷阱防御 | 7 | 多年平均股息率、异常支付率、盈利约束、周期顶部和股价暴跌防范 |
| 策略一致性 | 6 | 指数名称与目标是否真正落实在选样和加权中 |
| 加权与调仓 | 3 | 加权是否符合目标，调样是否兼顾响应速度与换手 |
| 规则透明度 | 2 | 现行方案是否清楚，新旧资料是否一致，关键公式能否复现 |

判断要点：

- 不把低波设成通用必答题。质量指数做好质量筛选可拿满策略一致性，低波指数把低波落实在筛选或加权也可拿满。
- 盈利增长与每股股息增长不是一回事；分别记录。
- 连续分红只能证明过去发过钱，不能单独证明未来可持续。
- 近12个月股息率更容易受一次性分红和周期高点影响；只有两年分红、单年股息率或仅设支付率上限时，持续性与陷阱防御通常不应满分。
- 行业和个股上限主要在结构维度评分，避免重复计分。

### 2. 历史风险收益：25分

| 子项 | 分值 | 评分重点 |
|---|---:|---|
| 精确年化全收益 | 10 | 同区间横向排名与差距，不只看名次 |
| 最大回撤 | 8 | 回撤深度、发生阶段和修复情况 |
| 收益/波动 | 7 | 统一口径下的直观风险收益效率 |

年化波动仍需计算和展示，但不单独计分，避免与收益/波动重复奖励低波。历史风险收益只评价序列成绩，不因发布前回溯扣分；回溯问题统一进入证据可信度。

建议使用相对评分而非固定阈值。第一名不自动拿满分；差距很小时不机械拉开。

### 3. 表现稳定性：15分

| 子项 | 分值 | 评分重点 |
|---|---:|---|
| 完整年度表现 | 7 | 正收益年份占比、最差年度、收益是否依赖少数年份 |
| 滚动3年 | 5 | 正收益占比、中位数、最低值和分布 |
| 滚动5年 | 3 | 正收益占比、中位数、最低值和分布 |

相邻月度滚动5年窗口共享59个月，不是独立检验。完整年度权重最高，滚动3年观察中期路径，滚动5年只作补充。发布后历史不在这里重复加减分。

### 4. 结构分散：10分

| 子项 | 分值 | 评分重点 |
|---|---:|---|
| 个股集中 | 3 | 最大个股、前十大权重、样本数及单股上限 |
| 行业集中 | 4 | 最新行业权重、行业上限及单一周期暴露 |
| 结构护栏 | 3 | 单股、前五大、行业和市场上限是否形成有效硬约束 |

结构证据同时标级：

- A：同日完整个股和行业数据；
- B：部分实际结构加规则约束；
- C：主要依据规则约束，缺少可对齐的实际快照。

有上限不等于当前一定分散，没有上限也不等于当前一定集中。C级资料可评价护栏，不能断言“当前结构最均衡”。最新快照不能反推十年结构；没有历史基本面数据时，不做股息、盈利增长和估值变化的精确归因。

### 5. 证据可信度：20分

| 子项 | 分值 | 评分重点 |
|---|---:|---|
| 数据可比性 | 6 | 币种、日期、TR/NTR、官方序列或代理口径是否一致 |
| 发布后历史 | 10 | 正式运行长度、经历的市场阶段及回测延续情况 |
| 资料一致性 | 4 | 现行方案、单张、修订公告和数据接口是否一致 |

发布前回溯只在本维度折价一次。官方全收益缺失而使用ETF复权净值时，降低数据可比性；若费用和跟踪误差足以影响精确分差，给总分区间或低置信度档位，不给伪精确单点分数。

## 二、数据口径

每个序列至少记录：

| 字段 | 示例 |
|---|---|
| 指数名称/代码 | 中证红利全收益 H00922 |
| 币种 | CNY |
| 回报类型 | TR |
| 期初/期末日期 | 2016-06-30 / 2026-07-31 |
| 交易日数 | 2451 |
| 数据来源 | 指数公司官网接口/XLS |
| 正式发布日期 | 2008-05-26 |
| 回溯区间 | 无，或期初至发布日期前 |

常用口径对应：

| 类型 | 分红处理 |
|---|---|
| Price Return | 不计现金分红再投资 |
| Total Return / TR / 全收益 | 通常按税前现金分红再投资 |
| Net Total Return / NTR / 净收益 | 按指数规则假设扣税后再投资 |

即使都标为NTR，不同指数公司的税率假设也可能不同。小于约1个百分点的差异，在口径无法完全对齐时不要写成显著优势。

## 三、计算公式

### 1. 精确年化收益

按实际日历天数计算：

`CAGR = (期末点位 / 期初点位) ^ (365.2425 / 实际天数) - 1`

不要把10.08年直接按整10年计算。

### 2. 年化波动率

日频：

`日频年化波动 = 日收益率标准差 × √252`

月频：

`月频年化波动 = 月末收益率标准差 × √12`

跨指数比较必须统一频率和样本区间。官方单张与自行复算口径不一致时，横向表统一使用自行复算值，并说明方法。

### 3. 最大回撤

`回撤_t = 点位_t / 截至t的历史最高点 - 1`

最大回撤为全区间最小值。记录对应高点、低点；修复时间是低点后首次回到前高的日期。区间结束仍未修复时写“尚未修复”，不要留空。

### 4. 收益/波动

`收益/波动 = CAGR / 年化波动率`

它不是夏普比率。只有在统一无风险利率后，才能计算并称为夏普比率。

### 5. 年度收益

采用每个自然年最后一个交易日点位：

`年度收益_y = 年末点位_y / 上年末点位_(y-1) - 1`

首尾不完整年度不进入“完整年度胜率”，可在附表单列。

### 6. 滚动收益

建议取月末点位：

`滚动N年年化收益 = (当前月末点位 / N年前对应月末点位) ^ (1/N) - 1`

至少报告：样本数、正收益占比、中位数、最小值和最大值。所有窗口为正只能描述样本期，不能外推为保本规律。

## 四、比较逻辑

### 规则与回测发生冲突时

- 规则完整、历史一般：写“逻辑合理，但历史验证不足”。
- 规则偏弱、历史很好：写“历史风险收益优秀，但可持续性证据较弱”。
- 规则与历史都好：写“规则合理，历史验证充分”。
- 规则与历史都弱：写“存在明显缺陷”。

不能因为回测漂亮而替规则缺陷找理由，也不能因为规则复杂而忽略真实表现差。

### 分组与分数精度

- 总分差1—2分：视为同档，强调取舍，不把79/80之类边界写成能力断层。
- 总分差3—5分：可以按“综合领先组、特色鲜明组”等组织阅读，但分组不是硬门槛。
- 分差较大仍要检查是否由单一主观子项造成。
- 规则与结构判断项通常承认约1分误差。
- 调整权重前先说明目标，不为得到预设冠军倒推权重。

### 回溯数据

- 发布前所有数据标为回溯试算。
- 基日、First Value Date、指数历史起始日均不能替代Launch Date。
- 历史风险收益和稳定性按序列事实评分；回溯占比、发布后长度和延续情况只在证据可信度中折价一次。
- 数据允许时，单独比较发布后区间，检查回测优势是否延续。
- ETF代理与官方全收益不等量齐观时，使用分数区间或置信度等级。

## 五、文章写法

面向普通读者时，不从方法论条款开始。推荐叙事：

1. 先制造一个值得解释的矛盾，例如“收益冠军、回撤冠军和风险收益效率冠军为什么不是同一只”；
2. 给出结论和策略分组，不强造唯一冠军；
3. 先展示当前持仓、行业暴露和集中风险，回答“最后买成了什么”；
4. 用一张核心表比较全收益、波动、回撤和风险收益效率；
5. 解释分红不是白捡、高股息陷阱、质量与低波的区别；
6. 按策略类型压缩规则，每只只写“怎么选、优势、代价”，完整链条放附录；
7. 比较发布前回溯、发布后表现和滚动稳定性；
8. 正文公开五维权重、一级得分和总分，详细子项与证据等级放附录或评分明细；
9. 用目标导航收束结论：采用无序列表，每条以加粗目标开头，再写优先研究对象、适合原因和必须接受的代价；避免把长内容塞进四列宽表；
10. 说明目标导航只负责筛选研究对象，不等于买入建议；当前估值和ETF工具质量另行分析；
11. 结尾回到指数质量，不延伸到估值择时或ETF推荐。

首次出现写指数全称，后文使用唯一且清楚的简称。只选一套核心比喻，避免赛跑、考试、尺子、开车等意象混用。标题要有真实问题，正文避免机械的优缺点堆砌。文章按首次发布的独立文本写作，不出现“原评分、重新调整、新版”等依赖旧稿的表达。每个结论尽量写成：

`事实：数据或规则是什么 → 判断：说明了什么 → 含义：读者应怎样理解`

## 六、程序复核清单

完成后用程序检查：

1. 各指数起止日期和交易日数；
2. CAGR是否按实际日历天数；
3. 波动频率是否统一；
4. 最大回撤日期是否与序列一致；
5. 完整年度是否排除首尾残年；
6. 滚动窗口样本数、正收益率和中位数；
7. 每只指数五维分数与全部子项之和是否等于总分；
8. 表格分组、总分和正文结论是否一致，1—2分差异是否被写成同档；
9. 回溯是否只在证据可信度中扣分一次；
10. 结构资料是否标注A/B/C等级，规则护栏是否与实际结构分开；
11. ETF代理是否使用区间或置信度而非伪精确单点；
12. 摘要、正文和结尾是否残留旧排名、旧日期、旧数值或修订历史措辞；
13. 本地引用是否存在，官方链接与资料名称是否匹配。
