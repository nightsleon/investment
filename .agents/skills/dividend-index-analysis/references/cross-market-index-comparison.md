# 跨市场红利指数统一比较

用于把A股、港股通或沪深港联合指数纳入同一红利指数比较。核心目标是统一收益口径，同时保留交易日历、汇率和市场结构差异。

## 1. 先锁定币种和回报类型

跨市场指数通常同时发布人民币、港元及对应TR版本。必须通过官方衍生指数接口和基础信息双重确认：

- 价格指数代码；
- 全收益指数代码；
- 币种；
- 是否为TR而非Price/NTR；
- 历史接口中的官方全称。

统一比较使用同一币种的全收益序列。例如人民币主比较不能混入港元TR，也不能用价格指数代替TR。

## 2. 保留不同交易日历

沪港深联合指数可能在港股单独开市日继续计算，因此交易日数会多于纯A股指数。不要为了追求相同行数而删除这些官方观测，也不要要求所有序列共用完全相同的日历。

统一要求应是：

1. 起止日期一致；
2. 每条序列内部日期递增、无重复、点位为正；
3. CAGR按实际日历天数计算；
4. 日频波动按各自实际交易日收益计算，并披露年化假设；
5. 跨指数稳定性优先用月末点位，避免交易日历差异放大；
6. 最大回撤按各自官方日度序列计算。

如果必须逐日横向计算相关性或组合收益，再单独建立共同交易日交集；不要把交集处理反向污染单指数CAGR和回撤。

## 3. 区分发布前回溯和发布后历史

基日、历史起点、发布日期必须分开。统一比较区间跨越发布日期时，同时报告：

- 完整区间CAGR；
- 发布后CAGR和最大回撤；
- 回溯数据占比或回溯阶段日期。

发布后收益弱于完整回溯不等于规则失效，但应降低稳定性和证据置信度。

## 4. 同时检查市场分散和行业集中

跨市场不自动等于真正分散。至少同时报告：

- 上海、深圳、北京、香港等市场权重；
- 最大行业权重；
- 最大个股、前五大和前十大权重；
- 规则中的市场、行业和个股上限。

常见情况是个股和市场分散明显改善，但同一行业仍跨市场集中。文章中应明确写成“分散了什么、没有分散什么”。

## 5. 最新市场权重的取数顺序

1. 先查官方最新结构API；
2. 若市场分布API不存在，下载官网最新样本权重文件，按官方市场字段汇总；
3. 若权重文件没有市场字段，可按官方证券代码与交易所字段匹配，但必须保留映射规则；
4. 只能取得指数单张时，使用单张市场权重并注明其日期，不与更新日期不同的行业数据伪装成同一截面。

最新行业、前十大和市场权重日期不一致时分别标注，不能笼统写“截至最新”。

## 6. 评分提示

- 跨市场和100只样本主要影响“个股集中”和市场分散，不应自动获得行业集中满分；
- 低波筛选是否真实有效，需由波动率和回撤分别验证；
- 最大回撤浅与波动率最低是两个不同结论；
- 规则使用“且”联合剔除时，不得改写为分别剔除；
- 复杂的预期股息率公式要说明输入来自历史财务数据还是分析师预测，不能只凭“预期”二字推断。

## 7. 扩容文章时的验证

加入新指数后必须同步更新：

- 比较对象数量和全收益/代理数量；
- 绩效、稳定性、评分CSV；
- 发布后表现表；
- 收益、风险、稳定性和综合排名；
- 标题、章节中残留的旧数量；
- 数据README和参考链接；
- 旧版文章的版本标识与新版入口。

最后程序校验评分加总、排名顺序、表格列数、本地链接、关键数字和官方URL状态。
