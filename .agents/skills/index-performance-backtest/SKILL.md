# 指数行情回溯分析

## Overview

回溯指数全收益序列过去 N 年的行情趋势，计算收益、风险、稳定性等关键指标并生成图表，附带最新持仓快照供参考。不评价编制规则、不打分。

严格区分：
- 本 skill 范围：历史行情回溯 + 指标计算 + 最新持仓快照展示；
- 不做：指数规则稳健性判断、结构分散度评分、当前估值择时、ETF产品质量筛选。

持仓快照只展示"当前买成了什么"的事实（前十大权重、行业分布、集中度），不做规则好坏判断，不打分。

## When to Use

适用于：
- 单指数或多指数过去 3 年、5 年、10 年或其他区间的全收益行情回溯；
- 计算 CAGR、年化波动率、最大回撤、滚动收益等指标；
- 生成归一化走势图、年度收益热力图、回撤图等图表；
- 展示最新持仓快照（前十大、行业分布），帮助理解收益来源；
- 面向读者输出行情分析报告。

不适用于：编制规则评价、结构分散度评分、估值判断、择时或 ETF 选择。

## 数据采集

### 数据源

中证指数官网（csindex.com.cn）官方接口。接口可能调整，每次使用时实际请求并核对返回字段、日期与文件类型。

### 全收益代码确认

先通过衍生指数接口确认全收益指数代码，不要按代码规律猜测：

- 衍生指数：`https://www.csindex.com.cn/csindex-home/perf/get-derivative-index?indexCode={PRICE_CODE}`
- 基础信息：`https://www.csindex.com.cn/csindex-home/indexInfo/index-basic-info/{CODE}`

### 历史数据下载

历史 JSON 接口：

```
https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode={TR_CODE}&startDate={YYYYMMDD}&endDate={YYYYMMDD}
```

可用交易日查询：

```
https://www.csindex.com.cn/csindex-home/perf/index-perf-tradeDate?indexCode={TR_CODE}
```

Excel 导出（POST）：

```
https://www.csindex.com.cn/csindex-home/exportExcel/downloadindex-perf?language=CH
```

请求体：

```json
[{"startDate": "20160810", "endDate": "20260810", "indexCode": "TR_CODE"}]
```

### 数据验证

1. JSON `code` 为 200，核对 `indexNameCnAll`、首末 `tradeDate`、首末 `close` 和记录数。
2. Excel 响应应是工作簿内容，而不是错误 JSON 或网页。
3. 确认序列为全收益（TR）而非价格指数；价格指数只作辅助参考。
4. 记录基日、历史起始日和正式发布日期三者，发布前数据标注为回溯。

### 非中证指数

标普指数（SPDJI）等需走对应官网或数据服务；港股通、沪港深等跨市场指数注意币种和交易日历差异。官方全收益无法核实时，可单列跟踪 ETF 含分红复权净值作为临时代理，必须标注"已扣费、受跟踪误差影响、非官方全收益"，降低结论置信度。

### 最新持仓数据

中证指数官网结构接口（用价格指数代码，非全收益代码）：

- 前十大权重：`https://www.csindex.com.cn/csindex-home/index/weight/top10new/{PRICE_CODE}`
- 中证一级行业权重：`https://www.csindex.com.cn/csindex-home/index/weight/industry-weight-two-new/{PRICE_CODE}?cicsType=1`
- 样本特征：`https://www.csindex.com.cn/csindex-home/indexInfo/index-feature/{PRICE_CODE}`

引用时必须写明接口返回的 `updateDate`。前十大接口通常直接给出 `top5Sum` 和 `top10Sum`，优先引用官方汇总字段而非手算。若接口数据与指数单张日期不一致，以较新的官方结构接口为准，并注明日期差异。

## 指标体系

五组指标，每组回答一个不同的问题。详细公式见 `references/metrics-formulas.md`。

### 一、收益能力 — 赚了多少

| 指标 | 说明 |
|---|---|
| 累计全收益 | 区间总回报，最直观的终值 |
| 年化收益（CAGR） | 按实际日历天数年化，方便横向比较 |
| 分年度收益 | 每个自然年收益，看是否靠少数年份撑起来 |

### 二、风险 — 过程多痛

| 指标 | 说明 |
|---|---|
| 年化波动率 | 日频或月频标准差 × √252 或 √12，跨指数必须统一频率 |
| 最大回撤 | 区间内从历史最高点到最低点的最大跌幅 |
| 回撤修复时间 | 低点后首次回到前高的天数；未修复写"尚未修复" |

### 三、风险收益效率 — 值不值得受这个罪

| 指标 | 说明 |
|---|---|
| 收益/波动 | CAGR ÷ 年化波动率，直观效率，不是夏普 |
| 夏普比率 | 需统一无风险利率和频率才能计算并称为夏普 |

### 四、稳定性 — 是实力还是运气

| 指标 | 说明 |
|---|---|
| 年度正收益占比 | 完整年度正收益次数 ÷ 总年数 |
| 最差年度收益 | 最差一年什么表现 |
| 滚动3年年化 | 中位数、正收益占比、最低值 |
| 滚动5年年化 | 中位数、正收益占比、最低值 |

滚动窗口高度重叠（相邻月度5年窗口共享59个月），不能当独立样本。稳定性以完整年度为主，滚动3年为辅，滚动5年只补充路径信息。

### 五、分阶段表现 — 不同市场环境下的行为特征

根据区间内的实际市场阶段，选取有代表性的时段比较：

- 单边下跌期（如2018、2022）：防御性够不够
- 快速反弹期（如2019Q1、2024Q4）：能不能跟上涨
- 震荡期：策略优势是否体现
- 特定事件冲击（贸易摩擦、核心资产泡沫、疫情等）

阶段选取应结合区间内实际发生的事件，不强套固定模板。3年区间可能只覆盖1-2个阶段，不强求五段全填。

## 持仓快照

展示指数当前"买成了什么"，帮助读者理解收益可能来自哪里。只展示事实，不做规则评价和打分。

### 展示内容

| 项目 | 说明 |
|---|---|
| 前十大权重股 | 股票名称 + 权重百分比，附 top5Sum / top10Sum |
| 行业分布 | 中证一级行业权重，标注前3大行业占比 |
| 集中度提示 | 前十大合计占比是否偏高，单一行业是否超40% |
| 截面日期 | 接口返回的 updateDate |

### 注意事项

- 持仓快照是截面数据，不能反推十年结构，也不做收益归因。
- 只展示"当前买成什么"，不判断"买得好不好"。
- 行业分布和前十大来自同一 updateDate，若无法统一则分别标日期。
- 持仓快照放在报告中的走势图之后、指标表之前，先让读者看到"买成什么"再看"表现如何"。

## 计算口径

### 精确年化收益

```
CAGR = (期末点位 / 期初点位) ^ (365.2425 / 实际天数) - 1
```

按实际日历天数，不把 10.08 年按整 10 年算。

### 年化波动率

日频：`日收益率标准差 × √252`
月频：`月末收益率标准差 × √12`

跨指数比较必须统一频率和样本区间。

### 最大回撤

```
回撤_t = 点位_t / 截至t的历史最高点 - 1
```

最大回撤为全区间最小值。记录高点、低点日期；修复时间为低点后首次回到前高的日期。

### 滚动收益

取月末点位：

```
滚动N年年化 = (当前月末点位 / N年前对应月末点位) ^ (1/N) - 1
```

至少报告：样本数、正收益占比、中位数、最小值、最大值。

### 年度收益

每个自然年最后一个交易日点位：

```
年度收益_y = 年末点位_y / 上年末点位_(y-1) - 1
```

首尾不完整年度不进入"完整年度胜率"，可单列。

## 区间选择

### 默认区间

支持 3 年、5 年、10 年三档回溯，以最近交易日为终点向前推：

| 档位 | 大致天数 | 备注 |
|---|---|---|
| 3年 | 约1096天 | 侧重近期表现，阶段分析可能只有1-2段 |
| 5年 | 约1826天 | 覆盖一个完整牛熊周期 |
| 10年 | 约3652天 | 长期复利验证，阶段分析最丰富 |

取最近交易日对齐。多指数比较时统一到共同起止日和共同交易日交集。

### 区间对齐

- 单指数 CAGR 和回撤使用各自完整序列；
- 多指数横向比较时统一到共同起止日；
- 相关性或组合收益另取共同交易日交集；
- 不要为追求相同行数删除官方交易日。

### 多区间并行

同时分析多个区间时（如 3Y + 5Y + 10Y），每个区间独立计算指标，不混用。对比不同区间结果可以观察策略在不同时间窗口的稳定性。

### 回溯数据标注

发布日之前的数据标注为回溯试算。基日、历史起始日和发布日期是三件事。回溯占比影响结论可信度，但不影响指标计算本身。3年区间如果指数发布不足3年，回溯占比可能较高，须明确标注。

## 图表规范

详细脚本模板见 `scripts/generate_backtest_charts.py`。

### 走势图

- 归一化到期初 = 100，多指数叠加比较；
- 线宽 0.8，白底，图高 7.5 英寸；
- 图例放左上角，用简写名称 + 累计收益，按累计收益降序排列；
- 可加宽基基准（如沪深300全收益）用灰色虚线，图例末尾标"基准 +XX%"，不参与排序；
- Y 轴顶部留约 3% 余量，不画末端标签；
- 标题中性，结论写正文。

### 年度收益热力图

- 行 = 指数简写，列 = 年份；
- A 股惯例红涨绿跌（TwoSlopeNorm）；
- 最差年用深色粗框标注；
- 格内标数值。

### 回撤图

- 可选；展示各指数回撤路径，辅助理解最大回撤和修复时间。

### 通用要求

- 字体：PingFang SC / Heiti SC / STHeiti / Arial Unicode MS；
- DPI 180；
- 图表紧跟其支撑的章节，不在文末集中堆图；
- 生成后逐张视觉验收，检查标签重叠或裁切。

## Workflow

### 1. 确定分析对象和区间

- 列出要分析的指数，记录全称、代码、币种、回报类型；
- 确定回溯区间（3年、5年、10年或自定义）；
- 记录每只指数的基日、历史起始日和发布日期。

### 2. 采集数据

- 确认全收益代码；
- 下载历史 JSON 或 Excel；
- 验证返回数据：字段、日期、记录数、序列连续性；
- 保存为 CSV，文件名格式：`{代码}_{简称}_全收益_{开始日}_{结束日}.csv`；
- 采集最新持仓：前十大权重、行业分布，记录 updateDate。

### 3. 计算指标

运行 `scripts/calculate_metrics.py` 或等价脚本，输出：

- 收益风险汇总表（CAGR、波动率、最大回撤、收益/波动等）；
- 稳定性表（年度胜率、最差年度、滚动3/5年统计）；
- 年度收益表；
- 分阶段收益表（如需要）。

### 4. 生成图表

- 归一化走势图（多指数 + 基准）；
- 年度收益热力图；
- 回撤图（可选）；
- 逐张视觉验收。

### 5. 输出分析

按以下结构组织报告：

1. 开头钩子：给出 2-3 个反常或值得注意的结果；
2. 持仓快照：前十大权重 + 行业分布 + 集中度提示（让读者先知道买成什么）；
3. 核心指标表：CAGR、波动率、最大回撤、收益/波动一览；
4. 走势图 + 解读；
5. 年度收益热力图 + 分阶段解读；
6. 稳定性分析；
7. 数据口径和来源说明。

## Hard Rules

- 只用全收益（TR）或净总收益（NTR）做长期主比较，价格指数只作辅助。
- 不混用币种、日期、税收口径或 Price/TR/NTR。
- 不把回溯数据写成实盘历史，发布前数据标注为回溯试算。
- CAGR 按实际日历天数计算，不按整数年近似。
- 跨指数比较必须统一波动率频率和样本区间。
- 滚动窗口须说明重叠性，不当作独立样本。
- 收益/波动不是夏普比率，除非统一无风险利率。
- ETF 代理使用区间或低置信度表达，不给伪精确单点结论。
- 持仓快照只展示事实，不做规则评价、不打分、不做收益归因。
- 持仓截面不能反推历史结构。
- 不混入估值择时或 ETF 工具质量。
- 不对缺失数据做精确归因或补全。

## Verification Checklist

- [ ] 全收益代码经官网接口确认，非猜测
- [ ] 币种、日期、TR/NTR 口径一致
- [ ] CAGR 按实际日历天数
- [ ] 波动率频率统一
- [ ] 最大回撤日期与序列一致
- [ ] 完整年度排除首尾残年
- [ ] 滚动窗口已说明重叠性
- [ ] 回溯数据已标注
- [ ] 持仓快照注明 updateDate，未做收益归因
- [ ] 图表视觉验收通过
- [ ] 未混入规则评价、打分或估值择时
