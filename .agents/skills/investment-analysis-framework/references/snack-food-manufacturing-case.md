# 休闲食品自主制造型公司分析要点（盐津铺子案例）

适用：自主制造、多品类、零食量贩/商超/电商并行、处于扩产期的休闲食品公司。案例数字只用于说明分析方法，不直接外推其他公司。

## 1. 先识别商业模式

区分三类能力：

1. 品牌与消费者心智；
2. 自主制造、原料和规模成本；
3. 渠道触达与新品铺货。

自主制造占比高不等于消费者粘性高。制造型公司的护城河通常是“新品快速量产+成本控制+全渠道铺货”，不是配方不可复制或强网络效应。

## 2. 产品结构不能只看年报大类表

A股年报“占营收10%以上的产品”可能漏掉多个小品类：

```text
其他产品及业务（本期） = 总营收（本期） - 已披露产品收入合计（本期）
其他产品及业务（上期） = 总营收（上期） - 已披露产品收入合计（上期）
残差同比 = 本期残差 / 上期残差 - 1
```

要求：
- 产品收入合计必须与总营收勾稽；
- 残差明确写“按总营收反推”，毛利率未披露则留空；
- 不得把已披露品类重新归一化到100%；
- 比较“核心品类收入增量”与“公司总收入增量”。若核心品类增量大于总增量，说明其他品类合计在收缩，增长并非全面开花。

## 3. 爆品增长要拆数量、结构和价格

优先从年报实物量表读取销量、产量、库存量：
- 收入增长远快于销量：检查提价、规格升级或渠道结构；
- 产量快于销量、库存量大增：检查压货和高基数；
- 销量高增且库存周转改善：爆品质量更高。

终端售价没有统一披露时标注“待验证”，不要用电商零散价格代替公司平均售价。

## 4. 渠道增长与议价权要一起看

零食量贩、会员店和头部商超能快速放量，也会强化渠道议价权。分析时同时看：
- 线下/线上收入与增速；
- 前五大客户集中度（如披露）；
- 经销、量贩、会员店、电商各自的收入和利润率（未披露则不推造）；
- 应收账款、合同负债、销售费用与毛利率变化。

“进入头部渠道”是增长信号，不自动等于品牌护城河增强。

## 5. 重资产扩张必须看累计FCF

自主制造公司可能出现CFO/净利润很好，但扩产吃掉全部现金。至少计算近5—6年：

```text
累计CFO/累计净利润
累计FCF/累计净利润
单年资本开支/经营现金流
固定资产+在建工程/总资产
总资产周转率趋势
```

若累计CFO高、累计FCF低，正确结论是“利润能回款，但股东可支配现金弱”；现金流质量项应实质扣分。扩产后的核心验证是产能利用率、资产周转率、折旧和自由现金流，而不是只看收入增长。

## 6. 现金头寸与资本配置

彼得林奇现金头寸仍按“货币资金+已核实定存+交易性金融资产-长期有息负债”。若现金头寸为负：
- 扣现金后估值不会改善；
- 短期借款虽不进林奇公式，仍要单独检查流动比率、流动负债和流动资产覆盖；
- 分红、回购、扩产和新增借款同时发生时，管理层资本配置应降分。

用于激励的回购不是注销；若回购由专项贷款支持，还要把利息和长期借款变化纳入现金安全性。

## 7. 激励与治理

旧激励未达标后推出新激励，需同时写：
- 旧计划未达标是经营信号；
- 新计划授予价、覆盖人数、解除比例和股份支付费用；
- 业绩考核目标不是盈利预测；
- 实控人兼任董事长/总经理、关联采购额度较大时，继续检查定价公允性和权力制衡。

## 8. 估值表达

历史PE低分位不能自动覆盖爆品高基数、收入降速和重资本风险。可用“当前TTM利润不增长”的14/18/22倍PE压力—中性—乐观档，避免使用公司激励目标或券商预测。净利润已包含利息收入时，不另加现金；负现金头寸可展示调整后PE略升而非略降。
