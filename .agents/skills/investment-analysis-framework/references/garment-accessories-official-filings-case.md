# 服饰辅料制造商官方公告研究案例

适用：钮扣、拉链、织带等非标准化服饰辅料企业；用户要求仅用年报、季报、官网和交易所公告，研究商业模式、产品结构、海外业务、产能、客户与风险。

## 1. 来源与检索

- 连续下载目标区间每一年的年报全文及最新季报，记录公告日期和巨潮 `static.cninfo.com.cn` 直接 PDF URL；不得以摘要替代全文。
- 巨潮标题未必使用标准名称。例如一季报可能题为“2026年一季度报告”，用“2026年第一季度报告”会返回零结果。依次检索：`第一季度报告`、`一季度报告`、`年一季度`，再按日期和证券代码核验。
- 当前日期若已进入下一年度，不能因年份看似“未来”而排除已正式披露的新年报；以巨潮公告时间和PDF正文为准。

## 2. 六张连续事实表

至少建立以下年度连续表，每一行附对应年度报告URL：

1. 商业模式：产品、定制方式、以单定产、直营/贸易商、品牌商与指定代工厂。
2. 产品结构：总收入、钮扣、拉链、其他辅料、其他业务；金额、占比、同比。
3. 海外业务：国际收入、占比、同比、覆盖国家、海外基地状态。
4. 产能：钮扣/拉链产能、综合利用率、境内外产能占比及利用率、在建/投产/爬坡状态。
5. 客户结构：前五大销售额及占比、第一大客户占比、关联销售占比、是否匿名。
6. 风险：需求、贸易/关税、汇率、原料人工环保成本、应收坏账、募投及产能爬坡。

年度表不得只列期初期末；连续区间能识别结构变化、海外替代国内、客户集中度和产能先行扩张。

## 3. 产品结构勾稽与量价线索

- 产品收入必须与营业收入勾稽。公司可能在后续年报重分类上年“其他服饰辅料/其他”，不要用后续比较数覆盖原年报的当年披露数；如需可比口径，另列“重述/重分类口径”。
- 若年报同时披露分产品收入和实物销量，可计算：
  - 钮扣隐含单位收入 = 钮扣收入 / 销量（粒）
  - 拉链隐含单位收入 = 拉链收入 / 销量（米）
- 必须标为“据年报数据计算的隐含单位收入”，不得写成公司正式售价。非标准化产品受规格、材质、客户、币种和产品组合影响，不能据此单独证明提价。
- 比较收入增速与销量增速：收入低于销量时可写“增长更偏销量驱动，隐含单位收入下降”，但同时保留组合效应限制。

## 4. 海外基地与利润风险

- 区分国际收入、境外产能占比、境外产能利用率和境外项目效益；四者不是同一口径。
- 按“在建→建成投产→客户验厂/打样→产能爬坡→达产→盈利”记录项目状态。投产不等于产能有效释放，更不等于盈利。
- 募投项目必须记录延期、未达效益原因及汇兑损益。海外收入高增长同时可能出现低利用率、汇兑损失和项目亏损。
- 最新季报若未披露分产品/分地区/产能，不得推造季度拆分；只列集团口径，并明确“无法验证季度增长来源”。

## 5. 客户结构

- 年报常只披露“客户一”等匿名信息。可确认集中度，但不能把官网合作品牌、市场传闻或机构调研提及对象当成前五大客户。
- 同时列前五大占比和第一大占比；前五大低于10%通常只能说明财务口径集中度低，不能证明品牌议价权、续约率或终端需求稳定。
- “全球众多知名品牌战略合作伙伴”属于公司定性表述；具体品牌名单、品牌级收入和续约率未有官方数字时标为未验证。

## 6. 内部矛盾与校验

- 同一份年报的专利数、基地数等若在“核心竞争力”和“经营回顾”出现不同数字，不擅自择一；并列位置与数值，标记“待公司澄清”。
- 对CAGR、占比、隐含单位收入等二次计算注明“据年报数字计算”，并复核起止年数。
- 精炼摘要仍应逐条保留公告日期和直接PDF URL；可先建立来源编号，再让每个表格行或结论引用对应编号。

## 7. 现金头寸：募投资金与短债必须单列

彼得林奇主口径不变：货币资金、已核实定期存款和交易性金融资产减长期有息债务；短期借款不进入主公式。但扩产型制造商还必须补两组观察：

1. **可自由支配货币资金**：货币资金减保证金等受限资金，再减只能用于募投项目的募集资金专户余额；
2. **短债覆盖**：货币资金/短期借款，以及可自由支配货币资金/短期借款。

募投专户资金可用于公司项目，却不等于可自由分红或随意配置的闲置净现金。不得因林奇现金头寸为正，就忽略短债增长和现金使用限制。

## 8. 高分红与重资本扩张的资金张力

高股息率不能孤立加分。若财年派息率接近或超过90%，同时存在高资本开支、累计FCF/累计净利润偏低、短期借款增长、募资持续投入或关联资产购买，应同步下调股息可持续性和资本配置评分。

报告需回答：分红来自持续自由现金流，还是来自经营现金流、借款和募资的组合调度。单年CFO覆盖分红，不代表长期FCF足以覆盖分红与扩产。

## 9. 行业与海外增长质量

- 服饰辅料并非强周期，但与服装终端消费、出口和品牌库存相关。至少核对规模以上服装产量、服装及衣着附件出口额/数量/均价，以及公司国内、国际收入变化。
- 海外收入增长不能单独证明增长质量；同时检查海外毛利率、汇兑损益、财务费用、海外产能利用率和资本开支。
- 海外收入增长、但海外毛利率下降且汇兑损失扩大时，应写成“增量来源已验证，利润兑现待验证”。
- 行业低端竞争激烈时，产品不可缺不等于供应商不可替换；认证、开发速度、稳定品质和全球交付才是降低替换概率的核心。
