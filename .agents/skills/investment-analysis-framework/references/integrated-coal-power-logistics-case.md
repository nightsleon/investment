# 煤—运—电一体化能源公司官方披露研究要点

适用：煤炭生产、铁路/港口/航运、火电及煤化工并存的重资产能源公司；尤其适用于年报后发生大额同一控制下资产注入、最新季报存在新旧合并范围切换的情况。

## 一、先拆利润池，再解释协同

按合并抵销前分部数据分别提取：

- 煤炭：收入、毛利率、利润总额、自产煤/外购煤销量与毛利。
- 发电：装机、电量、电价、单位售电成本、燃料结构、利润总额。
- 运输：铁路、港口、航运分别列收入、毛利率、利润总额及单位成本。
- 煤化工：产能、销量、售价、单位成本和利润；不要因业务存在就默认其是重要利润池。

用公司披露的分部利润占比优先；若自行计算，必须用同一口径、同一抵销层级，并用执行工具复核加总。纵向一体化公司的“合并抵销前分部收入”因内部交易存在，合计可以高于集团营业收入：不得强行补残差或归一化到集团营收；图表必须标注“合并抵销前”，占比只能称“抵销前分部收入占比”。利润总额占比通常比收入占比更能解释利润池结构。

一体化机制应解释为：

1. 自产煤提供资源租和主要利润。
2. 外购煤补充货源、掺配煤质、覆盖客户并提高铁路港口利用率；若外购煤毛利很薄，应将其视为渠道/流量业务，而非主要利润来源。
3. 自有铁路、港口、船队解决资源外运瓶颈，也可通过非煤货运分摊固定成本。
4. 内部煤供应提高电厂燃料安全、煤质匹配和调度效率；合并报表会抵销内部交易，不能重复计算利润。
5. 煤价下降通常损害煤炭利润、降低电厂燃料成本，形成部分周期对冲；但电价、利用小时和政策可能同步变化，因此不是无条件对冲。

## 二、煤炭“储量—产能—产量”必须严格区分

- **资源量/储量**：标明中国标准或 JORC 等标准；不同标准不可直接混用。
- **核定产能**：来自安全生产许可证、政府产能公告或公司逐矿披露。
- **设计/预计生产能力**：在建项目规划值，不等于已投产核定产能。
- **实际产量**：报告期运营结果，不得替代核定产能。
- **年度经营目标**：管理层目标，不等于实际产量或法定产能。

若年报未披露全集团核定煤矿产能合计：

1. 明确写“定期报告未披露汇总值”；
2. 不用实际产量反推或冒充产能；
3. 可列已披露的在建项目设计能力和重点矿山核定产能；
4. 若任务必须得到完整核定产能，则逐矿汇总许可证/产能公告，并说明是否包含在建、停产、托管或少数股权矿山。

## 三、资产注入后的合并范围边界

重大资产交易常同时出现以下不同口径：

- 年报期末原合并范围；
- 交易报告书“交易前/交易后”静态加总或备考口径；
- 季报报告期末运营口径；
- 截至季报披露日已经完成交割的范围；
- 纳入新资产后的调整年度目标和资本开支计划。

禁止把不同日期、不同范围的资源量、产量、装机简单拼接。研究时建立“日期—范围—指标性质”三列表：

| 日期 | 合并/控股范围 | 指标性质 |
|---|---|---|
| 年末 | 年报合并范围 | 实际运营/财务数据 |
| 交易基准日 | 交易前后静态加总 | 备考或交易展示数据 |
| 季末 | 季报披露范围 | 当季实际数据 |
| 全年 | 调整后经营目标 | 前瞻目标，不是实际值 |

当季报的装机等运营表与交易报告书“交易后”数据不一致时，优先解释日期和范围差异，不自行选一个覆盖另一个。纳入新资产后的调整全年产量、电量和资本开支目标，通常是判断新范围规模变化最清晰的官方桥梁，但必须标注为目标。

## 四、销售结构的最小完整表

至少提取：

- 总销量、平均不含税售价；
- 自产煤/外购煤销量、占比、售价及毛利率；
- 年度长协/月度长协/现货/坑口直销的量、占比、售价；
- 外部客户/内部发电/内部煤化工销量；
- 国内/出口销售；
- 前五大客户和最大客户占比，尤其识别控股股东关联销售。

不要把“长协”写成多年固定价格。年度、月度合同仍可能按政策和指数重定价；长协主要提高量、回款和供应可见度，同时限制价格快速上涨阶段的弹性。

内部煤销售量与电厂内部煤耗用量可能因确认时点、库存和统计范围不完全相等，披露差异即可，不要强行勾稽。

## 五、运输网络研究

同时看“能力、利用率、利润”：

- 铁路营业里程、周转量、单位运输成本、非煤货运量；
- 港口装船能力、装船量、单位成本；
- 自有船队载重吨、货运量、周转量、单位成本；
- 铁路、港口、航运分部各自利润，不要只报运输合计。

运输网络既是护城河也是单点中断风险。跟踪矿山事故、铁路港口检修、极端天气、电网调度、非计划停运及通道利用率。

## 六、煤价对冲的验证方法

至少用连续两个报告期验证：

- 煤炭售价、自产煤单位成本、煤炭分部利润；
- 售电价、发电量/利用小时、燃煤采购成本或单位售电成本、发电分部利润；
- 铁路/港口量、单位成本和利润。

典型有效对冲证据是：煤价下降导致煤炭利润回落，同时燃料成本下降使发电利润率改善，铁路/港口利润相对稳定。若电价和利用小时同步大幅下跌，则对冲可能失效。

## 七、资本开支与核心风险

资本开支必须区分：

- 实际资本开支；
- 原年度计划；
- 资产注入后的调整计划；
- 是否包含矿业权、股权投资；
- 煤炭、发电、铁路、港口、航运、煤化工分项。

风险排序建议：

1. 煤价及长协重定价；
2. 电价和利用小时；
3. 一体化链条中断；
4. 大额资本开支、延期和回报不足；
5. 资产注入整合、口径变化、少数股东及关联交易；
6. 安全、环保、矿权、产能核准、碳排放和保供政策。

对每类风险给出2—5个可跟踪指标，避免只抄公司风险章节。

## 八、官方来源优先级与校验

1. 年报、季报；
2. 重大资产交易报告书及交割公告；
3. 公司运营数据公告、项目核准公告；
4. 政府逐矿产能公告/安全生产许可证。

巨潮公告查询时，先用 topSearch 获取 `orgId`，再以 `stock={code},{orgId}` 查询；大额资产交易可用“发行股份”“购买资产”“交易报告书”“标的资产”等关键词分批搜索。

报告末尾按以下三类校验：

- **正确/已核验**：定期报告表格可直接复核；
- **正确但口径不同，已单列**：交易前后、备考、调整目标；
- **不可验证**：如未披露的全集团核定产能合计，明确缺口且不推造。

## 九、先增股、后完整并表的估值错配

重大资产注入可能出现新增股份已登记、标的利润尚未完整进入TTM的阶段，行情接口PE会被机械抬高。必须并列：

1. 行情接口报表PE，并注明利润与股本截止时点；
2. 当前总股本对应市值/旧口径扣非TTM利润；
3. 严格整体股权价值/官方备考利润，并注明备考年份不是当前TTM。

历史PE分位在此阶段只作辅助，不能直接判定极贵或极便宜。A/H公司必须按“A股股数×A股价格 + H股股数×H股价格×同日汇率”计算严格整体股权价值；行情供应商用A股价格乘全部股本的结果只能称“A股展示口径”。

林奇现金头寸仍不扣短债，但并购贷款常先进入短期借款。需另列短债、现金对价、受限资金和备考资产负债率；新资产尚未完整并表时，季报现金头寸和负债率不代表重组后稳定口径。

## 十、重组跨期分红与情景估值

重组前后股本变化时，中期和年度分红的参与股本可能不同：

- 分别使用两次实施公告的实际股本和金额；
- “每股合计”只适用于同时跨过两次登记日的旧股份；
- 当前新买入者不能追溯获得已实施中期股息；历史静态股息率不得写成未来承诺收益率。

估值优先使用公开历史利润和官方备考利润做压力测试，不使用券商预测：压力档采用旧口径当前利润附近与周期低倍数，中性档采用备考利润附近与合理倍数，乐观档采用整合顺利后的较高利润与较高倍数。净利润已含利息收入时，不再机械加回全部现金。
