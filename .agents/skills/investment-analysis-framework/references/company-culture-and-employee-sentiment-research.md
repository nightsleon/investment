# 公司制度、企业文化与员工舆情研究

适用场景：投资分析中需要判断企业文化是否形成制度、管理层价值观是否落地，或比较纽柯式低成本、平等、分权、利益共享文化时。

## 一、核心原则

企业文化研究必须区分三层：

1. **宣示文化**：官网使命、价值观、创始人讲话。
2. **制度文化**：员工手册、质量/成本/绩效/安全/授权/举报等正式制度。
3. **实际文化**：员工行为、奖惩、工时、晋升、安全记录、监管处罚和经营结果。

不能用创始人人设代替制度，也不能用单条匿名爆料代表全集团。最终结论应回答：价值观是否进入制度，制度是否进入一线行为，行为是否产生可持续经营结果。

## 二、资料优先级

### A级：原始、可核验资料

- 公司官网价值观、治理和管理团队页面；
- 最新年报、ESG报告、内部控制报告；
- 公司章程、董事会委员会规则、反舞弊和利益冲突制度；
- 劳动、安全、工会、法院等政府监管记录；
- 可获取的员工手册、集体合同、薪酬和授权制度。

### B级：可识别作者的经历

- 有明确任职年份、工厂、岗位和工作细节的员工长文；
- 深度访谈、纪录片、管理层口述史；
- 能与年报制度相互印证的车间流程描述。

### C级：匿名聚合与搜索摘要

- 脉脉、看准、职友集、Indeed、Glassdoor等；
- 招聘平台薪酬汇总、搜索引擎摘要、短视频评论。

C级资料只用于发现方向性风险，不能单独认定具体违规。必须记录平台、样本数、日期、地区和访问限制。

## 三、研究流程

### 1. 建立制度地图

至少覆盖：

| 模块 | 需要查什么 |
|---|---|
| 治理与内控 | 授权审批、子公司控制、审计、举报、利益冲突 |
| 质量 | 一票否决、全过程质量、客户投诉和追责 |
| 成本与精益 | 班组、5S、预算、损耗、改善提案、降本奖励 |
| 薪酬绩效 | 基本工资、绩效、奖金、公司与个人业绩挂钩方式 |
| 用工权益 | 反歧视、工时、倒班、加班、社保、劳务派遣 |
| 培训晋升 | 师徒带教、内部晋升、管理干部一线经历 |
| 安全健康 | 安全体系、隐患闭环、PPE、事故及监管记录 |
| 组织分权 | 总部规模、层级、工厂自主权、独立核算 |

### 2. 从管理层履历验证内部培养

不要只看任职年限。追踪高管是否做过车间、工艺、质量、采购、厂长等一线岗位；区分家族身份、内部培养和职业经理人来源。

### 3. 搜集员工舆情

优先找带有以下信息的样本：

- 任职工厂和岗位；
- 明确时间区间；
- 班次、工时、工资组成；
- 培训、师傅、班前会、5S、奖金公式；
- 晋升、管理风格、安全和员工流失。

平台需登录或反爬时，不要把不可访问的搜索摘要写成事实。明确写“未获得可逐条核验正文”，并转向可识别作者、监管机构或跨平台重复信号。

### 4. 交叉验证

建立“官方制度—员工行为—监管/经营结果”表：

- 年报称有精益培训，员工是否描述具体培训、5S和班组制度；
- 年报称绩效工资，员工是否能说明工资组成及奖金变化；
- 年报称安全体系完整，监管记录是否出现重复违规；
- 官网称最佳雇主，员工评分、流失和工时是否支持。

### 5. 区分地区与时间

- 中国工厂、美国工厂和欧洲工厂不能混写；
- 早期投产问题不能直接代表当前状态；
- 单一工厂样本不能外推集团；
- 所有历史处罚须区分“拟处罚/提出处罚”与最终裁决或和解。

### 6. 处理“官方指标互相冲突”

不要只挑对结论有利的指标。满意度、流失率、晋升、培训、安全伤害和损失工时必须并列阅读：

- 满意度很高但流失率也高时，不要替公司解释；把矛盾转成按工厂、岗位、年龄、地区访谈的问题；
- 年轻员工流失率显著高于集团时，优先验证倒班、劳动强度、薪酬透明、晋升、地点和管理沟通；
- 伤害频率下降但工伤损失小时数上升时，不能只写“安全改善”，应同时披露两个方向；
- 公司ESG数据即使有第三方鉴证，也要确认鉴证范围，并与监管记录交叉验证。

### 7. 海外劳工与安全监管的精确口径

研究跨国制造企业时，优先查当地监管原始记录：

- **OSHA**：区分初始处罚与和解后的当前处罚，列明删除、整改完成、检查中纠正、重复违规和案件关闭状态；不要用初始罚款冒充最终罚款。
- **NLRB**：`charge/allegations`只是指控，不是违法认定；页面状态、Dismissal Letter、和解、裁决和结案必须同时核对。工会投票失败只证明投票结果，不证明员工满意。
- **政府搜查/调查**：区分被调查目标、配合调查方和第三方劳务商；没有最终司法或监管结论时，不得把搜查写成违法成立。
- 监管事实只证明特定工厂和时期的问题，不能自动外推整个集团或当前状态。

若官方前端受限，可使用可访问的网页文本渲染服务读取官方页面内容，但最终引用必须保留监管机构原始URL，并记录访问边界。

### 8. 管理层、售后与公众风评的主体分离

- 家族接班研究同时看亲属关系、真实一线履历、经营结果、委员会制衡和关联交易；不能因“二代”自动否定能力，也不能用履历消除家族治理风险。
- 创始人辞任董事长但继续任执行董事、荣誉职务或战略委员会成员时，应写“第一步交接/职责调整”，不能写“完全退出”。
- OEM量产质量与售后门店/安装体验分开：消费者投诉可能涉及产品、运输、安装、授权商和质保，先核对责任主体，再判断是否为系统性问题。
- 投诉绝对数没有分母时，不判断质量高低；优先找安装量、投诉率、返工率和解决率。
- 创始人个人、慈善基金会、大学和上市公司必须分主体；基金会捐赠不能写成上市公司资本配置，也不能用慈善声誉替代治理与员工评价。

## 四、纽柯式文化比较框架

“低成本”不等于“平等”。比较时至少分开判断：

| 维度 | 要找的制度证据 |
|---|---|
| 低成本 | 良率、损耗、自动化、物流、能源和预算管理 |
| 节俭 | 高管差旅、公务车、办公室、餐厅和行政待遇 |
| 平等 | 管理层与员工福利是否接近，是否取消高管特权 |
| 利益共享 | 一线班组是否按明确公式高比例分享效率提升 |
| 风险共担 | 业绩下滑时高管薪酬是否比基层下降更多 |
| 分权 | 工厂定价、采购、用人和设备投资权限 |
| 低层级 | 总部人数、管理层级和越级沟通渠道 |
| 开放信息 | 成本、质量和经营数据是否向基层透明 |
| 内部晋升 | 优秀技术工人能否获得接近管理岗的收入与地位 |

只有价值观口号和“公平薪酬”原则时，应写“纽柯式平等证据不足”，不能推断已经形成平等共同体。

## 五、低成本文化的质量判断

低成本可能来自：

- 技术、自动化、规模采购；
- 材料利用率、良率和流程改善；
- 员工主动创新并分享收益；

也可能来自：

- 长工时、高劳动强度；
- 压低工资或转嫁给供应商；
- 削弱安全、培训或维护投入。

投资分析必须区分两者。前者形成可持续护城河，后者可能积累流失、安全、劳资和海外合规成本。

## 六、输出写法

企业风评报告首先是研究判断，不是审计底稿。正文按读者最关心的矛盾组织，不必把每个利益相关者排成完全对称的模板。通常可这样展开：

1. 开头用几段自然文字说清总体判断及主要矛盾，例如经营口碑与员工口碑为何分化；
2. 沿控制权与接班、制度与实际文化、国内外员工、客户与售后、供应商、公众声誉展开，但篇幅按证据重要性分配；
3. 把监管记录、员工数据和投诉责任链写进对应叙述，不在每段末尾重复“边界/结论”；
4. 结尾只保留有决策价值的观察点；
5. 资料按A/B/C级放在文末，正文只在来源性质影响判断时说明等级。

去AI味要求：

- 不用“维度—结论—证据强度”大表代替开篇判断，除非用户明确要求证据台账；
- 少用“结论先行、综合判断、正面之处、需要保留的判断、正确表述、核心矛盾”等成套话术；
- 删除连续加粗、完全对称的小节、强行凑成三点的总结和同义反复；
- 用具体主体、地点、时间和事件承载判断。可以直接写“治理要打一点折扣”“董事长换了，实际控制人没变”，不必包装成评级标签；
- 保留不确定性，但集中说明证据边界，不要每段都补一遍免责声明；
- 最后一轮逐项核对数字、日期、主体、监管状态和链接，去AI改写不能改变事实。

## 七、常见误区

- 用创始人节俭或慈善直接证明公司平等；
- 把“有绩效工资”等同于“基层利益共享”；
- 把公平就业、反歧视与管理层去特权混为一谈；
- 用一条脉脉、知乎或短视频爆料代表全公司；
- 用工会投票失败直接证明员工满意；
- 引用监管新闻稿时把拟处罚写成最终处罚；
- 只写正面文化口号，不检查工时、安全和员工体验；
- 只写负面舆情，不核对制度、地区、年份和整改状态。
