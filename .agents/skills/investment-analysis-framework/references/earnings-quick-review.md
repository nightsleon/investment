# 财报速览指南

适用：用户要求"财报速览、财报速读、季报/中报快速分析"等轻量化财务报告解读。与完整投资报告和3R简报不同，速览的目标是**快速排雷 + 抓核心亮点风险 + 通俗可读**，不是全面打分。

---

## 定位边界

| 类型 | 深度 | 用途 | 结构 |
|------|------|------|------|
| 完整投资报告 | 最深 | 全面研究决策 | 好行业/好公司/好时机 9章+评分 |
| 3R投资简报 | 中等 | 独立评分决策 | Right Business/People/Price 三模块 |
| 财报速览 | 最浅 | 单期报告快速解读 | 四问框架 + 红绿灯 |

速览不是把完整报告删短，而是**以一份财报为中心**的快速阅读理解工具。重点回答"这份报告说了什么、是好是坏、需要盯什么"。

---

## 数据纪律（铁则）

**必须先下载官方财报PDF，再分析。** 不得用新闻报道、自媒体解读拼凑数据。

- 数据源优先级：巨潮资讯网PDF ＞ 公司官网PDF ＞ 交易所披露 ＞ 同花顺Excel ＞ 东方财富API
- 核心数字（营收、利润、扣非、现金流、资产负债关键项）必须从PDF直接读取
- 新闻解读只能作为辅助视角，不能作为数据来源
- 巨潮下载方法见 `references/cninfo-annual-report-download.md`；中报/季报下载方法相同，只需把 category 从 `category_ndbg_szsh` 改为 `category_bndbg_szsh`（半年报）或对应季度类别
- PDF 存放在公司研究包 `年报/` 目录，命名统一：`山西汾酒：2026年半年度报告.pdf`

### 数据分级标签（正文强制，2026-09新增）

每篇速览的正文论断和数据点必须标注三级口径之一，混用不标=作假：

- **【PDF】** = 财报原文数据（含附注、现金流量表补充资料等倒算），速览主体
- **【MD&A】** = 管理层讨论与分析的定性自述（"主动调整""稳健经营"等），是管理层说法，需找PDF硬指标交叉验证（如"主动控货"用厂端存货增速佐证：控货期存货微增=主动，存货大增=被动滞销）
- **【调研】** = 媒体引用的第三方市场/渠道调研（具体产品增速、渠道库存月数等），非公司披露，仅供参考方向

典型陷阱（汾酒2026中报真实案例）：媒体常把调研数据写成"半年报显示"，而正式财报的产品披露层级往往只到"酒类销售/其他"两级——具体单品增速（如"青花25增20%"）在PDF里根本查不到。出现这类"精确到单品"的数据时默认怀疑其来源；头部只写"数据来源：巨潮PDF"但正文混入新闻数据，等于造假。

### 季节性年化（重大陷阱，2026-09新增）

**禁止"半年利润×2"估算全年。** 白酒等消费类公司利润高度季节化：春节旺季利润前置，H1占全年约69%（2024/2025年汾酒实测），Q4是全年最低点。简单翻倍会高估全年利润约38%，并连带得出错误的PE和"历史最低估值"结论（汾酒案例：H1×2得128亿/PE 11-12倍，实际约93亿/PE 15.5倍，"历史最低区间"结论被推翻）。

正确做法：
1. 取该公司近2-3年"上半年利润/全年利润"的历史占比（用季度数据计算）
2. 全年利润 ≈ H1利润 ÷ 历史占比
3. 季节占比数据见 `references/a-share-q4-seasonality.md`
4. 若无历史占比数据，标注"无法可靠年化"，只给TTM口径
5. 估值段落注明：市值是时点快照（新闻口径），PE随股价波动，仅作量级参考

### 现金流来源拆解（防"渠道出清红利"幻觉，2026-09新增）

"利润降、现金流增"不能只写"回款改善"，必须查现金流量表补充资料的调节项目：

- **经营性应收项目变动**是关键：从"净减少"（资金被占用）反转为"净回收"（收回欠款）时，一来一回可能贡献全部现金流增量（汾酒案例：+52亿增量中应收项目摆动贡献超50亿）——这是一次性去库存红利，不可持续
- 剔除一次性回收后算"经常性现金流/净利润"，才是可持续的利润含金量（汾酒剔除后仅约0.5）
- 同时检查经营性应付项目增加（占压上下游）对现金流的贡献
- 双向解读：收现比>100%乐观面是回款质量改善，警惕面是预收款/占款模式是否在透支渠道

## 四问框架

核心思路：**先排雷，再谈好坏。** 按顺序回答四个问题。

### 第一问：它真的赚到钱了吗？（利润表）

**三个核心数字：**
- 营业收入：同比增速 + 环比变化，看增长趋势是加速还是减速
- 扣非净利润：看主业真实利润，和净利润差额大不大
- 毛利率：看盈利能力趋势，提升=定价权增强，下滑=竞争加剧/成本失控

**还要看：**
- 销售费用率：收入降但费用升？可能是在投品牌/做渠道（长期好短期疼）
- 净利率：降幅 vs 收入降幅，判断经营杠杆暴露程度
- 非经常性损益：占比高不高，是不是靠"外快"凑数

**亮点信号：** 收入和扣非双增、毛利率逆势提升、费用率下降有规模效应
**风险信号：** 收入增应收增更快、净利润远大于扣非、毛利率大幅下滑
**单季拆解：** H1整体数字会掩盖单季拐点——必须倒算Q2单季（H1-Q1）看最新变化（汾酒案例：H1利润-24%，但Q2单季-43%，调整最猛烈的信号藏在单季里）

### 第二问：赚到的钱到手了吗？（现金流量表）

**一个核心比值：经营现金流 / 净利润**

- ≥ 0.8：健康，利润基本是真金白银
- 0.5-0.8：有水分，需要找原因
- ＜ 0.5 或为负：严重警惕，纸面富贵

**还要看：**
- 收现比（销售商品收到现金 / 营业收入）：≥100% 说明回款很好
- 经营现金流趋势：和利润趋势是否同向，背离要找原因
- 现金流来源拆解（见上"数据纪律"）：一次性回收 vs 经常性现金流

**反常但可能是好事的情况：**
- 利润降、现金流增：可能是主动去库存/控货，渠道回款改善，短期降速换长期健康——但必须拆解来源，确认可持续部分

### 第三问：家底厚不厚？（资产负债表）

**速查项（含排雷）：**

1. **现金家底**：货币资金 + 定期存款/大额存单（查其他流动资产附注）- 有息负债 = 净现金
2. **大存大贷排雷**：账上现金多同时有息负债也多，直接排除（受限制资产占比可作辅助：附注"所有权或使用权受限资产"）
3. **存货与应收**：增速 vs 收入增速；白酒/高端奢侈品例外——基酒越存越值钱，存货占比高是行业特征；存货构成要翻附注（库存商品/自制半成品/在产品）
4. **商誉**：商誉/净资产 ＞ 30% 打黄灯、＞ 50% 绕道
5. **关联交易**：占收入比>10%且上升=黄灯（附注"关联方及关联交易"）
6. **在建工程**：附注核实各项目工程进度，防"常年不转固"（预算投入比例长期不动=美化利润）
7. **资产负债率异动归因**：负债率大变时翻附注找科目级原因（如应付股利暴增=分红未付，不是真负债恶化；剔除后重算）

### 第四问：明年还能赚吗？（看未来）

**找线索：**
- 在建工程：产能扩张还是收缩？（结合行业供需判断是否盲目扩张）
- 研发投入：在投未来还是吃老本？（科技/医药适用；白酒食品等传统行业研发占比天然低，不适用此条）
- 管理层措辞：把最近2-3年同期MD&A放一起对比，"充满信心"变"审慎应对"是拐点信号——辅助线索非证据，需注明比对口径（逐字比对还是印象比对）
- 股东动向：大股东质押比例（>70%持仓=红灯）、增减持
- 合同负债/预收款：渠道信心的领先指标（双面性：控货期微降=没压货，持续下滑=渠道信心不足）

## 红绿灯速判

每篇速览结尾必须有红绿灯清单。红灯五项逐项核对（大存大贷/商誉>50%/现金流连续为负且成熟期/大股东质押>70%/主业频繁变换），全部通过写"无排除项"；绿灯每条挂【PDF】来源标签；黄灯写跟踪条件。

### 🟢 绿灯（积极信号）
列出3-5条，每条一句话+来源标签。

### 🟡 黄灯（需要跟踪观察）
列出3-5条，每条一句话 + 跟踪条件 + 来源标签。

### 🔴 红灯（直接排除项）
五项逐项核对结论；如有，明确列出；没有就写"五项全部通过，无排除项"。

## 目录与命名规范

遵循"A为主、B做索引"原则：

- **原文**：`{代码}_{公司名}/reports/{公司名}_财报速览_{期数}.md`（文件名带公司名前缀，与公司目录内其他报告命名一致，如`山西汾酒_财报速览_2026中报.md`）
  - 期数命名：`2026中报`、`2026Q1`、`2025年报`
  - 和公司的完整报告、3R简报放在一起，研究资产跟着公司走
- **索引**：`财报速览/README.md`
  - 按财报季聚合（2026中报、2026Q1等），列出本期所有公司的核心结论摘要+链接
  - 方便按财报季批量浏览和横向对比
  - 不重复存正文，只做索引
  - 重命名/移动速览文件后必须同步修复索引里的旧链接（曾出现索引指向旧文件名的断链）

## 标签呈现规则（2026-09后期修订）

初版"每条论断挂标签"（【PDF】【MD&A】【调研】满篇标注）被用户否决——速览变成审计底稿，阅读成本过高。最终规则：

- **正文默认无标签**：速览默认数据来自财报PDF，就像菜谱不需要每句标注"来自菜谱"
- **文首统一声明**（引言块，一次说清）："本文财务数据均来自公司《XX年半年度报告》（巨潮资讯网），含据其计算的衍生指标；凡属市场调研、媒体报道等非公司披露信息，在正文中单独标注"
- **仅例外处逐条标注**：①第三方调研数据（"市场调研口径，非公司披露"）；②媒体报道冒充披露的澄清（"'摒弃压货冲量'出自媒体报道，非本中报"）；③市值等时点数据口径
- 红绿灯部分同样不带标签（检查动作在正文已完成）

### 读者向文章的修改痕迹纪律（2026-09修订，重要）

给读者的速览**不得保留任何审稿/纠错过程痕迹**：

- 禁止出现："修正口径"、"对比旧算法"、"按指南要求"、"按v2逐项核对"、纠错历史叙述等过程性文字——读者是第一次看，不需要知道作者改过什么
- 方法论教训融入行文而非单独成段：如H1×2错误应写成一句提示（"白酒利润前高后低，H1约占全年69%，不能用H1×2简单年化"），不展示"我曾经算错"的过程
- 结论句只含财报可验证事实；主观判断（"主动降速""以退为进"）必须单独成句，并注明是解读还是披露——"主动控货"这类定性能用PDF间接证据佐证（存货微增、毛利率逆势）时写明"间接证据偏向主动，最终定论需渠道库存数据"

### 单季拆分口径（迈瑞2026中报案例）

新闻媒体的Q2拆分数据（如"Q2归母净利24.67亿"）与PDF倒算值（一季报24.27+半年报47.97→Q2=23.70亿）可能存在口径差异——**一律以PDF差值倒算为准**，新闻单季数据弃用；差异明显时不必逐条解释，直接用正确值。

### PDF获取路径补充（迈瑞案例）

巨潮公告搜索接口（fulltextSearch）有时搜不到目标公告，备用路径：东方财富公告API `np-anotice-stock.eastmoney.com/api/security/ann?...&stock_list={code}` 取公告art_code，再拼 `https://pdf.dfcfw.com/pdf/H2_{art_code}_1.pdf` 下载全文。深交所公司季报也可用 `disc.static.szse.cn` 直链。

## 写作风格

- **通俗可读**：类比优先，术语第一次出现用大白话解释
- **先结论后细节**：每节开头给一句话判断，再展开论证
- **数字要具体**：不说"大幅增长"，说"增长24.3%"
- **不堆砌概念**：财报速览是给普通人看的，不是同行评审
- **诚实承认局限**：数据不全就说待验证，不要硬编；MD&A措辞对比没做逐字比对就注明
- **不做投资建议**：只做财报解读和风险提示，不说"买"或"卖"
