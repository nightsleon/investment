# 投资分析报告校验清单

## 校验流程

### 第一步：提取源数据（三重数据源交叉验证）
1. 用 `pdfplumber` 打开年报PDF，按页码提取关键数据（权威来源）
2. 用 `python-calamine` 读取 `xxx_main_year.xls`（年度汇总数据）
3. 用 `python-calamine` 读取 `xxx_main_simple.xls`（季度拆分数据）
4. 用季度CSV数据验证TTM和季度拆分
5. **三个数据源交叉比对**：PDF是权威源，两个Excel是辅助验证源。三源一致=确认正确；PDF与Excel不一致时以PDF为准；两个Excel之间不一致时以main_year为准

### 第二步：逐项比对（三源交叉验证）
对报告中每个数字，分别与三个数据源比对：
1. **年报PDF**：权威来源，最终以PDF为准
2. **main_year.xls**：年度汇总数据，用于快速验证营收/扣非/ROE/毛利率/资产负债率
3. **main_simple.xls**：季度数据，用于验证季度拆分（各季之和=全年）、TTM计算、周转天数/流动比率

比对优先级：
- 三源一致 → ✅ 确认正确
- PDF与main_year一致，main_simple略有差异 → ✅ 正确（可能是口径差异）
- PDF与Excel不一致 → 以PDF为准，标记差异
- 两个Excel之间不一致 → 以main_year为准，标记差异

### 第三步：分类输出
```
✅ 正确: [数据项] — 报告值 vs 源值
❌ 错误: [数据项] — 报告值 XX，源值 YY，建议改为 ZZ
⚠️ 不可验证: [数据项] — 源数据不包含此年份/此指标
```

## 常见校验错误类型

### 1. CAGR年数标注错误
**最常见也最危险的错误。**
- 2021→2025是4年CAGR，不是3年
- 2022→2025才是3年CAGR
- 计算公式：(期末/期初)^(1/n) - 1，n=年数
- 福耀案例：报告写"3年CAGR(34.2%)"，实际34.2%是4年CAGR(2021→2025)
  - 3年CAGR(2022→2025) = (91.65/46.66)^(1/3) - 1 = 25.3%
  - 用错误的34.2%算PEG=0.44，用正确的25.3%算PEG=0.60

### 2. 杜邦ROE口径不一致
- **加权平均ROE**：年报直接披露，用期间加权平均净资产
- **简单ROE**：年末归母净利润 / 年末归母净资产
- 两种方法差1-2个百分点，趋势一致但绝对值不同
- 杜邦分析如果用简单ROE，三个因子也要统一用年末数据
- 建议在报告中注明用的是哪种口径

### 3. PE TTM vs 年末PE
- 年报出后、Q1报出前：TTM = 上年全年扣非
- Q1报出后：TTM = 上年Q2-Q4 + 本年Q1
- 如果Q1利润同比下降（如福耀2026Q1因汇兑损失），TTM会低于全年数
- 福耀案例：全年扣非91.65亿→PE 14.8；TTM 88.2亿→PE 15.7
- 报告中应注明用的是哪个口径

### 4. 经营现金流/利润比值
- 分子(经营现金流)和分母(净利润)都要单独验证
- 年报现金流量表通常只披露最近2年，更早年份无法从当年年报验证
- 如需验证更早年份，需要找对应年份的年报

### 5. 现金头寸中的“长期负债”
- 彼得林奇主口径优先只扣长期有息债务：长期借款、应付债券等。
- **不扣**短期借款；但必须另行验证现金、存货和应收等流动资产能否覆盖短期有息债务。
- 一年内到期的非流动负债、租赁负债不混入彼得林奇主口径；可在“保守净金融现金”敏感性口径中单列扣除。
- 不要直接扣“非流动负债合计”，其中通常包含递延收益、递延所得税负债等非有息负债。
- 应付债券若确实存在，属于长期有息债务，应计入减项；不能写成默认不含。

### 6. 营收口径不一致（营业总收入 vs 营业收入）
- **营业收入**：纯产品/服务销售收入
- **营业总收入**：营业收入 + 利息收入 + 手续费佣金等金融收入
- 有金融子公司（如美的旗下金融板块）的公司，两者可能差20-50亿
- 美的案例：营业收入4564.5亿 vs 营业总收入4585.0亿，差20亿
- 报告中应统一用一种口径，如果用营业总收入需注明
- **验证方法**：利润表第一行"营业收入"和"一、营业总收入"是两个不同数字

### 7. 毛利率口径不一致
- 合并毛利率 = (营业收入 - 营业成本) / 营业收入
- 分部毛利率：各业务板块单独计算
- 有金融业务的公司，合并毛利率会因为金融收入（低成本/零成本）被拉高
- 美的案例：合并毛利率37.1%（含金融收入），制造业分部毛利率27.93%
- 报告中写的28.4%可能是用了一个中间口径
- **验证方法**：先确认报告用的是哪个口径（合并/分部/加权），再验证

### 8. 扣非净利润的定义可能因来源不同而异
- 不同数据源（东方财富API、同花顺、年报附注）对"非经常性损益"的定义可能略有差异
- 美的案例：2022年扣非用年报附注算约267.6亿，但报告写286.1亿，差18.5亿
- 差异原因可能是：(a)数据源使用了不同版本的非经常性调整 (b)包含了其他非经常性项目
- **main_year.xls和main_simple.xls的扣非也可能不一致**：美的2022年main_year=286.1亿，main_simple季度加总=274.4亿，差11.7亿
- **验证方法**：优先用main_year.xls的年度数据；用main_simple验证季度拆分和增长率；用年报附注验证非经常性损益明细
- 如果差异>5亿且无法解释，标注为"⚠️口径待确认"

### 9. 四舍五入差异
- 营收45,787,435,563元 = 457.87亿（报告写457.9亿，合理）
- 增速用四舍五入后的数字算可能差0.1%，不算错误
- 但如果差1%以上就要查原因

### 10. 季度拆分验证
- 各季度利润之和必须等于全年数
- 验证方法：从年报"分季度主要财务数据"提取4个季度，加总后与年度数据比对
- 如有季度CSV数据，CSV中的季度数据也应与年报一致
- 经营现金流的季度加总也需验证（Q4可能为负，如美的2025Q4经营现金流-37亿）

### 11. Q1报的额外信息
- Q1报可能包含年报没有的分部数据（如美的Q1报披露楼宇科技/机器人/工业技术各季度收入）
- Q1报的同比增速需要与上年同期数据交叉验证
- Q1报的资产负债表可用来验证最新现金头寸

### 12. PDF纵向表格的空值与比较期错位
- PyMuPDF/pdfplumber 抽取资产负债表时，当前期空白科目可能只留下比较期金额；不能把关键词后的第一个数字机械当作当前期值。
- 必须回看表头列顺序、同页“本期/上期”结构和非流动负债合计做勾稽。典型案例：伊利2024年资产负债表“应付债券”当前期为空，紧随其后的35.4135亿元是2023年比较期余额；误计会低估2024年现金头寸35.41亿元。
- 对长期借款、应付债券、交易性金融资产等可能归零的科目，至少用下一年度年报的比较期列再反向验证一次。

### 13. A/H 或多地上市公司的市值与PE
- 先确认 A 股、H 股及其他类别股份数量，不能用 A 股价格乘全部 A+H 总股本当作严格公司总市值。
- 整体股权价值应按“各类别股份数量 × 对应市场收盘价”计算，再用同日汇率折算到统一币种后加总。
- 若采用行情接口的“总市值”，必须核验供应商是否把单一市场价格映射到全部股本；这种展示口径不能不加说明地用于跨公司比较。
- PE、扣现金后PE、每股现金及毛估估必须与市值/股本口径一致。A股单市场估值、H股单市场估值和整体股权价值三种口径不可混写。
- 校验表需额外列出：各类别股数、价格、汇率、分项市值、合计市值、采用的利润币种与口径。

### pdfplumber 用法
```python
import pdfplumber
pdf = pdfplumber.open('年报.pdf')
page = pdf.pages[页码-1]  # 0-indexed
text = page.extract_text()
```

### 同花顺 .xls 文件读取
- xlrd 2.0.2 和 1.2.0 都会报 `CompDocError: Workbook corruption: seen[2] == 4`
- 文件是合法的 OLE Compound Document，但内部 SST 结构有兼容性问题
- **解决方案：用 `python-calamine` 库**（`pip install python-calamine`），能完美读取同花顺导出的 .xls 文件
  ```python
  from python_calamine import CalamineWorkbook
  wb = CalamineWorkbook.from_path('xxx_main_simple.xls')
  data = wb.get_sheet_by_name(wb.sheet_names[0]).to_python()
  for row in data:
      print('\t'.join([str(c) for c in row]))
  ```
- **不要放弃Excel数据源**——同花顺Excel是交叉验证的关键数据源
- **两个Excel文件的用途不同**：
  - `xxx_main_year.xls`：年度数据（营收、扣非、ROE、毛利率等），用于验证年度汇总数据
  - `xxx_main_simple.xls`：季度数据（单季度营收/利润/扣非），用于验证季度拆分和TTM计算
  - 两者都有：资产负债率、流动比率、速动比率、存货周转天数、应收周转天数
