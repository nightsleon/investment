# 兴齐眼药/眼科处方药分析案例（2026）

适用场景：分析眼科处方药、医药消费/慢病用药、近视防控/干眼治疗等公司时参考。核心不是简单套消费品逻辑，而是把“获批进度、临床证据、处方渠道、医保/集采、竞品管线、单品集中度”放在同一张图里看。

## 兴齐眼药关键结论样例

- 公司从传统眼科药多品类，切换为“阿托品近视防控 + 环孢素干眼治疗 + 兴齐眼科医院协同”的高弹性处方药公司。
- 阿托品是最大边际变量：0.01% 已获批近视适应症，0.02%/0.04% 获批后形成梯度浓度矩阵。分析时要跟踪放量持续性、竞品获批节奏、长期安全性/用药规范变化。
- 环孢素是干眼处方药核心品种，已纳入医保；医保提高可及性，也带来价格/控费风险。
- 兴齐眼科医院更多是临床、患者教育、真实世界研究和学术品牌协同平台，不应直接按全国连锁眼科服务龙头估值。
- 2025 年滴眼剂收入占比约 79%，同比高增长；产品结构按年报“剂型”披露时，不能误以为已经拆到具体产品。正文要说明阿托品/环孢素是核心逻辑，但收入表只能验证到滴眼剂口径。

## 评分与估值启发

- 眼科处方药需求弱周期、长期存在，但并非无替代：近视防控有 OK 镜、离焦镜片、多焦软镜和眼视光服务；干眼有人工泪液、进口药、其他抗炎机制药物。
- 高毛利/高ROE若来自新品放量和费用率摊薄，是优质信号；但要检查是否由单品集中度上升带来，不能机械给满分。
- 若年报显示滴眼剂占比接近80%，且分析判断滴眼剂中大部分增量来自阿托品，同时恒瑞等竞品上市申请已推进，则兴齐更应按“阿托品先发窗口期”而非长期垄断型护城河打分：护城河可压到约3/7，定价权可压到约1.5/5，产品结构也需因单品集中度降权。
- PE历史百分位极低 + 扣非TTM继续上行，是“预期差”而不是价值陷阱的候选形态；但前提是未来几个季度利润线不能掉头。
- PEG在新品放量跃迁期容易偏低，不能简单外推高CAGR；应将 PEG 作为“估值未明显透支”的辅助证据。
- 现金头寸通常不是这类公司的主安全边际：重点仍是研发/注册先发、处方渠道、现金流质量和竞品压力。

## 数据处理经验

- 同花顺 `stock_financial_benefit_ths/debt_ths/cash_ths` 可快速拉年度利润表、资产负债表、现金流；若 `stock_zh_a_spot_em` 批量行情失败，可用 `stock_value_em(symbol)` 对各同行逐个取最新估值兜底。
- 医药公司年报产品结构可能按“剂型/治疗领域”披露，不一定披露具体大单品收入；无法确认具体产品收入时标注“年报未拆分，待验证”。
- 现金头寸要查年报附注：其他流动资产若为待抵扣进项税/预缴所得税，不计入现金；应收款项融资也不计入现金。

## 风险传闻核查规则

- 集采/联盟采购降价传闻必须回到官方药交中心、医保局、采购联盟文件核验；找不到官方文件时，写“暂未找到官方文件支撑”，不能把传闻价纳入基准估值。
- 低浓度阿托品竞争格局必须区分四类：NMPA已获批上市、上市申请已受理、临床/管线、医疗机构院内制剂；院内制剂不能等同于全国药品上市竞品。
- “利润90%来自阿托品”这类单品利润占比，若年报未披露单品收入/利润，只能写“增长高度依赖高毛利滴眼剂，阿托品是关键增量品种”，不能写成事实。
- PE回归要分清历史高点静态PE、当前TTM PE、当前按上年利润计算的静态PE；不要把“当前16-20倍”误写成“10倍左右”。

## 报告表达模板

- 一句话结论：不是“低估值稳健白马”，而是“核心新品放量后的高利润弹性公司”。
- 好时机判断：当前若表现为利润TTM上行、股价回落、PE分位极低，可写“预期差阶段”；但必须列出证伪条件：新品放量放缓、竞品获批、价格战/医保控费、现金流转弱、应收存货快于收入增长。
