# 福耀玻璃 2026Q1 案例：出口制造龙头的“汇兑扰动 vs 经营趋势”拆解

适用场景：汽车零部件、出口制造、海外收入占比较高的公司，最新季度利润下滑但管理层/季报明确提示汇兑影响较大时。

## 一句话结论

看到利润同比下滑，先拆“主业经营”与“汇率扰动”；看到经营现金流骤降，先拆“回款结构变化”与“真实回款恶化”。

## 本案数据（福耀玻璃）

2026Q1：
- 营收 104.13 亿，同比 +5.08%
- 归母净利润 17.12 亿，同比 -15.68%
- 扣非净利润 16.43 亿，同比 -17.32%
- 经营现金流净额 3.57 亿，同比 -82.22%

季报原文：
- 本期利润总额同比 -18.42%，主要由于汇兑损益影响
- 本期汇兑损失 4.39 亿，上年同期汇兑收益 2.36 亿
- 若扣除上述因素影响，本期利润总额同比 +9.63%
- 经营现金流下降主要因客户以汇票结算金额同比增加，同时本期到期应付票据支付金额同比增加

## 分析框架

### 1. 利润下滑先拆汇兑

不要直接把“净利润同比下降”写成“主业恶化”。

先看三件事：
1. 公司是否在季报/年报中直接量化汇兑影响；
2. 财务费用、汇兑收益/损失是否发生明显反向波动；
3. 剔除汇兑后，利润总额或经营利润是增长还是下滑。

本案里，报表利润下滑主要由汇兑从收益转为损失造成，剔除汇兑后经营趋势明显好于报表表象。

### 2. 经营现金流大降先拆回款结构

经营现金流大降时，不能只看净额，至少交叉看：
- 应收账款
- 应收款项融资（银行承兑汇票）
- 合同负债
- 存货

本案里：
- 应收账款：84.78 亿 -> 63.60 亿，下降
- 应收款项融资：29.23 亿 -> 50.23 亿，大增
- 存货：67.99 亿 -> 67.46 亿，基本持平
- 合同负债：7.18 亿 -> 7.36 亿，小增

结论：更接近“回款票据化/结算结构变化”，而不是“客户回不来款”或“压货恶化”。

### 3. 现金流质量的写法

即使判断为“结算结构变化”，也不能完全轻描淡写。

正确写法：
- 短期现金流承压主要由票据结算占比提升引起；
- 由于应收账款下降、存货稳定、合同负债未恶化，暂不视为经营质量明显转差；
- 但若票据化持续多个季度，应下调现金流质量评分，或明确列为后续观察点。

## 可复用结论模板

### 模板A：利润口径

“最新季度归母/扣非利润同比下滑，表面承压，但季报已明确披露汇兑损益为主要拖累项。若剔除汇兑波动，经营利润仍保持增长/降幅明显收窄，因此当前利润压力不能简单等同于主业恶化。”

### 模板B：现金流口径

“经营现金流净额明显回落，主要受票据结算占比提升影响。结合应收账款下降、应收款项融资上升、存货基本稳定来看，更接近回款结构变化而非真实回款恶化。但若票据回款占比持续抬升，后续现金流质量仍需继续跟踪。”

## 评分影响

- ROE质量：通常不因为单季汇兑大幅波动直接下调长期ROE质量判断
- 利润增长持续性：若剔除汇兑后经营仍稳，可小幅扣分而非重扣
- 现金流质量：若只是票据化，一般扣 0.5-1 分；若连续多季持续，则进一步降分
- 营运质量：应收下降、存货稳定时，不宜误判为压货或坏账恶化

## 本案提醒

- 福耀属于高质量制造龙头，但不是纯无周期消费股
- 行业需求、汇率、海外扩产、资本开支，都会让其波动高于典型消费复利股
- 因此结论常常是“好公司，但需接受制造业波动”，不能套用纯消费白马写法
