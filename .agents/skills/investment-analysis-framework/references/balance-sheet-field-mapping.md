# 东方财富API资产负债表字段映射与踩坑

## 关键字段映射

| API字段名 | 资产负债表科目 | 性质 | 是否现金 |
|-----------|-------------|------|---------|
| MONETARYFUNDS | 货币资金 | 活期存款+银行存款 | ✅ 是 |
| TRADE_FINASSET_NOTFVTPL | 交易性金融资产 | 理财产品、基金等 | ✅ 是（流动性好） |
| FINANCE_RECE | **应收款项融资** | **银行承兑汇票** | ❌ **不是现金** |
| OTHER_CURRENT_ASSET | 其他流动资产 | 可能含定期存款 | ⚠️ 需查年报附注 |
| SHORT_LOAN | 短期借款 | 经营性周转资金 | 不计入长期负债 |
| LONG_LOAN | 长期借款 | | 计入长期负债 |
| NONCURRENT_LIAB_1YEAR | 一年内到期的非流动负债 | | 计入长期负债 |
| BOND_PAYABLE | 应付债券 | | 计入长期负债 |
| LEASE_LIAB | 租赁负债 | | 计入长期负债 |

## 踩坑记录

### FINANCE_RECE ≠ 理财产品
- API字段名"FINANCE_RECE"容易误解为"财务应收=理财"
- 实际对应"应收款项融资"，主要是**银行承兑汇票**
- 银行承兑汇票是经销商付的货票，可以贴现但不是现金
- **汾酒案例**：FINANCE_RECE=20.60亿，年报附注显示全部是银行承兑汇票
- **福耀案例**：FINANCE_RECE=29.23亿，同上
- **美的案例**：FINANCE_RECE=149.4亿，同上
- **结论：不应计入现金头寸**

### OTHER_CURRENT_ASSET 可能含大额定期存款
- API字段名"OTHER_CURRENT_ASSET"对应"其他流动资产"
- 汾酒案例：194.74亿，年报附注显示全部是"短期定期存款及利息"
- 美的案例：253.76亿，年报附注显示：固定收益类14.27亿 + 待抵扣增值税90.40亿 + 套期工具32.01亿 + 其他117.08亿
- **必须查年报附注确认明细，不能直接计入现金头寸**

### 正确的现金头寸公式
```
现金头寸 = 货币资金(MONETARYFUNDS)
         + 交易性金融资产(TRADE_FINASSET_NOTFVTPL)  # 理财产品
         + 其他流动资产中的定期存款(OTHER_CURRENT_ASSET子项)  # 需查年报
         - 长期借款(LONG_LOAN)
         - 一年内到期非流动负债(NONCURRENT_LIAB_1YEAR)
         - 应付债券(BOND_PAYABLE)
         - 租赁负债(LEASE_LIAB)
         
不含：应收款项融资(FINANCE_RECE) — 这是银行承兑汇票，不是现金
不含：短期借款(SHORT_LOAN) — 经营性周转资金，不计入
```

### 校验流程
1. 先用API获取资产负债表数据
2. 计算初步现金头寸（不含OTHER_CURRENT_ASSET）
3. 查年报PDF附注中"其他流动资产"的明细
4. 如果含定期存款，加入现金头寸
5. 确认FINANCE_RECE的性质（通常是银行承兑汇票，不计入）
6. 确认一年内到期非流动负债是否遗漏（API有时缺失）
