# 东阿阿胶 2026 案例：品牌中药修复后现金流型公司

适用场景：分析品牌中药/滋补消费品公司，尤其是经历过渠道出清后进入稳健修复期的公司。

## 关键数据口径

- 公司研究包：`000423_东阿阿胶/`
- 有同花顺 Excel：`data/000423_main_year.xls`、`data/000423_main_simple.xls`。
- 图表应优先用同花顺 `main_simple.xls` 的单季度扣非净利润，不要在有同花顺数据时退回东方财富累计值。
- 最新报告示例：`000423_东阿阿胶/reports/东阿阿胶_投资分析报告_2026-06-10.md`。

## 分析要点

1. 东阿阿胶是“强品牌 + 高毛利 + 高现金 + 修复后稳增长”的品牌中药/滋补消费品公司，不应按高速成长股估值。
2. 2019-2020 年渠道库存/经营出清是重要历史风险样本：品牌强不等于永远免疫经营失误。
3. 2020 年后 ROE 修复主要来自净利率提升和周转改善，不是靠高杠杆。
4. 现金头寸要用年报附注校验：货币资金 + 交易性金融资产 + 一年内到期定期存款 - 租赁负债相关长期负债；其他流动资产主要为增值税留抵/预缴所得税时不计入；应收款项融资不计入。
5. 扣现金后 PE 能显著改善估值判断，但现金不能替代主业增长。若利润线下行，估值仍会压缩。
6. 阿胶及系列产品收入占比高（2025 年约 92.5%），产品集中度是主要扣分项；复方阿胶浆、桃花姬、速溶粉等第二曲线需要持续验证。
7. 2026Q1 若出现合同负债下降、经营现金流偏低，优先写为“需半年报验证的渠道/季节性信号”，不要直接年化或过度定性为恶化。

## 估值措辞

- PE 分位约 20%-30%、扣现金后 PE 较低时，优先写“合理偏低/有吸引力但非极端低估”。
- 不要写成“明显低估”或“无脑买点”，除非 PE 分位接近历史极值且利润线/渠道指标同步确认。

阶段复盘建议：
- 2018-2020：渠道库存和经营出清，利润大幅下滑，股价承压。
- 2021-2023：利润从低谷快速修复，估值未明显泡沫化。
- 2024：利润 TTM 继续上台阶，市场重新定价修复逻辑。
- 2025-2026Q1：利润线仍上行但增速放缓，估值消化后处于合理偏低区间。

第四章基本面图表建议：
- 4.5 营运质量：主图用 2020-2025 年末年度口径展示应收账款、存货、合同负债；用小图展示资产负债率；2026Q1 只作为右上角补充观察，不要混入年度主图造成口径跳变。正文同步补 2020-2025 数据表。
- 4.6 产品结构与增长来源：不要只画收入绝对值横条。更优结构是“主图看收入占比 + 小图看同比增速”，标题用结论式表达（如“阿胶主品占比 92.5%，第二曲线增速快但体量仍小”）。主图标签保留金额+占比，增速拆到小图，避免增长来源被主品绝对规模淹没。
