# A股治理、资本配置与产品战略：官方公告研究流程

适用：用户要求以最新年报、季度报告和公司公告为主，研究实际控制人、管理层、员工持股、分红回购、并购商誉、产品结构和海外业务，并禁止使用券商预测。

## 1. 官方材料清单

按优先级收集并记录直接 PDF URL：

1. 最新年度报告全文（不用摘要替代）。
2. 最新季度报告。
3. 年报后至截止日的股东会决议、董事会换届、高管任免、董高减持、股东质押公告。
4. 权益分派实施公告、未来股东回报规划、回购结果暨股份变动公告。
5. 员工持股/长期服务计划、股权激励解除限售或终止公告。
6. 收购、配售、认购新股、重大投资进展公告。
7. 交易所针对并购/收购的工作函、问询函及公司回复；交易公告只写“形成一定商誉”时，回复文件常披露预计商誉、历史持股成本、估值假设和敏感性。

巨潮查询时，`stock` 必须用 `{code},{orgId}`。若 `topSearch` 不稳定，可从 `https://www.cninfo.com.cn/new/data/szse_stock.json` 的 `stockList` 按代码查 `orgId`；该列表也可能包含沪市证券。公告接口：

```python
import requests
stocks = requests.get(
    'https://www.cninfo.com.cn/new/data/szse_stock.json',
    headers={'User-Agent': 'Mozilla/5.0'}, timeout=30,
).json()['stockList']
org_id = next(x['orgId'] for x in stocks if x['code'] == code)

j = requests.post(
    'https://www.cninfo.com.cn/new/hisAnnouncement/query',
    headers={'User-Agent':'Mozilla/5.0', 'Referer':'https://www.cninfo.com.cn/'},
    data={
        'pageNum':1, 'pageSize':100, 'column':'sse', 'tabName':'fulltext',
        'plate':'sh', 'stock':f'{code},{org_id}', 'searchkey':'',
        'secid':'', 'category':'', 'trade':'',
        'seDate':f'{start}~{end}', 'sortName':'', 'sortType':'',
        'isHLtitle':'true',
    }, timeout=30,
).json()
```

不要假设一次查询返回全部公告：按年度或季度缩小 `seDate`，检查 `totalAnnouncement`、`hasMore` 和 `totalpages`；公告多时翻页。**分页后必须按 `adjunctUrl` 去重，并核对不同页最早/最晚公告日期**；巨潮接口偶尔会重复返回第一页或让 `hasMore` 表现异常，若页间公告高度重复，改用逐月 `seDate` 查询（每月 `pageSize=100`）后合并去重，不能继续盲翻页。直接 URL 为 `https://static.cninfo.com.cn/` + `adjunctUrl`。

**必做的完整性补查**：即使逐月无关键词查询返回的数量小于 `pageSize`，结果也可能漏掉年报全文、审计报告等关键文件；不能据此认定已完整。完成月度清单后，至少再分别用关键词定向查询：`年度报告`、`审计报告`、`减持`、`质押`、`回购`、`激励`、`分红`、`对外投资`、`收购`、`重大资产重组`、`问询函`、`监管`、`处罚`。将定向结果与月度结果按 `adjunctUrl` 合并去重，并确认最新年报全文、财报审计、内控审计和年报后重大事项都已进入来源台账。不要把“无关键词月度清单未出现”直接写成“公司未披露”。

## 2. PDF 抽取与复核

优先用 PyMuPDF 在内存中抽取，避免依赖外部 `pdftotext`：

```python
import fitz, requests
b = requests.get(pdf_url, timeout=60).content
doc = fitz.open(stream=b, filetype='pdf')
pages = [p.get_text() for p in doc]
```

**临时研究文件规则**：一次性查询、下载、PDF 抽取和核对脚本不得写到项目根目录。优先直接在内存运行；确需落盘时，用 Python `tempfile` 在系统临时目录创建带 `hermes-research-` 前缀的目录或脚本，并在核验完成后清理。只有可复用的数据底稿、来源台账和最终事实表才写入公司研究包的 `data/`。这可避免一次性脚本被误算为代码交付、触发无关代码验证，或在清理权限受限时污染仓库。

建议关键词：

- 治理：`无控股股东`、`无实际控制人`、`前十名股东`、`董事长`、`总裁`、`质押`、`减持`。
- 激励：`股权激励`、`员工持股`、`长期服务计划`、`解除限售`、`终止实施`。
- 资本配置：`现金分红`、`权益分派`、`回购并注销`、`投资方案`。
- 并购商誉：`非同一控制下企业合并`、`商誉账面原值`、`商誉减值准备`、`可收回金额`。
- 产品战略：`主要经营情况`、`收入和成本分析`、`分产品`、`市场份额`、`海外业务`。

关键表格需读取完整相邻页，不能只取关键词单行；股东表、商誉原值/减值表、产品收入表尤其如此。

## 3. 必须区分的口径

### 治理

- 严格区分：第一大股东、控股股东、实际控制人、董事长、总裁。
- 年报管理层任期可能在披露后届满；必须继续查年报后的换届和任免公告。
- 季报股东表是最新持股快照，但不能单独证明控制权变化。
- 董高减持要列：减持前后持股、数量、比例、金额、公告原因；若为偿还质押融资，也要作为治理观察项，而不是只转述“信心不变”。
- 严格区分`质押`、`司法冻结/标记`与`限售`：冻结不是质押。对重要股东冻结，至少计算“冻结股数/该股东持股”和“冻结股数/总股本”；关联大股东也不能未经年报认定就写成实控人或一致行动人。

### 分红与回购

- 区分财年中期分红、财年年度分红、自然年实际到账。
- 分红预案要继续核对股东会是否批准及权益分派是否实施；若截止日位于实施公告日与现金发放日之间，只能写“已发实施公告、尚未到账”，不得写“已实施/已到账”。
- 若预案后因回购注销、行权等导致股本变化，预案总额会与最终派发总额不同：以实施公告的参与股本和实派金额替换预案数；计算“财年中期+年度合计”时也必须用两次实际实施金额重算，并注明为据公告计算值，不能继续沿用预案披露的合计或派息率。
- 回购要区分：库存股、用于激励、注销减少股本；只有实际注销才确认减少股本。
- 限制性股票“回购注销完成”公告可能把不同董事会/股东会批次合并办理；最终人数、股数、金额和股本变动以完成公告为准，同时解释其与最近一次拟注销公告之间的差额来源，避免把单一批次误当最终总数。
- 最近三年“累计分红/年均净利润”不是三年累计派息率，避免误读。

### 激励

- 区分限制性股票/期权、员工持股计划、长期服务计划。
- 同时写明新增、归属/解锁、终止、出售完毕；不能仅因年报写“无新增授予”就说“无激励”。
- 长期服务计划至少列参与人数、资金、股票来源、购买股数/均价、锁定期及董高份额。

### 并购与商誉

同时列：

1. 当年收购价、持股比例、是否形成新增商誉；
2. 商誉原值、累计减值、净额；
3. 主要资产组的原值、累计减值及当年新增减值；
4. 商誉净额/总资产、商誉净额/归母净资产；
5. 联营投资或认购新股属于长期股权投资时，不要误写成并购商誉。
6. 报告期后“参股转控股”交易若尚未满足审批/交割条件，不得写成已经并表；若公司只披露预计商誉，必须标为“预计、最终以审计/财报为准”，并用最新已审计总资产和归母净资产（或明确标注总权益替代）测算潜在占比，不能与报告期末账面商誉混写。
7. 高溢价收益法收购同时检查：评估增值率、历史持股成本、本次增持价格、付款释放条件、是否有业绩承诺、核心团队稳定条款及监管问询回复；“不构成重大重组”不等于商誉风险低。
8. 控股股东大规模资产注入采用“交易方案→审批/注册→资产过户→对价股份登记→配套融资登记→最终股本与控股股东比例”的事件链核对。事实表至少列总对价、股份/现金对价、发行价与股数、锁定期、募资总额/净额、最终总股本及控股股东稀释前后比例；不得把对价股份发行和配套融资发行合并成一次发行。
9. 同一控制下企业合并要写明是否追溯重述比较报表，并区分“全部标的完成过户”与“全部标的纳入合并范围”：参股标的即使过户完成也可能不并表。后续经营同比必须注明法定披露口径或重述口径，二者不能混用。

若利润同比受上年大额商誉减值低基数影响，必须显式提示，禁止把表观增速直接外推。

### 产品与海外

- 用年报分产品收入表计算结构占比，并列收入、同比、毛利率；占比基数要注明是营业收入还是主营收入。
- “奶粉及奶制品”可能包含婴配粉、成人粉、奶酪、乳脂等，不能把大类增速等同于奶粉单品增速。
- 子品类只采用公司披露的准确口径，如“营收双位数增长”“零售额份额”；不要擅自换算。
- 若最新季报未披露分产品数据，应明确写“Q1仅披露集团口径，最新分部数据仍为年报”，禁止伪造季度分部增速。
- 海外需区分消费品（冷饮、奶粉）与乳原料/生产基地；列国家地区数、基地数、产能及公司明确披露的海外增速。

### 报告期后信息冲突检查

- 写完后搜索年报时点的旧持股比例、质押数量、分红“预案”和未完成交易比例，确保没有与最新实施公告并存冲突。
- “资金拟用于偿还质押融资”不能自动写成“已解除全部质押”；只写公告能确认的结果。
- 认购/配售公告要区分本次新增比例与交易完成后的合计持股比例，并把重大投资同步写入资本配置、资产负债表风险和证伪条件。
- 财报期后重大投资即使尚未进入最新财务报表，也可能改变“现金充足/资本配置克制”的结论。

## 4. 简洁输出模板

若用户明确要求“事实表、不写报告、不做预测”，直接输出单表，列固定为 `类别｜日期｜关键事实/数字｜状态/口径｜官方URL`：

- 不加投资结论、观察点、评分、风险推演或预测；公司披露的经营目标只能标成“公司目标/指引”，不得改写为分析者预测。
- 用“预案/股东会已批准/实施公告已发/已到账”“待审批/已注册/已过户/已登记/已并表”等状态词，避免时点混淆。
- A/H 两地事项分别写到账或实施状态；同一事实可合并引用多个官方 PDF，但每个 URL 应直接可打开。
- 聊天回复应直接给出用户要的精炼事实表；如同时落盘，可在表后附文件路径，不能只回复文件位置和摘要。

若用户未限定为纯事实表，则按用户决策顺序压缩：

1. **治理**：控制权、最新股东、董事长/总裁、减持质押风险。
2. **激励**：当前机制、最新一期规模、已终止项目。
3. **资本配置**：年度分红、回购注销、投资计划。
4. **并购商誉**：最新投资、商誉净额与减值。
5. **产品战略**：三大业务表 + 奶粉/奶酪等子品类亮点。
6. **海外**：布局、准确增速、战略方向。
7. **结论/观察点**：3—6条，避免扩展成完整估值报告。
8. **官方URL**：直接 PDF 链接，注明公告日期。

全文禁用券商盈利预测；若引用第三方市场份额，只能明确标为公司年报转引的第三方零研数据。
