# 港股官方财报连续年度研究工作流

适用：用户要求只引用公司官网或港交所文件，整理连续多年年报/中报/业绩公告及财务趋势。

## 1. 官方文件发现与台账

1. 先找公司投资者关系页的“财务资料”和“公告及通函”索引，不以搜索引擎摘要作为最终来源。
2. 动态公告页若HTML没有文件链接，检查页面脚本中的JSON接口。常见模式是公司CMS提供分页接口，返回：标题、披露日、中文/英文PDF URL、文件哈希等。调用接口后按 `Annual Report`、`Annual Results`、`Interim Report`、`Interim Results` 过滤。
3. 港交所标题搜索页可作第二官方入口；最终台账至少记录：报告期、披露日、文件类型、语言、可直接下载URL。
4. 对所有交付链接做HTTP可达性验证；不要把第三方转载链接混进官方台账。
5. “报告日期”要区分：报告期截止日、业绩公告日、年报发布日期、审计报告签署日。

## 2. 连续年度提取的高效方法

- **先落盘再扩展**：完成首轮官方文件发现后，立即创建来源台账、结构化数据表和最终交付骨架；每提取完一组指标就写入文件并校验。不要把大量工具调用耗在检索和只存在于上下文中的摘录上，以免达到调用上限时没有可交付成果。
- 年报主表通常带上年比较数。六年趋势可优先读取三份交替年报：最新年报覆盖最近两年，往前每隔一年读取一份，形成两年一组；再用各年度原始年报核验分部表、股息和附注。例如六年期末资产负债表可优先读取“最新年/上年、第三年/第四年、第五年/第六年”三组比较表。
- 公司官网改版后，新旧投资者页面可能并存：新站财务报告页可按分页抓取年报，旧站业绩发布页的服务器端 HTML 可能仍包含完整历史业绩公告。界面只显示少数年份时，不要据此判断历史文件不存在；应检查页面 HTML、全部 PDF 锚点及分页链接。
- PDF 提取后先锁定页码/章节，再批量取表，避免反复全文件搜索。推荐顺序：业绩摘要 → 损益表 → 分部表 → 现金流量表 → 财务状况表 → 股息/回购附注。
- 核心位置：
  - 综合损益表：收入、股东/母公司拥有人应占溢利；
  - 管理层讨论与分析：产品类别或分部收入；
  - 综合财务状况表：存货、应收、合同负债、金融资产、计息借贷；
  - 综合现金流量表：经营现金流、购买PPE、已付股息；
  - 年末现金余额分析：银行现金、短期存款、长期存款拆分；
  - 董事会报告/股息章节：财年末期股息每股及建议总额。
- PDF文本提取器缺失时，可用PyMuPDF/fitz逐页提取；表格顺序仍需回看上下文，不能只靠关键词命中。

## 3. 口径陷阱

### 现金与存款

- `Cash and bank balances` 往往已经包含银行现金和短期银行存款；长期银行存款单列在非流动资产。
- 建议展示：银行现金、短期银行存款、长期银行存款、三者合计。不要把现金及现金等价物与全部定期存款混为一谈。
- 按公平值计入损益的金融资产（FVTPL）单列；报表未出现时才记0，并注明“未列示”。

### 借款

- 区分流动计息借贷、非流动计息借贷、租赁负债。没有非流动计息借贷时可写“长期借款为0”，但不要把非流动租赁负债混入长期借款。

### 资本开支与自由现金流

- 不同公司对 `capital expenditure` 的口径可能是**资产增加额**而非现金流量表付款额。业绩公告若给出定义，应以公司定义为主，并在表头写清“增加额/付款额”；不要把两者静默混用。
- 自由现金流必须沿用公司的定义。例如公司可能定义为：经营现金流净额减资本开支付款、媒体内容付款及租赁负债付款，此时不能简单写成“经营现金流－资本开支”。
- 若公司只逐季披露自由现金流、未披露年度合计，可将同一财年的四个官方季度数相加，但必须标为“据官方季度数据加总（计算值）”，并保留四份季度公告链接；不得把计算值表述成公司直接披露的年度数。
- 默认以现金流量表“购买物業、廠房及設備”作为核心现金资本开支；若加上土地使用权或无形资产，必须另列“扩展口径”，不可静默混算。

### 分红

- “已付股息”是自然年度现金流，通常对应上一财年已批准分红；“财年末期股息”是该财年的董事会建议/股东批准口径。两者应并列，不能当作同一指标。
- 上市前或特殊分派可能使某年现金流已付股息异常高，应查附注解释。

### 分部和产品收入

- 产品类别表常按人民币百万元取整，审计主表按人民币千元；合计微差应标注为取整，不要强行调平。
- 港股公司可能披露产品类别收入而非IFRS经营分部利润；标题应忠实写“产品类别收入”，不要擅自称为“分部利润”。
- 若公司披露分部收入和分部毛利、但不披露分部经营利润，应明确写“分部经营利润未披露”，并展示官方分部毛利/毛利率作为最接近的已披露盈利指标；不得用集团费用进行主观分摊后伪造分部经营利润。
- 若年报只给分部收入与分部收入成本，可在同一官方表内计算 `分部毛利=分部收入－分部收入成本`，但需标为计算值，并用集团毛利总额核对加总。

## 4. 最新经营信息判断

1. 从公告索引按披露日检查年报之后的全部公告。
2. 证券变动月报、股息表格、股东大会结果不属于经营财务更新。
3. 若年报后没有季度/半年经营数据，应明确写“最新经营性披露仍为年报”，不得根据月报或新闻推算季度经营。
4. 年报中截至“最后可行日期”的经营扩展（新产能、水源、门店等）可以作为下一年度已披露信息，但必须与下一年度财务数据分开。

## 5. 推荐交付结构

1. 一页结论和最新披露边界；
2. 连续年度营收/股东应占溢利/产品类别收入表；
3. 现金与存款/金融资产/借款表；
4. 经营现金流/核心资本开支/分红表；
5. 应收/存货/合同负债表；
6. 年报、中报、全年业绩、中期业绩的官方文件台账；
7. “正确/需注意/不可验证”校验结果。

交付前必须校验：相邻年报比较数是否一致、单位是否一致、产品表取整差异、链接可达、最新经营披露边界。
