# 投资研究报告改写为平台长文

## 适用场景

用于把完整公司研究报告、3R简报等材料改写成雪球、知乎或公众号可读长文。目标是有结构、有故事性、简洁但不牺牲关键判断。

普通的平台风格讨论不需要加载投资分析框架；当任务进入具体公司、具体报告、文章框架设计或实际改写时再使用本流程。

## 核心原则：研究框架和文章框架分层

- 研究框架负责“不漏项”：行业、公司、财务、估值、风险、数据校验都要完成。
- 文章框架负责“读得下去”：围绕一个核心矛盾组织少量决定性证据。
- 不要把完整报告逐章缩写。报告是证据仓库，不是文章目录。
- 故事性不是编故事，而是呈现“市场怎么看 → 关键矛盾是什么 → 数据支持哪种判断 → 当前价格反映了什么 → 什么情况会证伪”。

## 动笔前先锁定一句话主线与评级

用下面的句式概括全文：

> **一句话选股判断｜3R综合评级：字母等级（总分/100，行动评级）**：这是一家______的公司，市场担心______，真正需要验证的是______，当前价格______。

这句话不是宣传语，而是选股框架的压缩结论。应尽量覆盖：行业竞争格局是否“月朗星稀”、公司所处位置、业务是否简单可持续、护城河、轻资本与资本回报、可替代性、长期与短期定价权，以及当前行动条件。不要机械罗列指标，要写成“长期质量 → 最新变化 → 价格与买点”的判断链。

若文章基于3R简报，字母评级必须由3R总分直接映射，不能根据文章语气另评：

| 3R总分 | 字母评级 | 含义 |
|---:|---|---|
| 90—100 | A+ | 生意、管理层和价格都很突出，重大短板很少 |
| 80—89.9 | A | 高质量投资候选，具备较强关注价值 |
| 75—79.9 | B+ | 基本面较好，但存在需要验证的关键问题 |
| 70—74.9 | B | 优点明确，短板也较明显，以观察为主 |
| 60—69.9 | C | 公司质量或价格存在明显不足 |
| 60以下 | D | 暂不值得投入研究精力 |

字母评级负责快速识别，3R分数负责精确比较，行动评级负责告诉读者现在怎么办。三者必须一致。

一句话说不清，通常说明还没有抓住核心矛盾。全文中的行业、产品、财务和估值信息都应服务于这条主线。

常见叙事类型：

1. 好公司遇到坏预期：基本面仍稳，市场是否过度悲观。
2. 表面增长，质量转弱：销量、收入、利润、现金流开始背离。
3. 公司优秀，股票未必便宜：好生意已被高估值充分定价。
4. 低估值陷阱待验证：价格很低，但利润是否仍在下修。

## 默认六段式阅读结构

1. **这家公司最大的争议是什么**
   - 200—300字。
   - 用反常事实开场，给出市场解释、作者初步判断和全文待验证问题。
   - 不以公司成立时间、荣誉或业务百科开头。

2. **它真正靠什么赚钱**
   - 300—450字。
   - 说明产品、客户、付费原因、利润来源和商业模式。
   - 读者看完后应能用一句话复述公司如何赚钱。

3. **为什么它能比同行赚得更多**
   - 300—450字。
   - 把行业竞争、护城河、复购、定价权和管理层放到同一个问题下解释。
   - 护城河必须落到份额、毛利率、ROE、渠道或现金流等结果，不能只用“品牌强”。

4. **增长还能不能持续**
   - 450—650字。
   - 拆解销量、价格、产品结构、份额、区域和新业务。
   - 区分增长来源与增长想象；行业扩张结束后，要说明未来是否只能靠抢份额。

5. **财务是否支持这个故事**
   - 500—700字。
   - 只保留能验证商业故事的数据：ROE及杜邦、扣非利润、CFO/FCF、现金头寸、营运信号。
   - 每个问题采用“一个结论 + 一张图或一组数字 + 一段解释”。

6. **当前价格值不值得承担风险**
   - 估值、风险和结论合计约700—1000字。
   - 解释市场隐含预期，而不是只说PE低于历史均值。
   - 同时给出保守/中性情景、证伪条件和当前行动。

平台深度长文默认约2500—3600个汉字；若用户明确要短帖，再压缩到500—1500字。超过约4000字时，优先删除重复论证、评分过程和数据台账，而不是删掉核心矛盾、估值边界与证伪条件。

## 开篇四句话

1. 一个反常事实或关键背离。
2. 市场通常如何解释。
3. 作者的初步判断。
4. 本文究竟要验证什么。

示例骨架：

> 利润增长了，股价却持续下跌。市场认为核心业务已经见顶。数据表明问题可能不在需求消失，而在增长质量和市场愿意支付的估值下降。本文要回答：当前价格是否已经充分反映这些风险。

## 标题与段落写法

- 章节标题直接写判断，不用“行业分析、财务分析、估值分析”等报告式标题。
- 每节只解决一个问题，按“问题 → 证据 → 原因 → 判断 → 下一问题”推进。
- 每三四个自然段至少提供一次信息推进：反常数据、关键对比、被证伪的观点或改变估值的信息。
- 数字用来建立关系，不用来展示工作量。优先写“利润增长但现金流下降说明什么”，而不是连续罗列五个指标。
- 专业术语可以保留，但第一次出现时用一句话解释。
- 避免AI腔：不要机械三段论、密集加粗、空泛总结、促销式形容词和“接下来我们分析”等提示语。

## 图表和评分

- 正文通常保留3—5张图、1—2张小表。
- 优先图表：利润趋势、ROE与杜邦、利润/CFO/FCF、股价与扣非TTM利润；产品结构或现金头寸按公司核心矛盾选用。
- 每张图只承担一个判断，图后必须解释“它改变了什么判断”。
- 评分是研究与横向比较工具，不应打断叙事。正文引用总分时，文末必须保留紧凑的“维度、权重、得分、核心判断”表，不能只报总分。
- 同一材料存在多个评分版本时，作者在写作前先确定已复核的最终版本，正文只使用这一版。不要向普通读者解释盲评过程、人工复核、旧新评分差异等内部生产信息。

## 增长陷阱与明确表态

当文章讨论朝阳行业、夕阳行业或低估值成熟公司时，可在估值章节开头简要引入西格尔的“增长陷阱”：

> 市场容易为扩张行业支付过高价格，也容易给收缩行业过低预期；最终回报取决于实际增长能否超过当前股价所隐含的市场预期增长。

写法要求：
- 前文先证明公司质量，再讨论价格与预期；不要一开篇就写成泛泛的读书笔记。
- 理论控制在一段，随后立刻给出对当前公司的基准判断。
- 不能把“可能更好、也可能更差”并列后不表态。应明确判断市场预期偏高还是偏低，以及实际经营大概率会如何。
- “投资价值已经出现”和“重仓条件尚未确认”可以同时成立：前者说明赔率，后者说明盈利趋势和验证门槛。全文要统一这一区分。
- 开头的一句话选股判断可写“增长陷阱”的结论，估值章节再解释原理，避免两处重复展开。

## 数据边界

- 行情若未刷新，必须称“报告基准日价格/估值”，不能写成当前行情。
- 估算数据必须保留“估算”标签；有年报确认值时，正文判断优先采用已确认值。
- 不补造报告未披露的单品收入、批价、渠道库存或分部利润。
- 文末用短段说明数据截止日、未刷新事项和关键未验证项；参考材料使用“本文参考[《文章标题》](链接)”的读者向表达，不写“改写自”，也不要把完整校验台账或内部评分过程搬进正文。

## 实际改写流程

1. 读取完整报告和最新简报，确认哪份结论、评分和治理口径更新。
2. 写出一句话主线，选定一种叙事类型。
3. 从源报告筛出支持或反驳主线的决定性证据。
4. 按六段式先写正文，再补标题、评分表和数据边界。
5. 做一次去报告腔和去AI腔检查，删除重复总结与机械小标题。
6. 验证汉字数、图片路径、评分加总、行情日期和估算标签。
7. 通读全文做一致性复核，重点检查开头评级、估值判断、行动建议和结尾是否表达同一层次。

## 发布前一致性检查

1. 开头字母评级、3R总分、行动等级和文末评分表是否一致。
2. 同一材料存在旧报告和新简报时，是否只采用用户指定或最新复核的评分来源。
3. “好公司”“投资价值已经出现”“适合重仓”是否清楚分层，避免一处说可以买、一处又说完全不是买点。
4. 长期定价权与短期定价权是否明确区分，术语是否统一。
5. FCF略低于分红时只能写“接近覆盖”，不能写“覆盖”；其他比例措辞也要先计算。
6. “增长陷阱”是否落到实际增长与当前股价所隐含的市场预期增长，而不是泛泛比较行业增速。
7. 估算现金与年报确认现金、历史行情与当前行情是否明确区分。
8. 图片链接和公开参考链接是否真实可访问。
9. 是否残留“改写自、盲评过程、旧分数、内部评估器”等对读者无用的信息。
10. 全文是否仍在目标篇幅内，新增理论后是否造成重复和臃肿。

## 常见错误

1. 把“好行业—好公司—好时机”原样当作文章目录，导致文章像压缩研报。
2. 开头先讲公司历史，核心矛盾到千字后才出现。
3. 每个研究维度都单列一章，章节过多，读者看目录就退出。
4. 用历史高增长外推未来，忽略最新季度已反转。
5. 因为低PE就直接下结论，没有解释利润继续下降时的估值变化。
6. 只保留总分，不给维度、权重与分项得分。
7. 把估算现金、旧行情或未验证渠道数据写成确定事实。
