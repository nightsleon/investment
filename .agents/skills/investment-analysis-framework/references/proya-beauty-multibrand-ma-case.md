# 国货美妆多品牌与并购商誉案例：珀莱雅（2026）

## 适用场景

研究高毛利、强投放、线上直营占比高的美妆/个护公司，尤其是“主品牌降速 + 第二曲线接棒 + 收购新品牌”的组合。

## 1. 商业模式判断

- 高毛利不等于强净定价权。应同时看毛利率、销售费用率、形象宣传推广费率和净利率；若提价或高毛利需要持续增加流量投放，股东最终获得的定价权弱于毛利率表象。
- 线上直营占比极高时，平台流量规则、达人佣金、广告竞价和平台应收比传统经销商库存更关键。
- 品类高复购不等于公司客户高粘性。没有统一复购率/会员留存率披露时，不得把护肤品复购属性直接写成品牌强粘性。
- 护城河重点看“洞察—研发—开品—营销—复购”的可重复组织能力，而非单个爆品或单一配方。

## 2. 产品结构与增长来源

必须同时拆品牌、品类和渠道：

- 品牌：主品牌收入、占比、同比；第二品牌是否足以覆盖主品牌下降。
- 品类：护肤、彩妆、洗护等，区分成熟基本盘与低基数高增。
- 渠道：线上直营、线上分销、线下；高线上占比意味着平台依赖和流量成本风险。

珀莱雅2025案例：主品牌收入76.89亿元、占主营72.64%、同比-10.39%；Off&Relax同比+102.19%，但体量仅7.44亿元。判断应写成“第二曲线增长快，但尚未完全覆盖主品牌下降”，不能只展示高增品牌。

## 3. 现金头寸与受限存款

- 大额存单/定期存款若已包含在货币资金中，不得重复加计。
- 同时列形式现金头寸和扣受限资金后的可用现金头寸。
- 珀莱雅2025年末货币资金50.61亿元，其中受限资金11.27亿元；应付债券8.04亿元。林奇现金头寸42.57亿元，扣受限资金后的保守可用现金头寸约31.30亿元。
- 其他流动资产需查附注；待抵扣增值税、上市费用、预缴税费、退货成本均不计现金。

## 4. 报告期后并购：不能停在交易公告

高溢价收购必须继续扫描交易所工作函及回复，交易公告往往只写“形成一定金额商誉”，工作函回复可能披露更具体的初步估计。

珀莱雅收购花知晓案例：

- 持股拟由38.4521%升至51%，截至2026-07-17仍待经营者集中审查和交割，不得写成已并表。
- 标的2025年收入17.26亿元、净利润2.80亿元；整体估值28.27亿元，收益法增值率595.76%，无业绩对赌。
- 交易所工作函回复披露预计新增约11亿元商誉，约相当于珀莱雅2025年末总资产13%、股东权益17.6%；最终以购买日审计/财报为准。
- 该风险必须进入管理层/资本配置与资产负债表评分，不能只在文字中提示后维持近满分。
- 并表后必须拆分“内生增长”和“并购贡献”，否则收购会掩盖原有品牌下滑。

## 5. 估值与评分

- 历史PE分位极低时，先判断历史高估值对应的增长阶段是否已经结束；高速增长期中位PE不能直接当合理价值。
- 历史3年CAGR可能被前两年高速增长抬高；若最新年和最新季度已转负，PEG仅作滞后参考并明显降权。
- 压力测试直接用当前TTM利润 × PE时，不再机械加回净现金，避免现金利息和本金重复估值。
- 低PE、高现金不能抵消主品牌连续下滑和重大新增商誉；风险应在管理层、产品结构、现金头寸/资产质量和好时机中真实扣分。

## 6. 核验清单

- [ ] 品牌、品类、渠道三张结构表口径一致。
- [ ] 主品牌下降是否被第二品牌真实覆盖。
- [ ] 销售费用率、推广费率与毛利率同步分析。
- [ ] 大额存单是否已经包含在货币资金。
- [ ] 年报后是否有收购、工作函回复、交割和商誉估计更新。
- [ ] 员工持股计划区分草案、股东会批准、过户实施；回购区分激励用途与注销。
- [ ] 并购后增长拆分内生与并表。
- [ ] 商誉风险已进入分数，而非只进入文字。
