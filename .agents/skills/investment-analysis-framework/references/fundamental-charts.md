# 第四章定量图表建议：图 + 表 + 简洁结论

适用场景：用户希望把“好公司·定量”做得更直观，让读者快速理解利润质量、增长健康度和资产负债表安全性。

## 总原则

- 第四章默认采用“结论标题 + 对应图表 + 数据表 + 简洁解读”。
- 图用于快速看趋势、结构和异常；表用于核对原始数字和计算口径。除非用户明确要求删表，否则不要只放图不放表。
- 每个小节优先 1 张主图，不追求图多；一张图只回答 1 个核心问题。
- 图下只配 1 句结论 + 1~2 条补充，不重复表格内容。
- 数据表紧跟对应图表，优先列近 5-6 年年度数据 + 最新季度/TTM 观察项。
- 图表 title 优先使用统一、中性的图名（如“股东应占溢利趋势”“2025年产品收入结构”），不要在 title 里塞过多判断；关键结论放在图下 1 句结论或正文解读里。
- 白底、极简、少颜色；柱状图默认适当收窄，避免宽柱挤压留白和标签。
- 大主图 + 小辅助图优先于把多种量纲强行塞进一个坐标轴。

## 4.1 ROE质量与盈利模式

图名建议：`ROE与杜邦三因子趋势图`

图形：
- 上方主图：ROE 用柱状图或折线图，突出结果；柱状图不要过宽，建议 `bar width≈0.45-0.55`，留出呼吸感。
- 下方副图：默认可用销售净利率、总资产周转率、权益乘数 3 个小折线图，突出原因。
- 若用户希望更紧凑或强调趋势对比，可将杜邦三因子放在同一张图里，但必须先归一化（如 2019=100），不要把 `% / 次 / 倍` 原始量纲强行共轴。
- 归一化图右侧必须标注最新真实值（例如“净利率 9.1% / 总资产周转率 0.9次 / 权益乘数 1.9倍”），并用上下 offset 错开标签，避免末端标签重叠。
- 只有三因子量纲接近时，才考虑原始值放在同一坐标区；若量纲差异大，优先 small multiples 或归一化单图。

表格：
- 列：年份、销售净利率、总资产周转率、权益乘数、ROE、ROE变化主因。
- 结论要回答：高ROE主要靠什么；ROE变化来自哪里；变化是否健康。

结论模板：
- `ROE仍处高位，但回落主要来自周转率下降；权益乘数未上升，说明不是靠加杠杆维持。`

## 4.2 利润增长来源与持续性

图名建议：`扣非利润趋势与同比增速图`

图形：
- 利润规模用柱状图；柱宽默认收窄。
- 同比增速/TTM同比用折线保留，除非用户明确要求去掉；新增最新季度 TTM 时，不要因为补 TTM 柱而删除同比趋势线。
- 若最新季度变化关键，可在年度柱后追加“最新季度TTM”异色柱，并标注口径（例如“2026Q1 TTM”）。
- 若低基数导致同比尖峰，可用正文/脚注说明或灰化异常点，但不要直接删除同比变化趋势。

表格：
- 列：年份/季度、营收、归母净利润、扣非净利润、扣非同比、3年CAGR、5年CAGR、主要增长来源。
- CAGR 年数必须反算，低基数要注明。

结论模板：
- `利润已走出低谷，但近几个季度增速明显回落，后续应按稳增长而非高增长评估。`

## 4.3 产品结构与增长来源

图名建议：`收入结构与产品增速图`

图形：
- 横向条形图优先于饼图。
- 左图看收入规模/占比；条末可直接标：收入 / 占比 / 毛利率。
- 右图优先看“收入增量贡献”（可用当年收入和同比反推上年收入，再算增量），比单纯同比更能回答增长来源。
- 如果保留同比，把同比作为增量柱标签（例如“+733亿 / +223.8%”），避免汽车/新业务低基数高增速拉坏坐标。
- 如果产品很多，只展示核心产品，其余合并为“其他”。
- 多指标量纲差异大时，拆成“主图看占比 + 小图看增量/增速”。

表格：
- 列：产品线、收入、收入占比、同比、毛利率、增长贡献、备注。
- 产品售价无法验证时标注“待验证”。

结论模板：
- `主品收入占比超过九成，第二曲线仍不足以改变集中格局。`

## 4.4 现金流质量

图名建议：`净利润、经营现金流与自由现金流对比图`

图形：
- 上图：净利润、经营现金流、自由现金流用分组柱状图。
- 下图：经营现金流/净利润、自由现金流/净利润用两条折线。
- 净利润基数极低年份会导致覆盖倍数失真，可不展示该点或用灰字说明，不要让异常点拉坏坐标。
- 数值标签至少补最新一年，方便和表格核对。

表格：
- 列：年份、归母净利润、经营现金流、资本开支、自由现金流、经营现金流/净利润、自由现金流/净利润、分红、自由现金流/分红。

结论模板：
- `长期现金兑现能力强，近年经营/自由现金流持续覆盖净利润。`
- `现金兑现能力仍好，但最新一年覆盖倍数回落，需跟踪回款和资本开支。`

## 4.5 资产负债与现金头寸

图名建议：`现金头寸拆解与资产负债安全垫图`

图形：
- 主图：货币资金、定期存款、交易性金融资产、长期负债、现金头寸用堆叠/瀑布图。
- 辅助图：资产负债率、有息负债率或扣现金后PE趋势。
- 如果定期存款藏在“其他流动资产”，图上必须注明“已按年报附注确认”。

表格：
- 列：货币资金、定期存款、交易性金融资产、长期负债、现金头寸、总股本、每股现金头寸、当前市值、扣现金后市值、扣现金后PE。
- 应收款项融资、短期借款不计入现金头寸；其他流动资产不能整体当作定期存款。

结论模板：
- `现金头寸提供较厚安全垫，但需区分真实现金、定期存款和不可计入的票据资产。`

## 4.6 营运质量与风险信号

图名建议：`应收、存货与合同负债变化图`

图形：
- 上图：应收、存货、合同负债用分组柱状图。
- 下图：营收同比、存货同比、存货/营收用折线/柱状组合。
- 若重点是最新风险提示，优先展示近 2-3 个年末 + 最新 Q1/Q2，而不是拉太长时间线。

表格：
- 列：年份、营收、营收同比、应收账款、存货、存货同比、存货/营收、合同负债、应收/存货周转异常说明。

结论模板：
- `应收上升、合同负债回落时，先写成观察信号，不要直接定性为恶化。`

## 字体与渲染坑点（macOS）

如果 matplotlib 中文渲染成方块，仅设置 `rcParams['font.sans-serif']` 可能不够，尤其图例、标题、说明框、脚注不一定都吃到同一字体。

更稳的做法：
1. 用 `matplotlib.font_manager.addfont()` 显式注册字体文件；
2. 优先尝试：
   - `/System/Library/Fonts/Hiragino Sans GB.ttc`
   - `/System/Library/Fonts/STHeiti Medium.ttc`
   - `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`
3. 对标题、图例、text 注释、脚注显式传 `fontproperties=FONT_PROP`；
4. 生成后最好目视检查至少 1 张图，确认不是方块字。
