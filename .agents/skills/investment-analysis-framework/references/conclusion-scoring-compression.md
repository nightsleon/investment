# 投资报告结尾压缩与客观评分复核

## 适用场景

当用户要求：

- 客观复核报告评分；
- 压缩投资结论、投资逻辑与证伪条件；
- 证伪条件“太细、太多”；
- 保持结论简洁、抓重点。

## 一、先复核评分，再压缩结论

不要先维护原评级，再反向解释分数。按以下顺序：

1. 将正文中的每项风险映射到具体评分项；风险只写在文字里、分数仍接近满分，属于虚假扣分。
2. 检查定量细项之和、模块小计、总分和评级是否一致。
3. 检查“好时机”是否被低PE机械抬高：
   - 主估值用Non-IFRS、历史分位却只有GAAP时，PE分位不宜满分；
   - PEG受低基数、减值恢复或利润率修复影响时，明显降权；
   - 市场预期差缺少独立证据时，不给满分；
   - 压力档仍有明显亏损、保守档回报仅一般时，情景赔率不满分。
4. 评分变化必须同步报告摘要、章节小计、汇总表、评级、行动建议、README入口和数据校验章节。

## 二、投资结论：一个短段落 + 最多3条行动

短段落只回答：

```text
胜率来自什么 + 当前赔率如何 + 最大不确定性 + 总分/评级
```

行动最多3条：

1. 当前如何配置；
2. 什么改善后可以加仓；
3. 什么恶化后不能机械补仓。

删除重复的“胜率”“赔率”“长期持有检查表”等多个小节；能力圈、红线和证伪条件已覆盖的内容不要再列大表。

## 三、投资逻辑：最多3条

按固定顺序组织：

1. **核心资产如何增值**：品牌、生态、渠道、网络效应或核心产品。
2. **增长由什么支撑**：产品结构、第二曲线、多元利润池或效率提升。
3. **安全边际来自哪里**：现金流、资产负债表、估值、股息或回购。

每条采用“结论标题 + 一句解释”，不要重新列出所有产品和财务指标。

## 四、证伪条件：默认压缩为4组

总原则：以下任一情况持续两个报告期，应重新评估。避免用单季波动触发证伪。

1. **核心产品/生态失速**：基本盘、用户、份额或商业化同步走弱。
2. **主要利润池与经营质量恶化**：多个增长来源同时转弱，利润率、渠道或现金流恶化。
3. **关键投入、资产负债表或资本配置恶化**：新业务投入无法兑现；债务、并购、减值、治理出现问题。
4. **股东回报或估值失去安全边际**：自由现金流不能覆盖回报，或低增长阶段估值明显偏高。

不同公司可以替换组名，但通常不超过4组。具体阈值只保留真正决定逻辑成立与否、且公开数据可验证的少数指标；不要把普通风险清单改写成9—10条季度监控项。

## 五、两类公司的落地侧重点

### 平台/科技公司

证伪重点：核心生态活跃度、多利润池同步恶化、AI/新业务投入回报、资本配置与估值。

### 成熟消费龙头

证伪重点：基本盘与产品结构、利润/渠道/现金流、短债与并购治理、分红覆盖和估值。

## 六、PE情景估值防重复计算

若净利润已经包含现金利息收入：

```text
未来股权价值 = 未来净利润 × PE
```

不得机械再加全部净现金，否则现金收益和现金本金可能被重复估值。只有以下情况才可单独加回现金：

- 已从利润中剔除净利息收入；
- 使用经营利润/EV口径；
- 使用分部估值，并对受限现金、短债和战略投资做折价。

## 七、完成后校验

- 结论只有一个短段落和不超过3条行动；
- 投资逻辑不超过3条；
- 证伪条件通常为3—4组；
- 风险与扣分一一对应；
- 分项、小计、总分、评级和README一致；
- 情景估值没有现金重复计算；
- 压缩未删除真正影响投资决策的风险。
