# 港股公司分析补充规则

适用：分析港股公司（如 1810.HK 小米集团）时，在通用投资分析框架基础上的口径补充。

## 1. 行情与估值口径

- yfinance 代码通常为 `{港股数字}.HK`，例如小米集团为 `1810.HK`；东方财富港股代码常为补零格式，如 `01810`。
- 股价与市值通常为港元；公司财报可能以人民币或其他币种列报。估值计算必须先统一币种。
- 汇率可用 yfinance：`HKDCNY=X`；报告中注明汇率日期与来源。
- 市值人民币口径：`股价港元 × 总股本 × HKD/CNY`。

## 2. 利润与 TTM

- 港股没有 A 股“扣非净利润”的完全对应口径，不要强行写“扣非”。
- 可用主线：`股东应占溢利`（GAAP）；若公告披露 `经调整净利润`，作为经营质量辅助口径。
- 若港股公司披露季度业绩，东方财富利润表常为年初至报告期累计值，需要差分成单季度，再滚动 4 季得 TTM。
- 若只披露半年报/年报，则不能伪造季度 TTM；按可得披露频率说明限制。
- 只有季度收入/经营增速更新、没有季度利润时，当前PE仍只能标为“最新股价 ÷ 最新已披露年度或半年度TTM利润”，不能把收入增速推算成利润TTM。报告需把“最新经营增速”和“估值利润口径”分开标注。

## 3. 股价 vs 利润图

- 股价轴写港元；利润轴写财报列报币种，正文说明两者不可直接混算。
- 双 Y 轴只看趋势方向和斜率是否匹配，不比较绝对位置高低。
- 若上市早期利润 TTM 为负，归一化图应从第一个正利润 TTM 点开始，否则会误导。
- 对最新交易日股价 + 最新已披露 TTM 利润的组合，应在图注中写清楚“最新点为当前股价 + 最新财报 TTM”。

## 4. 产品结构与分部

- 港股年报/业绩公告的分部口径通常比行情 API 更可靠，产品结构优先用公告或年报管理层讨论与分析。
- 对“智能电动汽车及AI等创新业务”等新分部，既要写收入与毛利率，也要写经营收益/亏损；高毛利不等于分部已盈利。
- 第二曲线业务需同时跟踪：收入、交付/销量、ASP、毛利率、经营亏损、资本开支、自由现金流。

## 5. 港股总股本、行情与市值校验

港股行情供应商的 `shares` / `marketCap` 可能滞后，正式报告不得只用行情接口股本。

推荐流程：
1. 在港交所披露易找到最近一期“证券变动月报表”，读取第 II 部分 `Balance at close of the month / Total number of issued shares`，同时确认库存股数量。
2. 再检查月末之后最新的 `Next Day Disclosure Return / 翌日披露报表`；若其披露了更新的期末已发行股数，当前市值应采用该更晚官方股数，而不是机械沿用月报。
3. 区分三类股份：已发行股份（不含库存股）、库存股、已回购待注销股份。已回购待注销股份在正式注销前仍包含于法定已发行股数；不得提前从严格市值主口径扣除，可另列“经济股本”敏感性口径。
4. 严格市值 = 最近完整交易日收盘价 × 截至该日可得的最新官方已发行股份总数（不含库存股）。股本来源和截止日必须写入报告。
5. 基本 EPS 使用期间加权平均股数，因此“股价÷EPS”和“市值÷利润”会有小幅差异；正式主口径优先用最新官方股本的市值法，并说明差异来源。
6. 若当日仍在交易，报告基准采用最近完整交易日，不把盘中价格与收盘财务口径混写。

月报PDF可用 `pdfplumber` 提取；关键词：`Balance at close of the month`、`Total number of issued shares`、`treasury shares`。

### 港交所标题检索的可复用抓取流程

当公司官网页面由 JavaScript 动态加载、搜索引擎受限或需要连续下载多年公告时，优先直接使用港交所标题检索：

1. 用预测搜索取得公司 `stockId`：
   `GET https://www1.hkexnews.hk/search/partial.do?lang=EN&type=A&name={stock_code}&market=SEHK&callback=callback`
2. 从返回 JSONP 中选择公司普通股对应的 `stockId`，不要误选窝轮/衍生品。
3. 向 `https://www1.hkexnews.hk/search/titlesearch.xhtml?lang=en` POST：`market=SEHK`、`searchType=1`、`documentType=-1`、`t1code=-2`、`t2Gcode=-2`、`t2code=-2`、`stockId`、`from=YYYYMMDD`、`to=YYYYMMDD`、`category=0`、`title=`。
4. 解析结果页 `/listedco/listconews/sehk/...pdf` 链接，按标题筛选 Annual Report、Interim Report、Results Announcement、Monthly Return。
5. 下载后验证响应以 `%PDF` 开头，并生成“标题/发布日期/URL/本地文件”来源台账。

此流程的价值是取得真实公告日，便于点时PE在年报/中报业绩公告后切换，避免用报告期结束日或年报印刷日产生未来函数。

### 最近完整交易日的确定

- 报告生成时先读取香港本地时间；港股仍在交易时，必须剔除当天 yfinance 行并采用前一完整交易日。
- 自动化脚本可保守地用香港时间 `16:10` 作为当日行情可用阈值；阈值前取 `today-1` 后再向前寻找实际交易日。
- 同行表、汇率、市值、PE和报告抬头必须使用同一个完整交易日；不得出现“昨日股价+今日盘中市值/PE”的混合快照。

## 6. 仅披露半年报/年报港股的点时PE

不得伪造季度利润。半年度TTM按以下方式构造：

```text
年末TTM = 当年全年股东应占溢利
年中TTM = 上年全年 + 当年H1 - 上年H1
```

历史日频PE可采用“点时可得EPS阶梯”：
- 年报/中报/季报利润不得在报告期末回填；必须从真实业绩公告之后才切换。
- 默认采用**公告后的下一个交易日**作为新利润生效日，避免把收市后发布的业绩用于公告日收盘价；只有能证明公告在开市前发布时，才可从公告日生效。
- 年报生效后切换到上一财年EPS；中报生效后切换到 `上年全年EPS + 当年H1 EPS - 上年H1 EPS`；季度披露公司按单季差分后滚动四季。
- 股价使用未复权收盘价，EPS按每日汇率转换到股价币种。
- 最好使用真实公告日。若统一用近似切换日，必须在图注写明“点时近似，只看区间分位”。
- 当前PE与历史分位必须使用同一种方法：不要把当前官方期末股本市值法PE直接塞入历史EPS法分布；若两种方法并列，分别标注并解释期末股本与加权平均股本差异。

上市不足十年时取上市以来最长区间。上市早期利润低、估值高会抬升中位数，因此历史低分位只能说明市场预期压缩，不能直接把历史中位数当合理价值。

## 7. IP/消费爆款公司的集中度去重

分析IP消费公司时，分别披露“单一IP占比”和“单一品类占比”，但要判断二者是否由同一爆款驱动。若核心IP主要通过核心品类变现，两个集中度风险高度重合，报告中不得当成两个独立风险重复扣分。

推荐同时跟踪：
- 第一IP收入占比；
- 第一品类收入占比；
- 非第一IP合计增速；
- 第一IP流量是否外溢到第二梯队IP；
- 存货增速与收入增速之差；
- 存货周转天数、拨备比例和折扣清货信号；
- 经营现金流/利润是否随备货扩张下降。

爆款年份的高ROE、高毛利率和高净利率不宜直接外推。情景估值应使用稳态利润，并把现金头寸单独折价计入：

```text
股权价值 ≈ 稳态利润 × 合理PE + 折价后的可用现金头寸
```

至少包含压力、保守、中性三档；压力档应允许利润显著回撤，而不是只假设增速放缓。

## 8. 小米集团案例要点（可复用为港股硬件生态公司分析模板）

- 不能再把小米简单当手机公司；应拆为：智能手机、IoT与生活消费品、互联网服务、智能电动汽车及AI创新业务。
- 互联网服务通常是高毛利利润池；汽车是估值弹性来源，但也可能消耗现金流。
- 现金头寸很厚时，要计算扣现金后 PE；但汽车扩张期不能把全部现金视为可分配资产。
- 2026Q1 小米案例显示：即使汽车毛利率较好，分部仍可能有经营亏损；报告要明确区分“毛利率好看”和“经营利润兑现”。
