# 腾讯类港股季度披露公司的点时估值案例

适用：腾讯等按季度披露 GAAP/IFRS 与公司自定义 Non-IFRS 归母利润、同时持续回购的港股公司。

## 1. 同日行情与市值快照

- 报告日若当日尚未收市，统一采用最近完整港股交易日；股价、汇率、市值和 PE 必须同日。
- 股价取港元未复权收盘价；财报利润若为人民币，使用同日 `HKDCNY=X` 转换。
- 正式总股本优先取最近一期港交所证券变动月报的 `Number of issued shares (excluding treasury shares)`，并单列库存股。
- 若月报后有 Next Day Disclosure Return，不要静默混入口径：用户明确要求“官方最新月报”时以月报期末股本为主；可另列月报后更新股本作为敏感性口径。
- 主市值：`股价HKD × 月报期末已发行股份（不含库存股）`；人民币市值再乘 HKD/CNY。
- 已回购待注销股份在法定注销前通常仍属于已发行股份；若未列为库存股，主市值不得擅自扣除。可另列“经济流通口径”，但要与法定股本口径分开。

## 2. GAAP 与 Non-IFRS TTM

- 两条利润线都使用“公司权益持有人应占利润”，不得混入集团净利润。
- 腾讯季度公告通常直接披露单季度 GAAP 与 Non-IFRS 归母利润；年度及第四季度公告有时同时给全年和 Q4，优先取明确披露的 Q4，不必用全年减前三季。
- 若公告首页先给 H1、后给 Q2，不能把 H1 累计值误当单季度；应定位 `2Q... Financial Highlights` 或第二组 Non-IFRS/IFRS 区块。
- TTM = 最近四个真实单季度归母利润之和。GAAP 与 Non-IFRS 分开计算、分开给 PE。
- 正式当前 PE 推荐市值法：`人民币市值 ÷ 人民币TTM归母利润`。说明其与 `股价÷基本EPS` 的差异来自期末股本和季内加权平均股本。
- 腾讯 2020—2022 年 GAAP 利润容易受投资处置、公允价值和实物分派等项目扰动；经营估值主判断宜看 Non-IFRS，GAAP 作会计口径对照。

## 3. 无未来函数的十年点时 PE

1. 从公司官方每季业绩公告提取真实公告日、GAAP/Non-IFRS 单季归母利润及基本 EPS。
2. 股价使用每日未复权 Close；利润阶梯在公告后的下一个港股交易日才切换，除非已核实公告在开市前发布。
3. 推荐主序列用 EPS 法：`PE_t = Close_HKD_t ÷ (TTM EPS_RMB_t ÷ HKD/CNY_t)`。这样不必伪造每日股本，但需注明各季加权平均股数略有不同。
4. 严格复核序列可用市值法：根据月报和 Next Day Disclosure Return 重建历史股本；股本信息只能从披露日起使用，不得把后来披露的月末股本提前回填。
5. 当前分位必须用与历史完全一致的方法重算，不能把当前官方期末股本市值法 PE 塞入历史 EPS 法分布。
6. 同时输出日频时间分位和“每季公告后首个交易日”截面分位；后者避免一个利润阶梯因持续时间长而被重复计权。
7. GAAP 与 Non-IFRS 分位分别统计；剔除 TTM≤0/缺失点，不随意删除极端正 PE。

## 4. 持续回购的归集规则

- 年报/季报中的“期内回购股数与金额”可作总量主来源。
- 季度尚未披露时，可用港交所月报与 Next Day Disclosure Return 补齐，但必须按**实际回购日期**归集，不能按注销日期归集。
- 月报常同时出现：本月注销的前期回购、当月新回购待注销、期权行权新增股本。不能用“当月股本减少量”代替回购量。
- 跨月示例处理：若4月注销的股份包含3月与4月回购，应按公告备注中的实际交易日期拆回各季度。
- 回购收益与股息率分开：静态股息率仅用每股现金股息/股价；回购可另算股东回报率，不并入“股息率”。

## 5. 情景估值

- 不用券商预测时，以当前 TTM 为锚，自设保守/中性/乐观利润和 PE，明确它们是分析假设而非市场一致预期。
- 建议 GAAP 与 Non-IFRS 两套假设互相校验；若两套目标股价相差很大，先解释非经常项目而不是机械平均。
- 目标价：`归母利润假设 × PE ÷ HKD/CNY ÷ 官方股本`。
- 若使用 PE 法，上市投资组合和净现金不宜再无折价全额加回，以免与倍数隐含资产价值重复计算；若采用 SOTP，则应显式改用经营利润价值加折价资产价值。
- 压力档必须允许利润负增长和 PE 压缩，不能所有情景都给出正收益；高增长 PEG 若来自低基数修复，必须降权，并补稳态低增速情景。

## 6. 三种现金/投资口径必须分开

1. **总现金**：公司披露的现金及现金等价物、定期存款及高流动性理财。
2. **彼得林奇现金头寸**：总现金 - 长期借款及票据；不扣短期借款，不混入租赁负债。
3. **公司净现金**：总现金 - 全部借款及票据，通常更保守。

战略投资另列：上市投资按公允价值，非上市投资按账面价值；二者不是现金，不能 1:1 抵扣市值。还要查年报“资金所在地/汇兑限制”附注，现金很多不等于全部可自由汇回、分红或回购。

## 7. AI投入：用“剔除新AI产品利润”量化净拖累

当公司同时披露集团经营利润和“剔除新AI产品后的经营利润”时：

```text
新AI产品净经营拖累 ≈ 剔除新AI产品经营利润 - 集团经营利润
```

该差额不是纯研发费用，因为剔除口径同时排除了相关收入、成本和费用；报告应写“净经营拖累/净投入”。至少跟踪 AI 资本开支、净投入占核心经营利润比例，以及广告转化、游戏效率、云AI收入等已兑现收益。

## 8. 自由现金流口径

腾讯定义的自由现金流并非简单 `经营现金流-资本开支`，还扣除媒体内容付款及租赁负债付款。报告表格、图和文字必须统一采用同一口径，并在首次出现时解释。

## 9. 冻结行情快照与可复现验证

- 港股收盘后汇率仍可能波动；报告定稿前应冻结 `as_of` 快照，随后图表和验证读取冻结数据，不要在每次验证时重新拉取实时汇率，导致报告、JSON和图注轻微漂移。
- 数据脚本最好支持 `--as-of YYYY-MM-DD`，或分成“采集一次保存原始行情”和“本地重放计算”两阶段。
- 校验必须覆盖：IFRS累计值差分后季度之和=全年、Non-IFRS单季之和=年度、TTM公式、股价/汇率/股本同日、图表与报告同一快照、评分加总。
- 临时验证脚本只能称为 ad-hoc verification，不表述为标准测试套件全绿。
