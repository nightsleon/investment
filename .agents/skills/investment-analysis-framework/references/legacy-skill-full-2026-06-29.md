# 投资分析框架：好行业 / 好公司 / 好时机

融合彼得林奇的成长与PEG、巴菲特的能力圈/护城河/自由现金流、西格尔的长期股权收益与股息再投资、邱国鹭的好行业/好公司/好价格与胜率赔率，以及段永平 3R 选股哲学，结合A股/港股实践整理。

> 本框架默认投资范围：不考虑强周期行业，优先筛选长期稳定、可复购、有定价权、自由现金流好的非周期复利型公司。

## 投资大师核心思想

- **彼得林奇**：在自己看得懂的生活和行业中，寻找增长真实、估值合理、现金充足、尚未被市场过度追捧的公司，靠企业盈利增长赚钱。
- **巴菲特**：在能力圈内，用有安全边际的价格，买入具备长期护城河、优秀管理层和持续自由现金流的好生意，并长期持有。
- **西格尔**：长期股票收益主要来自企业盈利增长、股息再投资和合理估值，高股息+低估值往往能带来更好的长期回报。
- **邱国鹭**：在好行业里找好公司，在好价格时买入，用企业质量提高胜率，用低估值和安全边际提高赔率。
- **段永平 3R**：按 Right Business → Right People → Right Price 的顺序，先找对生意，再看对人，最后等对价格。

## 使用方式

用户给出股票代码时，按以下顺序执行：

1. 先做能力圈检查：如果看不懂公司靠什么赚钱、增长来自哪里、最坏情况是什么，不强行分析。
2. 刷新最新股价、市值、PE、股息率；报告中的股价/市值必须是最新交易日数据。
3. 判断是否触发行行业红线、财务治理红线或价值陷阱红线；触发一票否决则先说明，不继续强行打高分。
4. 拉取财务数据：利润表、资产负债表、现金流、估值历史、股东结构、产品结构。
5. 若用户提供同花顺Excel，优先用同花顺与东方财富API交叉验证；没有Excel时以东方财富API为准，但现金头寸必须用年报附注校验。
6. 竞争格局必须查同行最新市值/PE，不能凭记忆写。
7. 好时机分析必须加载 quarterly-stock-profit-analysis，生成并在“好时机”章节正文嵌入三张图：股价 vs 扣非TTM双Y轴主图、归一化辅助图、单季度扣非利润图；不能只在报告开头或文件夹里放图。
8. 按本框架完成好行业、好公司定性、好公司定量、好时机评分；“好时机”不能只给PE/毛估估，必须结合图表做分阶段股价与利润线复盘。
9. 做中性档和保守档毛估估；不做乐观档。
10. 做投资结论、投资逻辑与证伪条件。
11. 写完后按校验清单核对关键数据，并验算所有小计和总分。

- 优先做减法：先压缩标题、核心问题和 bullet 数量，再考虑合并维度。
- 用户通常更接受“保留经典维度、压缩表达”，不偏好为了简洁而随意合并核心分析维度。
- 初筛模块可把“公司画像”和“能力圈判断”合并成一节，标题可更口语化，如“公司画像：这门生意看得懂吗？”。
- 行业模块标题可更判断化，如“好行业（20分）：是不是好生意？”。若维度本身来自经典框架（如波特五力精简版），优先保留维度，只把每项压到“1句核心问题 + 2~3条重点看”。
- 公司定性模块适合保留“护城河 / 复购粘性 / 定价权 / 管理层”四维，不随意合并；每项压成“1句核心问题 + 2~3条重点看”。
- 好时机模块里，PE部分可改成“PE及PE百分位”：同时看当前PE、近十年PE百分位，以及扣现金后市值/扣现金后PE。注意术语应写“净现金/现金头寸”或“扣现金后估值”，不要误写成“净现金流”。
- 估值措辞要和分位匹配：若近十年PE分位约10%-20%，优先写“偏低”或“合理偏低”，不要轻易写“明显偏低”或“极低估”，除非有更强证据（如接近历史极值、扣现金后估值也显著压缩、且利润线未明显下修）。

## 一、先判断能不能研究：公司画像 + 能力圈 + 红线

一句话：这一节只解决一个问题——这家公司是否值得继续往下研究。如果看不懂、触发一票否决，或明显不符合“非周期复利型”偏好，就先停止或降级处理，不强行打分。

停止条件：如果初筛结论为“不通过”，或虽为“谨慎通过”但关键问题暂时无法验证，后续二到五可停止，不强行完成全套分析。

### 1.1 公司画像：这门生意看得懂吗？

核心问题：这家公司是做什么的、靠什么赚钱、我能不能看懂，值不值得继续研究？

重点看：
- 主营业务：公司到底靠什么赚钱；
- 核心产品/服务：最赚钱、最有竞争力的业务是什么；
- 增长来源：增长来自销量、提价、产品结构、效率、市占率，还是一次性因素；
- 控制人与管理层：实际控制人是谁，经营管理层是谁；
- 最新估值概况：股价、市值、PE、股息率大致处于什么水平；
- 看不看得懂：能否说清商业模式、护城河、行业关键变量和最坏情况。

结论写法：
- 通过：继续分析；
- 谨慎通过：带着待验证问题继续；
- 不通过：停止分析。

### 1.2 红线检查（一票否决 / 降级项）

核心问题：有没有明显不该碰、或者至少要大幅降权的问题？

重点看：
- 财务治理：审计意见非标、频繁更正财报、经营现金流长期远低于净利润、商誉过高、频繁跨界并购、大股东大比例减持、股权质押率过高；
- 资产负债：有息负债压力大、短债长投、债务集中到期、受限资金高、资产负债率异常抬升、商誉/存货/长期股权投资等资产质量存疑；
- 行业属性：强周期行业；需求主要由宏观周期、库存周期、价格周期驱动；利润主要来自商品价格上涨而非公司能力；
- 经营质量：应收账款/存货周转异常恶化，压货冲收入，核心产品份额持续下降；
- 价值陷阱：低PE但利润持续下滑；高股息但分红不可持续；净现金多但主业衰退；低PB但资产质量差；行业永久衰退；现金流长期差。

处理原则：
- 触发财务治理重大红线：一票否决或大幅降级；
- 触发行业属性红线：默认不投，除非用户明确要求研究；
- 触发经营质量或价值陷阱问题：不一定一票否决，但必须解释并降权。

本节输出格式：

```
初筛结论：通过 / 谨慎通过 / 不通过
- 公司画像：……
- 能力圈：能看懂 / 部分看懂 / 看不懂
- 红线：未触发 / 触发降级项 / 触发一票否决
- 后续重点：列出后文必须验证的2-3个核心问题
```

## 二、好行业（20分）：是不是好生意？

一句话：好行业先看需求质量，再看行业结构。重点看需求是否长期稳定、竞争格局是否有序、进入壁垒是否足够高、上下游议价权是否健康，以及替代风险是否可控。

### 2.1 需求质量 / 非周期性（6分）

核心问题：需求是不是长期稳定、弱周期、可持续？

重点看：
- 需求是否长期存在，10年后是否仍然需要；
- 是否弱周期/无周期，少受宏观、库存、价格周期影响；
- 行业是否仍有增长空间，如渗透率提升、结构升级、消费升级、龙头提份额。

### 2.2 竞争格局（4分）

核心问题：行业竞争是否有序，龙头能不能持续提升份额和盈利能力？

重点看：
- 龙头份额是否清晰，是一超多强、寡头格局，还是高度分散；
- 行业集中度是否提升，龙头是否更受益；
- 是否容易陷入价格战、补贴战、渠道内卷。

### 2.3 进入壁垒（4分）

核心问题：新进入者是不是很难复制？

重点看：
- 新进入者是否容易进入：资本、技术、牌照、渠道、品牌、规模要求高不高；
- 壁垒是否随时间增强，而不是被技术迭代快速削弱；
- 行业是否需要长期积累，如品牌心智、客户认证、供应链、工艺经验、数据网络、渠道网络。

### 2.4 上下游议价权（3分）

核心问题：行业利润会不会被上游拿走、被下游压缩？

重点看：
- 对上游：原材料或核心供应是否被少数供应商卡脖子，成本上涨能否转嫁；
- 对下游：客户/渠道是否依赖行业龙头，是否能先款后货、缩短账期、控制渠道利润；
- 议价权最终要落实到毛利率、净利率、应收账款、经营现金流上。

### 2.5 替代品威胁（3分）

核心问题：需求会不会被别的技术、产品或消费方式替代？

重点看：
- 这个行业满足的底层需求是否稳定；
- 是否存在明显替代路径，如技术替代、消费习惯迁移、政策替代、渠道替代；
- 短期替代风险和长期替代风险要区分。

**好行业评分：/20**
- 需求质量/非周期性：/6
- 竞争格局：/4
- 进入壁垒：/4
- 上下游议价权：/3
- 替代品威胁：/3

## 三、好公司·定性（20分）：有没有长期复利能力？

一句话：定性看的是“这是不是一门能长期越做越好的生意”。重点看护城河、复购粘性、定价权和管理层，而不是短期业绩波动。

### 3.1 护城河（7分）

核心问题：竞争对手为什么难以复制？

重点看：
- 品牌、渠道、规模、成本、技术等壁垒是否真实存在；
- 护城河是单一壁垒，还是多重壁垒叠加；
- 护城河是否会随着时间增强，并兑现到经营结果上。

### 3.2 复购/粘性/低替代性（5分）

核心问题：客户会不会持续买，换别家是不是很容易？

重点看：
- 是否存在高频复购、持续消费或长期使用场景；
- 用户习惯是否稳定，替代成本是否高；
- 收入是否具有持续性，而不是一次性爆发。

### 3.3 定价权（5分）

核心问题：公司能不能提价，还不明显伤害销量和客户关系？

重点看：
- 公司是否具备提价能力，提价后销量和渠道关系是否稳定；
- 成本上涨时，公司能否顺利转嫁；
- 历史上是否有成功提价并保持利润率的记录。

### 3.4 管理层（3分）

核心问题：管理层能不能长期把公司经营好？

重点看：
- 实际控制人和经营管理层是否区分清楚；
- 是否专注主业、本分、诚信，不乱扩张；
- 资本配置是否克制，是否重视长期回报。

**好公司·定性评分：/20**
- 护城河：/7
- 复购/粘性/低替代性：/5
- 定价权：/5
- 管理层：/3

## 四、好公司·定量（40分）：利润是不是真，增长是否健康，资产负债表是否安全？

一句话：定量看的是“好生意有没有真正兑现成高质量利润、现金流和资产负债表”。先看利润表，再解释增长来源，再看现金流和资产负债表，最后用营运指标寻找前瞻风险。ROE是发动机，现金头寸是安全垫。

去重规则：
- 4.1 只看盈利模式质量；
- 4.2 只看利润增长质量与持续性；
- 4.3 只看产品层面的增长驱动；
- 4.4 只看利润向现金的兑现能力；
- 4.5 只看资产负债表安全垫、资产质量和扣现金后估值；
- 4.6 只看营运前瞻信号。
若同一现象已在某节展开，后文不重复论证，只做引用。

### 4.1 ROE质量与盈利模式（9分）

核心问题：这门生意是不是高质量赚钱生意？ROE是否健康、可持续，而不是主要靠杠杆或一次性因素支撑？

ROE = 净利率 × 总资产周转率 × 权益乘数。

杜邦分析看趋势，不只看当前值。重点看：
- ROE是否长期较高且稳定；
- ROE主要来自净利率、总资产周转率，还是权益乘数；
- 净利率是否来自品牌、定价权、产品结构、规模效率等可持续因素；
- 周转率提升是否建立在真实动销和健康营运基础上；
- ROE提升如果主要来自加杠杆，要视为风险信号；
- 一次性收益、投资收益、公允价值变动若明显扰动ROE，要降权判断。

报告写法：4.1 不能只列ROE、毛利率、资产负债率；有数据时至少列近5-6年“销售净利率、总资产周转率、权益乘数、ROE”杜邦趋势表。结论要回答三件事：
- 高ROE主要靠什么：净利率、周转率，还是杠杆；
- ROE变化来自哪里：净利率变化、周转率变化，还是权益乘数变化；
- 变化是否健康：净利率是否来自品牌/定价权/结构升级/规模效率，周转率是否有真实动销支撑，权益乘数上升是否意味着加杠杆风险。

若出现“ROE仍高但近年回落”的情况，要像汾酒案例一样拆开看：高ROE若主要来自净利率且权益乘数下降，说明盈利模式仍优质、不是靠杠杆；但若净利率和总资产周转率同步下降，说明利润率和资产效率开始承压，后续要跟踪净利率、动销、库存和周转率能否企稳。

这一项里的净利率，主要用于判断盈利模式质量，不用于重复拆解阶段性利润增长来源。

### 4.2 利润增长来源与持续性（7分）

核心问题：扣非利润是否真实增长？增长来自哪里？这种增长未来还能不能持续？

CAGR必须重算并核对年数：2020→2025是5年，2022→2025是3年。低基数CAGR要注明基数效应。

重点看：
- 扣非净利润3年、5年CAGR；
- 增长来自销量增长、提价、产品结构升级、市占率提升、效率改善，还是并表/收购、一次性收益；
- 如果利润增长主要来自净利率扩张，要判断这种扩张是否可持续；
- 增长是否稳定，是否依赖单一年份、单一产品、单一渠道；
- 并表、补贴、资产处置、投资收益等因素，不能简单视为高质量增长。

这一项里的净利率，只用于拆解利润增长来源，不重复评价“净利率本身高不高”。

### 4.3 产品结构与增长来源（6分）

核心问题：增长来自核心产品稳固和结构升级，还是单一产品透支？

产品结构分析必填。它要放在现金流和资产负债表之前，因为产品结构是解释“利润增长为什么能持续”的关键。重点看：
- 各产品线收入占比、毛利率、增速；
- 核心大单品是否稳固；
- 第二增长曲线是否在起来；
- 结构升级是否真正贡献利润；
- 是否过度依赖单一产品；
- 产品售价无法验证时标注“待验证”。

这一项重点回答“增长具体由哪些产品和结构变化驱动”：
- 4.2看利润增长是否真实、是否可持续；
- 4.3看增长具体由哪些产品和结构变化驱动。

### 4.4 现金流质量（7分）

核心问题：利润是否真正变成现金？增长和分红是否依赖自身造血能力？

自由现金流 = 经营现金流净额 - 资本开支。
资本开支通常取现金流量表中的“购建固定资产、无形资产和其他长期资产支付的现金”。

重点看：
- 经营现金流/净利润；
- 自由现金流/净利润；
- 资本开支/经营现金流；
- 自由现金流是否长期为正；
- 自由现金流是否覆盖分红；
- 如果利润增长较快，但经营现金流和自由现金流长期跟不上，要重点解释原因。

报告写法：4.4 不能只列经营现金流、资本开支、自由现金流三个绝对值；至少列近5-6年“归母净利润、经营现金流、资本开支、自由现金流、经营现金流/净利润、自由现金流/净利润”的对比表，再判断利润兑现能力和资本开支压力。若已有最新Q1/Q2/Q3，还应补一句最新单季的经营现金流/净利润、自由现金流/净利润，说明是否出现阶段性承压。

利润好看但现金流差，往往说明增长质量要打折。

### 4.5 资产负债分析与财务安全性（6分）

核心问题：公司有没有安全垫？资产负债表是否稳健？扣现金后估值是否更便宜？

现金头寸 = 现金等价物 + 定期存款 + 有价证券 - 长期负债
每股净现金 = 现金头寸 / 流通股数
扣现金后市值 = 当前市值 - 现金头寸
扣现金后PE = 扣现金后市值 / 扣非净利润TTM

科目规则：
- 现金等价物 = 货币资金；
- 定期存款必须查年报附注确认；
- 有价证券 = 交易性金融资产；
- 长期负债 = 长期借款 + 一年内到期的非流动负债 + 应付债券 + 租赁负债；
- 不计入应收款项融资、短期借款；
- 其他流动资产不等于定期存款，必须逐项确认。

重点不是“现金多就高分”，而是看：
- 现金是否真实可用；
- 长期负债和有息负债压力大不大；
- 资产负债率、权益乘数是否主要由经营模式决定，还是靠加杠杆支撑；
- 商誉、资本化开发支出、长期股权投资、其他流动资产等资产质量是否可靠；
- 是否存在短债长投、债务集中到期、表外负担或受限资金；
- 扣现金后估值是否明显改善。

资产负债分析既是风险项，也是安全边际来源：净现金厚、长期负债低、资产质量清晰，可以提高下限；但如果现金不可用、负债刚性高、商誉和存货质量差，则要明显降权。

### 4.6 营运质量与风险信号：应收/存货/合同负债（5分）

核心问题：是否存在压货、赊销、回款恶化或收入蓄水池下降？

重点看：
- 应收账款、应收票据、合同资产增速是否明显快于营收；
- 存货增速是否明显快于营收；
- 合同负债/预收款是否稳定或增长；
- 应收和存货周转是否恶化；
- 若营收增长但合同负债下降、应收和存货上升，要重点警惕。

表格与图表要求：
- 4.6 表格优先合并，不要拆成“营运绝对值表 + 存货营收对比表”两张重复表；建议列：年份、营收、营收同比、应收账款、存货、存货同比、存货/营收、合同负债。
- 营运质量图要体现“存货增长与营收增长对比”：可用上半图显示应收/存货/合同负债绝对值，下半图显示营收同比、存货同比、存货/营收，避免正文写了对比但图上看不到。

这一项本质上是对利润质量、现金流质量和资产负债表的前瞻验证：很多问题会先出现在应收、存货和合同负债上，再传导到利润、现金流和资产质量。

**好公司·定量评分：/40**
- ROE质量与盈利模式：/9
- 利润增长来源与持续性：/7
- 产品结构与增长来源：/6
- 现金流质量：/7
- 资产负债分析与财务安全性：/6
- 营运质量与风险信号：应收/存货/合同负债：/5

## 五、好时机（20分）：现在买贵不贵？

一句话：好公司不等于好价格。好时机看的是当前价格是否已经透支未来增长，还是仍然留有安全边际。

优先级顺序：先看股价vs利润线和PE及PE百分位，再看保守档毛估估；PEG、股息率、市场信号与预期差都作辅助判断，不单独决定买卖结论。

### 5.1 股价vs利润线（5分）

核心问题：股价走势和利润走势是否匹配？市场是否已经明显提前透支了未来盈利？

重点看：
- 必须在本节正文嵌入股价 vs 扣非TTM双Y轴主图；如果报告在 `reports/` 下，图片路径用 `../charts/文件名.png`，写完必须脚本校验链接真实存在；
- 同时嵌入归一化辅助图和单季度扣非利润图：归一化图只看走势同步性，单季度图用于解释季节性和最新季度修复/恶化，二者不能替代TTM主图；
- 用双Y轴折线图对比股价与扣非TTM利润；
- 看趋势方向是否一致、增幅是否匹配，不是看绝对位置谁高谁低；
- 分阶段复盘股价与利润线（如泡沫扩张期、估值出清期、利润下修期、修复验证期），每个阶段都要同时写股价表现、利润表现和估值判断；默认先写 4-5 个阶段、每阶段 1 句话，除非用户明确要求展开，不要把阶段复盘写成过细长段；
- 若股价长期显著跑赢利润，要警惕PE扩张透支；
- 若利润持续增长而股价长期不涨，要判断是否存在预期差或市场担忧。

写作坑点：只在报告开头放图、或只写“股价跌了很多/PE不高”而没有在好时机章节展开图表复盘，会导致好时机分析不完整。

### 5.2 PE及PE百分位（5分）

核心问题：当前PE本身贵不贵？放在公司自己的历史区间里，又是便宜、合理，还是偏贵？

计算：
- 当前PE = 当前市值 / 扣非净利润TTM
- PE百分位 = 当前PE在近十年PE(TTM)历史分布中的位置
- 扣现金后市值 = 当前市值 - 现金头寸
- 扣现金后股价 = 扣现金后市值 / 总股本
- 扣现金后PE = 扣现金后市值 / 扣非净利润TTM

重点看：
- 当前PE（TTM）大致处于什么水平；
- 统一口径：近十年PE(TTM)历史分位；
- 若自算PE百分位与同花顺手工查询值有差异，报告优先统一到同花顺近十年口径，并简短说明差异常见来自起止日、异常值处理和最新收盘日口径；
- 扣现金后股价、扣现金后PE是否明显更便宜，更接近主业真实估值；
- 百分位 < 20% 通常属于低估区间，> 80% 通常属于高估区间；
- 表述要克制：若PE分位大致在10%-20%，默认写“偏低/合理偏低”，不要轻易写“明显偏低/极低估”；只有分位极低且利润线已企稳、市场悲观已较充分反映时，才适合用更强表述；
- 若上市未满十年，取可用最长区间；若历史区间包含亏损、极端泡沫或业务结构重大变化，要说明分位参考价值下降。

### 5.3 PEG（2分）

核心问题：当前PE和公司过去几年的真实增长相比，是便宜、合理，还是偏贵？

重点看：
- PEG = PE(TTM) / 3年CAGR；
- 不用券商盈利预测；
- PEG < 1 可能低估，> 2 往往偏贵；
- 增速>30%或低基数导致的PEG偏低，参考价值下降。

### 5.4 股息率（3分）

核心问题：当前价格下，分红回报是否足够有吸引力，且是否可持续？

重点看：
- 高股息+低估值通常是长期回报较好的组合；
- 股息率 > 3% 且 PE百分位 < 30% ，通常是较好的长期买入区间；
- 必须区分股息率口径：年度分配预案单次股息率、财年中期+年度预案合计股息率、自然年实际到账股息率，三者不能混写；
- 分红API字段或年报“每10股派息数”计算每股分红时必须除以10，再除以最新股价；
- 高股息不能脱离分红可持续性单独判断：对比 EPS、净利润、自由现金流覆盖率；若全年分红高于 EPS/FCF，股息率评分可上调但不能满分；
- 若利润下滑、现金流弱、靠举债或消耗历史现金垫分红，高股息要打折看。

### 5.5 市场信号与预期差（2分）

核心问题：市场信号是在增强信心，还是在释放风险？市场现在又可能低估了什么？

重点看：
- 机构持股、内部人交易、增持减持、公司回购；
- 市场是否把短期波动误当成长期恶化；
- 市场是否低估了结构升级、提份额、利润修复或现金价值。

### 5.6 毛估估（3分）

核心问题：按中性和保守假设推演，当前价格的上行空间和下行风险是否划算？

本框架默认不投强周期行业，因此毛估估只保留中性档和保守档，不做乐观档。

重点看：
- 中性档：按历史增长、行业空间、产品结构、自由现金流情况推演；
- 保守档：按偏低增速和偏低PE推演最坏情况；
- 两档都要给出利润、PE、市值和当前空间。

**好时机评分：/20**
- 股价vs利润线：/5
- PE及PE百分位：/5
- PEG：/2
- 股息率：/3
- 市场信号与预期差：/2
- 毛估估：/3

## 六、投资结论：值不值得下注，拿不拿得住？

一句话：这一节不再重复展开分析，而是把前面的行业、公司、价格判断收束成最终决策。重点回答四个问题：胜率高不高、赔率划不划算、能不能长期持有、当前应采取什么行动。

### 6.1 胜率

核心问题：公司长期变好的概率大不大？

重点看：
- 主要来源于行业、公司质量、管理层、现金流；
- 好行业提高下限，好公司提高上限；
- 管理层、现金流和护城河共同决定长期稳定性；
- 如果多个核心维度都存在疑点，胜率不能高估。

### 6.2 赔率

核心问题：当前价格下，上涨空间和下跌空间是否划算？

重点看：
- 主要来源于估值、PE百分位、股息率、保守档亏损空间；
- 好赔率不等于一定上涨，而是下行可控、上行值得等；
- 若价格已经过高，再好的公司赔率也会变差；
- 赔率最终要结合保守档毛估估判断，而不是看单一估值指标。

### 6.3 长期持有检查项

核心问题：这家公司未来5到10年还有没有理由继续拿着？

重点看：
- 长期需求是否仍然存在；
- 护城河会不会随着时间变强；
- 增长是否不需要持续烧钱，客户是否会持续回来；
- 公司是否具备长期定价权，管理层是否本分、专注主业、不乱扩张；
- 即使PE不扩张，靠利润增长和分红，长期回报是否仍然可接受。

如果长期持有检查项中出现多个否定答案，即使总分较高，也要降低评级或等待更好价格。

### 6.4 评级与行动

核心问题：胜率、赔率和长期持有综合后，当前应采取什么行动？

| 情形 | 结论 |
|------|------|
| 高胜率 + 高赔率 | 最值得关注，可进入重点研究/买入候选 |
| 高胜率 + 低赔率 | 好公司但价格一般，等待更好价格 |
| 低胜率 + 高赔率 | 只适合小仓位观察，不适合重仓 |
| 低胜率 + 低赔率 | 不碰 |

| 总分 | 评级 | 行动 |
|------|------|------|
| >80分 | 强烈关注 | 值得重点研究，可作为核心候选；符合验证条件后再加大仓位 |
| 70-80分 | 关注 | 纳入观察池，持续跟踪关键指标与估值 |
| 60-70分 | 一般 | 公司或价格仍有明显短板，等待更好时机 |
| <60分 | 不碰 | 暂时排除，不浪费精力 |

评级校正规则：
- 默认按总分直接映射评级：>80分=强烈关注，70-80分=关注，60-70分=一般，<60分=不碰；
- 分数是主规则，写报告和复核现成报告时，先看总分档位是否与评级一致；
- 只有当红线、证伪条件、长期持有检查项明显不通过时，才下调结论；
- 若最终评级不是总分档位的直译，必须在“评级与行动”或“汇总结论”里显式写出降档原因，避免出现口径漂移；
- 行业调整、利润下修、修复验证期本身不自动触发降档，除非已达到“红线/证伪/长期持有检查项明显不通过”的程度。

打分纪律：
- 报告标题和各级章节标题不标注分数/权重；评分只放在每个章节末尾的评分表和小计中。
- 每个模块写完分析后，紧跟一个列表统一打分；
- 打分汇总表子项得分之和必须等于小计；
- 四个小计之和必须等于总分；
- 复核现成报告分数是否合理时，先看两处：1) 有没有给太多满分项；2) “好时机”是否把低PE、低分位、现金头寸机械打成高分。通常最该先复核的是护城河满分、现金头寸满分、PE/PEG/预期差满分。
- 若公司处于行业调整期、利润下修期或“等待验证期”（如最新季度收入/扣非利润明显下滑，利润线尚未企稳），先如实体现在正文风险提示、证伪条件和行动建议中；只有当这些问题已构成红线、证伪条件或长期持有检查项明显不通过时，才下调评级。
- 如果红线、证伪条件、长期持有检查项明显不通过，即使分数较高，也要下调结论。

## 七、投资逻辑与证伪条件：为什么买，什么情况下不再买？

一句话：每篇报告都必须把“为什么值得买”和“什么情况下判断失效”写清楚。投资逻辑说的是未来为什么能赚钱，证伪条件说的是出现什么变化就要重新判断。

### 7.1 投资逻辑

核心问题：这家公司未来为什么能继续赚钱？市场现在可能低估了什么？

重点看：
- 投资故事：这家公司未来为什么能继续赚钱；
- 增长来源：增长来自销量、提价、产品结构、效率、市占率，还是一次性因素；
- 市场误判：市场现在可能低估了什么；
- 当前价格理由：为什么当前估值值得关注，安全边际在哪里。

### 7.2 证伪条件

核心问题：什么情况发生，说明这笔投资逻辑错了？

重点看：
- 核心产品增长停滞或份额持续下降；
- 毛利率/净利率持续恶化且无法解释；
- 自由现金流长期低于净利润；
- 资产负债表恶化：有息负债快速上升、短债压力变大、现金受限、商誉/存货/长期股权投资等资产质量明显恶化；
- 产品结构升级失败或第二曲线证伪；
- 管理层开始乱扩张、高价并购或大比例减持；
- 估值已经严重透支未来增长。

证伪条件要具体，避免写成空话。

## 输出格式

报告结构：

1. 先判断能不能研究：公司画像 + 能力圈 + 红线
2. 好行业（评分）
3. 好公司·定性（评分）
4. 好公司·定量（评分）
5. 好时机（评分，含股价vs利润图与毛估估）
6. 投资结论（胜率、赔率、长期持有检查项、评级与行动）
7. 投资逻辑与证伪条件
8. 维度打分汇总表（验算）
9. 总结
10. 数据校验结果

约束：
- 报告标题和各级章节标题不带打分/权重。
- 不引用券商盈利预测。
- 表格优先，关键数据标注来源。
- 报告图片必须用 Markdown 图片语法嵌入，不能只写代码路径；报告放在公司目录内 `reports/` 时图表路径写 `![说明](../charts/文件名.png)`，且必须引用真实存在的文件。
- 单家公司深度分析采用“公司研究包”作为主档案：`{code}_{公司名}/data/`、`{code}_{公司名}/年报/`、`{code}_{公司名}/charts/`、`{code}_{公司名}/reports/`。根目录外部 `reports/` 只做总览、索引、组合对比或最终导出版；外部 `charts/` 不作为主图表存放地，避免图表和数据源分离。
- 写报告前必须从巨潮资讯网下载近几年年报 PDF 到公司研究包 `年报/` 目录（至少近5年，能取到则含最新年度），并生成来源清单；不能只用东方财富 API 替代年报 PDF。
- 用户要求“报告名称加日期后缀”或“重新分析”时，新建 dated copy（如 `公司_投资分析报告_YYYY-MM-DD.md`），不要覆盖旧报告；写完后用脚本校验文件存在、图片链接存在、打分小计加总正确。
- 多家公司批量重写时，先统一最新交易日、行情口径、PE百分位口径，再逐家公司给结论；若行业不符合“非周期复利型”偏好（如汽车产业链），在行业维度降权并在行动建议中明确仓位管理。

## 数据源优先级

1. 年报PDF/半年报PDF：权威来源，现金头寸、产品结构、附注必须查这里。
2. 同花顺导出Excel：`main_year.xls` 用年度指标，`main_simple.xls` 用季度拆分与TTM校验；用 `python-calamine` 读取，不用 xlrd。
3. 东方财富API：利润表、资产负债表、现金流、估值历史、股东、产品结构。
4. yfinance：长期股价用 `.SZ` / `.SS`，长期对比用 Adj Close。

东方财富注意：
- 基础：`https://datacenter.eastmoney.com/securities/api/data/v1/get`
- 利润表：`RPT_DMSK_FN_INCOME`
- 资产负债摘要：`RPT_DMSK_FN_BALANCE`
- 现金流：`RPT_DMSK_FN_CASHFLOW`
- filter 日期必须用单引号：`filter=(SECUCODE="600809.SH")(REPORT_DATE='2025-12-31')`
- 公司基本信息接口：`RPT_F10_ORG_BASICINFO`，可取主营业务、实际控制人、董事长等；该表没有 `REPORT_DATE` 排序列，调用时不要默认带 `sortColumns=REPORT_DATE`，否则会返回“REPORT_DATE排序列不存在”。
- 当东方财富 push2 实时行情接口被断开或限流时，可用 yfinance `Ticker('{code}.SS|SZ').history(period='5d')` 取最新收盘价，并用总股本估算当前市值；报告中要标注行情来源为 yfinance。

## 报告校验流程（必做）

写完投资分析报告后，用财报PDF和原始数据逐项校验。若有同花顺Excel，必须使用三重数据源：年报PDF + main_year.xls + main_simple.xls。

必验数据项：
1. 营收/利润/扣非。
2. 增速和CAGR年数。
3. 毛利率/净利率。
4. 经营现金流。
5. 自由现金流和资本开支。
6. 资产负债率。
7. 现金头寸各科目。
8. ROE与杜邦三因子口径。
9. 分红、EPS、PE、PEG。
10. 季度拆分：各季度利润之和必须等于全年数。
11. 股价/市值/PE是否为最新交易日数据。
12. 打分汇总表是否加总正确。

校验输出按：正确 / 需修正 / 不可验证 三类列出。

## 关键踩坑规则（去重版）

### 数据口径

- 有同花顺Excel时，以同花顺主要指标和年报PDF交叉验证；没有Excel时以东方财富API为准。
- 东方财富利润表常返回累计数据，不是单季度。
- 同花顺 `.xls` 用 `python-calamine`，xlrd 会报 CompDocError。
- 扣非净利润跨数据源可能差异较大，差异>5亿需标注“口径待确认”。

### 现金头寸

- FINANCE_RECE = 应收款项融资 = 银行承兑汇票，不是现金，不计入现金头寸。
- 其他流动资产不等于定期存款，必须查年报附注。
- 短期借款不计入彼得林奇现金头寸。
- 现金头寸是存量，自由现金流是流量，不能混用。

### 财务计算

- 4.1 ROE质量不能只列ROE/毛利率/资产负债率，必须体现杜邦趋势表；有数据时至少列近5-6年“销售净利率、总资产周转率、权益乘数、ROE”，再判断ROE来自净利率、周转率还是杠杆。
- 杜邦三因子计算用小数，最后再转百分比，避免百分比值误算。
- ROE口径要统一注明：简单ROE还是加权平均ROE。
- 杜邦分析看趋势，不只看当前值；若ROE下降，要分别判断净利率、总资产周转率、权益乘数哪一项拖累。总资产周转率下降要结合真实动销、库存、现金/资产扩张解释，不能机械扣分。
- 4.3 现金流质量评分不能只看最新一年；至少列近5-6年“经营现金流、资本开支、自由现金流、经营现金流/净利润、自由现金流/净利润”，再判断趋势、波动和分红覆盖。
- 当现金流质量给高分但非满分（如6/7）时，正文必须简短说明扣分原因，例如现金流覆盖率阶段性下降、资本开支抬升、自由现金流/净利润走弱或分红覆盖压力。
- CAGR年数最容易错，写完必须反算。
- Q1报出后PE TTM会变，不能混用全年PE和TTM PE。
- 分红API字段 `PRETAX_BONUS_RMB` 是每10股分红，计算股息率要除以10。
- 年报分红要先判定口径：年度分配预案（期末单次）、中期+年度预案（财年完整分红）、自然年实际到账分红不是同一概念。报告写“股息率”时必须标注口径；好时机评分也要跟随口径修正。若完整财年股息率高但分红高于 EPS/自由现金流，只能小幅加分，不能因为高股息给满分。
- A股公司若年内有中期分红，不能只用年报“每10股派息数”计算股息率。必须查分红实施明细（东方财富 `RPT_SHAREBONUS_DET` 或公告）：同一财年可能有“中期分红 + 年度期末分红”，且期末分红实施数可能因回购/股本口径从预案值微调。报告中至少列三种口径：中期、年度期末、完整财年合计；完整财年股息率 =（中期每股分红 + 期末每股分红）/ 最新股价。东阿阿胶2025案例：中期10派12.700919元 + 期末10派14.354904元，完整财年每股2.7056元，按49.08元股价股息率约5.51%，不是只看期末单次约2.92%。

### 估值与图表

- PE百分位统一用近十年；上市不足十年取可用最长区间；不再默认5年。
- PEG用3年CAGR，不用单年，不用券商预测。
- 好时机主图用双Y轴双折线，不用柱状图替代TTM。
- 好时机章节必须显式嵌入并解读三张图：TTM双Y轴主图、归一化辅助图、单季度扣非利润图；图表若只放在报告开头或目录中但未进入好时机正文，视为未完成。
- 当用户要求把第四章或类似基本面章节“图表化”时，默认结构是“图 + 表 + 简洁结论”，不是只留图和结论。图用于快速判断，表用于核对原始数字与后续复核；除非用户明确说删表，否则不要把原有数据表直接替换掉。
- 双Y轴图的阶段复盘优先用无序列表，不要默认做大表格；每个阶段直接合并“股价表现 + 利润表现 + 关键判断”，把关键点嵌入阶段描述，避免表格后再重复列“关键点”。
- 归一化图只作辅助，不能凭上下位置判断估值。
- 收益分解：股价涨幅 = 利润增长 × PE变化，用对数归因。
- 白酒季度规律写法要简化并体现消费节奏：Q1春节脉冲通常是全年利润高点；春节后Q2自然回落；中秋/国庆旺季或备货节奏带来Q3/Q4阶段性变化；若Q4利润偏弱，要解释可能来自费用投放、渠道节奏、库存消化或年底结算压力。估值判断仍以扣非TTM为主，不能用单季直接年化。

### 写作与判断

- 行业增速/公司增速必须用实际数据验证，不能凭印象写。
- 产品结构分析必填，不能省略。
- 港股/多业务公司若本次只从摘要接口拿到年度财务而未能逐项校验年报PDF分部附注，报告中必须把产品结构标注为“需复核/待补充”，不要把上一年分部口径硬写成最新年度确定值；可以先用“业务角色 + 质量判断”表承接结论。
- 竞争格局必须查同行最新市值/PE。
- 管理层必须区分实际控制人和经营管理层。
- 产品售价必须验证；无法确认时标注“待验证”。
- 白酒行业特殊性：经营现金流低于净利润可能与经销商打款节奏有关；经营现金流高于净利润也不能替代动销/库存/批价验证。存货增加不一定是坏事，但核心高端产品销量大跌且库存大增是重大风险信号。
- 白酒龙头深度调整期（五粮液2025案例）：若扣非利润断崖、3年TTM CAGR转负，PEG失效；改用“修复后合理利润 × 合理PE”和“当前市值反推隐含利润”判断赔率。季度口径要特别核对报告年份：44.17亿/-68.53%是2025Q1，不是2026Q1；2026Q1应以最新季度CSV/API/simple表校验。五粮液2025还必须先区分经营压力和收入确认口径重述：公司2026-04-30《前期会计差错更正公告》称，因对2025年业务模式进行梳理、基于谨慎性原则调整部分业务收入确认相关核算，对2025Q1/半年报/三季报重述，且不影响现金流量表。2025Q1-Q3累计营收从609.45亿调至306.38亿，调减303.08亿；归母净利润从215.11亿调至64.75亿，调减150.37亿。2026Q1高增长是在重述后低基数上形成，不能简单视为全面修复；但核心产品销量-53%、库存+306.9%仍说明渠道/动销压力真实存在。详见 `references/wuliangye-2025-case.md`。
- 白酒低PE+高现金头寸但利润线开始下行（汾酒2026案例）：若当前PE处于极低分位、扣现金后PE很低，但最新季度收入/扣非利润已双位数下滑，不能只写“股价低于利润线=买点”。必须同时判断扣非TTM是否从高点回落、利润是否继续下修、合同负债/批价/动销是否企稳、自由现金流是否覆盖分红。详见 `references/fenjiu-2026-case.md`。
- 出口制造/汽车零部件公司（福耀2026案例）：最新季度利润下滑时，先拆“经营承压”与“汇兑扰动”。若季报或年报明确披露“剔除汇兑后利润仍增长/降幅收窄”，正文必须同时给出报表口径与剔除汇兑后的经营判断，不能把汇率波动直接写成主业恶化。若经营现金流大降，不能只看净额；必须同时核对应收账款、应收款项融资（票据）、合同负债、存货。若应收账款下降而应收款项融资明显上升，通常更接近“回款票据化/结算结构变化”，不等于坏账或压货恶化；但若票据化持续多个季度，也要下调现金流质量评分或写明观察点。详见 `references/fuyao-2026-case.md`。
- 品牌中药/滋补消费品修复期（东阿阿胶2026案例）：经历渠道库存出清后，要把“品牌护城河仍在”和“经营曾失误”同时写清楚。现金头寸厚、扣现金后PE低可提高安全边际，但不能替代主业增长；若PE分位约20%-30%，措辞优先为“合理偏低/有吸引力但非极端低估”。合同负债下降、经营现金流单季偏低时，不要直接年化或定性为恶化，先作为需半年报验证的渠道/季节性信号。评分要克制：内部决策口径下东阿阿胶更接近 74.5/100“关注”，不要因现金头寸和扣现金后PE低而接近 80 分；产品结构图优先拆成“主图看占比 + 小图看增速”，营运质量图优先用 2020-2025 年度主图并把 2026Q1 作为补充观察。详见 `references/dongeejiao-2026-case.md`。
- 眼科处方药/近视防控公司（兴齐眼药2026案例）：不要简单按消费品或医疗服务估值。先拆“获批进度/临床证据/处方渠道/医保控费/竞品管线/单品集中度”。年报产品结构可能只按剂型披露（如滴眼剂、凝胶剂），不能把剂型收入直接等同于阿托品或环孢素单品收入；具体产品收入无法确认时标注“年报未拆分，待验证”。若出现 PE 历史分位极低、扣非TTM仍上行、股价从高位回落，可判断为“预期差阶段”，但必须用未来几个季度验证新品放量和利润线是否持续。详见 `references/xingqi-ophthalmology-2026-case.md`。
