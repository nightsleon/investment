# 腾讯控股官方连续财报研究案例（2020—2026Q1）

用途：作为大型港股互联网公司“官网/HKEX官方文件、连续年度、季度自由现金流、投资组合与回购”研究的提取范例。此文件记录抓取路径和口径，不替代每次任务的实时核验。

## 官方入口与发现路径

- 旧版完整业绩发布页：`https://www.tencent.com/en-us/investors/financial-news.html`
  - 页面服务器端 HTML 包含多年季度/年度业绩公告 PDF；即使可视界面只展开最近年份，也应解析全部 `<a href="...pdf">`。
  - 历史标题在 2020—2023 年常写作 `Fourth Quarter and Annual Results`，较新年份可能写作 `Annual and Fourth Quarter Results`；筛选时不要只匹配一种词序。
- 新版财务报告页：`https://www.tencent.com/zh-cn/investors/financial-reports/`
  - 年报/中报按 WordPress 风格分页；历史页可尝试 `/page/2/` 等。
  - 业绩公告和正式年报披露日不同，来源台账须分别记录。

## 高效覆盖六年

- 损益表、财务状况表及主要分部收入：优先取三组带比较数的官方文件，如 2025/2024、2023/2022、2021/2020。
- 分部盈利：腾讯年报通常给分部收入、分部收入成本或分部毛利/毛利率，但不披露分部经营利润。交付应写“分部经营利润未披露”，可列分部毛利；早期年度若只有收入与成本，毛利可据同一官方表相减并核对集团毛利。
- 年报用于附注、股息和回购核验；年度业绩公告用于统一口径的损益、资本开支、净现金、上市/非上市投资组合价值。

## 腾讯自由现金流口径

腾讯自 2020 年起披露的自由现金流通常为：

`经营活动现金流净额－资本开支付款－媒体内容付款－租赁负债付款`

注意：
- 业绩公告中的 `Capital expenditures` 可能是资产增加额口径，不等于自由现金流公式中的资本开支付款。
- 早期年份若只披露季度自由现金流，可把 Q1、Q2、Q3、Q4 四个官方公告值加总为年度计算值；必须标注“官方季度数据加总”，并列出四份公告。
- 经营现金流采用审计现金流量表的 `net cash flows generated from operating activities`。

## 现金与投资组合

建议拆列：
1. 现金及现金等价物；
2. 流动定期存款；
3. 非流动定期存款；
4. 公司口径 `Total cash`（如公告直接披露，可能还含库存管理用途的高流动性投资产品）；
5. 上市投资：公告披露的被投上市公司持股公允价值（排除附属公司，可能含通过SPV按应占基础持有）；
6. 非上市投资：公告披露的账面价值；早期未披露时写“未披露”，不要用财务资产科目粗暴替代；
7. 借款与票据分别列流动/非流动，净现金沿用公司定义。

## 股东回报

- 末期股息：按对应财年列示建议每股港元金额，同时记录次年股东大会批准/派付时间。
- 实物分派（如京东、美团股份）与现金股息分开。
- 回购同时记录股份数、总代价、币种；公告有时以人民币描述季度回购、以港元描述全年回购，不能直接混加。

## 交付防失误

- 首轮发现后马上建立来源台账和数据表，边提取边落盘；不要等所有 PDF 搜索完才开始写交付。
- 表头必须写人民币百万元/十亿元、港元每股等单位。
- 最新年度和最新季度分开：季度资产负债表是期末存量，季度损益/现金流是期间流量。
