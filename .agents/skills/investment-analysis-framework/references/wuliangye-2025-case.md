# 五粮液(000858) 2025案例：白酒龙头从复利到修复的判断要点

用于未来分析白酒/高端消费龙头时复用，避免只看品牌和低估值而忽略利润中枢变化。

## 关键事实

- 2025年五粮液营收405.29亿元，同比-54.55%；扣非净利润88.16亿元，同比-72.23%。这是更正后的官方口径，不应直接和前期未更正季度数据混用。
- 公司2026-04-30披露《前期会计差错更正公告》：因“对2025年业务模式进行梳理，基于谨慎性原则，调整2025年部分业务收入确认相关核算”，对2025年一季报、半年报、三季报合并资产负债表与合并利润表部分项目进行重述，且“不影响现金流量表列示”。
- 重述影响极大：2025Q1营收从369.40亿调至170.86亿，归母净利润从148.60亿调至44.16亿；2025Q1-Q3累计营收从609.45亿调至306.38亿，调减303.08亿，归母净利润从215.11亿调至64.75亿，调减150.37亿。
- 注意季度口径：44.17亿元、同比-68.53%是2025Q1扣非净利润，不是2026Q1；如果附件中只有“2025年第一季度报告”，不要误写成2026Q1。2026Q1应以最新季度CSV/东方财富API/同花顺simple表校验；本案例会话中，2026Q1扣非净利润约80.36亿元，同比+81.92%，最新扣非TTM（2025Q2-Q4 + 2026Q1）约124.34亿元。2026Q1高增长是在2025Q1重述后低基数上的增长，不能简单视为经营全面恢复。
- 2025年五粮液产品收入279.36亿元，毛利率89.55%，但收入同比-58.84%。
- 2025年五粮液产品销量-53.00%，期末库存+306.90%。这是比利润下滑更关键的经营风险信号。
- 2025年经营现金流297.06亿元，自由现金流约277.39亿元；现金流仍强，但不能抵消利润中枢下移风险。
- 2025现金头寸校验：现金及现金等价物约1241.15亿元；其他流动资产不是定期存款，附注显示主要为预缴税费29.26亿元、监管商品49.07亿元，不计入彼得林奇现金头寸；扣一年内到期非流动负债3.64亿元、租赁负债0.44亿元后，现金头寸约1237.06亿元，每股净现金约31.87元。
- 五粮液分红必须区分口径：2025年度分配预案每10股派25.78元（每股2.578元），按81.10元股价的单次股息率约3.18%；2025年中期分红也为每10股25.78元，若按2025财年“中期+年度预案”合计为每10股51.56元（每股5.156元），股息率约6.36%；2025自然年实际到账则包括2024年度分红31.69元/10股+2025中期分红25.78元/10股，约7.09%，但这不是2025财年利润分配口径。

## 分析要点

1. 白酒属于“弱周期消费”，不是强周期，但高端白酒受商务宴请、礼赠、居民收入预期和渠道库存周期影响；在深度调整期不能简单按非周期复利外推。
2. 对白酒龙头要区分：
   - 好公司：品牌、毛利率、现金流、净现金仍强。
   - 好价格：必须看利润中枢能否修复，不能只看股价跌幅或历史PE分位。
3. 如果最新3年扣非TTM CAGR为负，PEG失效；改用“修复后合理利润 × 合理PE”的毛估估。
4. 估值反推很重要：当前市值 / 合理PE = 隐含利润。用来判断市场已经假设利润修复到什么程度。
5. 经营现金流高于净利润在白酒中常见，可能来自先款后货、合同负债和经销商打款节奏；这是优点，但不能替代动销、库存、批价验证。
6. 库存要看产品结构：核心高端产品销量大跌且库存大增，比普通基酒/半成品酒库存增加更危险。

## 写作结论模板

“五粮液仍是好公司，但当前更像困境修复型消费龙头，不宜按过去白酒黄金时代线性外推。关键不是问公司好不好，而是问当前价格是否已经补偿利润中枢下移风险。若利润修复到180-200亿元，当前价格可以接受；若长期停在130亿元附近，当前估值仍可能偏贵。”

## 证伪条件模板

- 核心产品销量继续下降，库存继续高企，批价无法稳定。
- 扣非TTM利润连续4个季度低于130亿元且无修复趋势。
- 净利率长期无法恢复到30%以上。
- 经营现金流开始持续低于净利润，说明先款后货和渠道打款能力弱化。
- 管理层为保收入大幅压货、牺牲渠道利润或跨界扩张。
