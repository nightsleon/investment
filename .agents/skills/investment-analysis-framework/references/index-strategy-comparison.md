# 指数策略横向比较与发布稿压缩

适用于红利、低波、质量、价值等策略指数的横向研究，不限具体指数公司。

## 1. 先统一收益口径

比较收益前逐项确认：

| 项目 | 必查内容 |
|---|---|
| 计价币种 | CNY、HKD、USD；指数名称中的市场币种不等于当前所选收益序列币种 |
| 收益类型 | 价格指数（PR）、税前全收益/总收益（TR）、税后净收益（NTR） |
| 截止日 | 尽量同日；不同日必须标注，短期收益不做精确比较 |
| 分红处理 | 中证“（全）”通常对应税前全收益；“（净）”对应税后净收益。标普 TR 对应税前，NTR 对应税后 |
| 波动率频率 | 日度或月度、年化方式是否一致 |
| 实盘与回测 | 发布日前历史是回溯试算，不等于实盘记录 |

公平比较优先级：同币种 + 同截止日 + 同收益类型。中证全收益应优先对比标普同币种 TR，而不是 NTR。若只能取得不同截止日数据，明确差几天及其对近1年数据的影响。

## 2. 核心分析维度

建议100分制：

| 维度 | 常用权重 | 关注点 |
|---|---:|---|
| 策略与分红/因子可持续性 | 25 | 连续分红、支付率、盈利/ROE增长、价值陷阱过滤 |
| 中长期总收益 | 20 | 优先3年、5年年化全收益，不用价格指数替代 |
| 风险与风险收益比 | 20 | 波动率、最大回撤、收益/波动、夏普；“收益/波动”不能冒充严格夏普 |
| 分散度与集中风险 | 15 | 样本数、单股上限、行业/市场权重；持股多不等于行业分散 |
| 估值与股息率 | 10 | PE、PB、股息率及其可持续性 |
| 可投资性与实盘检验 | 10 | 发布年限、境内产品、费率、规模、流动性、跟踪误差、税务与汇率 |

评分不是固定真理。若用户更重视当期现金回报，可提高估值与股息率权重；若只允许单一市场，重新评估跨市场指数的适配度。

## 3. 方法论核查

必须读官方编制方案，不仅看指数简介。逐项核对：样本空间、连续分红年限、支付率/盈利质量条件、股息率定义、波动率窗口、最终样本数、加权方式、单股/行业/市场上限、调样频率、A/H重复处理、缓冲规则。

特别注意：

- “预期股息率”可能是规则公式，不一定是分析师一致预期。
- 高股息可能来自股价下跌、周期高点或不可持续分红。
- 单股权重低不代表分散；银行等同一行业成分高度相关。
- 官方指数单张的PDF文本提取顺序可能错乱，重要表格应渲染页面后视觉复核。

## 4. 评分与结论校验

1. 每个指数分项得分之和必须等于总分。
2. 各维度排序必须与分项得分一致。
3. 总排名变化后，同步修改摘要、结论、适用场景和数据校验表。
4. 不把不到1个百分点的差异写成“明显领先”，尤其当截止日不同。
5. 近3年与近5年可能各有赢家，应分别陈述，不强行制造单一赢家。

## 5. 从长报告压缩为发布稿

雪球等平台文章建议保留：

1. 有观点的标题与一句结论。
2. 三个策略的本质差异，用通俗语言，不展开全部公式。
3. 一张核心收益/波动表。
4. 一个最容易忽视的风险，例如行业集中。
5. 一张估值/股息率表（数据可得时）。
6. 一张紧凑评分表。
7. 按需求给出选择建议及投资限制。

硬规则：只要文章正文引用总分或排名，就必须同时给出评分维度、权重和分项得分表。独立文章不能要求读者回到原报告才能理解84分从哪里来。

删除：完整编制公式、逐条校验日志、冗长来源清单、重复结论。保留2-3个官方来源和“不构成投资建议”。

## 6. 最终核验

- [ ] PR/TR/NTR及币种已统一或明确披露差异
- [ ] 收益和波动率数字来自对应序列
- [ ] 截止日已标注
- [ ] 行业权重、单股上限来自官方资料
- [ ] 分项加总与排名正确
- [ ] 发布稿提到总分时包含紧凑评分表
- [ ] 指数表现与基金实际收益已区分
