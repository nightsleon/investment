# 山西汾酒2026案例：低PE + 高现金头寸，但利润线开始下行

适用场景：分析白酒龙头/次高端白酒在行业深度调整期的低估值机会，尤其是“PE极低、股息高、现金多，但最新季度收入和利润下滑”的情况。

## 关键数据口径（本案例）

- 2025年营收：387.18亿元，同比+7.52%。
- 2025年扣非净利润：122.53亿元，同比+0.06%，基本停滞。
- 2026Q1营收：149.23亿元，同比-9.68%。
- 2026Q1扣非净利润：53.79亿元，同比-19.18%。
- 2026Q1扣非TTM：约109.76亿元，较2025Q1后的126.41亿元明显回落。
- 2025年经营现金流：90.14亿元；资本开支：11.94亿元；自由现金流：78.19亿元。
- 2025年拟分红：每10股65.60元，合计约80.03亿元，基本由自由现金流覆盖。

## 现金头寸校验

汾酒2025年报附注确认：

- 其他流动资产中“短期定期存款及利息”为194.00亿元；
- 其中37.30亿元用于应付票据开票质押；
- 该科目可计入彼得林奇现金头寸，但需标注受限金额；
- 应收款项融资是银行承兑汇票，不计入现金头寸。

现金头寸口径：货币资金 + 短期定期存款及利息 + 有价证券 - 一年内到期非流动负债 - 租赁负债等长期负债口径。

本案例：

- 2025年末确认现金头寸约289.70亿元；
- 2026Q1货币资金125.14亿元、其他流动资产246.46亿元，但Q1未披露其他流动资产明细，只能估算现金头寸约371.36亿元，必须标注“估算”。

## 分析重点

低PE不是充分条件。白酒调整期需要同时回答：

1. 利润线是否还在上行：如果扣非TTM已经从高点回落，不能只说“股价低于利润线”。
2. 低PE是否来自利润下修前夜：当前PE低，但若利润继续从110亿元下滑到90-100亿元，估值安全边际会变薄。
3. 分红是否由自由现金流覆盖：高股息要看FCF覆盖，不只看账上现金。
4. 合同负债是否稳定：2025年末合同负债下降，2026Q1回升，只能算修复信号，需继续跟踪。
5. 销量与收入是否背离：若销量增速明显高于收入增速，可能意味着价格带/产品结构承压。

## 写作模板判断句

- “问题不在贵不贵，而在利润是否会继续下修。”
- “现金头寸和股息提供安全垫，但不能替代动销、批价和利润企稳。”
- “若利润线开始下行，股价vs利润线只能说明估值压缩充分，不能单独证明买点。”
- “白酒低估值分析要从‘好公司便宜’切换为‘好公司是否正在被证伪’。”

## 跟踪清单

- 下一期收入和扣非利润是否继续双位数下滑；
- 合同负债是否维持或回升；
- 毛利率是否继续下降；
- 核心产品批价、渠道库存、渠道利润；
- 自由现金流是否继续覆盖分红；
- 扩产项目投产后是否能被真实需求消化。
