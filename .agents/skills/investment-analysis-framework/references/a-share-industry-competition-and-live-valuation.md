# A股行业竞争格局与实时估值快研

用于“研究行业竞争格局、可比公司，并给出最新市值/PE”的短报告。目标是把官方披露中的事实、分析推断和不可验证项严格分开。

## 1. 来源与执行顺序

1. **公司与同业最新年报**：优先巨潮资讯/交易所PDF，提取行业现状、竞争格局、产能、销量、产品收入/毛利率、客户与供应商集中度。
2. **全球非上市龙头**：优先其官网综合报告/可持续发展报告，核验业务规模、覆盖区域、销量、设备与供应链布局；非上市公司明确写“无公开市场市值和PE”。
3. **行情**：优先交易所或官方行情；受限时，可用腾讯行情作为东财/yfinance之外的可靠备选，并用年报利润、股本复算静态PE。
4. **第三方行业份额**：只有在能核验统计口径、年份、分母和原始发布方时才引用。公司自称“龙头/领军”不等于可计算市场份额。

## 2. 巨潮资讯快速取年报

公司代码与 `orgId` 可从以下静态列表查询：

```text
https://www.cninfo.com.cn/new/data/szse_stock.json
```

公告查询：

```bash
curl -L -A 'Mozilla/5.0' \
  -H 'Referer: https://www.cninfo.com.cn/' \
  -H 'X-Requested-With: XMLHttpRequest' \
  -d 'pageNum=1&pageSize=30&column=szse&tabName=fulltext&plate=sz&stock=<代码>%2C<orgId>&searchkey=&secid=&category=category_ndbg_szsh&trade=&seDate=<起日>~<止日>&sortName=&sortType=&isHLtitle=true' \
  'https://www.cninfo.com.cn/new/hisAnnouncement/query'
```

若代码+orgId未返回结果，可暂时用 `searchkey=公司简称` 检索，再从返回JSON确认正确 `orgId`。PDF地址为：

```text
https://static.cninfo.com.cn/<adjunctUrl>
```

## 3. 腾讯行情备选与字段核验

实时行情：

```text
https://qt.gtimg.cn/q=sz002003,sz002098
```

近期日线：

```text
https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sz002003,day,,,5,qfq
```

常用实时字段位置（以 `~` 分隔，实际使用前仍应复核）：

- 当前价；行情时间戳；涨跌幅；
- PE-TTM；流通市值；总市值；PB；
- 动态PE、静态PE；
- 流通股本、总股本。

**禁止只凭字段序号盲报。必须做交叉验证：**

```text
总市值 ≈ 当前价 × 总股本
静态PE ≈ 总市值 ÷ 最近完整年度归母净利润
PE-TTM隐含利润 ≈ 总市值 ÷ PE-TTM
```

若复算偏差明显，先排查单位（元/亿元）、A/H多类别股本、送转除权、亏损或PE字段含义。

## 4. 盘中与完整交易日口径

- 行情时间若处于交易中或午间休市，必须写“盘中快照，并非当日收盘”。
- 用户要求“截至某日或最新交易日”时，可同时给：
  1. 最新盘中直接字段；
  2. 上一完整交易日收盘价及按股本计算的市值。
- 上一交易日PE若只是按价格比例从当前PE换算，必须标“估算”，不得冒充行情接口直接字段。

## 5. 行业竞争格局的证据框架

### 需求周期性

区分：

- 长期终端需求是否稳定；
- 品牌库存、季节/时尚、出口、关税和产地迁移带来的短周期；
- 龙头能否用份额、产品升级和海外布局对冲，而非简单写“消费品=无周期”。

### 份额与壁垒

- 公司产能/销量不是市场份额；没有行业总量分母就不能反推份额。
- 不同计量单位（米、条、码、粒、套）不可直接比较。
- 高端与低端必须分层：低端可能进入门槛低、价格竞争激烈；高端壁垒通常来自客户认证、质量一致性、非标研发、模具设备、快速打样、全球属地交付、环保认证和一站式服务。

### 下游议价权

同时检查：

- 品牌客户全球比价和降本压力；
- 前五大客户占比、最大客户占比；
- 辅料占成品成本低但失效成本高；
- 客户认证与换供应商成本；
- 高端定制品和低端标准品的定价权差异。

### 上游与替代风险

- 用原材料成本占比、前五大供应商占比判断是大宗价格风险还是单一供应商风险。
- 替代风险分三层：产品功能替代、材料内部替代、环保/可拆解规格升级。
- “替代会改变产品结构”与“替代会消灭总需求”必须分开。

## 6. 可比公司与估值限制

- 优先直接业务可比；多元化公司必须披露非核心业务占比和利润影响。
- 非上市全球龙头可用于竞争强度和壁垒研究，但没有公开市值/PE。
- 跨币种、跨会计准则、业务组合差异较大时，不强行排列PE高低。
- 输出表中把数据标成：**直接字段 / 复算核验 / 估算 / 不可验证**。

## 7. 推荐输出结构

1. 结论摘要；
2. 需求周期性；
3. 全球与国内竞争者；
4. 份额及壁垒；
5. 上下游议价权；
6. 替代风险；
7. 最新市值与PE；
8. 来源URL；
9. 估算与不可验证项。
