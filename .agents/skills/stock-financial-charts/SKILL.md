# 个股 3R 好生意·定量图表标准（6 张标准图）

## Overview

本 Skill 是 3R 投资分析报告中**「好生意（Right Business）」定量部分（3.3 资本回报/自由现金流、3.4 盈利成长、3.5 增长空间）的标准图表套件与唯一事实源**。
统一图表风格、指标量纲与脚本逻辑，杜绝不同公司、不同时期生成的图表风格各异或尺度失真。

### 核心设计原则
1. **图表服务决策，不搞花架子**：每张图只支撑一个核心商业常识判断。
2. **白底、清新、标注克制**：白底（`dpi=180`），主图饱满，浅灰 Y 轴网格，避免密集标签打架。
3. **固定 6 张主图**：编号 4.1 到 4.6 保持严格对应，不随意增删序列；4.2 在有营收/毛利率/净利率数据时，额外输出一张利润率变体（不计入 6 张主图）。
4. **排版铁律：图 $\to$ 表 $\to$ 简洁结论**：
   - **图看趋势和异常**：让读者一目了然看清 5~6 年斜率；
   - **表核对精确数字**：正文必须保留原始财务数据底表，方便复核，绝不只放图不放表；
   - **结论直白中性**：图标题使用中性陈述，结论放在正文“一句话判断”与 2~3 条要点中。

## 适用范围与边界

### 适用场景
- 撰写 3R 投资分析报告的定量章节与 3R 简报；
- 生成 ROE/杜邦、利润增长、产品结构、现金流、现金头寸、营运质量 6 张标准图；
- 统一个股研报的视觉规范与低基数/极端值处理逻辑。

### 不适用场景
- **股价 vs 利润趋势线（彼得·林奇收益线）**：使用 `stock-earnings-line`。
- **单期财报速评**：使用 `stock-financial-speedread`。
- **指数估值看板**：使用 `index-valuation-dashboard`。

## 4.1 ~ 4.6 默认画法与精细规则（吸收实战经验）

### 4.1 ROE 与杜邦三因子
- **图型**：ROE 用柱状图；净利率、总资产周转率、权益乘数按**首年 = 100 归一化**折线展示。
- **ROE 口径**：柱状图固定取年报披露的**加权平均 ROE**（输入列名 `加权ROE`），与报告正文表格一致；不使用年末简单 ROE。`简单ROE` 列仅作为数据留底，不参与画图。
- **看点**：只看三条折线的变动斜率，净利率抬升驱动为最高质量；若 ROE 抬升主要由杠杆（权益乘数）驱动，属于风险信号。

### 4.2 利润增长来源与持续性（多情景画法与低基数处理）
- **口径**：优先**年度口径**（配合 2020~2025 年报表），最后一根柱可补充最新单季 TTM（不同颜色标注）。港股用“股东应占溢利/经调整利润”。
- **三种重点取向**：
  1. **看增速放缓/周期变化**：`扣非净利润柱状 + 扣非同比折线`。
  2. **看增长来源拆解**：`营收、扣非双柱一组 + 毛利率、净利率双折线`（回答收入是否扩张、利润率是否持续改善）。
  3. **兼顾拆解与同比**：双柱+双折线基础上用第 3 右轴承载同比，但画面必须做减法，缩短说明文字。
- **强制变体**：当年报数据同时含营收、毛利率、净利率时，除主图外必须输出 `{code}_4.2_利润与利润率趋势图.png`：营收与扣非双柱一组，毛利率与净利率双折线，右轴从 0 起。它回答“利润被谁拿走了”，供报告 3.2 或文章第三问（定价权）直接引用；主图编号不变。
- **低基数/负基数处理铁律**：
  - 若上年利润为负或接近 0 导致同比极端异常（如 -900%、+1200%），**禁止让该异常点拉扁整个折线轴**；
  - 处理优先级：`隐藏该同比点或不标数值` > `保留折线但加注“低基数参考意义有限”`；
  - 务必让读者看到修复后正常的斜率演进（如 +98% $\to$ +54% $\to$ +33% $\to$ +13%）。

### 4.3 产品结构与增长来源
- **结构拆解**：必须采用**主图看占比（横条图） + 小图看增量贡献（点线/横向棒棒糖图）**。
- **主品占比高时的处理**：若主品占比 >90%，严禁用绝对值主图硬压小类，否则小类贴轴无法阅读；应在小图高亮第二曲线的增速与增量。
- **残差核对**：年报只披露部分品类时，核实各项总和是否等于营业总收入。不相等时补“其他产品及业务”残差，严禁直接归一化到 100% 从而夸大主品占比。
- **负增量标签**：只有柱体足够宽时才使用白色内嵌字；中小负柱标签统一放在零轴左侧、深红色、右对齐。

### 4.4 净利润、经营现金流与自由现金流
- **定义**：自由现金流（FCF）= 经营活动现金流量净额 - 购建固定资产/无形资产等资本开支。
- **覆盖率截断**：现金流/净利润覆盖率出现极端值（如基数极小导致 800%）时，进行截断并显著标注「极值已截断」。

### 4.5 现金头寸与资产负债安全垫
- **彼得·林奇现金头寸**：现金及现金等价物 + 核实定期存款/大额存单 + 交易性金融资产 - 长期有息负债。
- **资产负债率双轴控制**：严禁右轴自动缩放将小幅波动（如 48%~52%）放大为剧烈断崖；右轴必须固定固定范围（如 `0%~60%` 或 `0%~100%`）。
- **保留两位小数**：现金头寸标签保留两位小数（避免 `-0.26 亿` 被显示为 `-0 亿` 掩盖恶化），保留清晰的 0 轴基线。

### 4.6 营运质量（应收 / 存货 / 合同负债）
- **主图 + 最新季度补充**：主图呈现 2020~2025 年末应收、存货、合同负债柱状；若有最新一期（如 2026Q1），在图右上方小卡片补充观察值，**不混入主年度序列破坏年度节奏**。
- **量级真实**：合同负债较小时真实保留量级，严禁为“看得到柱子”强行篡改坐标轴或并表。
- **正文叙述联动**：正文明确区分“长期去化趋势”与“最新单季抬头观察信号”，不因单季波动轻率定性全年趋势。

## 数据文件与脚本调用

### 数据文件约定
在股票研究包 `stocks/{code}_{公司名}/data/` 下组织：
```text
stocks/{code}_{公司名}/
  data/
    annual_core.csv                # 核心年度财务表（必需）
    product_structure.csv          # 最新年度产品结构（4.3用，可选）
  charts/                          # 生成的 6 张图存放目录
  scripts/                         # 存放执行脚本
```

### 推荐执行方式
```bash
# 复制标准脚本至目标公司目录
cp .agents/skills/stock-financial-charts/scripts/generate_fundamental_quant_charts.py \
  stocks/{code}_{公司名}/scripts/generate_fundamental_quant_charts.py

# 运行生成全套 6 张图表
python3 stocks/{code}_{公司名}/scripts/generate_fundamental_quant_charts.py \
  --base stocks/{code}_{公司名} \
  --code {code} \
  --company {公司名} \
  --annual data/annual_core.csv \
  --product data/product_structure.csv \
  --recent-years 6
```

## 验收检查清单（Checklist）

- [ ] **编号与路径**：4.1~4.6 编号一致，全部输出至 `stocks/{code}_{公司名}/charts/`；
- [ ] **中性标题**：图表标题保持中性，副标题标明财务口径与单位，结论留给正文；
- [ ] **杜邦首年基准**：4.1 杜邦三因子折线首年均为 100 基准点；
- [ ] **低基数过滤**：4.2 负利润或低基数极端同比已截断/特殊标注，未拉扁正常年份；
- [ ] **4.2 利润率变体**：有营收/毛利率/净利率数据时，已输出 `4.2_利润与利润率趋势图.png`，毛利率/净利率轴从 0 起；
- [ ] **残差平衡**：4.3 产品结构各项收入之和严格勾稽年度营收；
- [ ] **现金头寸校验**：4.5 净现金逐项从年报附注核验，无 NaN 缺柱，保留两位小数；
- [ ] **负债率轴保护**：4.5 资产负债率右轴不随意自动缩放，基线自 0 开始；
- [ ] **图表正文闭环**：正文严格遵守“图 $\to$ 表 $\to$ 结论”排版，原始财务底表未被删减。
