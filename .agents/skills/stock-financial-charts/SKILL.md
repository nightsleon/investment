# 个股好生意·定量图表标准（精简 5 张主图）

## Overview

本 Skill 是个股投资分析报告与 3R 简报中**定量分析部分的标准图表套件与唯一事实源**。
统一图表风格、指标量纲与脚本逻辑，杜绝不同公司、不同时期生成的图表风格各异、信息重复或尺度失真。

### 核心设计原则
1. **图表服务决策，不搞花架子**：每张图只支撑一个核心商业常识判断，避免与正文表格大面积撞车。
2. **白底、清新、标注克制**：白底（`dpi=180`），主图饱满，浅灰 Y 轴网格，避免密集标签打架。
3. **默认输出 5 张核心图**：4.1（杜邦）、4.2（利润+利润率+增速双联主图）、4.3（收入结构）、4.4（现金流）、4.6（营运质量，报告按需引用）；4.5 现金头寸由资产负债表底表直接呈现，不再默认出图（如需兼容旧版，可传 `--with-45`）。
4. **排版铁律：文图配合、结论直白**：
   - **图看趋势和异常**：让读者一眼看清 5~6 年斜率与拐点；
   - **表与图不重复报数**：已有底表只列精确数字，正文只写因果与异常，不重复流水账；
   - **结论直白中性**：图标题使用中性陈述，结论放在正文关键判断中。

## 适用范围与边界

### 适用场景
- 撰写 3R 投资分析报告的定量章节与 3R 简报；
- 生成 ROE/杜邦、利润增长、产品结构、现金流、现金头寸、营运质量 6 张标准图；
- 统一个股研报的视觉规范与低基数/极端值处理逻辑。

### 不适用场景
- **股价 vs 利润趋势线（彼得·林奇收益线）**：使用 `stock-earnings-line`。
- **单期财报速评**：使用 `stock-financial-speedread`。
- **指数估值看板**：使用 `index-valuation-dashboard`。

## 4.1 ~ 4.6 默认画法与精细规则（吸收实战经验）

### 4.1 ROE 与杜邦三因子
- **图型**：ROE 用柱状图；净利率、总资产周转率、权益乘数按**首年 = 100 归一化**折线展示。
- **ROE 口径**：柱状图固定取年报披露的**加权平均 ROE**（输入列名 `加权ROE`），与报告正文表格一致；不使用年末简单 ROE。`简单ROE` 列仅作为数据留底，不参与画图。
- **看点**：只看三条折线的变动斜率，净利率抬升驱动为最高质量；若 ROE 抬升主要由杠杆（权益乘数）驱动，属于风险信号。

### 4.2 利润、利润率与增速（双联合并主图与低基数处理）
- **合并画法**：统一输出 `{code}_4.2_利润与利润率趋势图.png`——**上图**展示营收、扣非双柱与毛利率、净利率双折线（右轴从 0 起），**下图**展示扣非年度同比增速折线，一次看完“规模、利润率、增速”三件事，不再重复输出两张 4.2 图。港股利润列取“股东应占溢利/经调整利润”。
- **低基数/负基数处理铁律**：
  - 若上年利润为负或接近 0 导致同比极端异常（如 -900%、+1200%），**禁止让该异常点拉扁整个折线轴**；
  - 脚本对超出 `[-100%, +250%]` 范围的极值自动截断并加注“已截断”或“上期负基数”，保证正常年份斜率清晰可辨（如 `+98% → +54% → +33% → +13%`）。

### 4.3 产品结构与增长来源
- **结构拆解与防遮挡**：左图看各业务收入、占比与毛利率，右图看增量贡献。当存在中小负增量时，**负增量红字必须贴在零轴右侧白底处（宽负柱可居中置白字）**，严禁向右对齐越过零轴遮挡纵轴类目名称。
- **残差核对**：年报只披露部分品类时，核实各项总和是否等于营业总收入。不相等时补“其他业务（残差反推）”，严禁直接归一化到 100% 从而夸大主品占比。
- **与表格去重**：主报告将 `4.3` 放在 `1.2 怎么赚钱` 后，不在 `3.2` 重放字段完全相同的业务线底表。

### 4.4 净利润、经营现金流与自由现金流
- **定义**：自由现金流（FCF）= 经营活动现金流量净额 - 购建固定资产/无形资产等资本开支。
- **覆盖率截断**：现金流/净利润覆盖率出现极端值（如基数极小导致 800%）时，进行截断并显著标注「极值已截断」。

### 4.6 营运质量（应收 / 存货 / 合同负债）
- **按需使用**：脚本正常生成 `4.6` 底图供核查；主报告 `3.4` 仅在应收增速显著快于营收、存货明显积压或合同负债异常回落时嵌入此图，若营运稳健用精简表格即可。
- **量级真实**：合同负债较小时真实保留量级，严禁为“看得到柱子”强行篡改坐标轴或并表。

## 数据文件与脚本调用

### 数据文件约定
在股票研究包 `stocks/{code}_{公司名}/data/` 下组织：
```text
stocks/{code}_{公司名}/
  data/
    annual_core.csv                # 核心年度财务表（必需）
    product_structure.csv          # 最新年度产品结构（4.3用，可选）
  charts/                          # 生成的 6 张图存放目录
  scripts/                         # 存放执行脚本
```

### 推荐执行方式
```bash
# 复制标准脚本至目标公司目录
cp .agents/skills/stock-financial-charts/scripts/generate_fundamental_quant_charts.py \
  stocks/{code}_{公司名}/scripts/generate_fundamental_quant_charts.py

# 运行生成全套 6 张图表
python3 stocks/{code}_{公司名}/scripts/generate_fundamental_quant_charts.py \
  --base stocks/{code}_{公司名} \
  --code {code} \
  --company {公司名} \
  --annual data/annual_core.csv \
  --product data/product_structure.csv \
  --recent-years 6
```

## 验收检查清单（Checklist）

- [ ] **编号与路径**：4.1~4.4 及 4.6 编号一致，全部输出至 `stocks/{code}_{公司名}/charts/`；
- [ ] **中性标题**：图表标题保持中性，副标题标明财务口径与单位，结论留给正文；
- [ ] **杜邦首年基准**：4.1 杜邦三因子折线首年均为 100 基准点；
- [ ] **4.2 合并与低基数保护**：`4.2_利润与利润率趋势图.png` 已包含营收/利润/毛利率/净利率（右轴从 0 起）与下方扣非同比增速，极端同比已自动截断；
- [ ] **4.3 防遮挡与残差平衡**：产品结构各项收入之和严格勾稽年度营收；负增量标签位于零轴右侧或宽柱内，未遮挡纵轴标签；
- [ ] **4.6 按需嵌入**：仅当营运指标出现明显异动时嵌入主报告，正常情况用正文短评与精简底表即可。
