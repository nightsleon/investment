# 中证指数官网接口速查（世代回溯项目验证）

## index-perf：任意区间历史数据（世代回溯核心）
```
https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=<TR代码>&startDate=YYYYMMDD&endDate=YYYYMMDD
```
- indexCode 用**全收益（TR）代码**（如 H00015、932315CNY010），不是价格代码
- 返回 `{"code":"200","data":[{tradeDate, close, ...}]}`，按日；基日当天基点1000（部分为3000）
- 支持从基日起的任意区间——本地Excel导出常只有近10年，做基日至今回溯必须用此接口重采
- 无需登录，加 User-Agent 即可

## index-basic-info：基日/发布日/基点
- 归档于项目 `sources/excel-30index/basic_info.json`
- 字段：price_code / tr_code / name / publishDate / basicDate / basicIndex / market

## 官方定义（来自《中证指数有限公司股票指数计算规则》附录二）
- 基点 = 指数的初始值（基准数值）
- 基日 = 指数基点对应的日期（指数收益的起算零点）
- 归档：`references/csindex/中证指数有限公司股票指数计算规则.pdf`（项目内）

## 官网年化波动率口径（前端JS逆向验证）
官网指数详情页的"年化波动率"及夏普比率由前端计算，代码证据（chunk-c75f486c.js）：
- `波动率 = S.std(t, t => t.close - t.open) * Math.pow(242, .5)` → **日频、√242 年化**
- 详情页快照表的近一/三/五年年化波动率（oneYearNianHua 等字段）为后端算好下发，口径同为日频√242
- 复算验证：日收益率 std(ddof=1)×√242 与官网快照一致（上证红利 24.63% 验证通过）

## 注意
- 官网"基日"≠"发布日"：基日早于发布日的区间为回测试算；统一基日口径下回溯占比=(发布日-统一起点)/(终点-统一起点)
- 基日扎堆规律：港股通系=2014-11-14（沪港通2014-11-17开通前最后交易日，样本池硬约束）；央企定制系=2016-12-30（年末统一基期）
- 港股ETF可投资性：跟踪港股指数的港股上市ETF（如3070中国平安CSI香港高息股，港元柜台3070/美元柜台9070）多为港股通（南向）合资格ETF，内地投资者无需QDII、开通港股通即可买；分红扣20%红利税。HKEX官网名单文件抓取易404/被重定向，用户可直接确认资格，勿浪费时间爬列表
