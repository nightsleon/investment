# 个股投资分析文章写作（面向大众的五问框架）

## 1. 定位与边界

本 Skill 用于将专业的《投资分析报告》（6 章 13 节）底稿，转化为面向普通读者（雪球、知乎、微信公众号等）的平实基本面投资分析文章。文章默认保存为 `{原文件名}_雪球知乎版.md`，严禁覆盖原研报。

* **读者画像**：面向大众个人投资者。读者不需要阅读复杂的学术模型或翻阅冗长底账，需要用平实常识看清公司如何赚钱、核心风险在哪里、当前估值值不值得买。
* **克制原则**：正文严格控制在 **2,800 ~ 3,500 字**左右（上限 3,800 字）；全篇表格总数**锁死在 3 张以内**；正文以呼吸感短自然段流式推进，**严禁在五问内部使用三级小标题（`###`）嵌套**。
* **不凭空荐股与重评**：所有事实、数据、图表、得分与评级严格继承自最新《投资分析报告》，图表取自研报 `charts/` 目录（含 4.2 利润率变体），不另起炉灶重新打分。
* **执行底册**：动笔前先读 `references/article-template-and-review.md`，按其中的故事卡、标题/开头模板、逐问写作模板、表格模板和通俗语言对照表执行。本文件管边界与验收，底册管具体写法。

## 2. 核心架构：五个选股常识问题

文章围绕普通读者关心的五个常识问题展开单线叙事：

**每一问开篇先交代“为什么问这个”**：讲清这一问跟“公司值不值钱”的关系。这句话加粗、单独成段，再进入答案；它是正文，不是写给自己的校准批注，也不要写成“那么问题来了”式的设问自答。

1. **一、能不能看懂：公司到底靠什么赚钱？**
   讲清卖什么、谁付钱、客户为什么换不掉、核心效率差在哪里。多用生活常识打比方，不堆砌抽象概念，微观技术与复杂工序一笔带过。
   **开篇逻辑**：业务简单、盈利模式清楚，未来自由现金流才有一定可预测性，而公司的价值本质上是未来自由现金流的折现。
2. **二、能不能活得久：这门生意会不会消失？**
   底层需求能否长期存在、行业会不会衰落、会不会被新技术或新产品淘汰。未来增长靠行业扩容、抢份额、产品升级还是出海，实事求是交代。
   **开篇逻辑**：需求、产品和品类不易被替代，长期投资才有复利基础。
3. **三、利润能不能守住：同行为什么抢不走？**
   竞争壁垒在哪里；**护城河与定价权分开看**（有壁垒不等于能随便涨价，毛利率是定价权的直接账本，同时看对供应链的无息占款能力）；同行对比放在自然段中平实交代。
   **开篇逻辑**：行业竞争要“月朗星稀”，公司还要有护城河；护城河不等于定价权，强势客户仍可能拿走一部分利润。
4. **四、能不能高效复利：增长吃不吃资本？管理层厚不厚道？**
   - **开篇逻辑**：投入较少资本、产生较高回报，上行期能高效复利，下行时也会有保护。
   - **轻重资产定性**：这门生意是“不用多投钱就能自然长大的轻资产”，还是“每年必须砸大钱建厂房买设备的重制造”；
   - **赚来的是不是真金白银**：存量回报（ROE）靠高利润、快周转还是借钱加杠杆；扣除每年的厂房设备开支后，手里还剩多少自由现金流；
   - **管理层厚不厚道（分红与诚信底线）**：大股东有没有疯狂套现、财务造假或盲目并购劣迹；赚了钱愿不愿意常年大比例现金分红；留存的未分配利润有没有给股东创造真实市值（巴菲特“一美元原则”大白话检验）。大账本数据化入句子，不搬运大表。
5. **五、当前价格买得值不值：现在的价格贵不贵？**
   - **开篇逻辑**：市场预期已经反映在股价中，只有实际增长超过市场预期增长，投资者才容易获得好回报。前四问判断公司值不值得长期持有，第五问判断当前价格值不值得买。
   - **市场在担忧什么**：定价隐含了什么预期，利空是否已经钝化；
   - **贵不贵**：当前估值在历史上处于什么位置、扣现金 PE 是多少；先判断当前利润是不是周期顶，若是则用常态利润重算分位；
   - **拿不拿得住**：静态股息率、自由现金流对分红的覆盖、注销式回购；
   - **赔率划不划算**：用保守、中性两档简明情景赔率算账；
   - **时机研判基于安全边际**：立足当前估值与安全边际厚度判断是不是好时机（便宜且基本面未坏即具备配置价值；估值透支则建议耐心等待），不写“等经营拐点”等免责套话；不给喊单式买卖价格点位与仓位比例；
   - **明确证伪条件**：列出 2~3 条刚性的底线指标，清楚交代“什么情况下说明长线逻辑被证伪，必须果断认错”。

每一问结尾用一句话给出小结——这关过了/勉强/没过，并说明理由；再用一句因果句把读者推到下一问。证伪条件不在这里展开，统一放结尾。

## 3. 大众体裁排版与段落节奏

语言风格全局遵循 `AGENTS.md` 通用反 AI 与通俗算账规范。面向大众读者，本 Skill 重点执行以下排版与节奏约束：

* **呼吸感自然短段**：每个自然段建议在 120 字以内（2~3 句话），段落间以商业逻辑自然流转推进；
* **严禁清单列表病**：正文叙事禁止通篇堆砌垂直的项目符号列表（Bullet points），所有观点与论据化入连贯自然段；
* **通俗比方代替工序详解**：面对复杂工艺或微观技术，用买方常识和生活体验打比方，复杂工序细节一笔带过；
* **数字克制**：每问只允许 1 个主数字进段首或小标题，最多 2 个支撑数字进句子；主数字要能改变结论，其余数字化进句子。

## 4. 配图与表格约束

* **核心图表配置（全篇 4~5 张，图前叙事）**：
  - 第一问：嵌入 1 张 `收入结构图`，讲清钱从哪来；
  - 第二问：不配图，利润增速用正文数字带过；
  - 第三问：嵌入 1 张 `4.2 利润率变体`（营收/扣非双柱 + 毛利率/净利率双折线），直接看毛利率有没有被价格战和原料涨价压下去；4.6 的存货/合同负债数字并入第四问正文，不单独占图位；
  - 第四问：**同时嵌入 2 张核心图表**（`4.1 ROE杜邦图` 展现资本回报高度与杠杆质量，`4.4 现金流对比图` 展现真实造血与资本开支落差）；
  - 第五问：嵌入 1 张 `股价 vs 利润TTM双Y轴图`。
* **表格上限 3 张小表**：全篇表格总数 $\le 3$ 张（单表行数 $\le 7$ 行、列数 $\le 5$ 列）。标配为：核心估值卡片、情景赔率表、综合评级表；
* **图表互斥**：凡已配图的章节，**下方绝对严禁再贴数据底表**，研报财务大账本一律提炼进正文语句。

## 5. 交付自查清单

- [ ] **字数克制**：正文字数控制在 2,800 ~ 3,500 字（上限 3,800 字）；
- [ ] **单线无嵌套**：五问内部使用纯自然段展开，无任何三级小标题（`###`）嵌套；
- [ ] **每问先讲逻辑**：五问开篇各有一句加粗、单独成段的“为什么问这个”逻辑说明，讲清它和公司值不值钱的关系，不跳过逻辑直接讲业务；
- [ ] **每问收口**：五问结尾各有一句“这关过了/勉强/没过”的小结，并有一句因果过渡；
- [ ] **数字克制**：每问只保留 1 个主数字，支撑数字不超过 2 个，无数据堆砌；
- [ ] **章节标题带结论**：五个一级标题均拼接了具体业务主语与投资结论；
- [ ] **文风合规**：符合 AGENTS.md 通用反 AI 底线，段落短小自然，无 PPT 清单病；
- [ ] **第四问双图齐备**：已同时配置 ROE 杜邦图（回报率）与现金流对比图（造血与资本开支）；
- [ ] **表格至多 3 张**：全篇仅保留核心估值卡片、情景赔率表与综合评级表，无大账本整表搬运；
- [ ] **第五问三问齐备**：贵不贵、拿不拿得住、赔率划不划算，保守/中性两档与投资分析报告一致；
- [ ] **时机研判无拐点套话**：立足安全边际与估值客观定性，无“等经营拐点”套话与买卖喊单点位；
- [ ] **文末合规后缀闭环**：正文最末尾严格附带标准互动与风险提示文案（对话回复中严禁输出该文案）：
  ```text
  如果您觉得这篇文章有启发，欢迎点赞、转发、关注！

  风险提示：本文基于公开客观数据与独立研究，仅供交流参考，不构成任何投资建议。市场有风险，投资需谨慎。
  ```
