## 二、文章开头规范与标准模板

### 2.1 标题规范
标题必须带有公司名、估值事实或核心经营矛盾，拒绝研报公文八股：
* `{公司}：跌出 5% 股息率，但先别急着当成印钞机`
* `{公司}：市场在担心什么，当前估值到底有没有砸出安全边际？`
* `{公司}：好公司还在，为什么现在只能先建观察仓？`

### 2.2 开头模板

```markdown
# {结论型大标题}

> 数据范围：行情截至 {YYYY-MM-DD}，财务截至 {最新报告期}。本文仅为个人投资研究记录与探讨，不构成任何投资建议。

买股票就是买公司。抛开每天盘面上红绿波动的噪音，拉长到十年的周期来看，要搞清楚一家公司值不值得长线持有，其实只需要客观回答五个常识问题：**能不能看懂、能不能活得久、利润能不能守住、能不能高效复利，以及当前价格买得值不值。**

{抛出现实反差与核心矛盾：例如“过去大半年它的股价腰斩了 45%，市盈率被砸进历史极底；但翻开最新年报，在手现金却创下历史新高。这五个关卡，它到底能过几关？”}

> **{公司}的一句话判断｜综合评级：{评级}（{XX.X}/100，{核心重仓 / 核心储备 / 高性价比配置 / 次级观察池 / 不碰}）**：按五个问题检验，{逐项总结答案与决定性证据}；{当前核心矛盾与时机研判}。

{关键财务底盘：例如当前营收、扣非利润、加权ROE与纯净现金头寸。}
```

## 三、五个问题正文模板与通俗算账翻译

**执行边界**：字数、段落、配图、表格与每问收口规则以 `SKILL.md` 第 1、2、3、4 节为准；本节只给逐问写法、图表位置和语言示范。

**选股框架逻辑的用法**：下面每节开头的“选股框架逻辑”要写进正文第一段，加粗、单独成段，用生意大白话讲清楚这一问为什么重要；它是正文，不是给作者自己看的校准批注。只有“自由现金流折现”这类纯财务术语需要换成大白话，其余按正常表达写。

### 3.1 一、能不能看得懂：{公司到底靠什么赚钱}

* **选股框架逻辑（写进正文）**：业务简单、盈利模式清楚，未来自由现金流才有一定可预测性，而公司的价值本质上是未来自由现金流的折现。
* **写作指引**：
  * 用直白大白话讲清：向谁提供什么产品/服务、客户凭什么付钱、核心门槛到底在哪。
  * 严禁大篇幅纠缠微观工序与技术名词，点到为止。
  * 嵌入 `4.3 收入结构图`（1张），图下严禁贴长表，核心数据提炼进正文。
* **语言示范**：
  * ❌ *“公司业务涵盖多元板块，通过全产业链协同实现多轮驱动。”*
  * ✅ *“表面看它卖的是各种包装盒，再往下一层，真正帮它赚大钱的是无菌灌装机。机器以极低价格甚至免费租给下游乳企，但后续专用的包装耗材必须向它买，做的是典型的‘剃须刀+刀片’的印钞机生意。”*

### 3.2 二、能不能活得久：{这门生意会不会消失}

* **选股框架逻辑（写进正文）**：需求、产品和品类不易被替代，长期投资才有复利基础。
* **写作指引**：
  * 判断底层需求是否长期存在，品类会不会被新技术或新消费习惯替代。
  * 将“未来增长从哪里来”并入本节：分析行业是扩容、存量还是收缩；公司未来靠“抢占份额、结构升级、地域出海还是第二曲线”增长。
  * 本节不配图；利润增速用正文数字带过，图位留给第三问的营运资本图和第四问的现金流图。
* **语言示范**：
  * ❌ *“行业具备广阔的市场空间与长坡厚雪属性，未来渗透率有望持续提升。”*
  * ✅ *“中国人喝牛奶的习惯不会倒退，但常温白奶的人均消费量已经基本见顶。未来两三年行业总量很难再有大增长，公司要想继续多赚钱，只能靠两招：要么从外资手里抢高端冷藏奶的包装份额，要么跟着国产品牌一起出海去东南亚。”*

### 3.3 三、利润能不能守得住：{同行为什么抢不走}

* **选股框架逻辑（写进正文）**：行业竞争要“月朗星稀”，公司还要有护城河；护城河不等于定价权，强势客户仍可能拿走一部分利润。
* **写作指引**：
  * 同行为什么难以进入或抢夺利润。
  * **护城河与定价权必须分开拆解**：
    * 护城河：品牌、渠道、技术、规模、客户认证或高转换成本；
    * 定价权：能否主动提价、能否转嫁原材料上涨成本、逆风期是否被迫降价，以及**对上下游的无息占款能力（应付+合同负债 vs 应收+预付）**。
  * 同行对比优先在自然段中对比核心龙头数据，不贴冗长对比大表。
  * 毛利率是定价权的直接账本：把单季毛利率与上年同期对比，降幅超过 3 个百分点，就说明成本转嫁不出去，护城河没能变成提价权。
  * 嵌入 `4.2_利润与利润率趋势图`（利润率变体，1张）：营收/扣非双柱 + 毛利率/净利率双折线，直接看毛利率有没有被压下去；4.6 的存货/合同负债数字并入第四问正文，不单独占图位。
* **语言示范（生意算账翻译）**：
  * ❌ *“公司具备显著的产业链议价能力，营运资本优势突出，构筑了深厚壁垒。”*
  * ✅ *“做生意强势不强势，看账本一清二楚：它账上的应付账款常年高达 50 亿，而应收账款只有不到 5 亿。货还没生产，客户的全款先到了；原材料拉进厂，货款可以三个月后再结。这就是典型的拿上下游的钱做自己的生意，无息占款能力极强。”*

### 3.4 四、能不能高效复利：{增长吃不吃资本、真造血与管理层厚道度}

* **选股框架逻辑（写进正文）**：投入较少资本、产生较高回报，上行期能高效复利，下行时也会有保护。
* **写作指引**：
  * **轻重资产定性**：讲清做大这门生意需要吃多少本钱，是不用多投钱就能自然长大的轻资产，还是每年必须砸大钱投产线、建厂房的重制造。
  * **存量回报与真金白银**：ROE 靠卖得贵（净利率）、周转快（周转率）还是借钱加杠杆（权益乘数）；扣除每年厂房设备开支后，还剩多少真金白银的自由现金流。
  * **管理层厚不厚道**：大股东有没有疯狂套现、财务造假或盲目跨界并购的劣迹；赚了钱愿不愿意常年大比例现金分红；留在手里的未分配利润有没有给股东创造真实市值（一美元原则测算）。
  * 嵌入 **2 张核心图表**：`4.1 ROE杜邦图`（展现资本回报高度与杠杆质量）与 `4.4 现金流对比图`（展现真实造血与资本开支落差），文图互证，严禁贴六年财务大账本表。
  * 4.6 的存货、合同负债数字不单独配图，化进正文句子（如存货 +53.15%、合同负债 -17.40%），避免图位超预算。
* **语言示范（管理层厚道度与一美元原则大白话）**：
  * ❌ *“管理层资本配置效率处于较高水平，留存收益转化率表现良好，分红政策兼顾股东利益。”*
  * ✅ *“做生意不仅要看赚不赚钱，更要看管理层厚不厚道。过去五年公司累计赚了 120 亿净利润，大股东没有减持套现，反而实打实拿出 50 亿真金白银给全体股东分了红；留下的 70 亿未分配利润拿去扩产，对应市值增加了 95 亿。每留下 1 块利润，市值增加了 1 块 3 毛 5，这叫高效复利；如果每年赚假钱、不分红还不断找股东伸手配股，那就是资本黑洞。”*

### 3.5 五、当前价格买得值不值：{现在的价格贵不贵}

* **选股框架逻辑（写进正文）**：市场预期已经反映在股价中，只有实际增长超过市场预期增长，投资者才容易获得好回报。前四问判断公司值不值得长期持有，第五问判断当前价格值不值得买。
* **写作指引**（按报告的三问推进，正文用自然段，不加三级标题）：
  * 开头先交代市场在担忧什么、定价隐含了什么预期，再依次回答下面三问。
  * **贵不贵**：看 PE/PB 历史分位与扣现金 PE；先判断当前利润是不是周期顶，若处在景气高点，用常态利润重算一遍分位，避免把周期顶当成便宜。
  * **拿不拿得住**：看静态股息率、自由现金流对分红的覆盖、注销式回购；不能只看股息率，还要看分红是不是靠当年现金流赚出来的。
  * **赔率划不划算**：按保守、中性两档算 3 年价格空间，保守档的下行要能用三年股息抵掉大部分。
  * 结尾给时机判断和证伪条件。
  * 嵌入 `股价 vs 利润TTM双Y轴图`（1张）。
  * 嵌入 **核心估值卡片表**（表1，单列 6~7 行）。
  * 嵌入 **3 年情景赔率表**（表2，2 行）。
* **核心估值卡片模板**：


## 五、大众通俗语言对照表（远离公文套话，讲生意大白话）

| 公文套话与 AI 腔（避免使用） | 大众通俗大白话（提倡使用） |
|---|---|
| 值得注意的是 / 诚然 / 毋庸置疑 / 不可否认 | 翻开财报最反常的是…… / 真正关键的变量是…… |
| 深化协同 / 战略定力 / 重构基石 / 展现韧性 | 扣紧钱包过冬 / 砍掉低效产品线 / 没在牛市跟风扩产 |
| 对……进行了优化 / 开展了……去化工作 | 优化了销售渠道 / 砍掉了二线供应商 / 清理了积压库存 |
| 通过……实现了采购成本的边际改善 | 采购部把供应商压到两家，直接砍掉 15% 的采购成本 |
| 从动力电池到欧洲出海（生硬并列假区间） | 从单车净亏 2 万，到单车逆势挤出 3000 块净利 |
| 不仅是一次……更是一次……（刻意对偶升华） | 背后很具体，就是…… |
| 那么底牌究竟是什么？答案是……（设问自答） | 直接陈述主谓宾（如：“底牌是极高的用户转换成本。”） |
| 展望未来，公司未来可期，值得投资者持续关注 | 接下来就盯两个硬指标：三季报应收账款有没有收回，以及…… |
| 自由现金流折现 | 这家公司未来能掏出多少真钱，折算成今天值多少 |
