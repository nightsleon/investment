# 投资分析文章模板与复核清单

本文件按需加载。主 `SKILL.md` 是运行时控制器；本文件提供故事卡、逐章模板、情景估值和发布前检查。

## 一、写作前的故事卡

```text
公司：
决策源：用户指定文件 / 最新锁定3R简报
数据截止：行情____；财务____；年度____
3R：____/100；字母评级____；行动____

能不能看得懂：收入、利润、现金流、再投资和风险由什么驱动？
能不能活得久：需求、行业利润池和公司的适应能力能否持续，未来靠什么增长？
利润能不能守得住：竞争机制、护城河及广义定价权分别如何？
能不能高效复利：增量资本回报、再投资空间、资本配置和下行保护分别如何？
当前价格买得值不值：股价隐含什么整体预期，未来经营与每股价值大概率好于还是差于预期？

核心矛盾：
明确观点：
投资价值：已出现 / 尚未出现
仓位条件：关注 / 分批验证 / 提高关注 / 等待
提高关注条件：
证伪条件：
```

故事卡填不完就回到报告查证，不用漂亮文字掩盖研究缺口。

## 二、标题与开头

### 2.1 标题

标题要有公司、价格或经营矛盾：

```text
{公司}：{估值事实}，但{经营问题}
{公司}：{市场共识}，真正需要关注的是{变量}
{公司}：好公司还在，为什么现在不能重仓
```

不用“抄底、翻倍、闭眼买、严重低估”等煽动词。

### 2.2 开头模板

```markdown
# {结论型标题}

> 数据范围：行情截至{日期}，财务截至{报告期}，年度数据截至{年报期}。本文仅供学习研究，不构成投资建议。

**我的选股框架**：我先问五个问题。第一，能不能看得懂：关键不是业务客观上是否简单，而是收入、利润、现金流、再投资和风险能否理解。第二，能不能活得久：不仅看需求和品类，还看行业利润池能否持续、公司能否适应变化。第三，利润能不能守得住：集中格局通常有利但不是充分条件，护城河要持续转化为份额、利润率、资本回报和现金流；定价权也不只等于直接涨价。第四，能不能高效复利：重点看增量资本回报率、再投资空间和可持续时间，并区分复利效率与下行安全。第五，当前价格买得值不值：市场已经反映对增长、利润率、资本开支、资本回报、分红和风险的预期，最终回报取决于未来经营结果与每股价值是否好于买入价格隐含的整体预期。前四问判断公司值不值得长期持有，第五问判断当前价格值不值得买。

> **{公司}的一句话判断｜3R综合评级：{字母}（{分数}/100，{行动}）**：按五个问题看，{逐项给答案和决定性证据}；{预期差方向}。但{最新经营压力}，{投资价值判断}，{仓位条件}。

{决定性经营数字。}

{报告基准日估值、股息或现金安全垫。}

{一句话说明最大矛盾和当前行动。}
```

开头框架解释“为什么看”，公司一句话给“目标公司答案”。两段分开，不揉成一个巨句。

## 三、五个问题正文模板

### 3.1 能不能看得懂

回答：

- 公司卖什么，谁付钱；
- 真正的利润池在哪里；
- 品牌、产品、渠道、技术或成本中，谁创造溢价；
- 收入、成本、利润和现金流由什么驱动；
- 为什么未来自由现金流可以大致预测。

常用写法：

```text
表面看，它赚的是____的钱。再往下一层，真正值钱的是____。
过去需要回答的是____，现在需要回答的是____。
```

不复制完整公司概况表。产品复杂时才保留一张小表。

### 3.2 能不能活得久

回答：

- 需求和消费场景能否长期存在；
- 产品或品类会不会被技术、习惯或监管替代；
- 行业总量扩张、稳定还是收缩；
- 公司未来靠行业扩容、份额、提价、产品结构、地域还是新业务增长；
- 历史CAGR是否受低基数和高速扩张期影响。

把“未来增长从哪里来”并入本节。利润趋势图放这里。结论要说清公司能活多久、未来靠什么增长，不写空泛的“仍有空间”。

### 3.3 利润能不能守得住

顺序：

1. 行业是否“月朗星稀”，有没有价格战、补贴战、重复扩产和无利润跑马圈地；
2. 公司护城河来自品牌、技术、成本、规模、网络效应、转换成本、渠道、牌照还是垄断资源；
3. 什么事实证明竞争者难复制、难抢客户和利润；
4. 护城河是否转化为复购、份额、毛利、回款或现金流；
5. 公司能否提价或传导成本，监管、价格管制和强势客户是否限制定价权；
6. 长期定价权与短期价格压力分别是什么。

不要：

- 把品类不易替代当成公司护城河；
- 用品牌知名度直接证明定价权；
- 看到垄断和牌照就认定可以自由提价；
- 用高毛利率证明任何时期都能提价。

### 3.4 能不能高效复利

先判断“再投资空间 × 增量资本回报率 × 可持续时间”，再检查资本配置和下行安全。轻资本是常见优势，但不是必要条件；高回报重资本公司可以创造价值，低回报高投入的增长可能毁灭价值。

#### 增长需要多少投入

比较资本开支与经营现金流、净利润，区分维持性投入和增长性投入。判断利润是否容易被新增投入吞噬，但不要把低资本开支直接等同于高效复利。

#### 新增投入回报高不高

区分当前ROE/ROIC和增量ROIC。杜邦分析用于判断存量回报由利润率、周转率还是杠杆驱动；真正的复利能力还要看新增一元资本能产生多少税后经营利润，以及这种机会能持续多久。

#### 留存利润是否增加每股价值

检查公司是高回报再投资、分红、回购，还是低效扩产、溢价并购或持续增发。分析最终落到每股价值，不以总收入或总利润增长替代股东回报。

#### 下行能不能活下来

看自由现金流、负债、固定成本、闲置产能和现金头寸。下行安全是复利的前提，但现金充足本身不等于复利效率高。

推荐正文顺序：

```text
资本开支与经营现金流/利润对比
→ 当前ROE/ROIC与杜邦
→ 增量资本回报、再投资空间与资本配置
→ 自由现金流、分红、负债和现金头寸
```

精度规则：

- `FCF < 分红`时写“接近覆盖”，不写“覆盖”；
- 其他流动资产不等于定期存款；
- 应收款项融资不计入现金；
- 季报未披露现金明细时，估算值必须标注；
- 公开文章优先使用年报确认现金头寸。

### 3.5 当前价格买得值不值

本节只用一句话回扣增长陷阱，然后落到公司：

```text
市场已经反映对增长、利润率、资本开支、资本回报、分红和风险的预期，最终回报取决于未来经营结果与每股价值是否好于买入价格隐含的整体预期。
```

继续回答：

- 市场按高增长、低增长还是衰退型资产定价；
- 价格隐含的增长、利润率、资本开支和资本回报假设是什么；
- 实际经营和每股价值为什么可能高于或低于预期；
- 股价与利润经历了估值扩张、估值压缩还是利润下修；
- 回报分别来自自由现金流收益率、增长、股息/回购和估值变化中的哪几项；
- 股份数量变化是否稀释每股回报。

不要写成“只有实际利润增长超过预期增长才有好回报”。零增长但高自由现金流收益率、持续分红的公司也可能提供好回报；高增长但现金流差、持续增发或估值收缩的公司也可能提供差回报。

保留股价与TTM利润图、紧凑估值表和保守/中性情景。

## 四、情景估值写法

### 4.1 先说明为什么用PE

```text
公司的价值最终来自未来自由现金流。为了直观比较不同预期，文章不做完整现金流折现，而用“未来利润×期末PE”做简化情景估算。
```

### 4.2 展示计算过程

```text
未来利润 = 当前利润 × (1 + 增长率)^年数
期末市值 = 未来利润 × 期末PE
价格回报 = 期末市值 ÷ 当前市值 - 1
累计总回报 ≈ 价格回报 + 静态股息率 × 年数
```

表格模板：

```markdown
| 情景 | 未来利润公式 | 期末PE | 期末市值 | 价格回报 | 累计静态分红 | 累计总回报 |
|---|---:|---:|---:|---:|---:|---:|
| 中性 |  |  |  |  |  |  |
| 保守 |  |  |  |  |  |  |
```

表后说明：先估未来利润，再乘期末PE得到未来市值，最后加入持有期间的分红。

必须披露：

- 静态股息率乘年数只是粗略估算；
- 未考虑未来分红变化、税费和分红再投资；
- 情景用于比较赔率，不是精确预测；
- 利润×PE后不机械加回全部现金，避免重复计算。

## 五、结论与行动

先用一段回答五问，再放紧凑3R表：

```markdown
| 维度 | 得分 | 权重 | 核心判断 |
|---|---:|---:|---|
| Right Business |  | 60 |  |
| Right People |  | 20 |  |
| Right Price |  | 20 |  |
| 合计 |  | 100 |  |
```

正文或开头引用总分时必须保留分项与权重，不能只报总分。

结尾只回答：

- 现在怎么办；
- 什么情况下提高关注；
- 什么情况下判断错了。

可以同时成立：

```text
公司质量没有坏，但利润和渠道尚未企稳，当前更适合关注和分批验证，不适合一次性重仓。
```

不要写“未来值得期待”“一句话收尾”等模板痕迹。

## 六、3R字母评级

| 3R总分 | 字母评级 | 含义 |
|---:|---|---|
| 90—100 | A+ | 三个R均突出，重大短板很少 |
| 80—89.9 | A | 高质量候选，强烈关注 |
| 75—79.9 | B+ | 基本面较好，关键问题待验证 |
| 70—74.9 | B | 优点明确、短板明显，以观察为主 |
| 60—69.9 | C | 公司质量或价格存在明显不足 |
| 60以下 | D | 暂不投入研究精力 |

若门槛或重大红线降级，必须说明原因。

## 七、篇幅与图表

正文通常2500—3900个汉字。完整五问框架会增加篇幅，允许适度超过3600字，但不能超过约5000字并变成压缩研报。

优先复用四类图：

1. 利润趋势与增速；
2. ROE与杜邦三因子；
3. 净利润、经营现金流和自由现金流；
4. 股价与TTM利润。

图表紧跟分析段落，不堆在一起。正文通常只保留1—2张紧凑表。

## 八、独立反 AI 与文风自审

本框架成稿过程中，严格执行独立反 AI 规范与自审脱水，无需外部嵌套调用：

- 严格遵守“三不碰”铁律：不改财务数字、不删诚实限定语、不弱化五问核心立场；
- 清理“这意味着、总体来看、核心在于”等过渡套话与元话语；
- 打破同构对称句式，将正文长短句交错控制在呼吸感范围内；
- 将抽象研报词句降维为大众通感大白话，小标题业务语义化。

## 九、矛盾审计

| 主题 | 常见矛盾 | 统一方式 |
|---|---|---|
| 五问用词 | 看懂/看得懂、守住/守得住混用 | 全文统一同一组标题 |
| 评级 | B+、关注、强烈关注并存 | 以3R映射和门槛为准 |
| 价值/仓位 | 有投资价值又写完全不能买 | 区分关注、分批验证和重仓 |
| 定价权 | 长期存在、短期失效混写 | 明确长期能力和短期压力 |
| 增长 | 未来低增却套历史高CAGR | 历史与未来分开 |
| 市场预期 | 一会儿过度悲观，一会儿两面列举 | 给唯一基准判断 |
| 现金 | 年报确认值与季报估算值混用 | 正文优先确认值 |
| 分红 | FCF低于分红却写覆盖 | 写接近覆盖并核算 |
| 行情 | 历史基准价写成当前实时价格 | 全文使用报告基准日 |
| 估值 | 先说DCF，后面突然只用PE | 加一句简化估值桥接 |
| 来源 | 写旧分、盲评和锁分过程 | 只保留参考链接和数据边界 |

建议搜索：

```text
评级|总分|关注|重仓|投资价值|企稳|增长陷阱|覆盖|定价权|现金头寸|估算|当前价格|基准日|旧报告|盲评
```

## 十、机械验证

1. 图片链接存在；
2. 外部参考链接可访问；
3. 3R三项等于总分；
4. 字母评级与总分映射一致；
5. 数据截止日与股价、PE、股息率一致；
6. 情景估值中的利润、市值和回报可重算；
7. FCF/分红措辞与数值一致；
8. 估算现金和确认现金没有混用；
9. 全文篇幅合理；
10. `git diff --check`通过；
11. 只修改用户确认的文件。
