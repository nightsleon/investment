# 爆款商业特稿与财经大V写作 (Viral Financial Storytelling)

## 1. 触发场景与核心定位

当用户需要输出**兼具大众传播张力与买方投研深度**的爆款商业分析文章、深度特稿、产业评论或投资长文（面向微信公众号、雪球精选、知乎高赞、今日头条等平台）时触发本 Skill。

### 1.1 与现有相关 Skill 的边界划分
* **`investment-analysis-framework`**：买方 IC 内部严肃研究报告（严谨、完备、全景、机构投研视角）。
* **`investment-article-writing`**：按“五个选股问题”结构改写，偏技术型价值投资论证与答辩。
* **`viral-financial-storytelling`（本 Skill）**：**商业深度特稿与大V级传播爆款**。强调电影级场景切片、人物戏剧冲突、预期差揭示、单均UE财务硬核穿透、通感隐喻降维、以及扎心金句提炼。

### 1.2 语料库基准
本 Skill 的写作技法、段落呼吸感与语言范本直接锚定项目本地语料库：
* 全局索引与大V技法对照表：`references/大V文章库/README.md`
* 27 篇完整代表作全文：`references/大V文章库/`
* 理论框架与推演体系：`references/财经爆款写作大V库与融合方法论.md`

## 2. “骨·肉·皮”三位一体写作哲学

爆款财经文章绝不能沦为无脑情绪营销号，必须做到**“骨头硬、肌肉实、皮相绝”**：

### 2.1 骨（买方投研底线）：吸收“唐朝 + 表外表里”
* **硬核算账**：绝不使用泛泛而谈的形容词。必须给出**分部财务穿透、单位经济模型（UE/单店/单均毛利）、三年后净利润测算、自由现金流与估值买卖点**。
* **常识与安全边际**：恪守能力圈，向读者算清“白纸黑字写在报表上的确定性资产”。
* **态度坚决**：拒绝“既有机遇又有挑战”的中庸废话，给出掷地有声的多空结论与明确证伪线。

### 2.2 肉（商业特稿叙事）：吸收“晚点LatePost + 远川/戴老板”
* **电影级开场**：用具体的“时间 + 地点 + 关键人物微表情 + 戏剧性困境”切入（参考《中国芯酸往事》与《字节跳动怎么都十万人了》）。
* **组织机理穿透**：剖析战略背后的组织微观机制（如 OKR 机制、算法考核、汇报链条、履约铁军、地推肉搏）。
* **时代命运感**：将企业竞争上升为产业演进与时代浪潮（如“造车是一种命运”、“芯片三十年血泪”）。

### 2.3 皮（大众传播心理）：吸收“粥左罗 + 六神磊磊 + 韭圈儿”
* **标题矩阵**：严格遵循爆款心理学（反直觉、反常识、现实反差、利益痛点）。
* **通感隐喻降维**：用大众熟知的文史、金庸江湖或现代日常生活（如“大V朋友圈互推”、“高考查分落第”、“画线派”）重构晦涩商业金融机制。
* **情绪按摩与去AI味**：语言像在深夜小酒馆与聪明读者推心置腹，带有轻微自嘲与人情冷暖。

## 3. 标准创作工作流（5步流水线）

当接收到研究底稿、公司财报或特定主题时，严格执行以下 5 步：

### 第一步：嗅探“预期差”与戏剧冲突（核心立意）
绝不平铺直叙流水账，先在商业事实与大众认知之间寻找裂缝：
1. **反直觉反转**：为什么市场认为的“烂生意”正变成十倍股？（如腾讯音乐）
2. **辉煌下的暗礁**：为什么业绩狂飙的同时，组织系统正在濒临极限？（如字节十万人）
3. **狂欢中的踩踏**：为什么短期赚快钱的策略隐藏着巨大的道德与流动性风险？（如微盘股）
4. **守旧还是破局**：在行业夕阳或价格战中，究竟是在垂死挣扎还是在构筑反转壁垒？（如美团收缩、拼多多出海）

### 第二步：输出“粥式五维爆款标题矩阵”（供选）
在正文前，必须同时拟定 5 组不同传播维度的标题供用户决策：
* `[悬念反常识型]`：引发强烈认知冲突（例：《Labubu也许会过气，但泡泡玛特不会》）
* `[预期差反转型]`：揭示商业反差（例：《腾讯音乐们，何以从“烂生意”到“十倍股”？》）
* `[命运人物特写型]`：代入感极强（例：《猛人杜甫：一个小号的逆袭》）
* `[时代宏大史诗型]`：宿命与波澜（例：《中国芯酸往事》 / 《蔚来是一种命运》）
* `[扎心真相清醒型]`：直击利益痛点（例：《错付拼多多这五年》 / 《微盘股的苦日子》）

### 第三步：电影级冷开场（Cold Open）
正文第一段严禁“在当今快节奏的商业社会中”等套话。必须采用“场景切片”：
* **公式**：**时间坐标（某年某月） + 地理空间 + 具象动作/微表情 + 悬在头顶的危机**。
* *范例参考*：“公元735年，洛阳城外。24岁的杜甫查完高考成绩，用河南话骂了一句娘……”；“2020年盛夏，望京保利国际广场的会议室里，张一鸣面对一张十万人的组织架构图陷入了沉思……”

### 第四步：三明治式正文展开（特稿故事 $\leftrightarrow$ 硬核算账循环）
正文主体按 3-4 个章节推进，每个章节保持“微观故事 $\to$ 宏观博弈 $\to$ 财报数据穿透”的紧凑咬合：
1. **Part 1：商业模式降维拆解**：用 1 个极具画面感的生活/文史通感隐喻，讲清公司靠什么赚钱、为什么能赚钱。
2. **Part 2：硬核财报与UE模型穿透**：调用表外表里与唐朝的分析方法，拆解单店模型、单位经济学（客单价、变现率Take Rate、履约成本）、存货周转天数与现金流。
3. **Part 3：组织机理与关键人物抉择**：描写管理层面临的真实两难（如美团撤退社区团购守护主业利润，黄峥的海外Temu豪赌）。
4. **Part 4：三年后利润测算与估值底牌**：以推心置腹口吻给出“三年后净利润”测算、老唐估值法买卖点或核心安全边际。

### 第五步：升华收尾与硬性规范检查
1. **金句总结**：提炼 1-2 句具备“社交货币”属性的金句作为全篇落点。
2. **执行 AGENTS.md 强制文末规范**：文末必须原样附带互动引导与风险提示。

## 4. 语言风格与“去AI味”负向清单

### 4.1 绝对禁用的 AI 机械腔（命中即重写）
* ❌ 严禁出现总结套话：“综上所述”、“总而言之”、“是一把双刃剑”、“机遇与挑战并存”。
* ❌ 严禁空洞升华口号：“未来可期”、“扬帆起航”、“书写新的篇章”、“站在新的历史起点上”。
* ❌ 严禁机械排比句式（如连续三个“从……到……”、“不仅……而且……更……”）。
* ❌ 严禁机械自纠痕迹（如“经笔者核对”、“此前误写为”）。

### 4.2 提倡的表达习惯
* ✔ **口语化设问**：“这笔账到底怎么算？”、“钱到底流进谁的口袋了？”
* ✔ **接地气的度量衡**：“每卖出一杯奶茶净赚8毛钱”、“相当于每天烧掉一辆迈巴赫”。
* ✔ **穿透常识的断言**：“投资有时候不要算太精，常识比模型更管用”。

## 5. 输出文件规范与文末合规后缀

### 5.1 文件命名后缀规范（保护底稿约定）
当基于现有的研究底稿、评测草案或严肃研报改写为面向公开发布的特稿时，输出文件必须添加显式后缀（如 `{原文件名}_爆款版.md` 或 `{原文件名}_雪球知乎版.md`），严禁直接覆盖原研究底稿。

### 5.2 文末固定合规后缀（写进文件里，留在对话外）
在将文章写入最终 Markdown 文件时，正文最后一个句号结束后，必须换行并以 `---` 分割线附带以下固定文案，一字不差；**绝对严禁在日常聊天对话回复末尾输出此文案**：

```markdown
---

如果您觉得这篇文章有启发，欢迎点赞、转发、关注！

风险提示： 本文仅供参考，不构成投资建议。市场有风险，入市需谨慎。
```
