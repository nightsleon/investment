# 指数横向对比评分排名

## 评分方法（相对排名百分位制）

不设"达到多少算优秀"的及格线，只看组内排名。每个指标从小到大排队，排得越靠后（值越好）得分越高。

```
每项得分 = 你的位置 ÷ 总只数 × 100
```

### 四维度权重

| 维度 | 权重 | 核心指标 |
|------|------|----------|
| 收益能力 | 40% | CAGR |
| 风险控制 | 30% | 最大回撤 |
| 风险收益效率 | 15% | 收益/月频波动 |
| 稳定性 | 15% | 年度胜率60% + 滚动3年中位数40% |

总分 = 各维度百分位得分 × 权重之和。总分差3-5分以内视为同档。

### 排除的维度

- **分阶段表现**：不参与评分，作为独立小结供参考
- **最差年度**：去掉，避免与稳定性重复计分

### 稳定性详解

评测"收益可不可复制"——不同时间点买入，体验差异大不大。核心担心是十年CAGR好看但靠两三年暴涨撑起。
- 年度胜率（60%）：正收益年份占比
- 滚动3年中位数（40%）：任意起点买入的中等体验

## 分组策略

按发布年限分组，避免数据长度差异造成不公平：

| 组别 | 条件 | 用途 |
|------|------|------|
| 发布≥10年 | 发布日期≥2016年 | 实盘验证充分，可信度高 |
| 发布≥5年 | 发布日期≥2021年 | 覆盖完整牛熊周期 |
| 全部 | 全部 | 含回溯数据，排名仅供参考 |

## 报告结构

```
1. 数据说明
2. 评分权重表 + 打分通俗说明
3. 10年/5年/3年排名表（总分 总收益 CAGR 月频波动 最大回撤 收益/波动 年度胜率 滚动3年中位数 发布日期）
4. 维度得分明细（折叠块）
5. 四阶段表现小结（2018下跌、2019-2020牛市、2021-2022回调、2024反弹）
6. 指数分类（基于编制方案）
7. 持仓快照
8. 回溯数据可信度
9. ETF可投资性
10. 数据来源
```

## 表格格式约定

- 指数/代码合并为一列：`指数名/代码`
- 不加"市场"列（名称本身可判断）
- 不加"回溯占比"和"前后落差"列（在可信度章节单独展示）
- 排名表含"总收益"列

## 中证指数API要点

### 列表查询

POST `/csindex-home/index-list/query-index-item`
- `hotSpot=["26"]` = 红利/高股息
- `ifTracked="1"` = 有ETF跟踪
- **不要同时加 searchInput 和 indexFilter**，会破坏筛选逻辑

### 编制方案下载

GET `/csindex-home/indexInfo/index-details-data?fileLang=2&indexCode={CODE}`

新版返回结构：`data` 是字典，key为文件分类名。字段名 `filePath` 不是 `fileUrl`。

WAF限流：>13次/分钟会被拦截。OSS直链模式：`https://oss-ch.csindex.com.cn/static/upload/methodology/{code}_Index_Methodology_cn.pdf`

### 跟踪基金

GET `/csindex-home/index-list/queryByIndexCode/{indexCode}`
字段：`fund_code`, `fund_name`, `fund_type`, `aum_yi`, `inception_date`, `fund_manager`

### 持仓

- 前十大：`/csindex-home/index/weight/top10new/{PRICE_CODE}`
- 行业权重：`/csindex-home/index/weight/industry-weight-two-new/{PRICE_CODE}?cicsType=1`
- 行业字段名：`industryWeightList`，行业名 `csiType`，权重 `weightPct`

## 指数分类框架

基于编制方案，按策略逻辑分类：

| 大类 | 核心策略 | 样本空间修饰 |
|------|----------|-------------|
| 经典红利 | 纯股息率筛选排序 | 全市场/板块/央企/国企/港股通等 |
| 红利低波 | 叠加低波动因子 | 全市场/板块/定制等 |
| 红利质量 | 叠加质量因子（ROE/现金流） | 全指/港股通/定制等 |
| 红利成长 | 叠加成长因子（盈利增长） | 沪港深/全市场等 |
| 红利价值 | 叠加价值因子（PB/股息支付率） | 全市场等 |
| 行业主题 | 限定行业+红利筛选 | 消费等 |

## 四阶段小结

用10年区间的annual_data计算。不参与评分，作为独立章节。
- 2018下跌、2019-2020牛市、2021-2022回调、2024反弹
- 每个阶段：中位数、前三、后三
- 多年阶段用复利累乘
