# 红利指数分类（基于官方编制方案）

## 分类框架

红利指数按**策略逻辑**分为六大类。样本空间（板块/主题/市场）是修饰标签，不改变策略本质。

| 大类 | 策略核心 | 典型指数 |
|---|---|---|
| 经典红利 | 股息率筛选+排序，最基础形态 | 中证红利、上证红利、300红利、上国红利、国企红利、央企红利、央企红利50、诚通央企红利、央企股东回报、香港红利、港股通高股息、SHS高股息、港股通央企红利、国新港股通央企红利、智选高股息、中华预期高股息、高息策略 |
| 红利低波 | 分红筛选+低波动因子 | 红利低波、红利低波100、300红利低波、上红低波、东证红利低波、A500红利低波 |
| 红利质量 | 分红筛选+质量因子(ROE/盈利稳定性/现金流) | 红利质量、中证红利质量、港股通高息精选 |
| 红利成长 | 分红筛选+成长因子(盈利增长/股息增长) | SHS红利成长LV、红利潜力 |
| 红利价值 | 分红筛选+价值因子(PB/股息支付率) | 红利价值 |
| 行业主题 | 限定行业内的红利 | 消费红利 |

## 分类方法

1. 从编制方案PDF中提取选样方法的关键描述
2. 判断核心策略逻辑：除分红外还叠加了什么因子
3. 标注样本空间修饰标签（全市场/板块/央企/港股通等）
4. 标注定制指数（与特定机构合作开发）
5. 分类结果独立成模块，不与行情回溯混杂

## 样本空间修饰标签

样本空间是第一层筛选，不改变策略逻辑本质：

- 全市场（默认，如中证红利）
- 板块限定（上证/沪深300/A500等）
- 主题限定（央企/国企/消费等）
- 跨市场（港股通/沪港深/SHS等）

## 数据来源

中证指数官网编制方案下载接口：

```
GET /csindex-home/indexInfo/index-details-data?fileLang=2&indexCode={CODE}
```

若接口返回403，可构造OSS直链下载。需先成功下载一只已知的编制方案，解析其OSS URL模式。
