# ETF 1对1 实盘对比系列

把"从一堆基金里选出真老将，再逐一和基准打擂台"这件事做成流水线。五步顺序执行：定口径 → 立锚 → 打擂台 → 出图 → 校验交付。

**节奏红线**：用户说写才写。一篇交付后停下等指示，严禁连写下一场（第 2 战越权被叫停的教训）。

## 第一步：定口径（严选漏斗）

每一层都是一条能独立复算的硬规则，不用"优秀、龙头"这类形容词当门槛。

- 场内产品必须写明代码前缀（如沪深场内股票 ETF 为 51/56/58/159 开头），并点名剔除了什么：场外联接、QDII 跨境、固收类。
- 逐层给出留存率与剔除率（实例：1,596 → 84 → 12 → 10），正文数字必须和漏斗图完全一致。
- 实盘年限门槛用成立日判定（成立日 ≤ 截止日 − N 年）。晚成立基金宣传的漂亮年化，多半是指数发布前回测拟合，正文要戳穿且不得引用。

## 第二步：立锚（基准篇）

- 从入围池挑规模最大、成立最久、走势最稳的一只做基准锚，定基准分（实例 512890 = 85.0）。
- 基准分要回答"为什么不是 90、不是 80"：每一笔扣分都对应一个可查证的事实（如"2020 牛市只涨 9.46%，扣 7 分"）。
- 标题和结论慎用"最稳、最强"绝对词——后面每场对决都可能翻出反例（景顺回撤更浅，"最稳"就不成立）。

## 第三步：打擂台（对战篇）

每篇固定四节，顺序不换：

1. **编制规则照妖镜**：只讲两只的差异点，不抄编制说明书。
2. **实盘硬核 PK**：同区间归一化净值对比＋逐年战绩表，赢在哪一年、输在哪一年都摆出来。
3. **五维打分卡**：全周期收益 25 ／ 极限风控 25 ／ 持有稳定胜率 20 ／ 编制防坑 15 ／ 运营品质 15。逐项给分给理由，写明"胜负手"。
4. **最终建议**：风格平实克制，严禁模棱两可（标题直接使用《最终建议》等平实表述，严禁使用“决绝、裁决、一锤定音”等AI味或网文大词）。贴身分场写清“什么人适合哪一只”，给出鲜明的人群画像与场景适配。

每篇开头同步刷新一轮【动态天梯榜】：已赛的刷新座次与分数，新晋标 `[NEW]`，未赛的标"待评"。（注：若根据投研分析报告另行撰写面向大众的“商业特稿”时，为保持故事悬念与叙事张力，特稿版本可将天梯榜后置至五维打分之后）。

**分差小于 2 分时必须跑 `composite-score-audit` 做权重敏感性测试**。实例：第 1 战 84.5 vs 85.0，换成防守权重挑战者翻盘、换成进攻权重基准扩大优势——结论就得老实写"0.5 分差带权重偏好属性"，不能写"战胜"。

## 第四步：出图与封面规范

标配四件套，复用 `scripts/generate_duel_charts.py` 与 `scripts/generate_duel_cover.py`：
1. **极简宽屏对决封面（2.18:1）**：深夜蓝底（`#0B1120`），仅体现核心观点与核心数据反差。
2. **严选漏斗卡片图**：全市场至入围正规军。
3. **宽屏五维战力看板（2.18:1）**：左侧双雷达轮廓 + 右侧对比得分条。
4. **双子图实盘走势对比**：上图为同起点分红再投累计净值走势（起点=100），下图为累计超额收益差（百分点）。

### 宽屏封面画图规范（高质感金融杂志风）
- **画幅与布局**：宽屏 2.18:1 比例（12 x 5.5 英寸，导出分辨率 ≥ 3000 x 1375），元素上下结构清晰、整体居中对齐；
- **色彩体系**：深邃买方科技蓝黑背景（`#0B1120`），主标题用高反差冷白（`#F8FAFC`），核心算账金句用暖琥珀黄（`#F59E0B`），对比卡片采用深色卡底（`#131D31`）与细边框（`#1E2E4A`）；
- **极简内容架构（杜绝视觉杂质）**：
  1. 顶部胶囊标签：居中，展示专栏与场次（如 `红利 ETF 5周年实盘大决战 · 第 2 战`）；
  2. 核心命题主标题：大字加粗，直击商业冲突（如 `选股池限死在沪深 300，到底是稳妥还是作茧自缚？`）；
  3. 核心反差副标题：鲜明直白的算账金句（如 `实盘 7 年终局账单：为少挨 1.96% 的回撤，每年少赚 3.58% 的复利！`）；
  4. 三联核心数据卡片：左右均等对称排列（累计总回报、年化CAGR、全周期最大回撤），卡内只展现“基准数值 vs 挑战者数值”及底部彩色胶囊差异标签；
  5. 底部终局结论条：深色圆角框，展示最终定分与两头不靠/替代结论。

### 视觉铁律（硬性红线）：
- **左右留白对称**：用 PIL 测量非背景色像素边界，左右外边距差必须 < 2px（严格居中，不靠目测）；
- **单行单指标**：一个指标占一行，禁止在单元格塞多个指标或堆 `<br>`；文字不压在彩色块上，深红块上绝不放深字；
- **标题不重叠**：suptitle 与子图标题净间距 ≥ 50px；中文字体按 PingFang SC → Hiragino Sans GB → Heiti SC → Noto Sans CJK SC 链降级，防豆腐块。

## 第五步：数据红线与交付校验

来自两轮逐篇校验的硬规则：

- 收益一律用**分红再投净值（reinvested_nav）**复算，不用场内收盘价。与雪球前复权对不上时别慌，查三个根因：成立日 vs 上市日起点不同、首日折价、标的物是净值不是价格；差超 1pp 就在正文加一行脚注说明。
- 成立日与上市日是两个日子，净值序列从成立日起算；份额分拆（如 1:2）要验证折算正确。
- 净值 CSV 的 dividend 列全 0 时，必须确认 reinvested_nav 是逐日复利而来，否则总回报可能算低。
- 最大回撤在复权净值曲线上用 cummax 算全周期；跟踪误差、管理/托管费率查东方财富 F10——基金 API 常返回 None，改用 F10 页面。
- 文中每个数字回源核对：`indices/sources/fund-nav-correct/` 的净值 CSV、`indices/sources/etf-history-price/` 的跟踪差汇总 CSV；截图数据用 (end−start)/start 自洽验证。

交付前跑 `article-output-qa`：表格对齐、图片链接有效且图文同名、天梯榜与打分卡交叉一致。文末严格附带全项目统一的标准黄金模板后缀：


## 命名三层级

- 首次登场：基金公司全称＋产品法定全称（场内简称，代码，专栏简称）。
- 标题／天梯榜：公司简称＋策略特征＋ETF。
- 正文对抗：公司简称＋样本数，短兵相接（如"华泰 50" vs "景顺 100"）。
