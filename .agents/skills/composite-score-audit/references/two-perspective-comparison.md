# 双视角对比结构：稳定性排名 + 进取型排名

用户确认的红利指数统一排名报告组织方式（2026-08 起替代单一"核心前十"结构）。核心思想：**一个榜单无法同时回答"长期拿得住"和"现在多赚点"两个问题，拆成两个视角，各自带一套漏斗**。

## 双周期定位

- 10年周期 → 视角一·稳定性排名：回答"长期行不行"
- 3年周期 → 视角二·进取型排名：回答"现在还行不行"
- 5年周期因与两者重叠度过高（与10年、3年各重叠3年以上）不再单独列示，数据仍存档

## 视角一：稳定性排名（10年为主）

三轮漏斗，逐步收紧：

1. **第一轮·成立时间**：回溯占比≤50% 且 实盘≥5年（回溯占比 = (发布日−10年窗口起点).days / 窗口跨度；实盘年数 = (数据截止日−发布日)/365.25）。排除 2022 年后发布的新指数——回测数据不参与稳定榜。
2. **第二轮·规模+跟踪误差**：ETF≥2亿、场外指数基金≥5亿；LOF/指数增强不优先。跟踪误差只列示参考不参与过滤（港股系口径见 fund-tracking-analysis 陷阱 8b）。
3. **第三轮·逐年表现检验**（用户选定，从"标⚠标注"升级为"**移出主榜**"）：9个完整年度中 **负收益年≥3 或 存在连续3年后10名 → 移出主榜**。这正是"忍耐三年爆发两年"（香港红利 2019-2021 连续后10）的量化版本。**术语必须叫"逐年表现检验"或"'每年都不差'检验"，不能叫"路径检验"**——用户明确说看不懂"路径检验"这个内部术语（2026-08 纠正）。

排名键：10年总分，视角内相对排名（≠30只全量排名，报告需注明两套排名号不直接对应）。

**主榜精简**：用户嫌16只太多，第三轮改硬过滤后主榜只留逐年表现合格的指数（30只样本实际为8只）。**被筛掉的名单在筛选规则里一句话列出（指数+落榜原因），不单列"备选池"表格**——用户明确要求"备选池去掉，在第三轮筛选中体现"。

## 视角二：双周期验证榜（最终形态，2026-08 拍板）

演进记录（用户逐步收紧）：
1. 初版：只做规模+跟踪误差过滤，不限成立时间——新指数以回测数据参与，排名旁标注回溯占比，实盘数据标"实盘"
2. 加分组+各自基准（市场beta剥离），入榜条件=本组超额为正
3. **最终版（用户拍板）：仅规模过滤，不分市场、不设基准、不做逐年检验、不做主题归并，按均排=（10年排名+3年排名）÷2 取前十**。用户原话："简化视角二，只按照规模过滤，然后取3年、10年回溯的前十榜单"。

保留的硬原则（无论哪一版都不变）：
- **新指数就是这个视角的舞台，回测占比高的照常入榜，绝不降级**。把回测指数降为"观察区/备选池"等于否定视角二存在的意义，用户明确否决过该设计（2026-08）。
- 均排用30只全量口径排名（见附录全量表）；若用视角内相对排名需注明两套排名号不直接对应。
- 排名表必须含**总收益列**（用户要求：稳定性榜加10年总收益，双周期榜加3年总收益，附录D两表也加）——总收益=区间累计收益（如207.92%），与CAGR并列展示，不只有年化。
- 拆组方案（境内组基准=红利低波7.65%、港股组基准=港股通高股息17.75%、超额为正才入榜、基准行进榜作及格线锚点）是**做过且有效的备选方案**：统一基准下港股系占前十大半是2024-2025行情beta，拆组后真正跑赢同市场的只剩1-2只（实测：香港红利+5.72pp、港股通央企红利+0.61pp；国新港股通央企红利统一排名前五，拆组后-3.02pp 现出原形）。若用户后续要求按市场区分，直接复用此方案。
- 跨市场指数归属需显式声明：SHS红利成长LV 是沪港深（三地选股），按收益特征归入境内组，避免被港股基准误杀。
- **交集口径**：视角一主榜 ∩ 视角二前十（简化版无基准行，交集=两榜都上榜者，实测3只：SHS红利成长LV、东证红利低波、港股通央企红利）。

## 主题归并（榜内同质化标的过多时）

同主题标的合并为一行，代表在前、同类在后，榜单按主题组织而非逐只罗列（例：央国企红利 上国+2.78 / 诚通+2.33 / 央企红利+1.43 合并一行，代表取实盘且超额最高者）。**只归并不剔除**——新指数、回测指数全部保留在榜，数据性质列标注即可。

## 环境归因陷阱

进取榜某类标的扎堆时不要直接归因行情——**基准本身可能已含同风格暴露**。30只红利横评中境内进取榜央国企扎堆，初判"中特估行情"；实测红利低波基准本身央国企含量极高（金融53%+），行情beta已被基准吸收：上国红利 2023-2025 相对基准累计超额 -4.28pp（跑输！），中证红利质量超额全部来自2019-2020质量牛市。下结论前先算"近期 vs 前期 相对基准的累计超额"验证直觉。

## 双视角交集

两个视角都入选的指数 = "长期拿得住+近期有超额"的均衡之选，单列一小节。**交集口径 = 视角一主榜 ∩ 视角二榜单（含基准行）**——基准行在视角二"在榜"（作为及格线），因此稳定榜前三若恰好是基准（实测红利低波），以"境内基准"身份入选交集，逻辑自洽（"为什么选它当基准"由此得到回答）；实测4只：SHS红利成长LV、东证红利低波、红利低波（基准身份）、港股通央企红利。港股基准港股通高股息不在交集（稳定榜第三轮已出局）。交集之外注明出局原因（稳定榜被筛/进取榜跑输基准）。交集外的取舍写成"只想要A→看视角一前N；只想要B→看视角二前N；两者都要→交集"的目标导航。

## 分类视角的两种形态（用户按需切换）

- **形态A·落位对比表**：行=六大类，列=视角一最佳/视角二最佳/说明。适合回答"各类在两视角下表现如何"。
- **形态B·按类推荐表**（本会话最终采用）：行=分类（可多行，如经典红利推荐2只），列=推荐指数/入选情况/说明。每类给出1-2只推荐指数并标注入选情况（双视角入选/视角一#N/视角二#N/不推荐）。适合回答"我该买哪类、每类买谁"。
- 分类归属有争议时查编制方案定夺：**"红利质量"类判定标准**——编制方案选样含质量因子（ROA/Growth/Accrual/OPCFD）即属质量类，即使名字带"高息"（如港股通高息精选=股息率初筛70%+质量因子精选前30，名字只说初筛没说精选，实测属红利质量类）；不要被指数简称误导。
- 单类别只有1只指数（如红利价值类）时如实写"唯一选手"，不要为凑推荐硬造第二名。

## 评分口径（新，2026-08 确认）

| 维度 | 权重 | 核心指标 |
|---|---:|---|
| 收益能力 | 40% | CAGR |
| 风险控制 | 30% | 最大回撤50% + 月频波动50% |
| 收益波动比 | 15% | CAGR / 月频波动 |
| 稳定性 | 15% | 年度胜率60% + 滚动3年中位数40% |

关键约定：
- **"风险收益效率"更名"收益波动比"**——用户明确：不要用"效率"这类抽象词，直接用指标名。注释里写"思路同夏普比率（Sharpe Ratio）"
- 风险维度从"仅最大回撤"改为"回撤50%+波动50%"：回撤管单次最差极端，波动管日常颠簸，互补；且明确这是"偏好低波动持有体验"的框架取向，在方法说明里写清楚（低波类占结构性便宜）
- 收益波动比分子与收益维度同源，属"有意的双计"：对红利这类防御型策略，"涨得稳"与"涨得多"同等值得奖励——在方法说明里主动交代，不遮掩
- 排名百分位制只反映相对位置不反映差距大小：相邻1名固定差约3.3分

## 权重敏感性验证（本 skill 第4步的实战案例）

换6组权重（基准40/30/15/15、等权、收益加重、风险加重、稳定加重、收益极重60）实测：
- 10年/5年冠军在所有权重下稳健（东证红利低波、香港红利）
- **3年冠军对权重敏感**：收益权重升到50-60%时 SHS红利成长LV 被香港红利反超 → 结论表述弱化"3年第一"，写"3年前二互有胜负"

## 实施要点

- 先用独立脚本重算评分（从全部指标.json 提取 CAGR/回撤/月频波动/胜率/滚动3年中位数，排名百分位转分，并列名次取平均），**验证脚本输出与原报告已知分数一致后再写报告**（如东证10y 收益86.7/回撤分96.7）
- 回溯占比公式易写反：= (发布日−窗口起点).days / 窗口跨度，发布日在窗口起点之前为0
- 年度胜率分母=完整自然年度数：10年区间(2016-08-08起)完整年度是2017-2025共9个；3年区间(2023-08-08起)完整年度是2024-2025共2个。首尾不完整的零头年份不计入；数据起点晚的指数（如中华预期高股息2019年起）分母更小
- 跟踪误差口径：境内用分红再投净值复算 vs 指数全收益（年化日差×√252）；**港股系TE天然偏高（7-13%）是汇率+折溢价+红利税，不与境内同阈值比较，单列说明**；港元计价产品（如3070HK）对比人民币指数累计差可达-72pp，是币种错配，直接不可比
- **港股TE虚高三查法**（2026-08 验证3070HK TE=9.77%案例）：①查净值币种——港交所上市ETF为港元计价（Yahoo前复权），对比人民币指数必含汇率；②查日收益相关性——健康跟踪应 lag0 相关≥0.97（513530=0.971），3070HK 仅0.861，明显偏低即币种/数据源噪音；③按年度分解日收益差std——若早期年份（2015-2020）0.7-0.8%/日、近年（2024-2026）收敛到0.28-0.40%/日，且diff均值≈0（无系统性偏移），说明是早期复权数据质量问题而非真实费率。3070HK 真实TE估3-5%，9.77%被币种错配+早期数据质量放大约一倍。报告注记写法："港元计价、与人民币指数对比含币种错配，TE仅供参考，不可与境内指数同口径比较"。
- 报告正文按"视角一漏斗+榜单 → 视角二漏斗+双榜 → 交集 → 分类视角（两视角落位对比表）→ 四阶段（保留原文）→ 关键发现"组织；附录保留全量排名（30只，注明与视角内排名不同）、分类名单、回溯可信度、持仓、ETF可投资性、数据来源
- 3年期胜率几乎全员2/2，区分度极低（死重）——3年周期的稳定性子项实际只剩滚动3年中位数在起作用，可在方法说明中注明
- Markdown 表格分隔行段数必须与表头一致（11列表头配12段分隔行会渲染错乱，用户抓过两次）

- `全部指标.json` — 每样本长/中/短周期的CAGR、波动、回撤、胜率、滚动中位数
