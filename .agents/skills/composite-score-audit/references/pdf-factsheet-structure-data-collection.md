# PDF 指数单张 → 结构数据采集工作流

用于从官方指数单张（Factsheet）PDF 中提取行业权重分布和前十大权重股数据，作为结构分散维度的打分依据。

## 工具链

- `pymupdf`（`pip install pymupdf`，导入名 `fitz`）—— 将 PDF 每页渲染为 PNG 图片
- `vision_analyze` —— 逐张图片提取行业权重百分比和十大成分股明细

## 标准工作流

1. **检查本地已有单张**：`sources/index-factsheets/` 目录。中证系单张通常 2 页，标普系 6–7 页，深证红利（国证）需单独下载。
2. **PDF → 图片**：

```python
import fitz
doc = fitz.open("xxx.pdf")
for i in range(len(doc)):
    page = doc.load_page(i)
    pix = page.get_pixmap(dpi=150)
    pix.save(f"xxx_p{i+1}.png")
```

3. **Vision 提取**：对每张图片调用 `vision_analyze`，提问句式：
   - "提取行业权重分布：每个行业名称及百分比"
   - "提取十大权重股：名称、代码、权重%、所属行业、上市交易所"
4. **交叉校验**：vision 数值与文本提取的关键词（如"金融 53.6%"）对比确认准确性。

## 发行商披露粒度差异

| 发行商 | 行业权重分布 | 十大成分股明细 | 证据完整度 |
|---|---|---|---|
| 中证系（2 页单张） | 饼图，精确到 0.1% | 名称+代码+权重%+行业+交易所 | A 级（完整） |
| 标普红利机会（7 页） | GICS 饼图，精确到 0.1% | 只有名称+代码+行业，**无单只权重%**；有最大权重 1.7% 和前十大合计 13.7% | B 级（行业有，个股权重无） |
| 标普大盘低波 50（6 页） | **无行业权重分布图** | 十大有名称+代码+行业，**无单只权重%**；有最大权重 4.2% 和前十大合计 30.8% | C 级（行业和个股权重都不完整） |
| 深证红利（国证） | 需单独下载官网单张，路径不同 | 同左 | 视实际披露定级 |

## 证据等级定义

| 等级 | 含义 | 适用 |
|---|---|---|
| A | 同时有完整行业权重分布（精确到 0.1%）+ 十大权重股明细（含单只权重%） | 中证系 7 只 |
| B | 有行业权重分布，但十大成分股只有名称/代码/行业、无单只权重 | 标普红利机会等 |
| C | 缺少行业权重分布，十大成分股也无单只权重 | 标普大盘低波 50 等 |

## 基于采集数据重新打分要点

- **个股集中**：看前十大合计权重 / 最大单股权重。有精确值（中证系）用精确值，只有合计（标普系）用合计÷10 估算。
- **行业集中**：看最大行业占比。有精确值用精确值，无行业分布数据则按规则上限推断（但不得写成"当前实测"）。
- **规则上限**：看规则里的个股和行业上限。有硬订上限的比没有的得分高，但"有上限"≠"当前实测就分散"。

## 中证指数单张 → 发布日期提取

中证指数单张第1页的"基础参数"表格包含"发布日期"和"基日"两行。用 vision 提取时注意分辨：

- **发布日期**（Launch Date）：指数正式发布、开始实盘计算的日期。这是用来做"发布后历史"打分的依据。
- **基日**（Base Date）：指数回溯序列的起始日，通常早于发布日期数年。不是发布日期。

提取时确保读到的不是"基日"。标普系单张的发布日期在编制方案 Base Dates 表格中，不在单张概览页（单张概览页只写"历史起始日"）。

## 获取发布日期的工作流

1. **中证系**：单张第1页基础参数表 → "发布日期"行
2. **标普系**：编制方案（Methodology PDF）→ Base Dates and History Availability 表格 → Launch Date 列
3. **国证系（深证红利等）**：国证指数官网（cnindex.com.cn）→ 指数详情页 → "指数编制"区块 → "发布日期"行
4. **标普红利机会特殊说明**：单张明确写"无法提供最早发布日期"，实际发布日期需从编制方案中的 Base Dates 表获取
