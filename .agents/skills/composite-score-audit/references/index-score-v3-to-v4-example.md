# 真实案例：十只红利指数评分 V3→V4

这是 `composite-score-audit` 方法的一次真实应用。源材料：用户自建的 `dividend-index-analysis` skill（受保护，无法直接 patch，需 `hermes curator adopt`）与十只红利指数横评文章。

## 背景

一篇十只红利指数横评（对比区间 2016-06-30 至 2026-07-31，人民币全收益）用了五维加权评分，给出"中证红利低波动 84 分清晰第一"的结论。要求以机构投资经理口径审查评分是否客观、独立。

## 审查发现的缺陷（对应四步审计）

1. **零方差死重**：规则稳健性里"规则透明度/2"十只指数全拿 2 分、"加权与调仓/3"九只拿 3 分。这 5 分不产生区分度，纯占分母，给规则弱的指数发"免费分"。
2. **重复计分**："分红持续性/12"与"高股息陷阱防御/7"都看支付率、盈利、周期顶部，边界模糊；中证红利质量在两项同时拿满（12+7），同一份排雷实力被计两次。
3. **封顶档位不细分**：证据可信度"发布后历史/10"给 2005 年发布的上证红利和近年发布的指数都打 10，抹掉真实运行时长。
4. **未做权重敏感性测试**（关键）：84 分的第一恰好是"结构只占 10%"这个选择造出来的。

## 重构后（V4）结果

- 规则稳健性收敛为三项：分红持续性/14 + 陷阱防御/9 + 策略一致性(含加权调仓与透明度)/7。
- 发布后历史细分档位：上证红利2005/中证红利2008=10；红利低波2013/标普红利机会≈2013=9；红利低波100 2017=8；沪港深与标普大盘低波50 2019=7；中证红利质量2020=6；深证红利(代理)=7；全指红利质量2024=2。
- 敏感性测试（关键证据）——冠军会翻盘：

| 权重方案 | 第一 | 第二 |
|---|---|---|
| 主权重 30/25/15/10/20 | 红利低波动 81 | 全指红利质量 79 |
| 结构上调 30/25/15/15/15 | 全指红利质量 80 | 红利低波动 78.2 |
| 结构大幅上调 30/25/15/20/10 | 全指红利质量 81 | 红利低波动 75.5 |
| 证据上调 30/25/15/5/25 | 红利低波动 83.8 | 上证红利 80.5 |

**结论**：头部六只挤在 77–81 区间，谁当第一取决于你在乎结构分散还是真实历史，没有一只在所有合理权重下都第一。因此 V4 把"红利低波清晰第一(84)"改为"头部集群、按梯队组织"，并明确报告冠军不稳定，而非挑权重去"证明"它。

## 程序复核做法

写了 Python 脚本做三类一致性校验，全部通过：
1. CSV 每个子项之和 = 维度小计 = 总分；
2. 正文主评分表每行维度分相加 = 表格总分；
3. 敏感性测试表格里的每个第一/第二数字与脚本输出完全一致。

校验用脚本逐项加总，不靠肉眼。派生物（评分 CSV、脚本）文件名带版本号（如 综合评分_十指数_V4.csv）与文章对应，避免旧文引用新版评分。

## 延伸案例：30只红利指数四维评分的口径修订

同一用户后来对30只红利指数的"收益40% + 风险30% + 收益波动比15% + 稳定性15%"四维排名做了方法审计与修订，可复用的经验：

- **审计动作**：用附录明细里的分维度得分提取出数据，跑6组权重扰动（等权、收益加重、风险加重、稳定加重、收益极重）。结果：10y冠军（东证红利低波）与5y冠军（香港红利）在所有权重下不翻盘，且领先来自三个维度（收益+5.4/稳定+4.6/效率+2.0/风险-1.0），可称"稳健第一"；3y冠军收益权重升到50%即被反超，属权重产物，正文表述应弱化为"前二互有胜负"。
- **口径修订**（用户确认的方案）：风险控制30% = 最大回撤50% + 月频波动50%；"风险收益效率"更名"收益波动比"（更直白，读者看名字就知道公式）；明示框架价值取向为"偏好低波动的持有体验"。
- **周期精简**：三周期（10y/5y/3y）砍成两周期（10y+3y），5年重叠最多、信息增量最小。
- **重算验证**：新口径脚本先复现旧口径已知分项（东证10y收益86.7/回撤分96.7/A500回撤分100），完全一致后才切换；结果存 `新口径评分_10y3y.json`。首次脚本曾把回撤排序方向写反，靠交叉验证抓住。
- **报告内过渡**：规则表改新口径、排名未重算时，加注"本报告排名仍按旧口径计算，新口径为下一轮重算方向，预期利好低波类、利空高波动港股系"。
