## 数据来源

同花顺基金移动端页面的公开接口：

`https://fund.10jqka.com.cn/bff-server/v1/fund/position_rank?fund_code={基金代码}`

每个ETF目录保留：

- `{代码}_position_rank_raw.json`：接口原始响应；
- `{代码}_季度前十大持仓.csv`：每期前十大证券、排名、行业和占基金净值比例；
- `{代码}_前十大持仓行业构成.csv`：前十大内部行业占比，以及对应基金净值比例；
- `{代码}_季度前十大持仓变化.csv`：相邻报告期连续留在、新进入、退出前十名的证券；
- `{代码}_2026Q2前十大盈利分红_2025.csv`：最新前十大对应的2025年盈利、ROE、EPS、每股分红和支付率；
- 根目录 `ETF历史持仓覆盖汇总.csv`：四只ETF的覆盖与完整性摘要。

前十大财务数据由 `collect_etf_top10_fundamentals.py` 采集。盈利指标来自东方财富 `RPT_F10_FINANCE_MAINFINADATA`，分红来自 `RPT_SHAREBONUS_DET`；每股税前分红按同一报告年度的中期及年末方案合计，支付率按“每股分红÷基本EPS”估算。

## 重要限制

1. 数据是ETF定期报告披露的前十大持仓，不是指数公司的完整历史成分与权重。
2. ETF持仓可能受现金仓位、申赎、停牌、跟踪误差和披露时点影响，只能作为指数结构代理。
3. `占基金净值比例(%)` 的分母是基金净值；`前十大中占比(%)` 是前十大内部归一化占比，不能当作全基金行业权重。
4. 同花顺行业为宽口径分类，与中证、标普行业分类不一致，未做静默映射。
5. “新进入/退出”只表示进入或离开前十名，不能解释为买入、卖出或清仓。
6. 这些数据适合观察主要权重股和风格重心变化，不足以计算完整行业集中度或精确收益归因。

## 复现与验证

采集单只ETF：

```bash
python3 collect_etf_position_history.py 515450 --output-dir ./515450
```

使用已保存原始响应离线复算：

```bash
python3 collect_etf_position_history.py 515450 \
  --input-json ./515450/515450_position_rank_raw.json \
  --output-dir /tmp/515450-verify
```

四只ETF均已离线复算验证：每期恰有10只证券；持仓权重合计与接口 `share_per` 一致；前十大行业内部占比合计为100%；复算CSV与采集结果逐字节一致。

采集最新前十大盈利与分红：

```bash
python3 collect_etf_top10_fundamentals.py 515450 515180 515100
```

财务表只覆盖最新前十大，不代表ETF全部成分股；支付率也不能替代自由现金流、资本开支和中周期盈利检查。
