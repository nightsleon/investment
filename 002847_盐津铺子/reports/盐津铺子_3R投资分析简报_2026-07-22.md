# 盐津铺子（002847）3R投资分析简报

> 数据截止：行情截至2026-07-17收盘；财务截至2026Q1；年度数据截至2025年报；重大公告截至2026-07-20。  
> 3R总分：**68.5/100**  
> 当前评级：**观察；估值处于低位，但中性赔率不厚，继续等待收入与自由现金流确认**  
> 一句话结论：**盐津铺子的制造组织与经营再造能力已被业绩验证，魔芋仍推动利润快速增长；但竞争激烈、净定价权一般、重资本扩产几乎吞噬自由现金流，低估值尚未转化为足够厚的中性赔率。**

## 一、公司概况：这家公司靠什么赚钱？

| 项目 | 内容 |
|---|---|
| 主营业务 | 魔芋、蛋制品、海味、烘焙薯类、果干果冻和豆制品等休闲食品 |
| 赚钱方式 | 自主研发制造、原料和供应链布局，通过经销、商超、量贩、会员店与电商销售 |
| 核心产品 | “大魔王”魔芋、“蛋皇”鹌鹑蛋、“31°鲜”等品类品牌 |
| 行业位置 | A股多品类自主制造零食龙头之一；2025年魔芋收入占比30.15% |
| 实际控制人 | 张学武、张学文兄弟；盐津控股为控股股东 |
| 核心管理层 | 张学武兼任董事长和总经理 |
| 报告基准日价格 | 48.60元，总市值131.31亿元 |

盐津铺子的核心能力不是消费者非它不可，而是把新品快速做成稳定、低成本的规模化产品，再铺进全国渠道。自主制造和供应链效率是真优势；消费者容易换品牌、量贩渠道议价能力强，则决定其护城河和定价权弱于强品牌消费品。

## 六、最终行动

### 现在怎么办？
- 维持观察池或小仓跟踪；三门槛虽通过，但68.5分仅属“观察”，不因低PE直接重仓。

### 什么情况下提高关注？
- 收入恢复双位数增长，魔芋之外至少一个品类接棒；
- 资本开支下降，连续两个报告期FCF改善；
- 资产周转率、产能利用率改善，现金头寸转正。

### 什么情况下说明判断错了？
- 魔芋收入或毛利率明显转负且无第二品类接棒；
- 收入低增长转为利润下滑，应收和库存同时恶化；
- 扩产、借款、回购和分红继续挤压现金，FCF长期偏弱。
